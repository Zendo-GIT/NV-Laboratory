# NVMFG Unlock40

**Экспериментальный NVIDIA Multi Frame Generation для GeForce RTX 40 с центральным контроллером и возможностью выбора для каждой игры.**

[Загрузите 0.2.3 и статус](../docs/downloads.md#nvmfg-unlock40) · [Установка](#installation) · [вверх по течению](#upstream-and-modifications) · [Лицензии](LICENSES/README.md)

<a id="overview-and-purpose"></a>
## Обзор и цель

NVMFG Unlock40 – это приложение, независимо разработанное компанией 禅堂 Zendo (RevoluSound Team). Он сочетает в себе контроллер Windows, собственный уровень, помощник профиля и управление игрой/Streamline SDK. Он предназначен для игр, которые уже интегрируют NVIDIA, DLSS Frame Generation и совместимые среды выполнения NVIDIA.

Для сравнения и уточнения работы была проведена консультация с [RTX40MFG-Unlock](https://github.com/dashdogy/RTX40MFG-Unlock). Текущий собственный слой содержит общие и адаптированные компоненты, указанные ниже по отдельности. Эта ссылка не делает все приложение NVMFG fork этого проекта.

Он существует для централизованной координации экспериментального поведения MFG, запоминания выбора, специфичного для игры, а также для обеспечения видимости обновлений и резервных копий во время выполнения. Он не добавляет DLSS Frame Generation в каждую игру и не преобразует произвольную реализацию FSR.

Текущий пакет – **0.2.3**. Он добавляет постоянную библиотеку игр, информацию об активности и возможностях, локальную диагностику и исправленное поведение выбора/прогресса. [Загрузки](../docs/downloads.md#nvmfg-unlock40) идентифицирует точные файлы и хэши.

<a id="features"></a>
## Особенности

- Централизованное управление включением/выключением и дополнительный запуск лотка Windows.
- Выбор для каждой игры между Dynamic, MFG, настройками игры и поддерживаемыми фиксированными множителями.
- Отдельный запоминаемый выбор для наблюдаемых состояний включения/выключения V-Sync.
- Dynamic использует режим NVIDIA; он приостанавливается, когда V-Sync выключен, с отдельным внутриигровым/фиксированным выбором.
- Руководство по игровому меню и постоянные исключения; игры без DLSS FG сохраняют контроль.
- Обнаружение игр, выбор родительской папки, поиск, группировка и удаление без удаления файлов игры.
- Streamline SDK загрузка/импорт, проверенный локальный кэш, явный выбор, резервное копирование и восстановление для каждой игры.
- Встроенная проверка поставщика, диагностика для каждого сеанса, глобальный журнал профилей и восстановление с учетом конфликтов.
- 34 языка интерфейса и четыре темы.

Если отключить FG в игре, он отключится. Фиксированный выбор от 2x до 6x зависит от игры/меню/времени выполнения; они не гарантируют, что каждая комбинация будет работать. Контроллер учитывает V-Sync и не устанавливает V-Sync или VRR для пользователя.

<a id="installation"></a>
## Установка

1. Прочтите [статус кандидата и примечание о лицензии](../docs/downloads.md#nvmfg-unlock40).
2. Загрузите `NVMFGUnlock40-0.2.3-Setup-x64.exe` или `NVMFGUnlock40-0.2.3-Portable-x64.zip`, когда его версия станет доступна.
3. Проверьте SHA-256 и сохраните сопроводительные примечания. Установите .NET Framework 4.8, если Windows еще не предоставляет его.
4. Запустите программу установки или извлеките **весь** портативный ZIP-архив в доступную для записи локальную папку.
5. Запустите `NVMFGUnlock40.exe`; сохраните `agent`, `driver`, `engine` и `Licenses` в прилагаемой компоновке.

Папка с именем `driver` содержит помощники пользовательского пространства, а не драйвер ядра. Не копируйте только основной EXE-файл и не заменяйте хеш-код поставщика для обеспечения совместимости. Текущие EXE-файлы не подписаны.

<a id="usage"></a>
## Использование

1. Начните с отключенного контроллера. Добавьте игру или родительскую папку и выберите актуальные установки.
2. Просмотрите настройки MFG каждой игры. Ответьте, что предлагает его меню; ответ сохраняется для каждой игры.
3. Выберите Dynamic или глобальные внутриигровые настройки, а затем при необходимости настройте подходящие параметры для каждой игры.
4. Включайте контроллер только тогда, когда вы собираетесь его использовать. Он может временно изменить шесть глобальных настроек профиля NVIDIA с помощью журнала восстановления.
5. Запустите подходящую игру и включите собственный DLSS Frame Generation. Выполните любой запрос на выбор отключения V-Sync.
6. Используйте исключения для игр, которыми вы не хотите управлять. Удаление игры записывает исключение и сохраняет ее файлы/резервные копии.
7. По завершении используйте полный процесс выхода/отключения и восстановления приложения.

Закрытие главного окна может оставить контроллер в трее. DLL, уже загруженная в игру, остается там до выхода из игры; отключение контроллера не является гарантией выгрузки. Закройте затронутые игры перед обслуживанием или обновлением.

**Streamline SDKs:** на странице NVIDIA SDK загрузите официальную версию или импортируйте совместимую локальную версию SDK. Импорт сохраняет проверенную копию; **Use this version** выбирает его, а **Uninstall** удаляет эту кэшированную копию. Отсутствующие библиотеки DLL Streamline можно дополнить из официальной библиотеки NVIDIA SDK с указанием источника. При этом модель NGX не загружается и не заменяется. Закройте игру, выберите необходимое обновление игры и сохраните исходную резервную копию. Чтобы вернуть файлы игры, используйте восстановление из резервной копии, а не кнопку Uninstall кеша.

<a id="library-diagnostics-and-updates"></a>
## Библиотека, диагностика и обновления

**Постоянная библиотека**: перед запуском сканирования выберите несколько папок с игрой, включая разные диски. Прогресс виден и возможна отмена. После первого сканирования локальный кэш восстанавливает библиотеку при запуске, не проходя каждую папку с игрой. Обновите, чтобы найти изменения или добавить другую папку. Операции обслуживания по-прежнему проверяют затронутые файлы; мониторинг резервного копирования остается активным. Кэш хранится по адресу `%LOCALAPPDATA%\RtxMfg\library-cache.json`.

**Выбор:** Ctrl+A выбирает все, а Ctrl+D очищает активную вкладку «Игры» или «Резервные копии». Ни одна игра не выбирается автоматически. Обновления и обновления активности больше не создают призрачные выборки или противоречивые подсчеты.

**Активность и совместимость:** информация MFG для каждой игры поступает из наблюдений NGX без нового наложения. Это не физический подсчет отображаемых кадров. Поддержка Dynamic-with-V-Sync обеспечивается возможностями среды выполнения; неизвестная возможность не выводится из номера версии. Приложение не изменяет ни V-Sync, ни VRR. Если V-Sync выключен, Dynamic остается приостановленным; фиксированные или управляемые игрой варианты являются отдельными.

**Следующий запуск:** временное исключение пропускает установку исправлений при следующем запуске игры и восстанавливает нормальное управление после выхода из игры. Он не может удалить DLL, уже загруженную в игру: закройте и перезапустите эту игру. Wallpaper Engine распознается как настольное приложение; это исправление сохраняет защиту для фактически игнорируемых игр.

**Настройки и поддержка:** для импорта/экспорта настроек требуется повторное связывание папок игры вручную. Локальная диагностика в разделе «О программе» фильтрует личную информацию и сообщает о доступных кодах ошибок NVAPI или категориях конфликтов. Просмотрите его, прежде чем поделиться; ничего не загружается автоматически.

**Обновления приложений**: при дополнительной проверке отображаются примечания к выпуску и предлагается официальная установка. Явная загрузка проверяется по размеру GitHub и метаданным SHA-256; вы инициируете установку самостоятельно. Версия 0.2.3 также удаляет сообщения о завершении выполнения, сохраняя при этом значимые ошибки и результаты. Эти дополнения включают изменения по сравнению с общедоступной версией 0.1.1.

<a id="update-and-uninstall"></a>
## Обновить и удалить

Закрыть затронутые игры. Отключите/выйдите из NVMFG и разрешите все ожидающие восстановления настроек NVIDIA перед обновлением. Установите следующую установку с существующим идентификатором или извлеките новую портативную версию в новую папку; сохранять состояние/резервные копии.

Перед удалением восстановите резервные копии нужной игры SDK и настройки NVIDIA через приложение, затем закройте игры и выйдите из контроллера. Используйте Windows **Installed apps** для установки или удалите закрытую переносную папку после сохранения необходимых файлов. Не удаляйте вручную активный журнал восстановления, чтобы разблокировать программу установки.

Локальные резервные копии во время выполнения игры используют `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`. Настройки MFG/данные SDK используют `%LOCALAPPDATA%\RtxMfg`; вывод сеанса находится под `Sessions` рядом с приложением. Эти файлы могут содержать пути к игре. Не публикуйте их неотредактированными.

<a id="known-limitations"></a>
## Известные ограничения

- Сообщенная блокировка активации/восстановления/удаления 0.1.1 остается невоспроизведенной, и ее причина неизвестна. Этот выпуск не претендует на исправление этой проблемы. После сбоя сохраните журнал восстановления и проверьте локальную диагностику; не принудительно удаляйте данные для восстановления.
- Экспериментальные собственные патчи могут вызывать сбои или визуальные артефакты; в истории разработки зафиксирован неразрешенный сбой Bodycam.
- Контролируемые тесты рендеринга не являются сертификацией для каждой игры, драйвера или античита.
- Сгенерированные кадры не создают новых входных выборок; Этот концентратор не обещает никаких измеренных задержек или прироста производительности.
- Несколько инструментов/наложений создания кадров могут конфликтовать. Приложение сообщает о наблюдаемых модулях, не доказывая каждый сценарий сосуществования.
- Манифест совместимости – это средство обнаружения, а не список полностью протестированных игр.
- Полные условия NVIDIA, SDK и неразрешенные технические ограничения остаются документированными в [происхождение](../docs/provenance.md).

<a id="faq"></a>
## Часто задаваемые вопросы

**Включает ли он библиотеки DLL или модели NVIDIA?** Драйвер, поставщик/модель NGX или среда выполнения Streamline не включены. Явные загрузки SDK происходят с NVIDIA.

**Работает ли Dynamic при выключенном V-Sync?** В этом состоянии он приостановлен. Выберите внутриигровую настройку или подходящий фиксированный множитель для отдельного состояния этой игры.

**Это пакет ReShade/OptiScaler/FSR?** Нет. Они не компилируются и не поставляются как часть этого производственного пакета.

**Являются ли измененные исходные коды общедоступными?** Нет. Предоставляются скомпилированные пакеты и необходимые кредиты/лицензии. Это не удаляет права или ограничения третьих лиц.

Руководство по происхождению отделяет эту работу от общих компонентов; сравнение файлов само по себе не позволяет установить, когда кому-либо из авторов пришла в голову эта идея.
