<a id="nvrasterpulse"></a>
# NVRasterPulse

**Ограничения FPS для каждого приложения через RivaTuner Statistics Server.**

> **Сначала установите RTSS.** Для NVRasterPulse требуется [RivaTuner Statistics Server (RTSS), скачан с Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/). RTSS должен быть запущен для обеспечения соблюдения ограничений. Установщик RTSS, DLL-перехватчик или SDK не входят в комплект.

[Загрузите 0.1 и статус](../docs/downloads.md#nvrasterpulse) · [Установка](#installation) · [Как работают лимиты](#usage) · [Лицензия](../../../../NVRasterPulse/LICENSE)

<a id="overview-and-purpose"></a>
## Обзор и цель

NVRasterPulse – это компактный интерфейс Windows для управления ограничениями кадров RTSS по имени исполняемого файла. RTSS выполняет ограничение. NVRasterPulse управляет соответствующими значениями профиля, запросами резервного копирования и перезагрузки с доступом к лотку и постоянным выбором.

Он существует для того, чтобы упростить редактирование точных ограничений для каждой игры без замены всего профиля RTSS или нарушения его настроек наложения. Текущий кандидат **0.1** – это сборка от 9 сентября 2026 г. с обязательной проверкой установки RTSS.

<a id="features"></a>
## Особенности

- Выберите работающее приложение или добавьте его исполняемый файл вручную.
- Сохраните ограничения FPS от 1 до 1000 с точностью до трех знаков после запятой.
- Точная рациональная кодировка введенных значений: 59.94 становится 2997/50.
- Конфигурация Front Edge Sync (`SyncLimiter=1`) с активным ожиданием (`PassiveWait=0`).
- Обновления профилей для каждого исполняемого файла, автоматическое резервное копирование и атомарная запись.
- Удаление переопределения ограничителей при сохранении остального содержимого профиля.
- Обнаружение установки RTSS, ручной выбор пути и явный запуск/перезагрузка.
- Управление одним экземпляром лотка, опциональный установленный запуск, 34 языка и четыре темы.
- Отдельные действия обычного выхода и **Quit + RTSS**.

<a id="compatibility"></a>
## Совместимость

| Требование | Подробности |
| --- | --- |
| Система | Windows 10/11 x64 |
| Время выполнения | [.NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48), при необходимости устанавливается отдельно |
| Необходимое программное обеспечение | RTSS с `RTSS.exe`, соответствующим каталогом `Profiles` и поддержкой совместимого профиля/перезагрузки. |
| GPU | Совместимость с RTSS определяет ограничитель; этот менеджер профилей не требует определенного поколения RTX |
| Разрешения | Текущее приложение запрашивает доступ администратора; выбранная папка профиля RTSS должна быть доступна |
| Игры | Зависит от поддержки перехвата RTSS и ограничений каждой игры; нет античит-гарантии |

В ходе этого аудита концентратора не была сертифицирована ни одна конкретная минимальная версия RTSS для каждой функции. Используйте официальный текущий дистрибутив и сообщите точную версию, если ключ профиля/перезагрузка не работает. Установленный, но остановленный RTSS проходит проверку установки; затем его необходимо запустить для фактического ограничения.

<a id="installation"></a>
## Установка

1. **[Загрузите и установите RTSS с Guru3D.](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/).**
2. Откройте [Загрузки NVRasterPulse](../docs/downloads.md#nvrasterpulse) и проверьте доступность выпуска.
3. Загрузите `NVRasterPulse-0.1-win-x64-Setup.exe` или `NVRasterPulse-0.1-win-x64-portable.zip`, а также уведомления/контрольные суммы.
4. Сравните SHA-256. Запустите программу установки или извлеките весь портативный ZIP-файл в доступную для записи локальную папку.
5. Откройте `NVRasterPulse.exe`. Если RTSS отсутствует, используйте **Загрузить RTSS**, установите его, затем **Проверьте еще раз** или выберите `RTSS.exe` вручную.
6. Запустите RTSS с помощью обычного ярлыка или кнопки RTSS на NVRasterPulse, если он остановлен.

Отключение дополнительного напоминания не приводит к пропуску предварительной проверки. Перед отображением этой проверки автоматический запуск лотка Windows ждет, пока откроется главное окно. Программа установки устанавливает только NVRasterPulse. Его EXE-файлы не подписаны.

<a id="usage"></a>
## Использование

1. Выберите предполагаемое запущенное приложение или перейдите к его игровому EXE-файлу.
2. Введите ограничение от 1 до 1000 FPS, включая дробное значение, если необходимо.
3. Сохраните и проверьте полученный результат. NVRasterPulse обновляет профиль RTSS исполняемого файла и запрашивает перезагрузку.
4. Убедитесь, что RTSS запущен, и проверьте его поведение в предполагаемой игре.

Профили имеют ключи по **имени исполняемого файла**, например `Game.exe.cfg`. Две разные папки, содержащие `Game.exe`, используют один и тот же профиль RTSS; сохранение полного пути не устраняет это столкновение.

При сохранении используется Front Edge Sync и активное ожидание. Активное ожидание может увеличить использование CPU. Альтернативные поля `LimitTime` нейтрализуются. Существующие комментарии, настройки наложения и `EnableHooking=0` сохраняются. Глобальный профиль RTSS не изменяется.

Используйте действие «Удалить», чтобы удалить переопределения ограничителя NVRasterPulse. Он не удаляет весь профиль RTSS. Ограничение, унаследованное от RTSS Global или другого инструмента, может применяться и после этого.

**Закрытие и выход:** главное окно можно спрятать в трее. Обычный вариант **Выход** оставляет RTSS работающим и сохраненные ограничения остаются неизменными. **Quit + RTSS** запрашивает нормальное закрытие соответствующего процесса RTSS в текущем сеансе, ждет до восьми секунд и не завершает его принудительно. Сохраненные ограничения сохраняются в обоих случаях.

Язык и тема выбираются в приложении. Запуск при входе в систему Windows не является обязательным и предназначен для установленной копии. Кнопка информации объясняет общие действия.

<a id="update-and-uninstall"></a>
## Обновить и удалить

Закройте NVRasterPulse, загрузите и проверьте новую версию, затем запустите ее установку или извлеките переносную версию в новую папку. Сохраните настройки и резервные копии RTSS. Обновления RTSS являются отдельными и поступают от Guru3D.

Чтобы удалить установленную копию, используйте Windows **Installed apps**. Для портативного устройства закройте, а затем удалите извлеченную папку, когда ваши резервные копии будут в безопасности. Сохраненные ограничения RTSS не удаляются при удалении NVRasterPulse: сначала удалите намеченные переопределения ограничителей. RTSS имеет собственный деинсталлятор.

Локальное состояние: `%LOCALAPPDATA%\NVRasterPulse`. Автоматическое резервное копирование RTSS: `%LOCALAPPDATA%\NVRasterPulse\Backups\RTSS`. Более старое расположение `%LOCALAPPDATA%\RTSSProfileBridge` может быть прочитано для миграции. Эти файлы могут содержать личные пути к исполняемым файлам и не должны публиковаться публично.

<a id="known-limitations"></a>
## Известные ограничения

- RTSS выполняет шапку. Сохраненное значение или успешный запрос на перезагрузку не являются результатом измерения времени кадра.
- Исполняемые файлы с одинаковыми именами имеют общий профиль.
- Другой глобальный/индивидуальный ограничитель может повлиять на результат; отключение локального переопределения не удаляет унаследованное ограничение.
- Намеренно отключенный перехватчик RTSS остается отключенным.
- Активное ожидание имеет компромисс между CPU и мощностью.
- Никакой универсальной игры, античита или сквозной проверки задержки.
- Более ранний экспериментальный движок независимого лимитера не компилируется и не поставляется.
- Автоматическое резервное копирование не подразумевает интерфейс полного резервного копирования и восстановления в один клик.

<a id="troubleshooting"></a>
## Устранение неполадок

| Симптом | Действие |
| --- | --- |
| Предварительное условие RTSS остается открытым. | Выберите фактический `RTSS.exe` и соответствующую папку профилей, затем проверьте еще раз. |
| Лимит сохранен, но эффекта нет. | Запустите RTSS; проверьте правильный EXE-файл/профиль игры, разрешения на перехват и другие ограничители. |
| Сохранить не удалось | Проверьте права доступа к папке и сохраните отображаемую ошибку/резервную копию. |
| Ограничение остается после удаления | Проверьте RTSS Global и другие инструменты; действие мусора удаляет только переопределения локального ограничителя. |
| Две игры получают одинаковый лимит | Проверьте, совпадают ли имена их исполняемых файлов. |
| Выйти + RTSS оставляет RTSS открытым. | Закройте RTSS самостоятельно; эта команда намеренно избегает принудительного завершения. |

При восстановлении резервной копии RTSS вручную сначала закройте RTSS и сохраните текущий профиль, прежде чем заменять его нужной резервной копией. Это может перезаписать несвязанные изменения профиля; проверьте файл и дату. [Общая поддержка](../docs/support.md).

<a id="faq"></a>
## Часто задаваемые вопросы

**Нужен ли мне еще MSI Afterburner?** Для NVRasterPulse требуется RTSS; это не зависит от приложения Afterburner. Следуйте вариантам установки дистрибьютора RTSS.

**Могу ли я использовать это без запуска RTSS?** Вы можете управлять профилями после обнаружения установки, но для ограничения необходимо запустить RTSS.

**Удаляет ли выход или удаление заглушки?** Нет. Перед удалением NVRasterPulse явно удалите нужные переопределения ограничителя.

**Это fork или RTSS?** Нет. Это независимый менеджер профилей; исходный или исполняемый файл RTSS не включен.
