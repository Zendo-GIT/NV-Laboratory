<a id="nvdriverforge"></a>
# NVDriverForge

**Подготовьте установку драйвера NVIDIA с четким выбором компонентов и дополнительными настройками.**

[Загрузите 0.1.3 и статус](../docs/downloads.md#nvdriverforge) · [Установка](#installation) · [Кредиты](#credits-and-upstream) · [Лицензия](../../../../NVDriverForge/LICENSE)

<a id="overview-and-purpose"></a>
## Обзор и цель

NVDriverForge проведет вас через оригинальный пакет драйверов NVIDIA: выберите драйвер, проверьте его компоненты, просмотрите дополнительные настройки, затем подтвердите установку. Он существует для того, чтобы сделать этот выбор понятным и хранить вместе информацию об установке, привилегированных операциях и восстановлении.

Это независимо разработанное приложение, частично вдохновленное рабочим процессом NVCleanstall. Он не включает NVCleanstall и не претендует на полную функциональность.

<a id="features"></a>
## Особенности

- NVIDIA Game Ready / Studio поиск и загрузка; дополнительное обнаружение исправлений с ручным откатом.
- Анализ исходного пакета, хэшей, сигнатур NVIDIA, манифестов и совместимых записей INF.
- Выбор компонентов с учетом зависимостей и сохранением неизвестных компонентов.
- Версия 0.1.3 сохраняет выбранные дополнительные компоненты NVIDIA с возможностью пропуска и исключает из обнаружения только проверенные непроверенные компоненты. Уже существующие или неприменимые дополнительные среды выполнения больше не считаются критически важными компонентами.
- Четкая сводка ошибок установки и доступ к подробным журналам на всех 34 языках.
- Явное подтверждение установки, защищенная промежуточная установка и экспорт существующих пакетов хранилища драйверов.
- Дополнительные расширенные настройки с предполетными проверками, журналами и восстановлением с учетом конфликтов.
- Дополнительная предустановка **Custom NV** с именами вариантов и пояснениями, включая отдельный выбор мощности SILK и проверки совместимости.
- Дополнительная загрузка патчей точной версии NVENC; проверяются исходный коммит и целевые байты.
- Отдельная дополнительная установка Profile Inspector fork с экрана «Инструменты».
- Дополнительные проверки обновлений установленных пользователей, 34 языка интерфейса и четыре темы.

Доступные расширенные параметры включают MPO, индикатор DLSS, Ansel, звуковой сон NVIDIA, MSI, политику/приоритет прерываний, HDCP, запуск контейнера дисплея и соответствующую устаревшую службу телеметрии. У каждого есть свои предпосылки и последствия; это не универсальное улучшение производительности.

<a id="compatibility"></a>
## Совместимость

| Требование | Подробности |
| --- | --- |
| Система | Windows 10, сборка 19041 или новее / Windows 11, x64 |
| GPU/драйвер | Совместимый пакет NVIDIA и обнаруженное оборудование; автоматический поиск по каталогу в основном охватывает известные модели GeForce |
| Время выполнения | .NET 8 / WPF 8.0.31 включен в подготовленный автономный пакет |
| Привилегии | Обычный пользовательский интерфейс/настройка для каждого пользователя; установка драйверов и изменения системы требуют доступа администратора |
| Сеть | Требуется для онлайн-поиска/загрузки NVIDIA и явных восходящих запросов NVENC; можно выбрать локальный оригинальный драйвер |
| Включенные инструменты | Немодифицированный 7-Zip 26.03, уведомления во время выполнения, дополнительный спутник MIT Profile Inspector |
| Дополнительный компаньон | .NET Framework 4.8 для отдельного Profile Inspector fork |

Никакая произвольная минимальная версия драйвера не охватывает все функции. Поиск Multi-GPU должен соответствовать каждому обнаруженному GPU. Неподдерживаемые/профессиональные модели могут потребовать выбора драйвера вручную. Установщик NVIDIA остается окончательным органом управления оборудованием/ОС.

<a id="installation"></a>
## Установка

1. Посетите [загрузки](../docs/downloads.md#nvdriverforge) и подтвердите публикацию релиза.
2. Выберите `NVDriverForge-Setup.exe` для установки или `NVDriverForge.exe` для портативного использования.
3. Сравните SHA-256 с версией `SHA256SUMS.txt`.
4. Запустите программу установки для индивидуальной установки и стандартной программы удаления или поместите переносимый EXE-файл в доступную для записи папку и откройте его.

Портативная версия включает в себя среду выполнения и дополнительный установщик. При установке NVDriverForge драйвер GPU не устанавливается. Его EXE-файлы в настоящее время не подписаны.

<a id="usage"></a>
## Использование

1. **Драйвер:** загрузите с NVIDIA или выберите оригинальный EXE-файл установщика NVIDIA. Дайте анализу закончиться.
2. **Компоненты**: просмотрите описания и необходимые зависимости. Неизвестные компоненты сохраняются.
3. **Улучшения:** оставьте ненужные параметры без изменений. Прежде чем выбирать что-либо, прочитайте эффекты и компромиссы.
4. **Проверка.** проверьте точный драйвер, компоненты и дополнительные операции, затем подтвердите установку.
5. Примите UAC только для выбранной вами операции. Сохраните инструкции по восстановлению защищенного задания.
6. Если новому драйверу требуется перезагрузка, следуйте сообщаемому состоянию. Отложенные операции требуют явного возобновления после перезапуска.

Custom NV запускается без изменений. Выберите отдельные именованные значения или просмотрите предоставленный набор настроек и его исключения. Два его информационных внутренних поля не записываются независимо друг от друга. Настройки применяются только в рабочем процессе проверенного нового драйвера, а не при открытии предварительного просмотра. Установка отдельного редактора NVPI не требуется.

Дополнительная работа NVENC загружает совместимые данные из закрепленного коммита keylase. Он изменяет две библиотеки DLL драйверов и делает их подписи недействительными; от него могут отказаться Windows, энкодеры, DRM или античит. Такие данные или DLL NVIDIA не встроены в NVDriverForge. [Происхождение и лицензионные ограничения](../docs/provenance.md).

Настройки управляют языком, темой и дополнительными проверками обновлений установленных пользователей. Портативная версия не создает установленную задачу фоновой проверки. Инструменты и восстановление отделены от четырех этапов установки.

<a id="update-and-uninstall"></a>
## Обновить и удалить

Закройте NVDriverForge, получите следующий официальный пакет и проверьте его хэш. Используйте тот же идентификатор установки для установленного обновления; замените закрытый портативный EXE-файл на новый. Сохраняйте настройки и защищенные задания.

Uninstall из Windows **Installed apps**. При этом удаляется приложение и его задача обновления, а не драйвер NVIDIA. Настройки, логи и резервные копии остаются. При желании восстановите дополнительные изменения/изменения NVENC с помощью документированной процедуры восстановления **перед** удалением приложения. Восстановление отклоняет конфликтующие изменения, внесенные другим инструментом.

Локальные данные находятся под `%LOCALAPPDATA%\NVDriverForge`; защищенные задания и экспорт драйверов находятся под `%PROGRAMDATA%\NVDriverForge\Jobs`. Портативное использование также создает локальные данные. Экспорт хранилища драйверов не является образом системы или полной резервной копией профиля.

<a id="known-limitations"></a>
## Известные ограничения

- Никаких дополнений к оборудованию/редактирования INF, повторной генерации сигнатур NVIDIA, совместимого с античитом отказа или автоматического принятия неподписанного предупреждения.
- Никакого полного удаления телеметрии/рекламы, экспорта тонких пакетов или автоматического полного отката к предыдущему драйверу.
- Установка драйвера, восстановление загрузки и запись дополнительных профилей не были всесторонне проверены на реальных машинах аудитом хаба.
- Повторное чтение реестра не является доказательством фактического влияния HDCP, производительности или задержки.
- При проверке подписи используется локально доступное доверие Windows; онлайн-отзыв не выполняется.
- Присутствуют 34 языка, но полное тестирование носителей языка и доступности остается неполным.

<a id="troubleshooting"></a>
## Устранение неполадок

| Симптом | Действие |
| --- | --- |
| Онлайн-каталог недоступен. | Выберите оригинальный пакет [Загрузка драйверов NVIDIA](https://www.nvidia.com/en-us/drivers/). Не заменяйте соседнюю модель GPU. |
| Поиск исправлений недоступен. | Используйте [Форум драйверов NVIDIA Game Ready](https://www.nvidia.com/en-us/geforce/forums/game-ready-drivers/13/) и проверьте фактический пакет. |
| Установка NVIDIA не удалась. | Прочтите сводку об ошибках и откройте подробные журналы. Дополнительные компоненты, уже существующие или неприменимые, остаются пропущенными в 0.1.3. Неудачные установки не вызывают дополнительные настройки или поток успеха/перезапуска. |
| Ошибка подписи/хеша/резервного копирования | Остановите установку и сохраните ошибку; получите исходный пакет снова, если он поврежден. |
| Опция недоступна | Прочтите причину его аппаратного обеспечения, компонента или целевого драйвера; оставьте его без изменений. |
| Перезапуск или задание все еще не выполнено | Используйте инструкции по восстановлению работы и подробное резюме; не стирайте его журнал. |
| Восстановить конфликт | Другое состояние отличается от записанной транзакции. Сохраните его и запросите помощь вместо принудительного восстановления. |

Для отчетов укажите выбранную версию инструмента, Windows, GPU, драйвер и воспроизводимые шаги; редактировать пути и личные данные из журналов. [Поддержка](../docs/support.md).

<a id="faq"></a>
## Часто задаваемые вопросы

**Устанавливает ли программа установки графический драйвер?** Нет. Для этого требуется отдельный анализ, проверка, подтверждение и процесс установки с повышенными правами приложения.

**Нужен ли мне NVCleanstall или NVPI?** Нет. NVCleanstall – это только пример. Компаньон Profile Inspector – это независимый дополнительный редактор.

**Сделает ли это каждый драйвер NVIDIA меньше или быстрее?** Нет. Отобранные компоненты и предварительные требования определяют, что может измениться; никакого измеренного выигрыша не обещано.

**Где исходные коды?** Исходные коды для конкретных приложений и частные тесты поддерживаются отдельно. Этот центр предоставляет документацию, двоичные файлы и ссылки на сторонние источники, необходимые для атрибуции/лицензирования.
