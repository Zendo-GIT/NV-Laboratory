<a id="repository-architecture-and-maintenance"></a>
# Архитектура и обслуживание репозитория

NV Laboratory – это общедоступный **центр документации и распространения двоичных файлов**. Он не содержит исходного кода приложения. В четырех проектах сохраняются отдельные деревья сборки, версии, идентификаторы и ресурсы выпуска. Их частная история разработки не импортируется в этот репозиторий Git.

<a id="layout"></a>
## Макет

| Расположение | Цель |
| --- | --- |
| README.md / README.fr.md | Английские/французские точки входа |
| Четыре папки проекта | Полные руководства и соответствующие оригинальные уведомления. |
| документы | Загрузки, совместимость, происхождение, процедура разработки и выпуска |
| документы/releases.json | Проверенные метаданные, размеры и хэши кандидатов/выпусков |
| документы/происхождение | Сравнение файлов/хэшей; нет кода приложения |
| лицензии | Общие полные сторонние тексты и сведения об переводчиках установщика. |
| активы | Существующие проверенные превью пользовательского интерфейса и их происхождение |
| .github | Формы выпуска и проверка документации, доступной только для чтения. |
| инструменты/validate_repository.py | Проверка границ публикаций и ссылок стандартной библиотеки |

Английский остается README GitHub по умолчанию. Существующие соседние ссылки `.fr.md` остаются действительными. Дополнительные переводы отражают документацию `docs/languages/<code>`; селектор языка сохраняет ту же страницу при переключении языков. В каталоге `docs/languages/catalog.json` записаны все 34 языка и исходные отпечатки. GitHub не выбирает автоматически README по языку браузера. См. [языковой индекс и политика перевода](../../README.md).

<a id="application-technologies"></a>
## Технологии применения

| Программа | Частная технология | Распространение |
| --- | --- | --- |
| NVPI fork | C#, WPF, .NET Framework 4.8, NVAPI/Windows взаимодействие | Полная переносная папка и отдельный Inno Setup |
| NVDriverForge | С#, WPF, .NET 8; собственный загрузчик C++; Процесс 7-Zip | Автономный портативный EXE-файл и программа установки. |
| NVMFG Unlock40 | C#/WPF .NET 8, вспомогательные средства Framework 4.8, механизм C++20/MASM/MinHook | Переносимое дерево и настройка |
| NVRasterPulse | Платформа C#/WPF 4.8; Интеграция профиля/перезагрузки RTSS; родной бутстрап | Переносимое дерево и настройка |

Эта общедоступная проверка не может пересобрать приложения. Автоматические архивы «Source code» представляют собой снимки концентратора. Ссылки на исходные тексты вверх по течению не представляют точный частный измененный источник. Публичный CI проверяет только этот репозиторий.

<a id="local-checks"></a>
## Местные чеки

Из корня репозитория:

```text
python tools/validate_repository.py
```

Python Достаточно 3.10 или новее. Проверка считывает файлы, локальные ссылки Markdown, необходимые уведомления/ссылки RTSS, метаданные выпуска и границы публикации. Он не запускает программное обеспечение, не устанавливает зависимости и не связывается с сетью.

Рабочий процесс GitHub выполняет ту же самую проверку с разрешением содержимого только для чтения при отправке, запросе на извлечение или отправке вручную. Checkout привязан к проверяемой фиксации и не сохраняет учетные данные. Задание выпуска или развертывания не настроено.

<a id="maintain-the-boundary"></a>
## Поддерживать границу

Обновите английскую справку, руководства на французском языке и затронутые переводы вместе. Держите существенные изменения отдельно от сравнений только по форматированию. Записывайте фактические хэши кандидатов, ссылки на исходные коммиты и лицензии; никогда не делайте вывод о лицензии из популярности проекта.

Используйте свежие версии ресурсов Release и повторно проверяйте измененные двоичные файлы, архивы и встроенные уведомления. Сохраняйте частные резервные копии за пределами этого хранилища. Не используйте общедоступный рабочий процесс для импорта исходного кода частного приложения или папок локальной сборки.

Тесты, соответствующие функциональному изменению приложения, выполняются в частном проекте. Не запускайте повторно программы установки драйверов и не записывайте реальные профили для обновления документации. [Процедура выпуска вручную](releasing.md).
