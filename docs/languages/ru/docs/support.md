<a id="compatibility-and-troubleshooting"></a>
# Совместимость и устранение неполадок

Это подготовленные кандидаты, а не матрица сертификации для всех комбинаций Windows, GPU, драйверов и игр.

| Инструмент | Windows / время выполнения | Аппаратное обеспечение/внешняя зависимость | Операции, требующие ухода |
| --- | --- | --- | --- |
| NVPI fork 3.0.2.3 | Windows 10/11 x64, .NET Framework 4.8 | Совместимый драйвер/дисплей NVIDIA | Профиль пишет и отображает предварительный просмотр |
| NVDriverForge 0.1.4 | Windows 10 сборка 19041+/11 x64; .NET/WPF включен | Совместимый пакет драйверов NVIDIA | Повышенная установка, расширенные настройки, дополнительный NVENC |
| NVMFG Unlock40 0.2.3 | Windows 10/11 x64; .NET/WPF включен, помощники Framework 4.8 | RTX 40, подходящая игра DLSS FG и закрепленный поставщик | Встроенные внутриигровые исправления, глобальный журнал профилей, обновления игры SDK. |
| NVRasterPulse 0.2 | Windows 10/11 x64, .NET Framework 4.8 | RTSS установлен; бег за кепками | RTSS изменения профиля для каждого исполняемого файла |

Пакет ARM64 не подготовлен. Доступность дисплея/API и старые версии Windows могут ограничивать отдельные функции. Никакой универсальной минимальной версии NVIDIA или RTSS не придумано. Точный хеш-код провайдера NVMFG находится в [происхождение](provenance.md).

<a id="before-reporting-a-bug"></a>
## Прежде чем сообщить об ошибке

Определите точный исполняемый файл/версию, которую вы открыли. Предыдущая установленная копия не обязательно является версией только что загруженного ZIP-файла. Запишите этапы воспроизведения, ожидаемый результат и фактический результат. При проблемах с рендерингом/ограничением укажите версию игры, обновление экрана, состояние FG/V-Sync/VRR и любой другой ограничитель или наложение.

Используйте [форма ошибки](https://github.com/Zendo-GIT/NV-Laboratory/issues/new?template=bug-report.yml). Никогда не прикрепляйте всю частную папку разработки, архив драйверов, модель, игровую DLL, дамп реестра или непроверенную коллекцию журналов.

| Проблема | Первые проверки |
| --- | --- |
| Неправильная версия приложения | Подтвердите личность EXE и освободите хэш; закройте старую копию перед заменой. |
| Ошибка выполнения/запуска | Установите необходимую платформу 4.8 или сохраните все прилагаемые переносимые подпапки. |
| UAC отменен | Повторите только намеченную операцию; отмена не успешная установка. |
| Несоответствие хеша/подписи | Прекратите использовать этого кандидата и получите ожидаемые официальные байты. |
| Цвет/режим NVPI отклонен | Вернитесь и используйте комбинацию, поддерживаемую реальным дисплеем/драйвером. |
| Ошибка резервного копирования или восстановления NVDF. | Сохраните защищенное задание и RECOVERY.txt; не стирайте журнал и не вызывайте конфликтующие записи. |
| Ожидаемые настройки NVMFG | Выполните восстановление с закрытыми играми, сохранив изменения, внесенные другими инструментами. |
| Крышка RP не имеет никакого эффекта. | Запустите RTSS, определите настоящий EXE-файл игры, проверьте состояние перехватчика и конкурирующие ограничения. |
| Колпачок RP сохраняется после снятия | Проверьте RTSS Global; удаление изменяет только локальный ограничитель. |

NVDriverForge предлагает доступный для предварительного просмотра локальный отчет JSON; NVMFG предлагает диагностику в разделе «О программе». Предпочитайте эти отфильтрованные отчеты полному архиву журналов и проверяйте их перед отправкой. Блокировка восстановления, о которой сообщается на NVMFG 0.1.1, до сих пор не имеет установленной причины; сохраните свой журнал и запишите все доступные коды ошибок. NVRasterPulse 0.2 предлагает диагностику конфигурации в меню действий без измерения FPS.

<a id="logs-and-privacy"></a>
## Журналы и конфиденциальность

| Инструмент | Местные данные для просмотра, а не для массовой загрузки |
| --- | --- |
| NVDF | `%LOCALAPPDATA%\NVDriverForge`; защищенные рабочие места `%PROGRAMDATA%\NVDriverForge\Jobs` |
| НВМФГ | `%LOCALAPPDATA%\RtxMfg`; резервные копии `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`; `Sessions` рядом с EXE |
| RP | `%LOCALAPPDATA%\NVRasterPulse`; `Backups\RTSS` ниже этого |
| NVPI | Выбранный вами экспорт и отображаемая ошибка; не придуман универсальный путь к журналу |

Удалите имена учетных записей, домашние каталоги, пути к библиотекам игр, идентификаторы устройств, токены и несвязанные окна из текста/изображений, которыми вы делитесь. Сохраните оригиналы в частном порядке для восстановления. Общественные проблемы видны всем.

Чтобы узнать об уязвимости, опасном привилегированном поведении или непреднамеренной разрушительной операции, подпишитесь на [SECURITY.md](../SECURITY.md) вместо того, чтобы публиковать подробности публично.

<a id="what-has-been-verified"></a>
## Что было проверено

Для подготовки хаба было выполнено сканирование статических полезных данных, ZIP-архивов, хешей и метаданных, а также проверка документации. Существующие тесты сборки/модуля/UI частных приложений являются историческими и датированными свидетельствами. В рамках этой подготовки не выполнялась установка драйверов, смена дисплея, работа RTSS в реальном времени или игровые тесты.

«Обнаружено», «записано», «перезагружено», «доступна возможность» и «измерено в игре» – это разные результаты. Сообщите, какой из них вы наблюдали.
