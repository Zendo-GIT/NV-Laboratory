# NVIDIA Profile Inspector – NV Tools Fork

**Независимый fork от [NVIDIA Profile Inspector от Orbmu2k](https://github.com/Orbmu2k/nvidiaProfileInspector), с дополнительными элементами управления отображением.** Прежнее название проекта: **NVPI Custom**.

[Статус загрузки и выпуска](../docs/downloads.md#nvidia-profile-inspector) · [Установка](#installation) · [Добыча и изменения](#upstream-and-changes) · [Лицензия](../../../../NVIDIA-Profile-Inspector/LICENSE)

<a id="overview"></a>
## Обзор

Приложение редактирует профили драйверов NVIDIA, включая настройки для каждого приложения. В этот fork также добавлен редактор **Экрана** для активного дисплея Windows: разрешение, частота обновления, настройки выходного цвета, HDR и установленные ассоциации профилей ICC/WCS.

Он существует для того, чтобы перенести соответствующие элементы управления отображением в редактор профиля и сделать результаты предварительного просмотра, подтверждения и восстановления более понятными. Он не устанавливает новые аппаратные возможности.

Первый кандидат – **3.0.2.3**, использующий очищенную автономную сопутствующую сборку от 9 сентября 2026 года. Его существующим исполняемым файлом остается `nvidiaProfileInspector.exe`; программа установки и некоторые внутренние этикетки по-прежнему содержат надпись `NVPI Custom NV`. Публичный заголовок выше идентифицирует fork без изменения идентификационных данных установки и не делает вид, что это официальный выпуск Orbmu2k.

<a id="features"></a>
## Особенности

- Просмотр существующих исходных профилей, сопоставление приложений, редактирование настроек и импорт/экспорт профилей.
- Диалоговое окно **Экран** для отображения, режима, Гц, RGB/YCbCr, глубины цвета, диапазона и колориметрии.
- Windows HDR контролирует и устанавливает выбор ассоциации ICC/WCS.
- 15-секундный предварительный просмотр с функциями **Сохранить**/**Вернуть** и восстановлением тайм-аута.
- Обратное чтение изменений режима/HDR и сообщений об ошибках восстановления.
- Отдельная отчетность о HDR, SDR с ACM/WCG и глубине цвета сигнала.
- Средство запуска NVRasterPulse для соответствующей отдельно установленной копии.

<a id="compatibility"></a>
## Совместимость

| Требование | Подробности |
| --- | --- |
| Система | Windows 10/11 x64 с совместимым драйвером NVIDIA |
| Время выполнения | [.NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48), поставляется Windows или устанавливается отдельно |
| Разрешения | Редактор запрашивает доступ администратора при открытии |
| Дисплеи | Фактические режимы и цветовые комбинации зависят от GPU, драйвера, дисплея, кабеля и API-интерфейсов Windows. |
| Дополнительные инструменты | NVRasterPulse для управления лимитами RTSS; ни он, ни RTSS для редактора экрана не нужны |
| Языки | Настройка: селектор на 34 языках. Редактор сохраняет существующую языковую поддержку. |

Для каждого GPU не существует проверенного минимума универсального драйвера или матрицы поддержки. Доступные варианты bpc в диалоговом окне – это запросы, а не сертифицированные комбинации. Современные элементы управления HDR и более старый резервный вариант Windows имеют разные возможности.

<a id="installation"></a>
## Установка

1. Откройте [страница загрузки](../docs/downloads.md#nvidia-profile-inspector) и проверьте статус публикации.
2. Загрузите установочный или переносной ресурс и сравните его SHA-256 с манифестом выпуска.
3. Для установки запустите `NVPI-CustomNV-3.0.2.3-Setup-r2.exe`, выберите язык и следуйте инструкциям установщика. Он создает собственный ярлык и программу удаления.
4. Для портативного устройства извлеките полный ZIP-архив в новую папку, доступную для записи. Сохраните `Reference.xml`, конфигурацию EXE и все примечания рядом с исполняемым файлом.
5. Запустите `nvidiaProfileInspector.exe`.

Установка только редактора не применяет профиль и не устанавливает драйвер GPU. Компаньон устанавливается отдельно, не принимает на себя ассоциации `.nip` и не включает запуск при входе в систему. Существующие двоичные файлы не подписаны.

<a id="usage"></a>
## Использование

**Версия установщика 2** добавляет тот же собственный переключатель на 34 языках, что и другие инструменты, с навигацией с помощью мыши/клавиатуры, светлым/темным оформлением и отменой. Выбор относится к настройке; он не переводит редактор NVPI. Явный аргумент `/LANG=fr` или тихий режим обходят выбор для вызывающих абонентов, которые уже предоставляют язык.

**Профили драйверов**: выберите профиль, экспортируйте резервную копию, затем отредактируйте только нужные настройки и примените их. Ассоциации приложений определяют, какая игра получит профиль. Сохраненное значение не является доказательством того, что его использует каждый драйвер или игра.

**Управление отображением:** откройте **Экран**, выберите отображение и запрошенные значения, затем запустите предварительный просмотр. Проверьте изображение, прежде чем выбрать **Сохранить** в течение 15 секунд. Используйте **Вернуть**, закройте подтверждение или дайте ему истечь, чтобы запросить восстановление. Прочтите любое сообщение об ошибке: сам по себе успешный вызов API не является доказательством восстановления.

Выбор ICC изменяет установленную ассоциацию профиля; он не создает, не калибрует и не распространяет файл ICC. HDR, ACM/WCG, RGB/YCbCr и bpc описывают различные аспекты конвейера. Новый независимый переключатель ACM не предусмотрен.

**NVRasterPulse:** кнопка на панели инструментов допускает отдельно зарегистрированную общесистемную установку в разделе «Программные файлы» с защищенным владением и разрешениями. Эта программа запуска с повышенными правами может отклонить переносимую копию или доступный для записи/связанный путь. В этом случае откройте NVRasterPulse, используя собственный ярлык. [Установите RTSS отдельно.](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) для использования NVRasterPulse.

<a id="update-and-uninstall"></a>
## Обновить и удалить

Закройте редактор перед обновлением. Сохраните экспортированные профили и загрузите новую версию fork; установите его с использованием того же идентификатора сопутствующего устройства или извлеките переносимые файлы в новую папку. Не смешивайте старый `Reference.xml` с новым исполняемым файлом. Встроенное подавление проверки обновлений восходящего потока принадлежит этому fork.

Для установки копии используйте Windows **Installed apps** и программу ее удаления. Для портативного устройства закройте его и удалите извлеченную папку, когда экспорт будет в безопасности. Удаление редактора **не** не отменяет изменения профиля драйвера, настройки дисплея, NVRasterPulse или RTSS. Перед удалением восстановите нужные настройки.

<a id="known-limitations"></a>
## Известные ограничения

- 15-секундное подтверждение не является сторожевым устройством для каждого сбоя водителя, отключения питания или принудительного отключения.
- Некоторые комбинации цвета/глубины/обновления возвращают `NVAPI_NOT_SUPPORTED`.
- Программное обратное считывание не измеряет битовую глубину панели, точность цветопередачи или задержку.
- Настройки экрана влияют на текущий дисплей Windows; этот диалог не создает настройки отображения для каждой игры.
- Никакой гарантии производительности, античита или универсальной совместимости с HDR.

<a id="troubleshooting"></a>
## Устранение неполадок

| Симптом | Действие |
| --- | --- |
| Ошибка выполнения при запуске | Проверьте обновления Windows и .NET Framework 4.8; используйте полный пакет. |
| Запрошенный режим отображения отклонен | Вернитесь и протестируйте режим, предлагаемый Windows/NVIDIA для этого дисплея. Прочтите точную ошибку и избегайте повторных слепых изменений. |
| HDR или цвет возвращается в старое состояние | Проверьте, не завершилась ли другая операция и не вызвала ли восстановление; отличить HDR от ACM. |
| Кнопка NVRasterPulse отказывается указать путь | Запустите собственный ярлык; эта кнопка требует защищенной общесистемной установки. |
| Изменение сохраняется после удаления | Восстановите экспортированный профиль NVIDIA или предполагаемые настройки дисплея Windows; деинсталляция не является откатом настроек. |

Перед отправкой журналов ознакомьтесь с [общие рекомендации по поддержке](../docs/support.md).

<a id="faq"></a>
## Часто задаваемые вопросы

**Это официальное программное обеспечение NVIDIA или официальная сборка Orbmu2k?** Нет. Это независимая версия fork; вышестоящий автор и лицензия MIT остаются в силе.

**Требуется ли NVDriverForge этот редактор?** Нет. Дополнительный пресет NVDriverForge Custom NV использует собственную интеграцию. Установка редактора – это отдельный выбор.

**Обязателен ли RTSS для этого fork?** Нет. RTSS является обязательным для ограничителя FPS NVRasterPulse, а не для редактирования профиля или экрана.

**Где находится исходный код?** Измененный исходный код приложения хранится в частном порядке. Предоставляется уведомление MIT и исходный репозиторий; MIT не требует публикации измененного исходного кода.
