<a id="changelog"></a>
# Журнал изменений

Этот концентратор следует за [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Записи описывают этот репозиторий; версии приложения независимы.

<a id="unreleased"></a>
## [Неизданный]

<a id="added"></a>
### Добавлено

- Хаб, полные руководства по проектам и документация по репозиторию на 34 языках приложений NV.
- Языковые селекторы с сохранением страниц, метаданные покрытия перевода и стабильные внутренние привязки.
- Кредиты на добычу, полные применимые уведомления и происхождение файлов.
- Требования к RTSS и официальная ссылка для загрузки NVRasterPulse.
- Отдельные ссылки RevoluSound Team.
- Подготовлен каталог пакетов первой версии, проверка SHA-256 и процедура выпуска вручную.
- Формы ошибок/функций, инструкции по вкладу и безопасности.
- Документация только для чтения и проверки границ публикации.

<a id="changed"></a>
### Изменено

- Атрибуция NVMFG теперь отличает независимо разработанное приложение,
ссылка на сравнение/уточнение и фактические общие собственные компоненты.   Существующие авторские права, лицензии и возможности сравнения файлов остаются неизменными.
- Кандидат NVDriverForge обновлен до 0.1.3: исправлена обработка дополнительных компонентов,
читаемые локализованные сбои и обновленная среда выполнения/сопутствующий пакет.

<a id="fixed"></a>
### Исправлено

- Версия установки NVIDIA Profile Inspector – NV Tools Fork 2 теперь отображает общий
Селектор на 34 языках при прямом запуске. Явный язык и тихая пересылка сохраняются; редактор и переносимый пакет не изменились.

Никакие исторические даты публичного выпуска не реконструированы. Возможные версии приложения: 3.0.2.3, 0.1.3, 0.1.1 и 0.1; их примечания к выпуску прилагаются к их будущим выпускам. Подготовка 9 сентября 2026 г. не является датой выпуска GitHub.
