# Безопасность

Эта политика распространяется на пакеты приложений NV Tools и этот центр распространения. Сопровождающий отдает приоритет отчетам, влияющим на последнюю опубликованную версию каждого инструмента. Подготовленные кандидаты не являются объявленной поддерживаемой стабильной версией. Никаких сроков ответа или сертификации безопасности не обещано.

<a id="report-privately"></a>
## Сообщить лично

В случае уязвимостей, небезопасного поведения с повышенными правами, непреднамеренных деструктивных изменений или раскрытия конфиденциальных данных используйте функцию хранилища **Безопасность → Report a vulnerability**, **если она включена**: [частный отчет](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new).

**Первоначальная настройка** сопровождающий должен включить частную отчетность об уязвимостях после создания общедоступного репозитория. Этот файл не включает его, и до этого момента не утверждается, что ни один почтовый ящик или частный канал не существовали.

Если кнопка недоступна, откройте общедоступную проблему, содержащую только следующее: «Мне нужен частный канал связи для отчета о безопасности, касающегося [инструмента/версии]». Не включайте сведения об эксплойте, учетные данные, затронутые пути, журналы или вложения. Прежде чем поделиться ими, подождите, пока сопровождающий предоставит частный канал.

В частном отчете укажите инструмент/версию и хеш, версии Windows/GPU/драйвера, влияние, минимальное безопасное воспроизведение и необходимость восстановления. Редактировать секреты и личные данные; сохранить локальные файлы восстановления. Не загружайте проприетарные драйверы или игровые библиотеки DLL. Координировать раскрытие информации с сопровождающим; исправление/выпуск требует проверки и не производится автоматически.


[Документация по частной отчетности GitHub](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
