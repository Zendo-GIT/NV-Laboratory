<a id="security"></a>
# セキュリティ

このポリシーは、NV Tools アプリケーション パッケージとこの配布ハブを対象としています。メンテナは、各ツールの最新の公開バージョンに影響を与えるレポートに優先順位を付けます。準備された候補は、発表されたサポートされている安定リリースではありません。回答期限やセキュリティ認証は約束されません。

<a id="report-privately"></a>
## 非公開で報告する

脆弱性、安全でない昇格された動作、意図しない破壊的な変更、または機密データの漏洩については、リポジトリの **セキュリティ → Report a vulnerability** 機能 **有効になっている場合**: [プライベートレポート](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new) を使用してください。

**初期設定:** メンテナはパブリック リポジトリを作成した後、プライベート脆弱性レポートを有効にする必要があります。このファイルはそれを有効にせず、それ以前にメールボックスまたはプライベート チャネルが存在すると主張されることはありません。

ボタンが使用できない場合は、「[ツール/バージョン] に関するセキュリティ レポートのプライベート連絡チャネルが必要です。」のみを含む公開問題を開きます。エクスプロイトの詳細、認証情報、影響を受けるパス、ログ、添付ファイルは含めないでください。メンテナがプライベート チャネルを提供するまで待ってから共有してください。

プライベート レポートには、ツール/バージョンとハッシュ、Windows/GPU/ドライバーのバージョン、影響、最小限の安全な複製、およびリカバリが必要かどうかが含まれます。機密情報と個人データを編集します。ローカルリカバリファイルを保存します。独自のドライバーやゲーム DLL をアップロードしないでください。管理者と開示を調整します。パッチ/リリースにはレビューが必要であり、自動的には行われません。


[GitHub プライベート レポート ドキュメント](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
