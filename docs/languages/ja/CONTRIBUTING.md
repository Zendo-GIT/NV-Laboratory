# 貢献する

NV Laboratory は 禅堂 Zendo (RevoluSound Team) によって保守されます。メンテナは、何を受け入れてリリースするかを決定します。 Issue または Pull Request を開くことは、投稿が受け入れられた、または配布が承認されたことを意味するものではありません。

バグまたは機能フォームを使用して、プログラム/バージョンを特定します。まず既存の問題を検索します。多額の寄付を準備する前に、大幅な変更について話し合ってください。セキュリティの問題については、[SECURITY.md](SECURITY.md) に従ってください。

このパブリック ハブには、ドキュメント、通知、リリース メタデータ、およびリポジトリの検証が含まれています。アプリケーションのソースとテストは非公開で維持されます。逆コンパイルされたコード、プライベート ソース、資格情報、ユーザー プロファイル、または実行可能ペイロードを送信しないでください。

ドキュメント PR では、34 の対応する言語とナビゲーションを整合させ、コマンド/ファイル/製品名を保持し、実際の動作を説明する必要があります。新しいスクリーンショットは、バージョンが識別され、個人情報が含まれていない自分のものである必要があります。合成データにはラベルを付ける必要があります。すべての新しいサードパーティ資産の出所と許可を提供します。

UTF-8、LF、読み取り可能なマークダウン、および焦点を絞った小さな変更を使用します。 Python バリデーターは、標準ライブラリのみを使用します。既存のスタイルに一致させ、不要な依存関係を避けて、次を実行します。

```text
python tools/validate_repository.py
```

リリース メタデータの変更については、監査されたバイナリからの正確なバージョン/タグ、ファイル サイズ、SHA-256 を含め、ダウンロード ページを揃えてください。アプリケーションの変更には、影響を受ける動作に適したプライベートなビルド/テストが必要です。ドキュメントのチェックはアプリケーションのテストではありません。過去のテスト結果や利益を決してでっち上げないでください。

オリジナルのハブ素材を提供することにより、[ライセンス](../../../LICENSE) の範囲指定された MIT ライセンスに同意したことになります。第三者への通知を保管し、変更を特定します。アップストリーム ライセンスを置き換えないでください。受け入れと公開はメンテナーの決定のままです。
