# 変更履歴

このハブは [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) に準拠しています。エントリではこのリポジトリについて説明します。アプリケーションのバージョンは独立しています。

<a id="unreleased"></a>
## 【未公開】

<a id="added"></a>
### 追加されました

- ハブ、34 の NV アプリケーション言語による完全なプロジェクト ガイドおよびリポジトリ ドキュメント。
- ページを保持する言語セレクター、翻訳対象メタデータ、安定した内部アンカー。
- 上流のクレジット、該当する完全な通知、およびファイルの出所。
- RTSS の要件と NVRasterPulse の公式ダウンロード リンク。
- 個別の RevoluSound Team リンク。
- 最初のリリースのパッケージ カタログ、SHA-256 の検証、および手動リリース手順を準備しました。
- バグ/機能フォーム、貢献およびセキュリティに関する指示。
- 読み取り専用のドキュメントと出版境界チェック。

<a id="changed"></a>
### 変更されました

- NVMFG の帰属により、独自に開発されたアプリケーションが区別されるようになりました。
比較/絞り込みリファレンス、および実際の共有ネイティブ コンポーネント。   既存の著作権、ライセンス、ファイル比較はそのまま残ります。
- NVDriverForge 候補が 0.1.3 に更新されました: オプション コンポーネントの処理が修正されました。
読みやすいローカライズされた障害と更新されたランタイム/コンパニオン パッケージ。

<a id="fixed"></a>
### 修正済み

- NVIDIA Profile Inspector – NV Tools Fork セットアップ リビジョン 2 では、共有
直接起動した場合は 34 言語セレクター。明示的な言語とサイレント転送は維持されます。エディターとポータブル パッケージは変更されていません。

過去の公開日は再構築されません。候補となるアプリケーションのバージョンは、3.0.2.3、0.1.3、0.1.1、および 0.1 です。彼らのリリース ノートは、彼ら自身の将来のリリースに添付されます。 2026 年 9 月 9 日の準備は、GitHub のリリース日ではありません。
