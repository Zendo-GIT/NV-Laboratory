<a id="changelog"></a>
# 変更履歴

このハブは [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) に準拠しています。アプリケーションのバージョンとリリース日は独立しています。以下の準備済みパッケージには、それぞれの GitHub リリースでの実際の発行日が記載されています。

<a id="unreleased"></a>
## 【未公開】

<a id="changed"></a>
### 変更されました

- ハブと NVDriverForge 0.1.4 の 34 のドキュメント言語すべてを更新します。
NVMFG Unlock40 0.2.3 および NVRasterPulse 0.2、2026 年 9 月 18 日に作成されました。
- NVDriverForge: 準備状況チェック、ネイティブ プロファイル バックアップ、保護されたリカバリ、
コンポーネントのガイダンス、再利用可能な設定、ドライバー キット、詳細な結果、ローカル サポート レポート、個別のアプリケーションのアップデート。
- NVMFG: マルチフォルダー検出、永続ライブラリ キャッシュ、監視された MFG アクティビティ、
ランタイム機能情報、次回起動時の除外、ローカル診断、設定の転送、およびオプションのアプリケーション更新。
- NVRasterPulse: 構成診断、FPS 提案、一時停止/再開、
1 レベルの取り消し、選択的なプロファイルのインポート/エクスポート、お気に入りおよび非表示のエントリ。
- パッケージ ハッシュ、リリース ノート、ネイティブ コンポーネントの出自マップを更新します。
すでに公開されている Profile Inspector 3.0.2.3/setup-r2 アセットは変更しないでください。

<a id="fixed"></a>
### 修正済み

- NVMFG ゲームの選択/カウント、Ctrl+D 処理および完了した進行状況メッセージ。
Wallpaper Engine はゲームの検出から除外されます。別途報告された 0.1.1 復元のブロックは再現されず、修正されたとは主張されていません。

<a id="initial-public-hub--2026-09-10"></a>
## [初期パブリックハブ] – 2026-09-10

<a id="added"></a>
### 追加されました

- 34 か国語で書かれた 4 つのプロジェクト ガイドとリポジトリ ドキュメント。
ページ保持セレクター、安定したアンカー、翻訳対象メタデータ。
- コンポーネントのクレジット、オリジナルのライセンス、出所、RTSS 要件、および
個別の RevoluSound Team リンク。
- 手動リリース パッケージ、SHA-256 値、発行フォーム、セキュリティ ポリシー、および
読み取り専用のドキュメント検証。アプリケーションのソースは非公開のままです。
- 最初の公開タグ: `nvpi-v3.0.2.3`、`nvdriverforge-v0.1.3`、
`nvmfg-unlock40-v0.1.1` および `nvrasterpulse-v0.1`。

<a id="included-fixes"></a>
### 含まれる修正

- Profile Inspector インストーラー リビジョン 2: スタンドアロンの 34 言語セレクター。
エディターとポータブル ペイロードは変更されません。
- NVDriverForge 0.1.3: オプションコンポーネントの処理を修正し、ローカライズしました
更新されたランタイムおよび関連パッケージを含む障害の概要。

上記の日付は検証された公開ハブの履歴であり、再構築された開発日ではありません。
