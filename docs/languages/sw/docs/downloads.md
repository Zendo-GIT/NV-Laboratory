# Vipakuliwa

Chagua programu na **Weka** au **inayobebeka**. Kila ukurasa wa Toleo la zana unaonyesha upatikanaji wa sasa, tarehe ya kuchapishwa na vidokezo vya kutolewa. Viungo vya moja kwa moja hufanya kazi wakati mtunza huduma anachapisha vipengee vinavyolingana. Chanzo cha maombi kinasalia kuwa cha faragha. Weka `Licenses-and-Credits.zip` na `SHA256SUMS.txt` na upakuaji wako. Kitufe cha **Source code (zip)** cha GitHub kina hati za kitovu.

> **NVRasterPulse inahitaji RTSS.** Sakinisha [RivaTuner Statistics Server kutoka Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) kando na uiendeshe kwa kikomo cha FPS.
