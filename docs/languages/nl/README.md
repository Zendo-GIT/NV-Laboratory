# NV Laboratory

**NV Tools door 禅堂 Zendo (RevoluSound Team).** Vier onafhankelijke Windows-hulpprogramma's voor NVIDIA-stuurprogrammaprofielen, stuurprogramma-installatie, experimentele Multi Frame Generation- en RTSS-framelimieten.

[Verkrijg de hulpmiddelen](docs/downloads.md) · [Installatie](docs/installation.md) · [Compatibiliteit en hulp](docs/support.md) · [Kredieten en licenties](THIRD_PARTY_NOTICES.md)

> **NVRasterPulse vereist RTSS.** Installeer eerst [RivaTuner Statistics Server van Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/). RTSS moet actief zijn om de FPS-limieten te laten werken. Het wordt afzonderlijk gedownload.

<a id="start-here"></a>
## Begin hier

1. Kies hierboven één hulpmiddel. Ieder werkt onafhankelijk; het installeren van de hele suite is niet nodig.
2. Lees de vereisten en kies **Setup** voor een geïnstalleerde app, of **draagbaar** voor een aparte map.
3. Wanneer de release ervan wordt gepubliceerd, downloadt u het genoemde applicatie-item, leest u de bijbehorende mededelingen en vergelijkt u de SHA-256.
4. Bewaar back-ups voordat u een stuurprogramma, weergave-instelling, NVIDIA-profiel of game-runtime wijzigt.

Documentatie is beschikbaar in dezelfde 34 talen als de NV-applicaties via de selector bovenaan elke gids. GitHub selecteert niet automatisch een README per browsertaal. De documentatietaal en de eigen taalinstelling van de applicatie zijn gescheiden.

<a id="provenance-and-ownership"></a>
## Herkomst en eigendom

Deze hub verspreidt documentatie en gecompileerde applicaties. De broncode van de applicatie wordt privé onderhouden. Upstream-projecten behouden hun auteurschap en licenties; distributie van particuliere bronnen vervangt deze termen niet.

- De Profile Inspector fork behoudt de MIT-licentie van Orbmu2k en wordt expliciet geïdentificeerd als een fork.
- NVDriverForge heeft zijn eigen binaire distributievoorwaarden en bevat afzonderlijk gelicentieerde runtime-/toolcomponenten.
- NVMFG Unlock40 is een onafhankelijk ontwikkelde applicatie. RTX40MFG-Unlock werd geraadpleegd voor vergelijking en verfijning; gedeelde native componenten behouden hun MIT-credits. MinHook en NVIDIA SDK-termen blijven gescheiden.
- NVRasterPulse behoudt de meegeleverde MIT-licentie en crediteert de van Profile Inspector afgeleide gebruikersinterface. RTSS is een vereist extern programma.

Zie de [volledige componententabel](THIRD_PARTY_NOTICES.md), [herkomst en wijzigingen van bestanden](docs/provenance.md) en [licentieomvang](../../../LICENSE).
