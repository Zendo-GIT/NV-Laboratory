# Seguridad

Sinasaklaw ng patakarang ito ang NV Tools application packages at ang distribution hub na ito. Inuuna ng tagapangasiwa ang mga ulat na nakakaapekto sa pinakabagong na-publish na bersyon ng bawat tool. Ang mga inihandang kandidato ay hindi isang inihayag na suportadong stable release. Walang ipinangako na deadline ng pagtugon o sertipikasyon sa seguridad.

<a id="report-privately"></a>
## Iulat nang pribado

Para sa mga kahinaan, hindi ligtas na mataas na gawi, hindi sinasadyang mapanirang pagbabago, o sensitibong pagkakalantad ng data, gamitin ang tampok na **Security → Report a vulnerability** ng repository **kapag ito ay pinagana**: [pribadong ulat](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new).

**Paunang pag-setup:** dapat i-enable ng maintainer ang pribadong pag-uulat ng kahinaan pagkatapos gawin ang pampublikong repositoryo. Hindi ito pinapagana ng file na ito, at walang mailbox o pribadong channel ang sinasabing umiiral bago noon.

Kung hindi available ang button, magbukas ng pampublikong Isyu na naglalaman lamang ng: "Kailangan ko ng pribadong contact channel para sa isang ulat sa seguridad tungkol sa [tool/version]." Huwag isama ang mga detalye ng pagsasamantala, mga kredensyal, mga apektadong landas, mga log o mga attachment. Hintaying magbigay ang maintainer ng pribadong channel bago ibahagi ang mga ito.

Sa pribadong ulat, isama ang tool/bersyon at hash, Windows/GPU/mga bersyon ng driver, epekto, minimal na ligtas na pagpaparami at kung kailangan ang pagbawi. I-react ang mga lihim at personal na data; panatilihin ang mga lokal na file sa pagbawi. Huwag mag-upload ng pagmamay-ari na driver o mga DLL ng laro. Makipag-ugnay sa pagsisiwalat sa tagapagpanatili; ang isang patch/release ay nangangailangan ng pagsusuri at hindi awtomatiko.


[GitHub pribadong pag-uulat na dokumentasyon](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
