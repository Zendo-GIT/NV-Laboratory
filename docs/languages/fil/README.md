# NV Laboratory

**NV Tools ng 禅堂 Zendo (RevoluSound Team).** Apat na independiyenteng Windows na mga utility para sa NVIDIA na mga profile ng driver, pag-install ng driver, pang-eksperimentong Multi Frame Generation at RTSS na mga limitasyon sa frame.

[Kunin ang mga gamit](docs/downloads.md) · [Pag-install](docs/installation.md) · [Pagkakatugma at tulong](docs/support.md) · [Mga kredito at lisensya](THIRD_PARTY_NOTICES.md)

> **Ang NVRasterPulse ay nangangailangan ng RTSS.** I-install muna ang [RivaTuner Statistics Server mula sa Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/). Dapat na gumagana ang RTSS para gumana ang mga limitasyon nito sa FPS. Ito ay nai-download nang hiwalay.

<a id="start-here"></a>
## Magsimula dito

1. Pumili ng isang tool sa itaas. Ang bawat isa ay gumagana nang nakapag-iisa; ang pag-install ng buong suite ay hindi kailangan.
2. Basahin ang mga kinakailangan nito at piliin ang **Setup** para sa isang naka-install na app, o **portable** para sa isang hiwalay na folder.
3. Kapag na-publish ang Paglabas nito, i-download ang pinangalanang asset ng application, basahin ang mga kasamang notice at ihambing ang SHA-256 nito.
4. Panatilihin ang mga backup bago magpalit ng driver, setting ng display, profile ng NVIDIA o runtime ng laro.

Available ang dokumentasyon sa parehong 34 na wika gaya ng mga NV application sa pamamagitan ng selector sa itaas ng bawat gabay. Ang GitHub ay hindi awtomatikong pumipili ng README ayon sa wika ng browser. Ang wika ng dokumentasyon at ang sariling setting ng wika ng application ay magkahiwalay.

<a id="provenance-and-ownership"></a>
## Provenance at pagmamay-ari

Ang hub na ito ay namamahagi ng dokumentasyon at pinagsama-samang mga aplikasyon. Ang source code ng application ay pinapanatili nang pribado. Ang mga upstream na proyekto ay nagpapanatili ng kanilang pagiging may-akda at mga lisensya; hindi pinapalitan ng pribadong pamamahagi ng pinagmulan ang mga terminong iyon.

- Pinapanatili ng Profile Inspector fork ang lisensya ng Orbmu2k ng MIT at tahasang kinilala bilang isang fork.
- Ang NVDriverForge ay may sariling binary distribution terms at may kasamang hiwalay na lisensyadong runtime/tool na mga bahagi.
- Ang NVMFG Unlock40 ay isang independiyenteng binuo na application. Ang RTX40MFG-Unlock ay kinonsulta para sa paghahambing at pagpipino; Ang mga nakabahaging katutubong bahagi ay nagpapanatili ng kanilang mga MIT na kredito. Nananatiling magkahiwalay ang mga tuntunin ng MinHook at NVIDIA SDK.
- Pinapanatili ng NVRasterPulse ang ibinigay na lisensyang MIT at kinikilala ang UI na nagmula sa Profile Inspector. Ang RTSS ay isang kinakailangang panlabas na programa.

Tingnan ang [kumpletong talahanayan ng bahagi](THIRD_PARTY_NOTICES.md), [file pinagmulan at mga pagbabago](docs/provenance.md), at [saklaw ng lisensya](../../../LICENSE).
