# Nag-aambag

Ang NV Laboratory ay pinananatili ng 禅堂 Zendo (RevoluSound Team). Nagpasya ang tagapangasiwa kung ano ang tinatanggap at ilalabas. Ang pagbubukas ng Isyu o Kahilingan sa Paghila ay hindi nangangahulugan na ang isang kontribusyon ay tinatanggap o pinahihintulutan para sa pamamahagi.

Gamitin ang bug o feature form at tukuyin ang program/bersyon. Maghanap muna ng mga umiiral na Isyu. Talakayin ang malalaking pagbabago bago maghanda ng malaking kontribusyon. Para sa mga usapin sa seguridad, sundin ang [SECURITY.md](SECURITY.md).

Ang pampublikong hub na ito ay naglalaman ng dokumentasyon, mga abiso, release metadata at pagpapatunay ng repositoryo. Ang pinagmulan ng aplikasyon at mga pagsubok ay pinapanatili nang pribado. Huwag magsumite ng decompiled code, pribadong pinagmulan, mga kredensyal, profile ng user, o mga executable na payload.

Dapat panatilihing nakahanay ng mga PR sa dokumentasyon ang 34 na mga katapat na wika at nabigasyon, panatilihin ang mga pangalan ng command/file/produkto, at ilarawan ang aktwal na pag-uugali. Ang mga bagong screenshot ay dapat na sarili mo, kinilala ng bersyon at walang mga personal na detalye; dapat na may label ang sintetikong data. Magbigay ng pinagmulan at pahintulot para sa bawat bagong asset ng third-party.

Gumamit ng UTF-8, LF, nababasang Markdown at maliliit na nakatutok na pagbabago. Ang Python validator ay gumagamit lamang ng karaniwang library. Itugma ang kasalukuyang istilo nito, iwasan ang mga hindi kinakailangang dependency, at patakbuhin ang:

```text
python tools/validate_repository.py
```

Para sa pagpapalabas ng mga pagbabago sa metadata, isama ang eksaktong bersyon/tag, mga laki ng file at SHA-256 mula sa mga na-audit na binary, at panatilihing nakahanay ang mga pahina sa pag-download. Ang mga pagbabago sa aplikasyon ay nangangailangan ng pribadong build/pagsusulit na naaangkop sa apektadong gawi; ang pagsusuri sa dokumentasyon ay hindi isang pagsubok sa aplikasyon. Huwag kailanman mag-imbento ng makasaysayang mga resulta ng pagsubok o mga nadagdag.

Sa pamamagitan ng pag-aambag ng orihinal na materyal ng hub, sumasang-ayon ka sa saklaw nitong lisensyang MIT sa [LISENSYA](../../../LICENSE). Panatilihin ang mga abiso ng third-party at tukuyin ang iyong mga pagbabago; huwag palitan ang isang upstream na lisensya. Ang pagtanggap at pag-publish ay nananatiling mga desisyon ng tagapangasiwa.
