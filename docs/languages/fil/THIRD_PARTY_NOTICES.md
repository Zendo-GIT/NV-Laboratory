## Mga obligasyon at hangganan

**MIT na mga bahagi:** panatilihin ang copyright, teksto ng pahintulot at disclaimer na may mga kopya. Ang kanilang lisensya ay hindi nangangailangan ng paglalathala ng binagong pinagmulan. Ang orihinal na may-akda ay pinapanatili kahit na pribado ang pinanggalingan ng application.

**MinHook/HDE:** panatilihin ang mga abiso, kundisyon at disclaimer sa binary na dokumentasyon. Ang buong pinagsamang paunawa ay ibinigay.

**7-Zip:** panatilihin ang mga abiso ng LGPL/BSD/unRAR at magbigay ng access sa eksaktong hindi binagong pinagmulan. Ang source archive ay naka-link sa itaas, kasama ang buong LGPL. Nalalapat ang paghihigpit sa unRAR sa nauugnay na decompression code; hindi ito isang blanket na dependency na MIT. Tingnan ang [pamamahagi FAQ](https://www.7-zip.org/faq.html) ng may-akda.

**Inno Setup:** panatilihin ang mga kinakailangang abiso sa copyright/website ng engine at markahan ang mga pagbabago sa pinagmulan kung naaangkop. Ang mga hindi binagong kredito ng makina ay nananatili sa mga installer. Ang mga inangkop na katalogo ay nagpapanatili ng mga orihinal na abiso sa pinagmulan; ang mga pangalan ay naka-index dito.

**NVIDIA na materyal:** ang MIT na lisensya para sa Streamline integration header ay hindi sumasaklaw sa bawat SDK file. Ang paunawa nito ay tahasang naghihiwalay sa materyal na Nsight Perf SDK; ang materyal na iyon ay hindi ginagamit sa target ng produksyon na ito. Ang mga header ng NGX ay nasa ilalim ng pagmamay-ari ng NVIDIA na mga tuntunin ng RTX SDK. Naidagdag na ang kanilang buong text, na may [orihinal na-byte na kopya](../../../NVMFG-Unlock40/LICENSES/NVIDIA-RTX-SDK.original.txt). Ang paghihigpit ng Seksyon 4(d) tungkol sa mga teknikal na limitasyon ay nananatiling hindi nalulutas para sa paggamit ng NVMFG. Walang apirmatibong pahintulot ang mahihinuha mula sa pagkakaroon ng isa pang mod.

** Panlabas na hindi alam/pagmamay-ari na mga bahagi:** RTSS, NVCleanstall, NVIDIA mga driver, modelo at keylase hindi naka-bundle ang patch data sa mga inihandang asset ng hub. Tinutukoy ng mga link ang kanilang mga aktwal na may-ari. Ang pag-download na na-trigger ng user ay hindi muling naglilisensya sa isang bahagi.

Gumagamit ang mga tool ng mga API at font na ibinigay ng Windows. Walang Windows SDK/compiler/font file ang nakopya sa Git repository na ito. Ang mga tool sa paggawa at mga pribadong pagsubok ay nasa labas ng pamamahagi. Ang runtime-internal na component notice ay nananatili sa kumpletong Microsoft na notice file sa halip na muling italaga sa publisher.
