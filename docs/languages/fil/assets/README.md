# Mga kredito sa asset

Ang mga larawang ito ay nakunan mula sa mga application o setup noong 2026-09-09 at biswal na sinuri bago isama. Ang mga ito ay hindi na-edit na mga preview ng interface. Gumagamit ang mga preview ng application ng synthetic na halimbawang data. Ang pagkuha ng setup ay nagmula sa isang pribadong pagsubok na nakansela bago ang pag-install. Ang mga larawang ito ay hindi nagtatatag ng pagiging tugma ng driver/SDK, mga resulta ng benchmark o isang tumatakbong laro.
