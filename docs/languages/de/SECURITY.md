<a id="security"></a>
# Sicherheit

Diese Richtlinie gilt für NV Tools-Anwendungspakete und diesen Distributions-Hub. Der Betreuer priorisiert Berichte, die sich auf die neueste veröffentlichte Version jedes Tools auswirken. Vorbereitete Kandidaten sind keine angekündigte unterstützte stabile Version. Es wird keine Antwortfrist oder Sicherheitszertifizierung versprochen.

<a id="report-privately"></a>
## Privat melden

Bei Schwachstellen, unsicherem erhöhtem Verhalten, unbeabsichtigten destruktiven Änderungen oder Offenlegung vertraulicher Daten verwenden Sie die Funktion **Sicherheit → Report a vulnerability** des Repositorys, **sofern diese aktiviert ist**: [privater Bericht](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new).

**Ersteinrichtung:** Der Betreuer muss nach der Erstellung des öffentlichen Repositorys die private Schwachstellenberichterstattung aktivieren. Diese Datei ermöglicht es nicht, und es wird nicht behauptet, dass bis dahin ein Postfach oder privater Kanal existiert.

Wenn die Schaltfläche nicht verfügbar ist, öffnen Sie ein öffentliches Problem, das nur Folgendes enthält: „Ich benötige einen privaten Kontaktkanal für einen Sicherheitsbericht zu [Tool/Version].“ Geben Sie keine Exploit-Details, Anmeldeinformationen, betroffene Pfade, Protokolle oder Anhänge an. Warten Sie, bis der Betreuer einen privaten Kanal bereitstellt, bevor Sie ihn freigeben.

Geben Sie im privaten Bericht Tool/Version und Hash, Windows/GPU/Treiberversionen, Auswirkungen, minimale sichere Reproduktion und ob eine Wiederherstellung erforderlich ist, an. Geheimnisse und persönliche Daten redigieren; Behalten Sie lokale Wiederherstellungsdateien bei. Laden Sie keine proprietären Treiber- oder Spiele-DLLs hoch. Koordinieren Sie die Offenlegung mit dem Betreuer. Ein Patch/Release erfordert eine Überprüfung und erfolgt nicht automatisch.


[GitHub private Berichtsdokumentation](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
