# NVRasterPulse

**FPS برای هر برنامه از طریق RivaTuner Statistics Server محدود می شود.**

> **ابتدا RTSS را نصب کنید.** NVRasterPulse به [RivaTuner Statistics Server (RTSS)، دانلود شده از Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) نیاز دارد. RTSS برای اعمال محدودیت ها باید در حال اجرا باشد. هیچ نصب کننده RTSS، Hook DLL یا SDK همراه نیست.

[دانلود 0.1 و وضعیت](../docs/downloads.md#nvrasterpulse) · [نصب و راه اندازی](#installation) · [محدودیت ها چگونه کار می کنند](#usage) · [مجوز](../../../../NVRasterPulse/LICENSE)

<a id="overview-and-purpose"></a>
## نمای کلی و هدف

NVRasterPulse یک رابط فشرده Windows برای مدیریت محدودیت های فریم RTSS با نام اجرایی است. RTSS محدودیت را انجام می دهد. NVRasterPulse مقادیر پروفایل مربوطه، پشتیبان گیری و درخواست های بارگذاری مجدد را با دسترسی به سینی و انتخاب های مداوم مدیریت می کند.

این وجود دارد تا محدودیت‌های دقیق هر بازی را بدون جایگزین کردن یک نمایه کامل RTSS یا ایجاد اختلال در تنظیمات پوشش آن آسان‌تر کند. نامزد فعلی **0.1** ساخت 9 سپتامبر 2026 با بررسی نصب RTSS مورد نیاز است.

<a id="features"></a>
## ویژگی ها

- یک برنامه در حال اجرا را انتخاب کنید یا فایل اجرایی آن را به صورت دستی اضافه کنید.
- محدودیت های FPS را از 1 تا 1000 با حداکثر سه رقم اعشار ذخیره کنید.
- رمزگذاری منطقی دقیق مقادیر وارد شده: 59.94 به 2997/50 تبدیل می شود.
- پیکربندی Front Edge Sync (`SyncLimiter=1`) با انتظار فعال (`PassiveWait=0`).
- به روز رسانی پروفایل هر اجرایی، پشتیبان گیری خودکار و نوشتن اتمی.
- حذف محدودیت‌ها با حفظ سایر محتوای نمایه.
- تشخیص نصب RTSS، انتخاب مسیر دستی و راه‌اندازی/بارگذاری مجدد صریح.
- عملکرد سینی تک‌نمونه، راه‌اندازی نصب شده اختیاری، 34 زبان و چهار تم.
- عملکردهای خروج عادی و **خروج + RTSS** را از هم جدا کنید.

<a id="compatibility"></a>
## سازگاری

| مورد نیاز | جزئیات |
| --- | --- |
| سیستم | Windows 10/11 x64 |
| زمان اجرا | [NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48)، در صورت نیاز به طور جداگانه نصب می شود |
| نرم افزار مورد نیاز | RTSS با `RTSS.exe`، دایرکتوری منطبق بر `Profiles` و پشتیبانی از نمایه/بارگذاری مجدد سازگار |
| GPU | سازگاری RTSS محدود کننده را تعیین می کند. این مدیر پروفایل نیازی به نسل خاصی از RTX ندارد |
| مجوزها | درخواست برنامه فعلی دسترسی مدیر؛ پوشه نمایه RTSS انتخاب شده باید قابل دسترسی باشد |
| بازی ها | بستگی به پشتیبانی RTSS Hooking و محدودیت های هر بازی دارد. بدون گارانتی ضد تقلب |

هیچ نسخه حداقل RTSS خاصی برای هر عملکرد توسط این ممیزی مرکز تایید نشده است. از توزیع رسمی فعلی استفاده کنید و اگر کلید نمایه/بارگذاری مجدد کار نکرد، نسخه دقیق را گزارش دهید. RTSS نصب شده اما متوقف شده، بررسی نصب را پشت سر می گذارد. سپس باید برای محدود کردن واقعی شروع شود.

<a id="installation"></a>
## نصب و راه اندازی

1. **[RTSS را از Guru3D دانلود و نصب کنید](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/).**
2. [دانلودهای NVRasterPulse](../docs/downloads.md#nvrasterpulse) را باز کنید و در دسترس بودن نسخه را بررسی کنید.
3. `NVRasterPulse-0.1-win-x64-Setup.exe` یا `NVRasterPulse-0.1-win-x64-portable.zip` را به همراه اعلامیه‌ها/جمع‌های چک دانلود کنید.
4. SHA-256 را مقایسه کنید. Setup را اجرا کنید یا کل ZIP قابل حمل را در یک پوشه محلی قابل نوشتن استخراج کنید.
5. `NVRasterPulse.exe` را باز کنید. اگر RTSS وجود ندارد، از **دانلود RTSS** استفاده کنید، آن را نصب کنید، سپس ** دوباره بررسی کنید**، یا `RTSS.exe` را به صورت دستی انتخاب کنید.
6. RTSS را با استفاده از میانبر معمولی یا دکمه RTSS NVRasterPulse در صورت توقف، راه اندازی کنید.

خاموش کردن یادآور اختیاری، بررسی پیش نیاز را نادیده نمی گیرد. یک راه‌اندازی سینی بی‌صدا Windows منتظر می‌ماند تا پنجره اصلی قبل از نمایش این بررسی باز شود. راه‌اندازی فقط NVRasterPulse را نصب می‌کند. EXE های آن بدون امضا هستند.

<a id="usage"></a>
## استفاده

1. برنامه در حال اجرا مورد نظر را انتخاب کنید یا به بازی EXE آن بروید.
2. حدی بین 1 تا 1000 FPS وارد کنید که در صورت نیاز مقدار کسری را نیز شامل می شود.
3. نتیجه گزارش شده را ذخیره و بررسی کنید. NVRasterPulse نمایه RTSS فایل اجرایی را به روز می کند و درخواست بارگذاری مجدد می کند.
4. تأیید کنید RTSS در حال اجرا است و رفتار در بازی مورد نظر را تأیید کنید.

نمایه ها با **نام اجرایی **، مانند `Game.exe.cfg` کلید می شوند. دو پوشه مختلف حاوی `Game.exe` نمایه RTSS یکسانی دارند. ذخیره کردن مسیر کامل این برخورد را حذف نمی کند.

ذخیره از Front Edge Sync و انتظار فعال استفاده می کند. انتظار فعال ممکن است استفاده از CPU را افزایش دهد. فیلدهای جایگزین `LimitTime` خنثی می شوند. نظرات موجود، تنظیمات همپوشانی و `EnableHooking=0` حفظ می شوند. نمایه جهانی RTSS تغییر نکرده است.

از عمل سطل زباله برای حذف نادیده گرفتن محدودکننده NVRasterPulse استفاده کنید. کل نمایه RTSS را حذف نمی کند. محدودیتی که از RTSS Global یا ابزار دیگری به ارث رسیده است ممکن است همچنان اعمال شود.

**بستن و خروج:** پنجره اصلی می تواند در سینی پنهان شود. نرمال **Quit** باعث می شود RTSS در حال اجرا و محدودیت های ذخیره شده دست نخورده باقی بماند. **خروج + RTSS** درخواست بسته شدن عادی فرآیند منطبق با RTSS در جلسه فعلی را می دهد، تا هشت ثانیه منتظر می ماند و آن را به زور نمی کشد. محدودیت های ذخیره شده در هر دو مورد باقی می ماند.

زبان و موضوع در برنامه انتخاب شده است. راه اندازی در ورود به سیستم Windows اختیاری است و برای یک نسخه نصب شده در نظر گرفته شده است. دکمه اطلاعات اقدامات رایج را توضیح می دهد.

<a id="update-and-uninstall"></a>
## به روز رسانی و حذف نصب کنید

NVRasterPulse را ترک کنید، نسخه جدید را دانلود و تأیید کنید، سپس Setup آن را اجرا کنید یا قابل حمل را در یک پوشه جدید استخراج کنید. تنظیمات و نسخه های پشتیبان RTSS را حفظ کنید. به روز رسانی های RTSS مجزا هستند و از Guru3D می آیند.

برای حذف یک کپی نصب شده، از Windows **Installed apps** استفاده کنید. برای قابل حمل، از آن خارج شوید، سپس پوشه استخراج شده آن را هنگامی که نسخه‌های پشتیبان شما ایمن هستند حذف کنید. محدودیت های ذخیره شده RTSS با حذف نصب NVRasterPulse حذف نمی شوند: ابتدا محدودیت های مورد نظر را لغو کنید. RTSS برنامه حذف نصب خود را دارد.

وضعیت محلی: `%LOCALAPPDATA%\NVRasterPulse`. پشتیبان گیری خودکار RTSS: `%LOCALAPPDATA%\NVRasterPulse\Backups\RTSS`. یک مکان قدیمی `%LOCALAPPDATA%\RTSSProfileBridge` ممکن است برای انتقال خوانده شود. این فایل ها می توانند حاوی مسیرهای اجرایی شخصی باشند و نباید به صورت عمومی ارسال شوند.

<a id="known-limitations"></a>
## محدودیت های شناخته شده

- RTSS درپوش را انجام می دهد. یک مقدار ذخیره شده یا درخواست بارگیری مجدد موفقیت آمیز یک نتیجه زمان فریم اندازه گیری شده نیست.
- فایل های اجرایی هم نام نمایه ای را به اشتراک می گذارند.
- یکی دیگر از محدود کننده های جهانی/در هر بازی می تواند بر نتیجه تأثیر بگذارد. غیرفعال کردن نادیده گرفتن محلی، سرپوش ارثی را حذف نمی کند.
- یک قلاب RTSS که عمداً غیرفعال شده است، غیرفعال می‌ماند.
- انتظار فعال دارای یک مبادله CPU/قدرت است.
- هیچ بازی جهانی، ضد تقلب یا تأیید تأخیر سرتاسری وجود ندارد.
- موتور محدودکننده مستقل تجربی قبلی کامپایل یا ارسال نشده است.
- پشتیبان‌گیری خودکار به معنای یک رابط بازیابی کامل پشتیبان‌گیری با یک کلیک نیست.

<a id="troubleshooting"></a>
## عیب یابی

| علامت | اقدام |
| --- | --- |
| پیش نیاز RTSS همچنان باز است | `RTSS.exe` واقعی و پوشه Profiles مطابق را انتخاب کنید، سپس دوباره بررسی کنید. |
| محدودیت ذخیره شد اما اثری نداشت | RTSS را راه اندازی کنید. EXE/پروفایل صحیح بازی، مجوزهای هوک و سایر محدودکننده‌ها را تأیید کنید. |
| ذخیره ناموفق است | مجوزهای پوشه را بررسی کنید و خطا/پشتیبان نمایش داده شده را حفظ کنید. |
| محدودیت پس از حذف باقی می ماند | RTSS Global و ابزارهای دیگر را بازرسی کنید. عمل سطل زباله فقط نادیده گرفتن محدود کننده های محلی را حذف می کند. |
| دو بازی محدودیت یکسانی دریافت می کنند | بررسی کنید که آیا نام فایل های اجرایی آنها یکسان است یا خیر. |
| Quit + RTSS RTSS را باز می گذارد | RTSS را به طور معمول خودتان ببندید. این دستور عمداً از خاتمه اجباری جلوگیری می کند. |

اگر به صورت دستی یک نسخه پشتیبان RTSS را بازیابی می کنید، ابتدا RTSS را ببندید و نمایه فعلی را قبل از جایگزینی با نسخه پشتیبان مورد نظر حفظ کنید. این می‌تواند ویرایش‌های نمایه نامرتبط را بازنویسی کند. پرونده و تاریخ را بررسی کنید. [پشتیبانی مشترک](../docs/support.md).

<a id="faq"></a>
## سوالات متداول

**آیا من به MSI Afterburner هم نیاز دارم؟** NVRasterPulse به RTSS نیاز دارد. به برنامه Afterburner بستگی ندارد. گزینه های نصب توزیع کننده RTSS را دنبال کنید.

**آیا می توانم بدون اجرای RTSS از آن استفاده کنم؟** پس از شناسایی نصب می توانید نمایه ها را مدیریت کنید، اما RTSS برای محدود کردن باید اجرا شود.

**آیا خروج یا حذف درپوش ها را حذف می کند؟** خیر. قبل از حذف NVRasterPulse، محدودیت های مورد نظر را به صراحت حذف کنید.

**آیا یک fork از RTSS است؟** خیر. این یک مدیر پروفایل مستقل است. هیچ منبع یا فایل اجرایی RTSS گنجانده نشده است.
