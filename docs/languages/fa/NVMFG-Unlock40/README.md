# NVMFG Unlock40

**تجربی NVIDIA Multi Frame Generation برای GeForce RTX 40، با یک کنترلر مرکزی و انتخاب های هر بازی.**

[دانلود 0.1.1 و وضعیت](../docs/downloads.md#nvmfg-unlock40) · [نصب و راه اندازی](#installation) · [بالادست](#upstream-and-modifications) · [مجوزها](LICENSES/README.md)

<a id="overview-and-purpose"></a>
## نمای کلی و هدف

NVMFG Unlock40 یک برنامه مستقل توسعه یافته توسط 禅堂 Zendo (RevoluSound Team) است. این یک کنترلر Windows، یک لایه بومی، یک کمک کننده پروفایل و مدیریت بازی/Streamline SDK را ترکیب می کند. این برنامه بازی‌هایی را هدف قرار می‌دهد که از قبل NVIDIA DLSS Frame Generation و زمان‌های اجرا سازگار NVIDIA را ادغام کرده‌اند.

[RTX40MFG-Unlock](https://github.com/dashdogy/RTX40MFG-Unlock) برای مقایسه و اصلاح کار مورد مشورت قرار گرفت. لایه بومی فعلی شامل اجزای به اشتراک گذاشته شده و سازگار است که به صورت جداگانه در زیر اعتبار داده می شود. این مرجع کل برنامه NVMFG را به یک fork آن پروژه تبدیل نمی کند.

برای هماهنگ کردن رفتار آزمایشی MFG به صورت مرکزی، به خاطر سپردن انتخاب های خاص بازی، و مشاهده به روز رسانی ها و نسخه های پشتیبان در زمان اجرا وجود دارد. DLSS Frame Generation را به هر بازی اضافه نمی کند یا اجرای دلخواه FSR را تبدیل نمی کند.

نامزد آماده شده **0.1.1** است، از جمله تصحیح بصری لیست SDK که در داخل به عنوان UI2 ثبت شده است. نسخه عمومی 0.1.1 باقی می ماند. هش‌های دقیق آن، این نامزد را از ساخت‌های محلی قدیمی‌تر متمایز می‌کند.

<a id="features"></a>
## ویژگی ها

- کنترل مرکزی فعال/غیرفعال و راه اندازی سینی اختیاری Windows.
- انتخاب هر بازی بین Dynamic MFG، تنظیمات بازی و ضریب‌های ثابت پشتیبانی‌شده.
- انتخاب های به خاطر سپرده شده را برای حالت های روشن/خاموش مشاهده شده V-Sync جدا کنید.
- Dynamic از حالت NVIDIA استفاده می کند. هنگامی که V-Sync خاموش است، با یک انتخاب جداگانه در بازی / ثابت به حالت تعلیق در می آید.
- راهنمای منوی بازی و حذف مداوم؛ بازی های بدون DLSS FG در کنترل باقی می مانند.
- کشف بازی، انتخاب پوشه والدین، جستجو، گروه بندی و حذف بدون حذف فایل های بازی.
- دانلود/وارد کردن Streamline SDK، حافظه پنهان محلی تأیید شده، انتخاب صریح، پشتیبان گیری و بازیابی هر بازی.
- تأیید ارائه دهنده بومی، تشخیص در هر جلسه، ژورنال نمایه جهانی و بازیابی آگاه از تضاد.
- 34 زبان رابط و چهار تم.

خاموش کردن FG در بازی باعث خاموش شدن آن می شود. انتخاب های ثابت از 2x تا 6x به بازی / منو / زمان اجرا بستگی دارد. آنها وعده ای نیستند که هر ترکیبی کار کند. کنترلر V-Sync را مشاهده می کند و V-Sync یا VRR را برای کاربر تنظیم نمی کند.

<a id="installation"></a>
## نصب و راه اندازی

1. [وضعیت نامزد و یادداشت مجوز](../docs/downloads.md#nvmfg-unlock40) را بخوانید.
2. `NVMFGUnlock40-0.1.1-Setup-x64.exe` یا `NVMFGUnlock40-0.1.1-Portable-x64.zip` را هنگامی که نسخه آن در دسترس است دانلود کنید.
3. SHA-256 را بررسی کنید و اعلامیه های همراه را نگه دارید. اگر Windows از قبل آن را ارائه نکرده است، NET Framework 4.8 را نصب کنید.
4. Setup را اجرا کنید، یا **کل** ZIP قابل حمل را در یک پوشه محلی قابل نوشتن استخراج کنید.
5. راه اندازی `NVMFGUnlock40.exe`؛ `agent`، `driver`، `engine` و `Licenses` را در طرح‌بندی ارائه شده نگه دارید.

پوشه ای به نام `driver` حاوی کمک کننده های فضای کاربر است، نه یک درایور هسته. فقط EXE اصلی را کپی نکنید یا هش ارائه دهنده را جایگزین نکنید تا سازگاری را مجبور کنید. EXEهای فعلی بدون امضا هستند.

<a id="usage"></a>
## استفاده

1. با غیرفعال بودن کنترلر شروع کنید. یک بازی یا یک پوشه والد اضافه کنید و نصب های واقعی را انتخاب کنید.
2. تنظیمات MFG هر بازی را مرور کنید. به آنچه که منوی آن ارائه می دهد پاسخ دهید. پاسخ در هر بازی ذخیره می شود.
3. Dynamic یا تنظیمات درون‌بازی را در سطح جهانی انتخاب کنید، سپس در صورت نیاز، انتخاب‌های واجد شرایط هر بازی را تنظیم کنید.
4. کنترلر را فقط زمانی فعال کنید که قصد استفاده از آن را دارید. این می تواند به طور موقت شش تنظیمات نمایه جهانی NVIDIA را با یک مجله بازیابی تغییر دهد.
5. یک بازی واجد شرایط را راه اندازی کنید و DLSS Frame Generation خودش را فعال کنید. هر درخواستی را برای انتخاب V-Sync-off دنبال کنید.
6. برای بازی‌هایی که نمی‌خواهید مدیریت شوند، از موارد استثنا استفاده کنید. حذف یک بازی یک استثنا را ثبت می کند و فایل ها/پشتیبان های آن را حفظ می کند.
7. پس از اتمام، از خروج/غیرفعال کردن کامل برنامه و جریان بازیابی استفاده کنید.

بستن پنجره اصلی می تواند کنترل کننده را در سینی باقی بگذارد. یک DLL که قبلاً در یک بازی بارگذاری شده است تا زمان خروج از بازی در آنجا باقی می ماند. غیرفعال کردن کنترلر یک ضمانت تخلیه نیست. بازی‌های آسیب‌دیده را قبل از نگهداری یا به‌روزرسانی ببندید.

**Streamline SDKs:** در صفحه NVIDIA SDK، یک نسخه رسمی را دانلود کنید یا یک SDK محلی سازگار وارد کنید. Import یک نسخه تأیید شده را ذخیره می کند. **Use this version** آن را انتخاب می کند و **Uninstall** آن کپی ذخیره شده را حذف می کند. DLL های موجود Streamline را می توان از یک NVIDIA SDK رسمی تکمیل کرد و منبع نشان داده شده است. این یک مدل NGX را دانلود یا جایگزین نمی کند. بازی را ببندید، آپدیت بازی مورد نظر را انتخاب کنید و نسخه پشتیبان اصلی آن را حفظ کنید. برای برگرداندن فایل‌های بازی، از بازیابی پشتیبان آن استفاده کنید، نه از دکمه Uninstall حافظه پنهان.

<a id="update-and-uninstall"></a>
## به روز رسانی و حذف نصب کنید

بازی های تحت تاثیر را ببندید. NVMFG را غیرفعال/ترک کنید و هرگونه بازیابی تنظیمات NVIDIA معلق را قبل از به‌روزرسانی حل کنید. Setup بعدی را با هویت موجود نصب کنید، یا قابل حمل جدید را در یک پوشه تازه استخراج کنید. حفظ وضعیت/پشتیبان گیری

قبل از حذف، نسخه های پشتیبان بازی مورد نظر SDK و تنظیمات NVIDIA را از طریق برنامه بازیابی کنید، سپس بازی ها را ببندید و از کنترلر خارج شوید. از Windows **Installed apps** برای راه اندازی استفاده کنید، یا پس از حفظ فایل های مورد نیاز، پوشه قابل حمل بسته را حذف کنید. برای رفع انسداد Setup، یک ژورنال بازیابی فعال را به صورت دستی حذف نکنید.

پشتیبان‌گیری‌های محلی در زمان اجرای بازی از `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups` استفاده می‌کنند. تنظیمات MFG/داده SDK از `%LOCALAPPDATA%\RtxMfg` استفاده می کند. خروجی جلسه تحت `Sessions` در کنار برنامه است. این فایل ها می توانند شامل مسیرهای بازی باشند. آنها را بدون ویرایش پست نکنید.

<a id="known-limitations"></a>
## محدودیت های شناخته شده

- وصله های بومی تجربی می توانند باعث خرابی یا مصنوعات بصری شوند. یک خرابی حل نشده Bodycam در تاریخچه توسعه ثبت شده است.
- تست های رندر کنترل شده گواهی برای هر بازی، راننده یا ضد تقلب نیست.
- فریم های تولید شده نمونه های ورودی جدیدی ایجاد نمی کنند. هیچ تأخیر اندازه گیری شده یا افزایش عملکرد توسط این هاب وعده داده نشده است.
- ابزارها/روکش‌های چندگانه تولید فریم ممکن است تضاد داشته باشند. برنامه برنامه ماژول ها را بدون اثبات هر سناریوی همزیستی گزارش می دهد.
- مانیفست سازگاری یک کمک تشخیص است، نه لیستی از بازی های کاملاً آزمایش شده.
- شرایط کامل NVIDIA SDK و محدودیت محدودیت فنی حل نشده همچنان در [منشأ](../docs/provenance.md) ثبت شده است.

<a id="faq"></a>
## سوالات متداول

** آیا شامل DLL ها یا مدل های NVIDIA می شود؟** هیچ راننده، ارائه دهنده/مدل NGX یا زمان اجرا Streamline گنجانده نشده است. دانلودهای صریح SDK از NVIDIA می آیند.

**آیا Dynamic با V-Sync خاموش کار می کند؟** در آن حالت به حالت تعلیق درآمده است. تنظیمات درون بازی یا یک ضریب ثابت واجد شرایط را برای حالت جداگانه آن بازی انتخاب کنید.

**آیا این یک بسته ReShade/OptiScaler/FSR است؟** خیر. این بسته ها به عنوان بخشی از این بسته تولیدی کامپایل یا ارسال نشده اند.

**آیا منابع اصلاح شده عمومی هستند؟** خیر. بسته های تدوین شده و اعتبار/مجوزهای مورد نیاز ارائه شده است. این حقوق یا محدودیت های اشخاص ثالث را حذف نمی کند.

## بالادست و تغییرات

مقایسه منبع، وصله‌های مشترک، مدیریت ارائه‌دهنده/خط‌مشی، اصلاحات زمانی و اجزای انحرافی مبتنی بر MinHook را شناسایی می‌کند. اعلامیه های MIT و BSD آنها حفظ می شود. مقایسه کامل شامل فایل های خارج از هدف تولید نیز می شود.

برنامه دسکتاپ، کنترلر و گردش کار مدیریت SDK توسط 禅堂 Zendo (RevoluSound Team) توسعه داده شده است. کار پروژه شامل بارگذاری مرکزی، ادغام بوت استرپ NGX، انتخاب ارائه دهنده تایید شده، هماهنگی بازی/V-Sync و تشخیص جلسه است. راهنمای منشأ آن کار را از اجزای مشترک جدا می کند. مقایسه فایل به تنهایی مشخص نمی کند که کدام یک از نویسندگان این ایده را داشته اند.
