# NV Laboratory

**NV Tools توسط 禅堂 Zendo (RevoluSound Team).** چهار ابزار مستقل Windows برای پروفایل های درایور NVIDIA، نصب درایور، محدودیت های فریم آزمایشی Multi Frame Generation و RTSS.

[ابزار را دریافت کنید](docs/downloads.md) · [نصب و راه اندازی](docs/installation.md) · [سازگاری و کمک](docs/support.md) · [اعتبارات و مجوزها](THIRD_PARTY_NOTICES.md)

> **NVRasterPulse به RTSS نیاز دارد.** ابتدا [RivaTuner Statistics Server از Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) را نصب کنید. RTSS باید در حال اجرا باشد تا محدودیت های FPS آن کار کند. به صورت جداگانه دانلود می شود.

<a id="start-here"></a>
## از اینجا شروع کنید

1. یکی از ابزارهای بالا را انتخاب کنید. هر کدام به طور مستقل کار می کنند. نصب کل مجموعه غیر ضروری است.
2. الزامات آن را بخوانید و **Setup** را برای یک برنامه نصب شده یا **قابل حمل** را برای یک پوشه جداگانه انتخاب کنید.
3. هنگامی که انتشار آن منتشر شد، دارایی برنامه نامگذاری شده را دانلود کنید، اطلاعیه های همراه را بخوانید و SHA-256 آن را مقایسه کنید.
4. قبل از تغییر درایور، تنظیمات نمایشگر، نمایه NVIDIA یا زمان اجرای بازی، نسخه پشتیبان تهیه کنید.

مستندات به همان 34 زبان برنامه های NV از طریق انتخابگر در بالای هر راهنما در دسترس است. GitHub به طور خودکار یک README را بر اساس زبان مرورگر انتخاب نمی کند. زبان اسناد و تنظیمات زبان خود برنامه جداگانه هستند.

<a id="provenance-and-ownership"></a>
## منشأ و مالکیت

این مرکز اسناد و برنامه های کاربردی را توزیع می کند. کد منبع برنامه به صورت خصوصی نگهداری می شود. پروژه های بالادستی نویسندگی و مجوزهای خود را حفظ می کنند. توزیع منبع خصوصی جایگزین آن شرایط نمی شود.

- Profile Inspector fork مجوز MIT Orbmu2k را حفظ می کند و به صراحت به عنوان fork شناخته می شود.
- NVDriverForge شرایط توزیع باینری خاص خود را دارد و شامل اجزای زمان اجرا/ابزار دارای مجوز جداگانه است.
- NVMFG Unlock40 یک برنامه مستقل توسعه یافته است. RTX40MFG-Unlock برای مقایسه و اصلاح مورد مشورت قرار گرفت. اجزای بومی مشترک اعتبار MIT خود را حفظ می کنند. شرایط MinHook و NVIDIA SDK جداگانه باقی می مانند.
- NVRasterPulse مجوز MIT ارائه شده را حفظ می کند و به رابط کاربری مشتق شده از Profile Inspector اعتبار می دهد. RTSS یک برنامه خارجی مورد نیاز است.

[جدول اجزای کامل](THIRD_PARTY_NOTICES.md)، [منشا و تغییرات فایل](docs/provenance.md) و [محدوده مجوز](../../../LICENSE) را ببینید.
