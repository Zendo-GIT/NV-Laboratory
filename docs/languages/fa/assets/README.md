# اعتبارات دارایی

این تصاویر از برنامه‌ها یا راه‌اندازی در 09/09/2026 گرفته شده‌اند و قبل از گنجاندن به صورت بصری بررسی شده‌اند. آنها پیش نمایش های رابط ویرایش نشده هستند. پیش نمایش های برنامه از داده های نمونه مصنوعی استفاده می کنند. ضبط راه‌اندازی از یک آزمایش خصوصی است که قبل از نصب لغو شده است. این تصاویر سازگاری درایور/SDK، نتایج محک یا یک بازی در حال اجرا را ایجاد نمی کنند.
