<a id="nvdriverforge"></a>
# NVDriverForge

**نصب درایور NVIDIA را با انتخاب اجزای واضح و تنظیمات اختیاری آماده کنید.**

[دانلود 0.1.4 و وضعیت](../docs/downloads.md#nvdriverforge) · [نصب و راه اندازی](#installation) · [اعتبارات](#credits-and-upstream) · [مجوز](../../../../NVDriverForge/LICENSE)

<a id="overview-and-purpose"></a>
## نمای کلی و هدف

NVDriverForge شما را از طریق بسته درایور اصلی NVIDIA راهنمایی می کند: درایور را انتخاب کنید، اجزای آن را بررسی کنید، ترفندهای اختیاری را بررسی کنید، سپس نصب را تأیید کنید. وجود دارد تا آن انتخاب ها را قابل درک کند و اطلاعات نصب، عملیات ممتاز و بازیابی را در کنار هم نگه دارد.

این یک برنامه مستقل توسعه یافته است که تا حدی از گردش کار NVCleanstall الهام گرفته شده است. این شامل NVCleanstall یا ادعای برابری کامل ویژگی نیست.

<a id="features"></a>
## ویژگی ها

- جستجو و دانلود NVIDIA Game Ready / Studio. کشف رفع فوری اختیاری با بازگشت دستی.
- تجزیه و تحلیل بسته اصلی، هش ها، امضاهای NVIDIA، مانیفست ها و ورودی های INF سازگار.
- انتخاب مولفه با وابستگی و حفظ اجزای ناشناخته.
- نسخه 0.1.4 اجزای انتخابی انتخابی NVIDIA را قابل رد شدن نگه می‌دارد و فقط مؤلفه‌های تأیید نشده بررسی نشده را از کشف مستثنی می‌کند. زمان‌های اجرا اختیاری از قبل فعلی یا غیرقابل اجرا دیگر به عنوان اجزای حیاتی اجباری نیستند.
- خلاصه‌های خرابی نصب را پاک کنید و به گزارش‌های دقیق در تمام ۳۴ زبان دسترسی داشته باشید.
- بررسی آمادگی، تأیید صریح، صادرات درایور فروشگاه و پشتیبان‌گیری از نمایه NVIDIA قبل از نصب.
- تنظیمات پیشرفته اختیاری، با چک های قبل از پرواز، مجلات و بازیابی آگاه از تعارض.
- اختیاری **Custom NV** از پیش تنظیم شده با گزینه ها و توضیحات نامگذاری شده، از جمله انتخاب قدرت جداگانه و بررسی سازگاری SILK.
- دانلود نسخه دقیق NVENC اختیاری. منبع commit و بایت های هدف بررسی می شوند.
- نصب جداگانه و اختیاری Profile Inspector fork از صفحه ابزار.
- راهنمای مؤلفه، اولویت‌های قابل استفاده مجدد، کیت‌های درایور، گزارش‌های پشتیبانی محلی و به‌روزرسانی‌های اختیاری برنامه‌ها.
- 34 زبان رابط و چهار تم.

گزینه های پیشرفته موجود مربوط به MPO، نشانگر DLSS، Ansel، خواب صوتی NVIDIA، MSI، خط مشی/اولویت وقفه، HDCP، راه اندازی کانتینر نمایشگر و سرویس تله متری قدیمی واجد شرایط است. هر کدام پیش نیازها و آثار خاص خود را دارند. اینها بهبود عملکرد جهانی نیستند.

## سازگاری

| مورد نیاز | جزئیات |
| --- | --- |
| سیستم | Windows 10 ساخت 19041 یا جدیدتر / Windows 11، x64 |
| GPU/درایور | بسته NVIDIA سازگار و سخت افزار شناسایی شده؛ جستجوی خودکار کاتالوگ در درجه اول مدل های شناخته شده GeForce را پوشش می دهد |
| زمان اجرا | .NET 8 / WPF 8.0.31 موجود در بسته خود شامل آماده شده |
| امتیازات | تنظیم رابط کاربری عادی/هر کاربر؛ نصب درایور و تغییرات سیستم درخواست دسترسی مدیر |
| شبکه | برای جستجو/دانلودهای آنلاین NVIDIA و درخواستهای صریح بالادست NVENC مورد نیاز است. یک درایور اصلی محلی را می توان انتخاب کرد |
| ابزار گنجانده شده است | 7-Zip 26.03 اصلاح نشده، اطلاعیه‌های زمان اجرا، همراه اختیاری MIT Profile Inspector |

هیچ نسخه حداقل درایور دلخواه تمام ویژگی ها را پوشش نمی دهد. جستجوی چند GPU باید با هر GPU شناسایی شده مطابقت داشته باشد. مدل‌های پشتیبانی‌نشده/حرفه‌ای ممکن است به انتخاب دستی درایور نیاز داشته باشند. نصب کننده NVIDIA همچنان مرجع نهایی سخت افزار/OS است.

<a id="installation"></a>
## نصب و راه اندازی

1. از [دانلودها](../docs/downloads.md#nvdriverforge) دیدن کنید و تأیید کنید که انتشار منتشر شده است.
2. `NVDriverForge-Setup.exe` را برای نصب یا `NVDriverForge.exe` را برای استفاده قابل حمل انتخاب کنید.
3. SHA-256 را با `SHA256SUMS.txt` نسخه Release مقایسه کنید.
4. Setup را برای نصب هر کاربر و Uninstaller استاندارد اجرا کنید یا EXE قابل حمل را در یک پوشه قابل نوشتن قرار دهید و آن را باز کنید.

قابل حمل شامل زمان اجرا و نصب کننده اختیاری آن است. نصب NVDriverForge درایور GPU را نصب نمی کند. EXE های آن در حال حاضر بدون امضا هستند.

<a id="usage"></a>
## استفاده

1. **درایور:** از NVIDIA دانلود کنید یا یک EXE نصب کننده اصلی NVIDIA را انتخاب کنید. بگذارید تحلیل تمام شود.
2. ** اجزاء: ** توضیحات و وابستگی های مورد نیاز را بررسی کنید. اجزای ناشناخته حفظ می شوند.
3. **ترفندها:** گزینه های ناخواسته را بدون تغییر رها کنید. قبل از انتخاب هر چیزی، جلوه ها و مبادلات را بخوانید.
4. **بازبینی:** درایور دقیق، اجزاء و عملیات اختیاری را بررسی کنید، سپس نصب را تایید کنید.
5. UAC را فقط برای عملیاتی که انتخاب کردید بپذیرید. دستورالعمل های بازیابی کار محافظت شده را حفظ کنید.
6. اگر درایور جدید نیاز به راه اندازی مجدد دارد، وضعیت گزارش شده را دنبال کنید. عملیات به تعویق افتاده نیاز به رزومه صریح پس از آن راه اندازی مجدد دارد.

Custom NV بدون تغییر شروع می شود. مقادیر نام‌گذاری شده را انتخاب کنید یا پیش‌تنظیمات ارائه شده و موارد استثنای آن را مرور کنید. دو زمینه داخلی اطلاعاتی آن به طور مستقل نوشته نشده اند. تنظیمات فقط در گردش کار تأییدشده درایور جدید اعمال می‌شوند و هرگز با باز کردن پیش‌نمایش انجام نمی‌شوند. نصب ویرایشگر جداگانه NVPI لازم نیست.

کار اختیاری NVENC داده های سازگار را از یک commit پین شده keylase دانلود می کند. این دو DLL درایور را تغییر می دهد و امضای آنها را باطل می کند. می توان آن را توسط Windows، رمزگذار، DRM یا ضد تقلب رد کرد. چنین داده یا NVIDIA DLL در NVDriverForge تعبیه نشده است. [حدود منشا و مجوز](../docs/provenance.md).

تنظیمات برگزیده، زبان، طرح زمینه و بررسی به‌روزرسانی اختیاری کاربر نصب‌شده را کنترل می‌کنند. قابل حمل وظیفه بررسی پس زمینه نصب شده را ایجاد نمی کند. ابزارها و بازیابی جدا از چهار مرحله نصب هستند.

<a id="backup-and-diagnostic-tools"></a>
## ابزارهای پشتیبان گیری و تشخیصی

**قبل از نصب:** بررسی های آمادگی امضای بسته، پردازنده های گرافیکی، فضای کاری تخمینی/فضای پشتیبان، راه اندازی مجدد در انتظار و نصب کنندگان رقیب را پوشش می دهد. کارگر مرتفع آنها را تکرار می کند. فرآیندهای رقابتی هرگز به طور خودکار متوقف نمی شوند. پیش از شروع راه‌اندازی NVIDIA، پشتیبان‌گیری پایگاه داده نمایه NVIDIA بومی باید انجام شود. صادرات درایور فروشگاه یک نسخه پشتیبان جداگانه است.

**گزینه های قابل استفاده مجدد:** راهنمای مؤلفه چهار سؤال در مورد بازی ها، صدا، NVIDIA App و ضبط می پرسد. پیشنهادات آن را مرور کنید؛ اجزای مورد نیاز، ناشناخته و وابستگی محافظت می شوند. تنظیمات برگزیده را صادر کنید، سپس هنگام وارد کردن، آنها را در برابر بسته انتخابی پیش نمایش و اعتبارسنجی مجدد کنید. رضایت‌ها، عملیات راه‌اندازی مجدد، مسیرهای برنامه و بارهای وصله وارد نمی‌شوند.

** کیت درایور: ** یک `.nvdfkit.zip` صادر کنید تا نصب کننده اصلی امضا شده NVIDIA، انتخاب ها، هش ها و دستورالعمل ها را با هم نگه دارید. `NVDriverForge.exe` را جداگانه حمل کنید. کیت را در Tools وارد کنید، پیش‌نمایش را مرور کنید، سپس از گردش کار نصب معمولی استفاده کنید. این یک درایور باریک یا نصب کننده مستقل اصلاح شده نیست. NVENC اختیاری همچنان به دانلود و رضایت برای آن درایور دقیق نیاز دارد. شرایط توزیع مجدد NVIDIA همچنان اعمال می شود.

**نتایج و پشتیبانی:** نتیجه کوتاه را بخوانید و جزئیات هر مرحله/در هر گزینه را گسترش دهید. بازخوانی موفقیت آمیز یک مقدار ذخیره شده ایجاد می کند، نه یک بهبود اندازه گیری شده. گزارش پشتیبانی محلی JSON از فیلدهای مجاز، از جمله آخرین کار ذخیره شده پس از راه اندازی مجدد برنامه استفاده می کند. قبل از ذخیره یا اشتراک گذاری آن را پیش نمایش کنید. این شامل هیچ گزارش خام، محتویات نمایه یا شناسه های سخت افزاری نیست و هرگز به صورت خودکار آپلود نمی شود.

**بازیابی:** راهنمای کار محافظت شده را دنبال کنید تا درایور پشتیبان‌گیری شده را بازیابی کنید. بازیابی نمایه صریح به نسخه اصلی درایور و همان GPU نیاز دارد. کل پایگاه داده را جایگزین می کند، یک نسخه فعلی را حفظ می کند و هش ها و وضعیت تضاد را بررسی می کند. ژورنال آن را پاک نکنید یا مجبور به عدم تطابق آن نکنید. نصب درایور واقعی، بازیابی کامل و وارد کردن نمایه بومی با این گردش کار جدید در یک سیستم واقعی بدون اعتبار باقی می‌ماند.

**به‌روزرسانی‌های برنامه:** یادداشت‌های انتشار را بخوانید، سپس صریحاً یک دانلود تأیید شده با SHA-256 را انتخاب کنید. بررسی به طور پیش‌فرض دستی است و در هنگام راه‌اندازی یک بررسی اختیاری انجام می‌شود. هیچ نصب کننده ای به طور خودکار شروع نمی شود. این ویژگی جدا از بررسی‌های به‌روزرسانی درایور و بررسی اختیاری درایور نسخه نصب‌شده است.

<a id="update-and-uninstall"></a>
## به روز رسانی و حذف نصب کنید

NVDriverForge را ببندید، بسته رسمی بعدی را دریافت کنید و هش آن را تأیید کنید. برای به‌روزرسانی نصب‌شده از همان هویت راه‌اندازی استفاده کنید. یک EXE قابل حمل بسته را با EXE جدید جایگزین کنید. تنظیمات و مشاغل محافظت شده را حفظ کنید.

Uninstall از Windows **Installed apps**. این برنامه و وظیفه به روز رسانی آن را حذف می کند، نه درایور NVIDIA. تنظیمات، گزارش‌ها و نسخه‌های پشتیبان باقی می‌مانند. در صورت تمایل، تغییرات پیشرفته/NVENC را از طریق جریان بازیابی مستند **قبل از** حذف برنامه بازیابی کنید. بازیابی تغییرات متناقض را از ابزار دیگری رد می کند.

داده های محلی تحت `%LOCALAPPDATA%\NVDriverForge` هستند. مشاغل محافظت شده و صادرات راننده تحت `%PROGRAMDATA%\NVDriverForge\Jobs` هستند. استفاده قابل حمل همچنین داده های محلی را ایجاد می کند. صادرات درایور فروشگاه و نسخه پشتیبان نمایه بومی جدا هستند. تصویر سیستمی هم نیست.

<a id="known-limitations"></a>
## محدودیت های شناخته شده

- بدون افزودن سخت افزار/ویرایش INF، امضاهای بازسازی شده NVIDIA، استعفای سازگار با تقلب یا پذیرش خودکار هشدار بدون امضا.
- بدون حذف کامل تله متری/تبلیغات، صادرات بسته باریک یا بازگشت کامل خودکار به درایور قبلی.
- نصب درایور، بازیابی بوت و نوشتن مشخصات اختیاری به طور جامع بر روی ماشین‌های واقعی توسط ممیزی هاب تأیید نشده است.
- بازخوانی رجیستری دلیلی بر HDCP واقعی، عملکرد یا اثرات تأخیر نیست.
- چک‌های امضا از اعتماد Windows در دسترس محلی استفاده می‌کنند. ابطال آنلاین انجام نمی شود.
- 34 زبان موجود است، اما تست کامل زبان مادری/دسترسی ناقص باقی مانده است.

| امضا / هش / شکست پشتیبان | نصب را متوقف کنید و خطا را حفظ کنید. در صورت خرابی بسته اصلی را دوباره دریافت کنید. |
| گزینه در دسترس نیست | دلیل سخت افزار، جزء یا هدف-درایور آن را بخوانید. آن را بدون تغییر نگه دارید |
| راه اندازی مجدد یا کار هنوز در انتظار است | از دستورالعمل های بازیابی کار و رزومه صریح استفاده کنید. دفترش رو پاک نکن |
| بازگرداندن تضاد | حالت دیگر با تراکنش ثبت شده متفاوت است. آن را حفظ کنید و به جای بازیابی اجباری، درخواست کمک کنید. |

برای گزارش‌ها، نسخه ابزار انتخابی، Windows، GPU، درایور و مراحل قابل تکرار را شامل شود. مسیرها و جزئیات شخصی را از سیاههها حذف کنید. [پشتیبانی کنید](../docs/support.md).

<a id="faq"></a>
## سوالات متداول

**آیا راه‌اندازی درایور گرافیک نصب می‌کند؟** خیر. این نیاز به تجزیه و تحلیل، بررسی، تأیید و فرآیند نصب بالاتر برنامه دارد.

** آیا به NVCleanstall یا NVPI نیاز دارم؟** نه. NVCleanstall فقط الهام بخش است. همراه Profile Inspector یک ویرایشگر اختیاری مستقل است.

**آیا هر درایور NVIDIA را کوچکتر یا سریعتر می کند؟** خیر. اجزای انتخاب شده و پیش نیازها تعیین می کنند که چه چیزی می تواند تغییر کند. هیچ سود اندازه گیری شده وعده داده نمی شود.

**منابع کجا هستند؟** تست های منبع خاص برنامه و خصوصی به طور جداگانه نگهداری می شوند. این مرکز اسناد، باینری ها و پیوندهای منبع شخص ثالث مورد نیاز برای انتساب/مجوز را فراهم می کند.
