<a id="changelog"></a>
# تغییرات

این هاب [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) را دنبال می کند. نسخه های برنامه و تاریخ انتشار مستقل هستند. بسته های آماده شده در زیر تاریخ انتشار واقعی خود را در نسخه های GitHub مربوطه خود دریافت می کنند.

<a id="unreleased"></a>
## [منتشر نشده]

<a id="changed"></a>
### تغییر کرد

- هاب و تمام 34 زبان اسناد را برای NVDriverForge 0.1.4 بازخوانی کنید،
NVMFG Unlock40 0.2.3 و NVRasterPulse 0.2 تهیه شده در تاریخ 2026-09-18.
- NVDriverForge: بررسی های آمادگی، پشتیبان گیری از پروفایل بومی و بازیابی محافظت شده،
راهنمای مؤلفه، اولویت‌های قابل استفاده مجدد، کیت‌های درایور، نتایج دقیق، گزارش‌های پشتیبانی محلی و به‌روزرسانی‌های برنامه جداگانه.
- NVMFG: کشف چند پوشه، حافظه پنهان کتابخانه پایدار، فعالیت MFG مشاهده شده،
اطلاعات قابلیت زمان اجرا، حذف راه اندازی بعدی، تشخیص محلی، انتقال اولویت و به روز رسانی اختیاری برنامه.
- NVRasterPulse: تشخیص پیکربندی، پیشنهادات FPS، مکث/رزومه،
لغو یک سطحی، واردات/صادرات انتخابی نمایه، موارد دلخواه و ورودی های پنهان.
- هش های بسته، یادداشت های انتشار و نقشه منشأ مؤلفه بومی را به روز کنید.
دارایی های منتشر شده Profile Inspector 3.0.2.3/setup-r2 را بدون تغییر نگه دارید.

<a id="fixed"></a>
### ثابت شد

- انتخاب/شمارش بازی NVMFG، مدیریت Ctrl+D و پیام‌های پیشرفت کامل؛
Wallpaper Engine از تشخیص بازی مستثنی است. انسداد بازیابی 0.1.1 گزارش شده جداگانه تکرار نشده است و ادعا نمی شود که ثابت شده است.

<a id="initial-public-hub--2026-09-10"></a>
## [مرکز عمومی اولیه] – 10-09-2026

<a id="added"></a>
### اضافه شد

- چهار راهنمای پروژه و اسناد مخزن به 34 زبان، با
انتخابگرهای حفظ صفحه، لنگرهای پایدار و ابرداده پوشش ترجمه.
- اعتبارات مؤلفه، مجوزهای اصلی، منشأ، الزامات RTSS و
پیوندهای RevoluSound Team جداگانه.
- بسته های انتشار دستی، مقادیر SHA-256، فرم های صدور، خط مشی امنیتی و
اعتبار اسنادی فقط خواندنی منابع برنامه خصوصی باقی می مانند.
- اولین برچسب های عمومی: `nvpi-v3.0.2.3`، `nvdriverforge-v0.1.3`،
`nvmfg-unlock40-v0.1.1` و `nvrasterpulse-v0.1`.

<a id="included-fixes"></a>
### شامل رفع

- نسخه 2 نصب کننده Profile Inspector: انتخابگر 34 زبانه مستقل.
ویرایشگر و محموله قابل حمل بدون تغییر.
- NVDriverForge 0.1.3: مدیریت اجزای اختیاری تصحیح شده و بومی سازی شده
خلاصه شکست، با زمان اجرا به روز و بسته بندی همراه.

تاریخ های بالا، تاریخچه هاب عمومی تأیید شده هستند، نه تاریخ های توسعه بازسازی شده.
