<a id="changelog"></a>
# تغییرات

این هاب [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) را دنبال می کند. مدخل ها این مخزن را توصیف می کنند. نسخه های برنامه مستقل هستند.

<a id="unreleased"></a>
## [منتشر نشده]

<a id="added"></a>
### اضافه شد

- هاب، راهنماهای پروژه کامل و اسناد مخزن به 34 زبان برنامه NV.
- انتخابگرهای زبان حفظ صفحه، فراداده پوشش ترجمه و لنگرهای داخلی پایدار.
- اعتبارات بالادستی، اعلامیه های قابل اجرا کامل و منشأ پرونده.
- نیاز RTSS و لینک دانلود رسمی برای NVRasterPulse.
- پیوندهای RevoluSound Team را جدا کنید.
- کاتالوگ بسته انتشار اول، تأیید SHA-256 و روش انتشار دستی آماده شده است.
- اشکال/ویژگی فرم ها، کمک و دستورالعمل های امنیتی.
- اسناد فقط خواندنی و بررسی های مرزی انتشار.

<a id="changed"></a>
### تغییر کرد

- انتساب NVMFG اکنون برنامه توسعه یافته مستقل را متمایز می کند،
مرجع مقایسه/تصفیه، و اجزای اصلی مشترک واقعی.   حق چاپ موجود، مجوزها و مقایسه فایل ها دست نخورده باقی می مانند.
- کاندید NVDriverForge به 0.1.3 به روز شد: مدیریت مولفه اختیاری اصلاح شد،
خطاهای محلی قابل خواندن و زمان اجرا/ بسته بندی همراه به روز شده.

<a id="fixed"></a>
### ثابت شد

- نسخه 2 راه اندازی NVIDIA Profile Inspector – NV Tools Fork اکنون به اشتراک گذاشته شده را نشان می دهد
انتخابگر 34 زبان هنگام راه اندازی مستقیم. زبان صریح و ارسال بی صدا حفظ می شود. ویرایشگر و بسته قابل حمل بدون تغییر هستند.

هیچ تاریخ انتشار عمومی تاریخی بازسازی نشده است. نسخه های برنامه کاندید عبارتند از 3.0.2.3، 0.1.3، 0.1.1 و 0.1. یادداشت های انتشار آنها به نسخه های آینده خود پیوست شده است. آماده سازی در 09-09-2026 تاریخ انتشار GitHub نیست.
