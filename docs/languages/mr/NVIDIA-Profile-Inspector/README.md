# NVIDIA Profile Inspector – NV Tools Fork

**[NVIDIA Profile Inspector द्वारे Orbmu2k](https://github.com/Orbmu2k/nvidiaProfileInspector) चा स्वतंत्र fork, जोडलेल्या डिस्प्ले नियंत्रणांसह.** पूर्वीचे प्रकल्प नाव: **NVPI Custom**.

[डाउनलोड करा आणि रिलीझ स्थिती](../docs/downloads.md#nvidia-profile-inspector) · [स्थापना](#installation) · [अपस्ट्रीम आणि बदल](#upstream-and-changes) · [परवाना](../../../../NVIDIA-Profile-Inspector/LICENSE)

<a id="overview"></a>
## विहंगावलोकन

ॲप्लिकेशन NVIDIA ड्रायव्हर प्रोफाइल संपादित करते, प्रति-अनुप्रयोग सेटिंग्जसह. हे fork सक्रिय Windows डिस्प्लेसाठी **स्क्रीन** संपादक देखील जोडते: रिझोल्यूशन, रिफ्रेश रेट, आउटपुट रंग सेटिंग्ज, HDR आणि स्थापित ICC/WCS प्रोफाइल असोसिएशन.

प्रोफाइल एडिटरमध्ये संबंधित प्रदर्शन नियंत्रणे आणण्यासाठी आणि पूर्वावलोकन, पुष्टीकरण आणि पुनर्संचयित परिणाम स्पष्ट करण्यासाठी ते अस्तित्वात आहे. हे नवीन हार्डवेअर क्षमता स्थापित करत नाही.

पहिला उमेदवार **3.0.2.3** आहे, जो 9 सप्टेंबर 2026 पासून क्लीन केलेला स्टँडअलोन कंपेनियन बिल्ड वापरत आहे. त्याची विद्यमान एक्झीक्यूटेबल `nvidiaProfileInspector.exe` आहे; इंस्टॉलर आणि काही अंतर्गत लेबल अजूनही `NVPI Custom NV` म्हणतात. वरील सार्वजनिक शीर्षक इंस्टॉलेशन ओळख न बदलता किंवा Orbmu2k चे अधिकृत प्रकाशन असल्याचे भासवल्याशिवाय fork ओळखते.

<a id="features"></a>
## वैशिष्ट्ये

- विद्यमान अपस्ट्रीम प्रोफाइल ब्राउझिंग, ऍप्लिकेशन असोसिएशन, सेटिंग संपादने आणि प्रोफाइल आयात/निर्यात.
- डिस्प्ले, मोड, Hz, RGB/YCbCr, कलर डेप्थ, रेंज आणि कलरमेट्रीसाठी **स्क्रीन** संवाद.
- Windows HDR नियंत्रण आणि स्थापित ICC/WCS असोसिएशन निवड.
- **कीप** / **परत** आणि कालबाह्य पुनर्संचयनासह 15-सेकंद प्रदर्शन पूर्वावलोकन.
- मोड/HDR चे रीड-बॅक बदल आणि पुनर्संचयित अपयशाची तक्रार नोंदवली.
- HDR चे वेगळे रिपोर्टिंग, ACM/WCG सह SDR आणि सिग्नल कलर डेप्थ.
- स्वतंत्रपणे स्थापित केलेल्या पात्र प्रतीसाठी NVRasterPulse लाँचर.

| प्रणाली | Windows 10/11 x64 सुसंगत NVIDIA ड्राइव्हरसह |
| रनटाइम | [.NET फ्रेमवर्क 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48), Windows द्वारे पुरवलेले किंवा स्वतंत्रपणे स्थापित केलेले |

| दाखवतो | वास्तविक मोड आणि रंग संयोजन GPU, ड्राइव्हर, डिस्प्ले, केबल आणि Windows API वर अवलंबून असतात |
| पर्यायी साधने | RTSS मर्यादा व्यवस्थापनासाठी NVRasterPulse; स्क्रीन एडिटरसाठी ते किंवा RTSS ची गरज नाही |
| भाषा | सेटअप: 34-भाषा निवडक. संपादकाने त्याचे विद्यमान भाषा समर्थन कायम ठेवले आहे. |

प्रत्येक GPU साठी कोणतेही सत्यापित युनिव्हर्सल ड्रायव्हर किमान किंवा समर्थन मॅट्रिक्स नाही. डायलॉगचे उपलब्ध bpc पर्याय विनंत्या आहेत, प्रमाणित संयोजन नाहीत. आधुनिक HDR नियंत्रणे आणि जुन्या Windows फॉलबॅकमध्ये भिन्न क्षमता आहेत.

<a id="installation"></a>
## स्थापना

1. [डाउनलोड पृष्ठ](../docs/downloads.md#nvidia-profile-inspector) उघडा आणि प्रकाशन स्थिती तपासा.
2. सेटअप किंवा पोर्टेबल मालमत्ता डाउनलोड करा आणि त्याची SHA-256 रिलीझ मॅनिफेस्टशी तुलना करा.
3. सेटअपसाठी, `NVPI-CustomNV-3.0.2.3-Setup-r2.exe` चालवा, भाषा निवडा आणि इंस्टॉलरचे अनुसरण करा. तो स्वतःचा शॉर्टकट आणि अनइन्स्टॉलर तयार करतो.
4. पोर्टेबलसाठी, नवीन लिहिण्यायोग्य फोल्डरमध्ये संपूर्ण ZIP काढा. `Reference.xml`, EXE कॉन्फिगरेशन आणि सर्व सूचना एक्झिक्युटेबलच्या बाजूला ठेवा.
5. `nvidiaProfileInspector.exe` लाँच करा.

केवळ संपादक स्थापित केल्याने प्रोफाइल लागू होत नाही किंवा GPU ड्राइव्हर स्थापित होत नाही. सहचर स्वतंत्रपणे स्थापित करतो, `.nip` असोसिएशन घेत नाही आणि साइन इन करताना स्टार्टअप सक्षम करत नाही. विद्यमान बायनरी स्वाक्षरी नसलेल्या आहेत.

<a id="usage"></a>
## वापर

**इंस्टॉलर पुनरावृत्ती 2** इतर साधनांप्रमाणेच मूळ 34-भाषा निवडक जोडते, माऊस/कीबोर्ड नेव्हिगेशन, प्रकाश/गडद देखावा आणि रद्द करणे. निवड सेटअपवर लागू होते; ते NVPI संपादकाचे भाषांतर करत नाही. एक सुस्पष्ट `/LANG=fr` युक्तिवाद किंवा सायलेंट मोड आधीपासून भाषा प्रदान करणाऱ्या कॉलरसाठी निवड बायपास करते.

**ड्रायव्हर प्रोफाइल:** प्रोफाइल निवडा, बॅकअप एक्सपोर्ट करा, त्यानंतर फक्त इच्छित सेटिंग्ज संपादित करा आणि त्यांना लागू करा. कोणता गेम प्रोफाईल प्राप्त करतो हे ऍप्लिकेशन असोसिएशन ठरवतात. संग्रहित मूल्य हे प्रत्येक ड्रायव्हर किंवा गेम वापरत असल्याचा पुरावा नाही.

**प्रदर्शन नियंत्रणे:** **स्क्रीन** उघडा, प्रदर्शन आणि विनंती केलेली मूल्ये निवडा, त्यानंतर पूर्वावलोकन सुरू करा. १५ सेकंदांच्या आत **ठेवा** निवडण्यापूर्वी प्रतिमा तपासा. **परत करा** वापरा, पुष्टीकरण बंद करा किंवा पुनर्संचयित करण्याची विनंती करण्यासाठी कालबाह्य होऊ द्या. कोणताही अयशस्वी संदेश वाचा: एकटा यशस्वी API कॉल पुनर्संचयित करण्याचा पुरावा नाही.

ICC निवड स्थापित प्रोफाइल असोसिएशन बदलते; ते ICC फाइल व्युत्पन्न, कॅलिब्रेट किंवा पुनर्वितरण करत नाही. HDR, ACM/WCG, RGB/YCbCr आणि bpc पाइपलाइनच्या विविध पैलूंचे वर्णन करतात. कोणताही नवीन स्वतंत्र ACM स्विच प्रदान केलेला नाही.

**NVRasterPulse:** टूलबार बटण संरक्षित मालकी आणि परवानग्यांसह प्रोग्राम फाइल्सच्या खाली स्वतंत्रपणे नोंदणीकृत सिस्टम-व्यापी स्थापना स्वीकारते. या एलिव्हेटेड लाँचरद्वारे पोर्टेबल कॉपी किंवा वापरकर्ता-लिहण्यायोग्य/लिंक केलेला मार्ग नाकारला जाऊ शकतो. अशावेळी स्वतःचा शॉर्टकट वापरून NVRasterPulse उघडा. NVRasterPulse वापरण्यासाठी [RTSS स्वतंत्रपणे स्थापित करा](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/).

<a id="update-and-uninstall"></a>
## अपडेट आणि अनइन्स्टॉल करा

अपडेट करण्यापूर्वी संपादक बंद करा. निर्यात केलेले प्रोफाइल ठेवा आणि नवीन fork रिलीझ डाउनलोड करा; त्याच साथीदार ओळखीवर स्थापित करा किंवा ताज्या फोल्डरमध्ये पोर्टेबल फाइल्स काढा. जुन्या `Reference.xml` नवीन एक्झिक्युटेबलमध्ये मिसळू नका. बंडल केलेले अपस्ट्रीम अपडेट-चेक सप्रेशन या fork चे आहे.

इंस्टॉल केलेल्या कॉपीसाठी, Windows **Installed apps** आणि त्याचा अनइंस्टॉलर वापरा. पोर्टेबलसाठी, ते बंद करा आणि जेव्हा तुमची निर्यात सुरक्षित असेल तेव्हा त्याचे काढलेले फोल्डर काढून टाका. एडिटर काढून टाकल्याने ड्रायव्हर प्रोफाइल संपादने, डिस्प्ले प्राधान्ये, NVRasterPulse किंवा RTSS **नाही** पूर्ववत होत नाहीत. काढण्यापूर्वी इच्छित सेटिंग्ज पुनर्संचयित करा.

<a id="known-limitations"></a>
## ज्ञात मर्यादा

- 15-सेकंदाची पुष्टी प्रत्येक ड्रायव्हर क्रॅश, पॉवर लॉस किंवा सक्तीने बंद करण्यासाठी वॉचडॉग नाही.
- काही रंग/खोली/रीफ्रेश संयोजन `NVAPI_NOT_SUPPORTED` परत करतात.
- सॉफ्टवेअर रीड-बॅक पॅनेल बिट खोली, रंग अचूकता किंवा विलंब मोजत नाही.
- स्क्रीन सेटिंग्ज सध्याच्या Windows डिस्प्लेवर परिणाम करतात; हा संवाद प्रति-गेम डिस्प्ले प्रीसेट तयार करत नाही.
- कोणतीही कामगिरी, अँटी-चीट किंवा सार्वत्रिक HDR सुसंगतता हमी नाही.

**NVDriverForge ला या संपादकाची आवश्यकता आहे का?** नाही. NVDriverForge चा पर्यायी Custom NV प्रीसेट स्वतःचे एकत्रीकरण वापरतो. संपादक स्थापित करणे ही एक वेगळी निवड आहे.

**या fork साठी RTSS अनिवार्य आहे का?** क्रमांक RTSS NVRasterPulse च्या FPS लिमिटरसाठी अनिवार्य आहे, प्रोफाइल किंवा स्क्रीन संपादनासाठी नाही.

**स्रोत कुठे आहे?** सुधारित ऍप्लिकेशन स्त्रोत खाजगीरित्या राखला जातो. MIT सूचना आणि अपस्ट्रीम रेपॉजिटरी प्रदान केले आहे; MIT ला सुधारित स्त्रोत प्रकाशित करण्याची आवश्यकता नाही.
