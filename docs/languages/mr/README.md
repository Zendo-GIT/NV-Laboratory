# NV Laboratory

**禅堂 Zendo (RevoluSound Team) द्वारे NV Tools.** NVIDIA ड्रायव्हर प्रोफाइल, ड्रायव्हर इंस्टॉलेशन, प्रायोगिक Multi Frame Generation आणि RTSS फ्रेम मर्यादांसाठी चार स्वतंत्र Windows उपयुक्तता.

[साधने मिळवा](docs/downloads.md) · [स्थापना](docs/installation.md) · [सुसंगतता आणि मदत](docs/support.md) · [क्रेडिट्स आणि परवाने](THIRD_PARTY_NOTICES.md)

> **NVRasterPulse ला RTSS आवश्यक आहे.** प्रथम [Guru3D कडून RivaTuner Statistics Server](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) स्थापित करा. RTSS त्याच्या FPS मर्यादा कार्य करण्यासाठी चालू असणे आवश्यक आहे. ते स्वतंत्रपणे डाउनलोड केले जाते.

<a id="start-here"></a>
## इथून सुरुवात करा

1. वरील एक साधन निवडा. प्रत्येक स्वतंत्रपणे कार्य करते; संपूर्ण संच स्थापित करणे अनावश्यक आहे.
2. त्याच्या आवश्यकता वाचा आणि स्थापित ॲपसाठी **सेटअप** निवडा किंवा वेगळ्या फोल्डरसाठी **पोर्टेबल** निवडा.
3. त्याचे प्रकाशन प्रकाशित झाल्यावर, नामित ॲप्लिकेशन मालमत्ता डाउनलोड करा, सोबतच्या सूचना वाचा आणि त्याची SHA-256 तुलना करा.
4. ड्रायव्हर, डिस्प्ले सेटिंग, NVIDIA प्रोफाइल किंवा गेम रनटाइम बदलण्यापूर्वी बॅकअप घ्या.

प्रत्येक मार्गदर्शकाच्या शीर्षस्थानी निवडकर्त्याद्वारे NV अनुप्रयोगांप्रमाणेच 34 भाषांमध्ये दस्तऐवजीकरण उपलब्ध आहे. GitHub ब्राउझर भाषेनुसार README स्वयंचलितपणे निवडत नाही. दस्तऐवजीकरण भाषा आणि अनुप्रयोगाची स्वतःची भाषा सेटिंग वेगळी आहेत.

<a id="provenance-and-ownership"></a>
## मूळ आणि मालकी

हे हब दस्तऐवजीकरण आणि संकलित अनुप्रयोगांचे वितरण करते. ऍप्लिकेशनचा सोर्स कोड खाजगीरित्या ठेवला जातो. अपस्ट्रीम प्रकल्प त्यांचे लेखकत्व आणि परवाने टिकवून ठेवतात; खाजगी स्त्रोत वितरण त्या अटी बदलत नाही.

- Profile Inspector fork ने Orbmu2k चा MIT परवाना राखून ठेवला आहे आणि स्पष्टपणे fork म्हणून ओळखला जातो.
- NVDriverForge च्या स्वतःच्या बायनरी वितरण अटी आहेत आणि त्यात स्वतंत्रपणे परवानाकृत रनटाइम/टूल घटक समाविष्ट आहेत.
- NVMFG Unlock40 हा स्वतंत्रपणे विकसित केलेला अनुप्रयोग आहे. तुलना आणि शुद्धीकरणासाठी RTX40MFG-Unlock चा सल्ला घेण्यात आला; सामायिक केलेले मूळ घटक त्यांचे MIT क्रेडिट राखून ठेवतात. MinHook आणि NVIDIA SDK अटी वेगळ्या राहतील.
- NVRasterPulse पुरवठा केलेला MIT परवाना राखून ठेवते आणि Profile Inspector-व्युत्पन्न UI ला क्रेडिट करते. RTSS हा एक आवश्यक बाह्य कार्यक्रम आहे.

[पूर्ण घटक सारणी](THIRD_PARTY_NOTICES.md), [फाइल मूळ आणि बदल](docs/provenance.md) आणि [परवाना व्याप्ती](../../../LICENSE) पहा.
