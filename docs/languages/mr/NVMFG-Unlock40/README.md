# NVMFG Unlock40

**प्रायोगिक NVIDIA Multi Frame Generation GeForce RTX 40 साठी, केंद्रीय नियंत्रक आणि प्रति-गेम पर्यायांसह.**

[0.1.1 आणि स्थिती डाउनलोड करा](../docs/downloads.md#nvmfg-unlock40) · [स्थापना](#installation) · [अपस्ट्रीम](#upstream-and-modifications) · [परवाने](LICENSES/README.md)

<a id="overview-and-purpose"></a>
## विहंगावलोकन आणि उद्देश

NVMFG Unlock40 हा 禅堂 Zendo (RevoluSound Team) द्वारे स्वतंत्रपणे विकसित केलेला अनुप्रयोग आहे. हे Windows कंट्रोलर, नेटिव्ह लेयर, प्रोफाइल मदतनीस आणि गेम/Streamline SDK व्यवस्थापन एकत्र करते. हे आधीच NVIDIA DLSS Frame Generation आणि सुसंगत NVIDIA रनटाइम्स एकत्रित करणाऱ्या खेळांना लक्ष्य करते.

कामाची तुलना आणि परिष्कृत करण्यासाठी [RTX40MFG-Unlock](https://github.com/dashdogy/RTX40MFG-Unlock) चा सल्ला घेण्यात आला. सध्याच्या मूळ स्तरामध्ये सामायिक आणि रुपांतरित घटक आहेत, खाली वैयक्तिकरित्या श्रेय दिले आहेत. हा संदर्भ संपूर्ण NVMFG अनुप्रयोगास त्या प्रकल्पाचा fork बनवत नाही.

हे प्रायोगिक MFG वर्तन मध्यवर्तीपणे समन्वयित करण्यासाठी, गेम-विशिष्ट निवडी लक्षात ठेवण्यासाठी आणि रनटाइम अद्यतने आणि बॅकअप दृश्यमान ठेवण्यासाठी अस्तित्वात आहे. हे प्रत्येक गेममध्ये DLSS Frame Generation जोडत नाही किंवा अनियंत्रित FSR अंमलबजावणीमध्ये रूपांतरित करत नाही.

तयार केलेला उमेदवार **0.1.1** आहे, ज्यामध्ये SDK-यादी व्हिज्युअल सुधारणा UI2 म्हणून अंतर्गत रेकॉर्ड केलेल्या आहेत. सार्वजनिक आवृत्ती 0.1.1 राहते; त्याचे अचूक हॅश या उमेदवाराला जुन्या स्थानिक बिल्डपेक्षा वेगळे करतात.

<a id="features"></a>
## वैशिष्ट्ये

- केंद्रीय सक्षम/अक्षम नियंत्रण आणि पर्यायी Windows ट्रे स्टार्टअप.
- Dynamic MFG मधील प्रति-गेम निवड, गेमची सेटिंग आणि समर्थित निश्चित गुणक.
- निरीक्षण केलेल्या V-Sync चालू/बंद स्थितीसाठी वेगळे लक्षात ठेवलेले पर्याय.
- Dynamic NVIDIA मोड वापरते; V-Sync बंद असताना, वेगळ्या इन-गेम/निश्चित निवडीसह ते निलंबित केले जाते.
- गेम-मेनू मार्गदर्शन आणि सतत अपवर्जन; DLSS FG शिवाय गेम नियंत्रणात राहतात.
- गेम फायली न हटवता गेम शोध, पालक-फोल्डर निवड, शोध, गटबद्ध करणे आणि काढणे.
- Streamline SDK डाउनलोड/आयात, सत्यापित स्थानिक कॅशे, स्पष्ट निवड, प्रति-गेम बॅकअप आणि पुनर्संचयित.
- मूळ प्रदाता सत्यापन, प्रति-सत्र निदान, जागतिक प्रोफाइल जर्नल आणि संघर्ष-जागरूक पुनर्प्राप्ती.
- 34 इंटरफेस भाषा आणि चार थीम.

गेममध्ये FG बंद केल्याने ते बंद राहते. 2x ते 6x पर्यंतच्या निश्चित निवडी गेम/मेनू/रनटाइमवर अवलंबून असतात; ते असे वचन नाहीत की प्रत्येक संयोजन कार्य करते. कंट्रोलर V-Sync चे निरीक्षण करतो आणि वापरकर्त्यासाठी V-Sync किंवा VRR सेट करत नाही.

<a id="installation"></a>
## स्थापना

1. [उमेदवार स्थिती आणि परवाना नोट](../docs/downloads.md#nvmfg-unlock40) वाचा.
2. जेव्हा त्याचे प्रकाशन उपलब्ध असेल तेव्हा `NVMFGUnlock40-0.1.1-Setup-x64.exe` किंवा `NVMFGUnlock40-0.1.1-Portable-x64.zip` डाउनलोड करा.
3. SHA-256 तपासा आणि सोबतच्या सूचना ठेवा. जर Windows आधीपासून प्रदान करत नसेल तर .NET फ्रेमवर्क 4.8 स्थापित करा.
4. सेटअप चालवा किंवा **संपूर्ण** पोर्टेबल ZIP एका लिहिण्यायोग्य स्थानिक फोल्डरमध्ये काढा.
5. `NVMFGUnlock40.exe` लाँच करा; `agent`, `driver`, `engine` आणि `Licenses` पुरवलेल्या लेआउटमध्ये ठेवा.

`driver` नावाच्या फोल्डरमध्ये कर्नल ड्रायव्हर नसून वापरकर्ता-स्पेस मदतनीस आहेत. सक्तीने सुसंगततेसाठी फक्त मुख्य EXE कॉपी करू नका किंवा प्रदाता हॅश बदलू नका. सध्याचे EXE स्वाक्षरी केलेले नाहीत.

<a id="usage"></a>
## वापर

1. कंट्रोलर अक्षम करून प्रारंभ करा. गेम किंवा पालक फोल्डर जोडा आणि वास्तविक इंस्टॉलेशन्स निवडा.
2. प्रत्येक गेमच्या MFG सेटिंग्जचे पुनरावलोकन करा. त्याचे मेनू काय देते याचे उत्तर द्या; उत्तर प्रत्येक गेममध्ये साठवले जाते.
3. Dynamic किंवा जागतिक स्तरावर इन-गेम सेटिंग निवडा, त्यानंतर आवश्यकतेनुसार पात्र प्रति-गेम निवडी समायोजित करा.
4. जेव्हा तुम्ही त्याचा वापर करू इच्छित असाल तेव्हाच कंट्रोलर सक्षम करा. हे रिकव्हरी जर्नलसह सहा जागतिक NVIDIA प्रोफाइल सेटिंग्ज तात्पुरते बदलू शकते.
5. एक पात्र गेम लाँच करा आणि स्वतःचे DLSS Frame Generation सक्षम करा. V-Sync-ऑफ निवडीसाठी कोणत्याही विनंतीचे अनुसरण करा.
6. तुम्ही व्यवस्थापित करू इच्छित नसलेल्या गेमसाठी अपवाद वापरा. गेम काढून टाकणे एक अपवर्जन रेकॉर्ड करते आणि त्याच्या फायली/बॅकअप जतन करते.
7. पूर्ण झाल्यावर ऍप्लिकेशनचा पूर्ण क्विट/डिसेबल आणि रिकव्हरी फ्लो वापरा.

मुख्य विंडो बंद केल्याने कंट्रोलर ट्रेमध्ये राहू शकतो. गेममध्ये आधीच लोड केलेला DLL गेम बाहेर येईपर्यंत तिथेच असतो; कंट्रोलर अक्षम करणे ही अनलोड हमी नाही. देखभाल किंवा अपडेट करण्यापूर्वी प्रभावित गेम बंद करा.

**Streamline SDKs:** NVIDIA SDK पृष्ठावर, अधिकृत आवृत्ती डाउनलोड करा किंवा सुसंगत स्थानिक SDK आयात करा. एक सत्यापित प्रत आयात करा; **Use this version** ते निवडते आणि **Uninstall** ती कॅशे केलेली प्रत काढून टाकते. गहाळ Streamline DLLs अधिकृत NVIDIA SDK वरून पुरवले जाऊ शकतात, स्त्रोत दाखवले आहेत. हे NGX मॉडेल डाउनलोड/रिप्लेस करत नाही. गेम बंद करा, इच्छित गेम अपडेट निवडा आणि त्याचा मूळ बॅकअप ठेवा. गेम फाइल्स रिव्हर्ट करण्यासाठी, कॅशेचे Uninstall बटण नव्हे तर बॅकअप रिस्टोरेशन वापरा.

## अपडेट आणि अनइन्स्टॉल करा

प्रभावित गेम बंद करा. NVMFG अक्षम करा/बाहेर पडा आणि अपडेट करण्यापूर्वी कोणत्याही प्रलंबित NVIDIA सेटिंग्ज पुनर्प्राप्तीचे निराकरण करा. विद्यमान ओळखीसह पुढील सेटअप स्थापित करा किंवा नवीन फोल्डरमध्ये नवीन पोर्टेबल काढा; राज्य/बॅकअप ठेवा.

विस्थापित करण्यापूर्वी, अनुप्रयोगाद्वारे इच्छित गेम SDK बॅकअप आणि NVIDIA सेटिंग्ज पुनर्संचयित करा, नंतर गेम बंद करा आणि कंट्रोलर सोडा. सेटअपसाठी Windows **Installed apps** वापरा किंवा आवश्यक फाइल्स जतन केल्यानंतर बंद पोर्टेबल फोल्डर काढून टाका. सेटअप अनब्लॉक करण्यासाठी सक्रिय पुनर्प्राप्ती जर्नल व्यक्तिचलितपणे हटवू नका.

स्थानिक गेम-रनटाइम बॅकअप `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups` वापरतात. MFG सेटिंग्ज/SDK डेटा `%LOCALAPPDATA%\RtxMfg` वापरते; सत्र आउटपुट अनुप्रयोगाच्या बाजूला `Sessions` अंतर्गत आहे. या फायलींमध्ये गेम पथ असू शकतात. त्यांना न छापलेल्या पोस्ट करू नका.

<a id="known-limitations"></a>
## ज्ञात मर्यादा

- प्रायोगिक मूळ पॅच क्रॅश किंवा व्हिज्युअल आर्टिफॅक्ट्स होऊ शकतात; एक निराकरण न झालेला Bodycam क्रॅश विकास इतिहासात नोंदवला जातो.
- नियंत्रित रेंडरर चाचण्या प्रत्येक गेम, ड्रायव्हर किंवा अँटी-चीटसाठी प्रमाणन नाहीत.
- व्युत्पन्न केलेल्या फ्रेम नवीन इनपुट नमुने तयार करत नाहीत; या हबद्वारे कोणतेही मोजलेले विलंब किंवा कार्यप्रदर्शन वाढण्याचे वचन दिलेले नाही.
- एकाधिक फ्रेम-जनरेशन टूल्स/ओव्हरले विरोध करू शकतात. अनुप्रयोगाने प्रत्येक सहअस्तित्वाची परिस्थिती सिद्ध न करता निरीक्षण केलेल्या मॉड्यूल्सचा अहवाल दिला आहे.
- कंपॅटिबिलिटी मॅनिफेस्ट एक डिटेक्शन एड आहे, पूर्णतः चाचणी केलेल्या गेमची सूची नाही.
