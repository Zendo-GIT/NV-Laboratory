<a id="repository-architecture-and-maintenance"></a>
# रेपॉजिटरी आर्किटेक्चर आणि देखभाल

NV Laboratory हे सार्वजनिक **दस्तऐवजीकरण आणि बायनरी-वितरण केंद्र** आहे. त्यात अनुप्रयोग स्त्रोत नाही. चार प्रकल्प स्वतंत्र बिल्ड ट्री, आवृत्त्या, ओळख आणि रिलीझ मालमत्ता राखून ठेवतात. त्यांचा खाजगी विकास इतिहास या Git भांडारात आयात केलेला नाही.

<a id="layout"></a>
## मांडणी

| मालमत्ता | विद्यमान पुनरावलोकन केलेले UI पूर्वावलोकन आणि त्यांचे मूळ |

इंग्रजी हे डीफॉल्ट GitHub README राहते. विद्यमान शेजारील `.fr.md` लिंक वैध राहतील. अतिरिक्त भाषांतरे `docs/languages/<code>` अंतर्गत दस्तऐवजीकरण मिरर करतात; भाषा बदलताना भाषा निवडकर्ता समान पृष्ठ ठेवतो. कॅटलॉग `docs/languages/catalog.json` सर्व 34 भाषा आणि स्त्रोत फिंगरप्रिंट्स रेकॉर्ड करतो. GitHub ब्राउझर भाषेनुसार README स्वयंचलितपणे निवडत नाही. [भाषा निर्देशांक आणि भाषांतर धोरण](../../README.md) पहा.

<a id="local-checks"></a>
## स्थानिक तपासण्या

रेपॉजिटरी रूट पासून:

```text
python tools/validate_repository.py
```

Python 3.10 किंवा नवीन पुरेसे आहे. चेक फाईल्स, स्थानिक मार्कडाउन लिंक्स, आवश्यक नोटिस/RTSS लिंक्स, रिलीझ मेटाडेटा आणि प्रकाशन सीमा वाचतो. हे सॉफ्टवेअर कार्यान्वित करत नाही, अवलंबित्व स्थापित करत नाही किंवा नेटवर्कशी संपर्क साधत नाही.

GitHub वर्कफ्लो पुश, पुल रिक्वेस्ट किंवा मॅन्युअल डिस्पॅचवर केवळ-वाचनीय सामग्री परवानगीसह समान तपासणी चालवते. चेकआउट ऑडिट केलेल्या कमिटमध्ये पिन केलेले आहे आणि क्रेडेन्शियल्स टिकून राहत नाही. कोणतेही प्रकाशन किंवा उपयोजन कार्य कॉन्फिगर केलेले नाही.

<a id="maintain-the-boundary"></a>
## सीमा सांभाळा

इंग्रजी संदर्भ, फ्रेंच मार्गदर्शक आणि प्रभावित भाषांतरे एकत्र अद्यतनित करा. केवळ-फॉर्मेटिंग तुलनांपासून मूलभूत बदल वेगळे ठेवा. वास्तविक उमेदवार हॅश, अपस्ट्रीम कमिट संदर्भ आणि परवाने रेकॉर्ड करा; प्रकल्पाच्या लोकप्रियतेवरून कधीही परवाना काढू नका.

ताज्या आवृत्तीत रिलीझ मालमत्ता वापरा आणि बदललेल्या बायनरी, संग्रहण आणि एम्बेड केलेल्या सूचनांचे पुन्हा ऑडिट करा. या भांडाराच्या बाहेर खाजगी बॅकअप जतन करा. खाजगी अनुप्रयोग स्त्रोत किंवा स्थानिक बिल्ड फोल्डर आयात करण्यासाठी सार्वजनिक कार्यप्रवाह वापरू नका.

खाजगी प्रकल्पात चालवल्या जाणाऱ्या कार्यात्मक अनुप्रयोग बदलासाठी योग्य चाचण्या. ड्रायव्हर इंस्टॉलर्स पुन्हा चालवू नका किंवा दस्तऐवजीकरण अद्यतनासाठी वास्तविक प्रोफाइल लिहू नका. [मॅन्युअल रिलीझ प्रक्रिया](releasing.md).
