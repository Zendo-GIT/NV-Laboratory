<a id="compatibility-and-troubleshooting"></a>
# सुसंगतता आणि समस्यानिवारण

हे तयार केलेले उमेदवार आहेत, सर्व Windows, GPU, ड्रायव्हर आणि गेम कॉम्बिनेशनसाठी प्रमाणन मॅट्रिक्स नाही.

| साधन | Windows / रनटाइम | हार्डवेअर / बाह्य अवलंबित्व | काळजी आवश्यक ऑपरेशन्स |
| --- | --- | --- | --- |
| NVPI fork 3.0.2.3 | Windows 10/11 x64, .NET फ्रेमवर्क 4.8 | सुसंगत NVIDIA ड्रायव्हर/डिस्प्ले | प्रोफाइल लिहिते आणि पूर्वावलोकन प्रदर्शित करा |
| NVDriverForge 0.1.2 | Windows 10 बिल्ड 19041+ / 11 x64; .NET/WPF समाविष्ट | सुसंगत NVIDIA ड्राइव्हर पॅकेज | उन्नत स्थापना, प्रगत सेटिंग्ज, पर्यायी NVENC |
| NVMFG Unlock40 0.1.1 | Windows 10/11 x64; .NET/WPF समाविष्ट, फ्रेमवर्क 4.8 मदतनीस | RTX 40, पात्र DLSS FG गेम आणि पिन केलेला प्रदाता | नेटिव्ह इन-गेम पॅचिंग, ग्लोबल प्रोफाईल जर्नल, SDK गेम अपडेट |
| NVRasterPulse 0.1 | Windows 10/11 x64, .NET फ्रेमवर्क 4.8 | RTSS स्थापित; कॅप्ससाठी धावणे | RTSS प्रति-एक्झिक्युटेबल प्रोफाइल बदल |

कोणतेही ARM64 पॅकेज तयार केलेले नाही. डिस्प्ले/API उपलब्धता आणि जुन्या Windows आवृत्त्या वैयक्तिक वैशिष्ट्ये मर्यादित करू शकतात. कोणत्याही सार्वत्रिक किमान NVIDIA किंवा RTSS आवृत्तीचा शोध लावलेला नाही. अचूक NVMFG प्रदाता हॅश [मूळ](provenance.md) मध्ये आहे.

<a id="before-reporting-a-bug"></a>
## दोष नोंदवण्यापूर्वी

तुम्ही उघडलेली अचूक एक्झिक्यूटेबल/आवृत्ती ओळखा. पूर्वीची स्थापित केलेली प्रत नवीन डाउनलोड केलेल्या ZIP ची आवृत्ती असणे आवश्यक नाही. पुनरुत्पादनाचे टप्पे, अपेक्षित परिणाम आणि वास्तविक परिणाम नोंदवा. प्रस्तुतीकरण/मर्यादित समस्यांसाठी, गेम आवृत्ती, डिस्प्ले रिफ्रेश, FG/V-Sync/VRR स्थिती आणि इतर कोणतेही लिमिटर किंवा आच्छादन समाविष्ट करा.

[बग फॉर्म](https://github.com/Zendo-GIT/NV-Laboratory/issues/new?template=bug-report.yml) वापरा. संपूर्ण खाजगी विकास फोल्डर, ड्रायव्हर संग्रहण, मॉडेल, गेम DLL, रेजिस्ट्री डंप किंवा पुनरावलोकन न केलेले लॉग संग्रह कधीही संलग्न करू नका.

| समस्या | प्रथम तपासले |
| --- | --- |
| चुकीची ऍप्लिकेशन आवृत्ती | EXE ओळखीची पुष्टी करा आणि हॅश सोडा; बदलण्यापूर्वी जुनी प्रत बंद करा. |
| रनटाइम/स्टार्टअप त्रुटी | आवश्यक फ्रेमवर्क 4.8 स्थापित करा किंवा सर्व पुरवलेले पोर्टेबल सबफोल्डर ठेवा. |
| UAC रद्द केले | केवळ इच्छित ऑपरेशनसाठी पुन्हा प्रयत्न करा; रद्द करणे यशस्वी स्थापना नाही. |
| हॅश/स्वाक्षरी जुळत नाही | तो उमेदवार वापरणे थांबवा आणि अपेक्षित अधिकृत बाइट्स मिळवा. |
| NVPI रंग/मोड नाकारला | रिव्हर्ट करा आणि वास्तविक डिस्प्ले/ड्रायव्हरद्वारे समर्थित संयोजन वापरा. |
| NVDF बॅकअप किंवा पुनर्प्राप्ती अयशस्वी | संरक्षित नोकरी आणि RECOVERY.txt जतन करा; जर्नल पुसून टाकू नका किंवा परस्परविरोधी लेखनाची सक्ती करू नका. |
| NVMFG प्रलंबित सेटिंग्ज | इतर साधनांमधील बदल जतन करून, गेम बंद करून पुनर्प्राप्तीचे निराकरण करा. |
| RP कॅपचा कोणताही प्रभाव नाही | RTSS चालवा, वास्तविक गेम EXE ओळखा, हुक स्थिती आणि स्पर्धात्मक मर्यादा तपासा. |
| RP कॅप काढल्यानंतर कायम राहते | RTSS ग्लोबलची तपासणी करा; काढणे बदल स्थानिक मर्यादा ओव्हरराइड फक्त. |

<a id="logs-and-privacy"></a>
## नोंदी आणि गोपनीयता

| साधन | पुनरावलोकन करण्यासाठी स्थानिक डेटा, घाऊक अपलोड करू नका |
| --- | --- |
| NVDF | `%LOCALAPPDATA%\NVDriverForge`; संरक्षित नोकऱ्या `%PROGRAMDATA%\NVDriverForge\Jobs` |
| NVMFG | `%LOCALAPPDATA%\RtxMfg`; बॅकअप `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`; EXE च्या बाजूला `Sessions` |
| RP | `%LOCALAPPDATA%\NVRasterPulse`; त्याच्या खाली `Backups\RTSS` |
| NVPI | तुमची निवडलेली निर्यात आणि प्रदर्शित त्रुटी; सार्वत्रिक लॉग मार्ग शोधलेला नाही |

तुम्ही शेअर करत असलेल्या मजकूर/इमेजमधून खात्याची नावे, होम डिरेक्टरी, गेम-लायब्ररी पाथ, डिव्हाइस आयडेंटिफायर, टोकन आणि असंबंधित विंडो काढून टाका. पुनर्प्राप्तीसाठी मूळ खाजगी ठेवा. सार्वजनिक समस्या प्रत्येकाला दिसतात.

असुरक्षितता, धोकादायक विशेषाधिकार वर्तन किंवा अनपेक्षित विनाशकारी ऑपरेशनसाठी, तपशील सार्वजनिकपणे पोस्ट करण्याऐवजी [SECURITY.md](../SECURITY.md) चे अनुसरण करा.

<a id="what-has-been-verified"></a>
## काय सत्यापित केले गेले आहे

हब तयार करण्यासाठी, स्टॅटिक पेलोड/झिप/हॅश/मेटाडेटा स्कॅन आणि दस्तऐवजीकरण तपासण्या चालवल्या गेल्या. विद्यमान खाजगी अनुप्रयोग बिल्ड/युनिट/UI चाचण्या ऐतिहासिक, दिनांकित पुरावे आहेत. या तयारीचा भाग म्हणून ड्रायव्हर इन्स्टॉल, डिस्प्ले बदल, लाइव्ह RTSS ऑपरेशन किंवा गेम बेंचमार्क केले गेले नाही.

“डिटेक्टेड”, “लिहिलेले”, “रीलोड केलेले”, “क्षमता उपलब्ध” आणि “गेममध्ये मोजलेले” हे भिन्न परिणाम आहेत. तुम्ही कोणते निरीक्षण केले ते कळवा.
