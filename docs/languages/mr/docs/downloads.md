# डाउनलोड

प्रोग्राम निवडा आणि एकतर **सेटअप** किंवा **पोर्टेबल**. प्रत्येक साधनाचे प्रकाशन पृष्ठ वर्तमान उपलब्धता, प्रकाशन तारीख आणि प्रकाशन नोट्स दर्शवते. जेव्हा देखभालकर्ता संबंधित मालमत्ता प्रकाशित करतो तेव्हा थेट दुवे कार्य करतात. अर्जाचा स्रोत खाजगी राहतो. तुमच्या डाउनलोडसोबत `Licenses-and-Credits.zip` आणि `SHA256SUMS.txt` ठेवा. GitHub च्या **Source code (zip)** बटणामध्ये हब दस्तऐवजीकरण आहे.

> **NVRasterPulse ला RTSS आवश्यक आहे.** [Guru3D कडून RivaTuner Statistics Server](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) स्वतंत्रपणे स्थापित करा आणि FPS मर्यादित करण्यासाठी ते चालवा.
