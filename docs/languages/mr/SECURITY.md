# सुरक्षा

या पॉलिसीमध्ये NV Tools ऍप्लिकेशन पॅकेजेस आणि हे वितरण केंद्र समाविष्ट आहे. देखभालकर्ता प्रत्येक साधनाच्या नवीनतम प्रकाशित आवृत्तीवर परिणाम करणाऱ्या अहवालांना प्राधान्य देतो. तयार उमेदवार घोषित समर्थित स्थिर प्रकाशन नाहीत. प्रतिसादाची अंतिम मुदत किंवा सुरक्षा प्रमाणपत्र देण्याचे आश्वासन दिलेले नाही.

<a id="report-privately"></a>
## खाजगीरित्या अहवाल द्या

असुरक्षितता, असुरक्षित उन्नत वर्तन, अनपेक्षित विध्वंसक बदल किंवा संवेदनशील डेटा एक्सपोजरसाठी, भांडाराचे **सुरक्षा → Report a vulnerability** वैशिष्ट्य **जेव्हा ते सक्षम केलेले असते**: [खाजगी अहवाल](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new) वापरा.

**प्रारंभिक सेटअप:** देखभालकर्त्याने सार्वजनिक भांडार तयार केल्यानंतर खाजगी असुरक्षा अहवाल सक्षम करणे आवश्यक आहे. ही फाइल ती सक्षम करत नाही आणि त्यापूर्वी कोणताही मेलबॉक्स किंवा खाजगी चॅनेल अस्तित्वात नसल्याचा दावा केला जात नाही.

बटण अनुपलब्ध असल्यास, फक्त असलेली सार्वजनिक समस्या उघडा: "मला [टूल/आवृत्ती] संबंधित सुरक्षा अहवालासाठी खाजगी संपर्क चॅनेलची आवश्यकता आहे." शोषण तपशील, क्रेडेन्शियल, प्रभावित पथ, लॉग किंवा संलग्नक समाविष्ट करू नका. ते सामायिक करण्यापूर्वी देखभालकर्त्याने खाजगी चॅनेल प्रदान करण्याची प्रतीक्षा करा.

खाजगी अहवालात, टूल/आवृत्ती आणि हॅश, Windows/GPU/ड्रायव्हर आवृत्त्या, प्रभाव, किमान सुरक्षित पुनरुत्पादन आणि पुनर्प्राप्तीची आवश्यकता आहे का याचा समावेश करा. रहस्ये आणि वैयक्तिक डेटा सुधारणे; स्थानिक पुनर्प्राप्ती फाइल्स जतन करा. प्रोप्रायटरी ड्रायव्हर किंवा गेम DLL अपलोड करू नका. देखरेखीसह प्रकटीकरण समन्वयित करा; पॅच/रिलीझसाठी पुनरावलोकन आवश्यक आहे आणि ते स्वयंचलित नाही.


[GitHub खाजगी अहवाल दस्तऐवजीकरण](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
