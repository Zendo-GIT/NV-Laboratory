# चेंजलॉग

हे हब [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) चे अनुसरण करते. अर्ज आवृत्त्या आणि प्रकाशन तारखा स्वतंत्र आहेत. खाली तयार केलेले पॅकेज त्यांच्या संबंधित GitHub प्रकाशनांवर त्यांच्या वास्तविक प्रकाशन तारखा प्राप्त करतात.

<a id="unreleased"></a>
## [अप्रकाशित]

<a id="changed"></a>
### बदलले

- NVDriverForge 0.1.4 साठी हब आणि सर्व 34 दस्तऐवजीकरण भाषा रिफ्रेश करा,
NVMFG Unlock40 0.2.3 आणि NVRasterPulse 0.2, 2026-09-18 रोजी तयार.
- NVDriverForge: तयारी तपासणी, मूळ प्रोफाइल बॅकअप आणि संरक्षित पुनर्प्राप्ती,
घटक मार्गदर्शन, पुन्हा वापरण्यायोग्य प्राधान्ये, ड्रायव्हर किट, तपशीलवार परिणाम, स्थानिक समर्थन अहवाल आणि स्वतंत्र अनुप्रयोग अद्यतने.
- NVMFG: मल्टी-फोल्डर शोध, पर्सिस्टंट लायब्ररी कॅशे, निरीक्षण केलेले MFG क्रियाकलाप,
रनटाइम क्षमता माहिती, पुढील-लाँच बहिष्कार, स्थानिक निदान, प्राधान्य हस्तांतरण आणि पर्यायी अनुप्रयोग अद्यतने.
- NVRasterPulse: कॉन्फिगरेशन डायग्नोस्टिक्स, FPS सूचना, विराम/रिझ्युम,
एक-स्तरीय पूर्ववत, निवडक प्रोफाइल आयात/निर्यात, आवडी आणि लपविलेल्या नोंदी.
- पॅकेज हॅश रिफ्रेश करा, नोट्स रिलीझ करा आणि मूळ-घटक मूळ नकाशा.
आधीच प्रकाशित Profile Inspector 3.0.2.3/setup-r2 मालमत्ता अपरिवर्तित ठेवा.

<a id="fixed"></a>
### निश्चित

- NVMFG गेम निवड/गणना, Ctrl+D हाताळणी आणि पूर्ण झालेले प्रगती संदेश;
Wallpaper Engine ला गेम डिटेक्शनमधून वगळण्यात आले आहे. स्वतंत्रपणे नोंदवलेला 0.1.1 पुनर्संचयित अडथळा पुनरुत्पादित राहतो आणि दावा निश्चित केलेला नाही.

## [प्रारंभिक सार्वजनिक केंद्र] – 2026-09-10

<a id="added"></a>
### जोडले

- 34 भाषांमध्ये चार प्रकल्प मार्गदर्शक आणि भांडार दस्तऐवजीकरण
पृष्ठ-संरक्षण करणारे निवडक, स्थिर अँकर आणि भाषांतर कव्हरेज मेटाडेटा.
- घटक क्रेडिट्स, मूळ परवाने, मूळ, RTSS आवश्यकता आणि
वेगळे RevoluSound Team दुवे.
- मॅन्युअल रिलीझ पॅकेजेस, SHA-256 मूल्ये, इश्यू फॉर्म, सुरक्षा धोरण आणि
केवळ-वाचनीय दस्तऐवज प्रमाणीकरण. अर्जाचे स्रोत खाजगी राहतात.
- प्रथम सार्वजनिक टॅग: `nvpi-v3.0.2.3`, `nvdriverforge-v0.1.3`,
`nvmfg-unlock40-v0.1.1` आणि `nvrasterpulse-v0.1`.
