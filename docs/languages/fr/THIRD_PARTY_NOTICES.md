<a id="obligations-and-boundaries"></a>
## Obligations et limites

**Composants MIT :** conservent les droits d'auteur, le texte d'autorisation et la clause de non-responsabilité avec les copies. Leur licence ne nécessite pas la publication de source modifiée. La paternité originale est préservée même lorsque la source de l'application est gérée de manière privée.

**MinHook/HDE :** préserve les avis, conditions et avertissements dans la documentation binaire. L’avis combiné complet est fourni.

**7-Zip :** préserve les notifications LGPL/BSD/unRAR et donne accès à la source exacte non modifiée. L'archive source est liée ci-dessus, avec le LGPL complet. La restriction unRAR s'applique au code de décompression concerné ; il ne s'agit pas d'une dépendance générale de MIT. Voir le [FAQ sur la distribution](https://www.7-zip.org/faq.html) de l'auteur.

**Inno Setup :** préserve les avis de droits d'auteur/site Web requis pour le moteur et marque les modifications de source le cas échéant. Les crédits du moteur non modifié restent chez les installateurs. Les catalogues adaptés conservent les notices originales des sources ; les noms sont indexés ici.

**Matériel NVIDIA :** la licence MIT pour les en-têtes d'intégration Streamline ne couvre pas tous les fichiers SDK. Son avis sépare explicitement le matériel Nsight Perf SDK ; ce matériau n’est pas utilisé dans cet objectif de production. Les en-têtes NGX sont soumis aux termes propriétaires RTX SDK de NVIDIA. Leur texte intégral a été ajouté, avec un [copie de l'octet original](../../../NVMFG-Unlock40/LICENSES/NVIDIA-RTX-SDK.original.txt). La restriction de la section 4(d) concernant les limitations techniques reste non résolue pour l'utilisation de NVMFG. Aucune autorisation affirmative n'est déduite de l'existence d'un autre mod.

**Composants externes inconnus/propriétaires :** Les pilotes, modèles RTSS, NVCleanstall, NVIDIA et les données de correctif keylase ne sont pas regroupés dans les actifs du hub préparés. Les liens identifient leurs propriétaires réels. Un téléchargement déclenché par l'utilisateur ne permet pas de renouveler la licence d'un composant.

Les outils utilisent les API et les polices fournies par Windows. Aucun fichier Windows SDK/compiler/font n'est copié dans ce référentiel Git. Les outils de build et les tests privés sont en dehors de la distribution. Les notifications de composants internes à l'exécution restent dans le fichier de notifications Microsoft complet plutôt que d'être réaffectées à l'éditeur.
