# 下载

选择一个程序，然后选择 **安装** 或 **便携式**。每个工具的发布页面都会显示当前可用性、发布日期和发布说明。当维护者发布相应的资产时，直接链接就会起作用。应用程序源保持私密。下载时保留 `Licenses-and-Credits.zip` 和 `SHA256SUMS.txt`。 GitHub 的 **Source code (zip)** 按钮包含集线器文档。

> **NVRasterPulse 需要 RTSS。** 单独安装 [来自 Guru3D 的 RivaTuner Statistics Server](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) 并运行它以进行 FPS 限制。

<a id="sha-256"></a>
## SHA-256

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\NVDriverForge.exe'
```

将名称替换为您下载的文件并比较整个哈希值。匹配可以验证清单中的身份。当前的 EXE 未签名。
