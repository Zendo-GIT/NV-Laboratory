<a id="changelog"></a>
# 变更日志

该集线器遵循 [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)。应用程序版本和发布日期是独立的。下面准备好的软件包在各自的 GitHub 版本上收到实际发布日期。

<a id="unreleased"></a>
## [未发布]

<a id="changed"></a>
### 改变了

- 刷新 NVDriverForge 0.1.4 的中心和所有 34 种文档语言，
NVMFG Unlock40 0.2.3 和 NVRasterPulse 0.2，于 2026 年 9 月 18 日准备。
- NVDriverForge：准备情况检查、本机配置文件备份和受保护的恢复，
组件指南、可重用首选项、驱动程序套件、详细结果、本地支持报告和单独的应用程序更新。
- NVMFG：多文件夹发现、持久库缓存、观察到的 MFG 活动、
运行时功能信息、下次启动排除、本地诊断、首选项传输和可选应用程序更新。
- NVRasterPulse：配置诊断、FPS 建议、暂停/恢复、
一级撤消、选择性配置文件导入/导出、收藏夹和隐藏条目。
- 刷新包哈希、发行说明和本机组件来源图。
保持已发布的 Profile Inspector 3.0.2.3/setup-r2 资产不变。

<a id="fixed"></a>
### 固定

- NVMFG 游戏选择/计数、Ctrl+D 处理和已完成的进度消息；
Wallpaper Engine 被排除在游戏检测之外。单独报告的 0.1.1 恢复阻塞仍未重现，也未声称已修复。

<a id="initial-public-hub--2026-09-10"></a>
## [初始公共中心] – 2026-09-10

<a id="added"></a>
### 已添加

- 4 个项目指南和 34 种语言的存储库文档，
页面保留选择器、稳定锚点和翻译覆盖率元数据。
- 组件积分、原始许可证、出处、RTSS 要求和
单独的 RevoluSound Team 链接。
- 手动发布包、SHA-256 值、问题表单、安全策略和
只读文档验证。应用程序来源保持私密。
- 第一个公开标签：`nvpi-v3.0.2.3`、`nvdriverforge-v0.1.3`、
`nvmfg-unlock40-v0.1.1` 和 `nvrasterpulse-v0.1`。

<a id="included-fixes"></a>
### 包含的修复

- Profile Inspector 安装程序修订版 2：独立的 34 种语言选择器；
编辑器和便携式有效负载不变。
- NVDriverForge 0.1.3：更正了可选组件处理和本地化
故障摘要，以及更新的运行时和配套包装。

上述日期是经过验证的公共中心历史，而不是重建的开发日期。
