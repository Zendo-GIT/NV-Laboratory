# 变更日志

该集线器遵循 [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)。条目描述了这个存储库；应用程序版本是独立的。

<a id="unreleased"></a>
## [未发布]

<a id="added"></a>
### 已添加

- 中心、34 种 NV 应用语言的完整项目指南和存储库文档。
- 页面保留语言选择器、翻译覆盖元数据和稳定的内部锚点。
- 上游积分、完整的适用通知和文件出处。
- RTSS 要求和 NVRasterPulse 的官方下载链接。
- 单独的 RevoluSound Team 链接。
- 准备了首次发布的包目录、SHA-256验证和手动发布流程。
- 错误/功能形式、贡献和安全说明。
- 只读文档和发布边界检查。

<a id="changed"></a>
### 改变了

- NVMFG 归属现在可以区分独立开发的应用程序，
比较/细化参考，以及实际共享的本机组件。   现有版权、许可和文件比较保持不变。
- NVDriverForge 候选更新为 0.1.3：更正了可选组件处理，
可读的本地故障和更新的运行时/同伴包装。

<a id="fixed"></a>
### 固定

- NVIDIA Profile Inspector – NV Tools Fork 设置修订版 2 现在显示共享
直接启动时有 34 种语言选择器。保留露骨语言和无声转发；编辑器和便携包保持不变。

没有重建历史公开发布日期。候选应用版本为3.0.2.3、0.1.3、0.1.1和0.1；他们的发行说明附在他们自己的未来版本中。 2026 年 9 月 9 日的准备工作不是 GitHub 的发布日期。
