# 安全性

此策略涵盖 NV Tools 应用程序包和此分发中心。维护者优先考虑影响每个工具最新发布版本的报告。准备好的候选版本不是已宣布的受支持的稳定版本。不承诺回复期限或安全认证。

<a id="report-privately"></a>
## 私下举报

对于漏洞、不安全的提升行为、意外的破坏性更改或敏感数据暴露，请使用存储库的 **安全 → Report a vulnerability** 功能 **启用后**：[私人报告](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new)。

**初始设置：** 维护者必须在创建公共存储库后启用私有漏洞报告。该文件不会启用它，并且在此之前没有声称存在邮箱或私人频道。

如果该按钮不可用，请打开一个仅包含以下内容的公共问题：“我需要一个私人联系渠道来获取有关[工具/版本]的安全报告。”请勿包含漏洞利用详细信息、凭据、受影响的路径、日志或附件。等待维护者提供私人频道后再分享。

在私人报告中，包括工具/版本和哈希、Windows/GPU/驱动程序版本、影响、最小安全复制以及是否需要恢复。编辑秘密和个人数据；保留本地恢复文件。请勿上传专有驱动程序或游戏 DLL。与维护者协调披露；补丁/版本需要审查并且不是自动的。


[GitHub 私人报告文档](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
