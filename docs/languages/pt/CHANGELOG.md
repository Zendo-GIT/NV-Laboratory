# Registro de alterações

Este hub segue o [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). As entradas descrevem este repositório; as versões do aplicativo são independentes.

<a id="unreleased"></a>
## [Não lançado]

<a id="added"></a>
### Adicionado

- Hub, guias de projeto completos e documentação de repositório nas 34 linguagens de aplicação NV.
- Seletores de idiomas que preservam páginas, metadados de cobertura de tradução e âncoras internas estáveis.
- Créditos upstream, avisos completos aplicáveis e procedência do arquivo.
- Requisito RTSS e link de download oficial para NVRasterPulse.
- Links RevoluSound Team separados.
- Catálogo de pacotes de primeiro lançamento preparado, verificação SHA-256 e procedimento de liberação manual.
- Formulários de bugs/recursos, contribuições e instruções de segurança.
- Documentação somente leitura e verificações de limites de publicação.

<a id="changed"></a>
### Alterado

- A atribuição do NVMFG agora distingue a aplicação desenvolvida de forma independente,
a referência de comparação/refinamento e os componentes nativos compartilhados reais.   Os direitos autorais, licenças e comparações de arquivos existentes permanecem intactos.
- Candidato NVDriverForge atualizado para 0.1.3: manipulação de componentes opcionais corrigida,
falhas localizadas legíveis e pacote de tempo de execução/complemento atualizado.

<a id="fixed"></a>
### Corrigido

- A revisão 2 da configuração do NVIDIA Profile Inspector – NV Tools Fork agora mostra o arquivo compartilhado
Seletor de 34 idiomas quando iniciado diretamente. A linguagem explícita e o encaminhamento silencioso são preservados; o editor e o pacote portátil permanecem inalterados.

Nenhuma data histórica de lançamento público foi reconstruída. As versões candidatas do aplicativo são 3.0.2.3, 0.1.3, 0.1.1 e 0.1; suas notas de lançamento estão anexadas aos seus próprios lançamentos futuros. A preparação em 09/09/2026 não é uma data de lançamento do GitHub.
