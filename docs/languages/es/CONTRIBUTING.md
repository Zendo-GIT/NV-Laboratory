# Contribuyendo

NV Laboratory es mantenido por 禅堂 Zendo (RevoluSound Team). El mantenedor decide qué se acepta y se libera. Abrir una emisión o una solicitud de extracción no significa que se acepte o autorice una contribución para su distribución.

Utilice el formulario de error o característica e identifique el programa/versión. Busque primero los problemas existentes. Discuta cambios sustanciales antes de preparar una contribución importante. Para cuestiones de seguridad, siga [SECURITY.md](SECURITY.md).

Este centro público contiene documentación, avisos, metadatos de lanzamiento y validación del repositorio. La fuente de la aplicación y las pruebas se mantienen de forma privada. No envíe código descompilado, fuente privada, credenciales, perfiles de usuario o cargas útiles ejecutables.

Los RP de documentación deben mantener alineados los 34 idiomas y la navegación, preservar los nombres de comandos/archivos/productos y describir el comportamiento real. Las nuevas capturas de pantalla deben ser suyas, estar identificadas con la versión y estar libres de datos personales; los datos sintéticos deben etiquetarse. Proporcione procedencia y permiso para cada nuevo activo de terceros.

Utilice UTF-8, LF, Markdown legible y pequeños cambios enfocados. El validador Python utiliza únicamente la biblioteca estándar. Haga coincidir su estilo existente, evite dependencias innecesarias y ejecute:

```text
python tools/validate_repository.py
```

Para cambios en los metadatos de la versión, incluya la versión/etiqueta exacta, los tamaños de archivo y SHA-256 de los archivos binarios auditados y mantenga alineadas las páginas de descarga. Los cambios en las aplicaciones requieren compilaciones/pruebas privadas apropiadas para el comportamiento afectado; una verificación de documentación no es una prueba de solicitud. Nunca invente resultados o ganancias de pruebas históricas.

Al contribuir con material central original, acepta su licencia MIT en [LICENCIA](../../../LICENSE). Mantener avisos de terceros e identificar sus cambios; no reemplaza una licencia ascendente. La aceptación y la publicación siguen siendo decisiones del mantenedor.
