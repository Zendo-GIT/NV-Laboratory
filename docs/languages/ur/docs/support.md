<a id="compatibility-and-troubleshooting"></a>
# مطابقت اور خرابیوں کا سراغ لگانا

یہ تیار کردہ امیدوار ہیں، تمام Windows، GPU، ڈرائیور اور گیم کے امتزاج کے لیے سرٹیفیکیشن میٹرکس نہیں۔

| ٹول | Windows / رن ٹائم | ہارڈ ویئر / بیرونی انحصار | دیکھ بھال کی ضرورت کے آپریشن |
| --- | --- | --- | --- |
| NVPI fork 3.0.2.3 | Windows 10/11 x64, NET Framework 4.8 | ہم آہنگ NVIDIA ڈرائیور/ڈسپلے | پروفائل لکھتا ہے اور پیش نظارہ دکھاتا ہے۔ |
| NVDriverForge 0.1.2 | Windows 10 کی تعمیر 19041+ / 11 x64; .NET/WPF شامل ہے۔ | ہم آہنگ NVIDIA ڈرائیور پیکیج | بلند تنصیب، جدید ترتیبات، اختیاری NVENC |
| NVMFG Unlock40 0.1.1 | Windows 10/11 x64; NET/WPF شامل ہے، فریم ورک 4.8 مددگار | RTX 40، اہل DLSS FG گیم اور پن فراہم کنندہ | مقامی ان گیم پیچنگ، گلوبل پروفائل جرنل، SDK گیم اپ ڈیٹس |
| NVRasterPulse 0.1 | Windows 10/11 x64, NET Framework 4.8 | RTSS انسٹال؛ ٹوپیاں کے لئے چل رہا ہے | RTSS فی ایگزیکیوٹیبل پروفائل تبدیلیاں |

کوئی ARM64 پیکیج تیار نہیں ہے۔ ڈسپلے/API کی دستیابی اور پرانے Windows ورژن انفرادی خصوصیات کو محدود کر سکتے ہیں۔ کوئی یونیورسل کم از کم NVIDIA یا RTSS ورژن ایجاد نہیں ہوا ہے۔ عین مطابق NVMFG فراہم کنندہ ہیش [اصل](provenance.md) میں ہے۔

<a id="before-reporting-a-bug"></a>
## بگ کی اطلاع دینے سے پہلے

آپ نے کھولے ہوئے عین قابل عمل/ورژن کی شناخت کریں۔ ضروری نہیں کہ پچھلی انسٹال شدہ کاپی کسی نئے ڈاؤن لوڈ کردہ زپ کا ورژن ہو۔ تولیدی مراحل، متوقع نتیجہ اور حقیقی نتیجہ ریکارڈ کریں۔ رینڈرنگ/محدود مسائل کے لیے، گیم ورژن، ڈسپلے ریفریش، FG/V-Sync/VRR اسٹیٹ اور کوئی دوسرا محدود یا اوورلے شامل کریں۔

[بگ فارم](https://github.com/Zendo-GIT/NV-Laboratory/issues/new?template=bug-report.yml) استعمال کریں۔ مکمل پرائیویٹ ڈویلپمنٹ فولڈر، ڈرائیور آرکائیو، ماڈل، گیم ڈی ایل ایل، رجسٹری ڈمپ یا غیر جائزہ شدہ لاگ کلیکشن کو کبھی بھی منسلک نہ کریں۔

| مسئلہ | پہلے چیک کرتا ہے۔ |
| --- | --- |
| غلط ایپلیکیشن ورژن | EXE شناخت کی تصدیق کریں اور ہیش جاری کریں؛ تبدیل کرنے سے پہلے پرانی کاپی بند کریں۔ |
| رن ٹائم/اسٹارٹ اپ کی خرابی۔ | مطلوبہ فریم ورک 4.8 انسٹال کریں یا فراہم کردہ تمام پورٹیبل سب فولڈرز کو برقرار رکھیں۔ |
| UAC منسوخ کر دیا گیا۔ | صرف مطلوبہ آپریشن کی دوبارہ کوشش کریں؛ منسوخی کامیاب تنصیب نہیں ہے۔ |
| ہیش/دستخط کی مماثلت نہیں ہے۔ | اس امیدوار کا استعمال بند کریں اور متوقع آفیشل بائٹس حاصل کریں۔ |
| NVPI رنگ/موڈ کو مسترد کر دیا گیا۔ | اصل ڈسپلے/ڈرائیور کے ذریعے تعاون یافتہ امتزاج کو واپس لوٹائیں اور استعمال کریں۔ |
| NVDF بیک اپ یا ریکوری میں ناکامی۔ | محفوظ کام اور RECOVERY.txt کو محفوظ رکھیں؛ جریدے کو مت مٹایں یا متضاد تحریروں پر مجبور نہ کریں۔ |
| NVMFG زیر التواء ترتیبات | دیگر ٹولز سے تبدیلیوں کو محفوظ رکھتے ہوئے گیمز بند ہونے کے ساتھ ریکوری کو حل کریں۔ |
| RP ٹوپی کا کوئی اثر نہیں ہے۔ | RTSS چلائیں، اصلی گیم EXE کی شناخت کریں، ہک سٹیٹ اور مسابقتی حدود کا معائنہ کریں۔ |
| RP کیپ ہٹانے کے بعد برقرار رہتی ہے۔ | RTSS گلوبل کا معائنہ کریں؛ ہٹانے سے تبدیلیاں صرف مقامی حد کو اوور رائیڈ کرتا ہے۔ |

<a id="logs-and-privacy"></a>
## لاگ اور رازداری

| ٹول | جائزہ لینے کے لیے مقامی ڈیٹا، ہول سیل اپ لوڈ نہیں۔ |
| --- | --- |
| NVDF | `%LOCALAPPDATA%\NVDriverForge`؛ محفوظ ملازمتیں `%PROGRAMDATA%\NVDriverForge\Jobs` |
| NVMFG | `%LOCALAPPDATA%\RtxMfg`؛ بیک اپ `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`؛ EXE کے ساتھ `Sessions` |
| RP | `%LOCALAPPDATA%\NVRasterPulse`؛ اس کے نیچے `Backups\RTSS` |
| NVPI | آپ کی منتخب کردہ برآمدات اور ظاہر کردہ غلطی؛ کوئی ایجاد شدہ یونیورسل لاگ پاتھ نہیں۔ |

اپنے اشتراک کردہ متن/تصاویر سے اکاؤنٹ کے نام، ہوم ڈائریکٹریز، گیم-لائبریری کے راستے، ڈیوائس شناخت کنندگان، ٹوکنز اور غیر متعلقہ ونڈوز کو ہٹا دیں۔ وصولی کے لیے اصل کو نجی طور پر رکھیں۔ عوامی مسائل سب کو نظر آتے ہیں۔

کسی خطرے، خطرناک مراعات یافتہ رویے یا غیر ارادی تباہ کن آپریشن کے لیے، عوامی طور پر تفصیلات پوسٹ کرنے کے بجائے [SECURITY.md](../SECURITY.md) کی پیروی کریں۔

<a id="what-has-been-verified"></a>
## جس کی تصدیق ہو چکی ہے۔

حب کی تیاری کے لیے، جامد پے لوڈ/ZIP/hash/metadata اسکین اور دستاویزات کی جانچ پڑتال کی گئی۔ موجودہ پرائیویٹ ایپلیکیشن بلڈ/یونٹ/UI ٹیسٹ تاریخی، تاریخ کے ثبوت ہیں۔ اس تیاری کے حصے کے طور پر کوئی ڈرائیور انسٹال، ڈسپلے تبدیلی، لائیو RTSS آپریشن یا گیم بینچ مارک نہیں کیا گیا۔

"ڈیٹیکٹڈ"، "تحریری"، "دوبارہ لوڈ کی گئی"، "قابلیت دستیاب" اور "گیم میں ماپی گئی" مختلف نتائج ہیں۔ رپورٹ کریں کہ آپ نے کون سا مشاہدہ کیا ہے۔
