# چینج لاگ

یہ مرکز [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) کی پیروی کرتا ہے۔ اندراجات اس ذخیرہ کو بیان کرتی ہیں؛ ایپلیکیشن ورژن آزاد ہیں۔

<a id="unreleased"></a>
## [غیر ریلیز شدہ]

<a id="added"></a>
### شامل کیا گیا۔

- حب، 34 NV ایپلیکیشن زبانوں میں مکمل پروجیکٹ گائیڈز اور ذخیرہ دستاویزات۔
- صفحہ محفوظ کرنے والے زبان کے انتخاب کار، ترجمہ کوریج میٹا ڈیٹا اور مستحکم اندرونی اینکرز۔
- اپ اسٹریم کریڈٹس، مکمل قابل اطلاق نوٹسز اور فائل پرووینس۔
- RTSS کی ضرورت اور NVRasterPulse کے لیے آفیشل ڈاؤن لوڈ لنک۔
- RevoluSound Team لنکس کو الگ کریں۔
- پہلے ریلیز پیکیج کی کیٹلاگ، SHA-256 کی تصدیق اور دستی ریلیز کا طریقہ کار تیار۔
- بگ/فیچر فارم، شراکت اور حفاظتی ہدایات۔
- صرف پڑھنے کے لیے دستاویزات اور اشاعت کے لیے باؤنڈری چیک۔

<a id="changed"></a>
### بدل گیا۔

- NVMFG انتساب اب آزادانہ طور پر تیار کردہ ایپلیکیشن کو ممتاز کرتا ہے،
موازنہ/تطہیر کا حوالہ، اور اصل مشترکہ مقامی اجزاء۔   موجودہ کاپی رائٹس، لائسنس اور فائل کا موازنہ برقرار ہے۔
- NVDriverForge امیدوار کو 0.1.3 میں اپ ڈیٹ کیا گیا: اختیاری جزو کی ہینڈلنگ کو درست کیا گیا،
پڑھنے کے قابل مقامی ناکامیاں اور اپ ڈیٹ رن ٹائم/ساتھی پیکیجنگ۔

<a id="fixed"></a>
### فکسڈ

- NVIDIA Profile Inspector – NV Tools Fork سیٹ اپ نظرثانی 2 اب مشترکہ دکھاتا ہے۔
34 زبان کا انتخاب کنندہ جب براہ راست لانچ کیا جاتا ہے۔ واضح زبان اور خاموش فارورڈنگ محفوظ ہیں؛ ایڈیٹر اور پورٹیبل پیکیج میں کوئی تبدیلی نہیں ہے۔

کسی تاریخی عوامی ریلیز کی تاریخوں کو دوبارہ تشکیل نہیں دیا گیا ہے۔ امیدواروں کی درخواست کے ورژن 3.0.2.3، 0.1.3، 0.1.1 اور 0.1 ہیں؛ ان کے ریلیز نوٹس ان کی اپنی مستقبل کی ریلیز کے ساتھ منسلک ہیں۔ 2026-09-09 کی تیاری GitHub کی ریلیز کی تاریخ نہیں ہے۔
