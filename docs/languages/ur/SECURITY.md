# سیکورٹی

یہ پالیسی NV Tools ایپلیکیشن پیکجز اور اس ڈسٹری بیوشن ہب کا احاطہ کرتی ہے۔ دیکھ بھال کرنے والا ہر ٹول کے تازہ ترین شائع شدہ ورژن کو متاثر کرنے والی رپورٹوں کو ترجیح دیتا ہے۔ تیار امیدوار اعلان کردہ حمایت یافتہ مستحکم ریلیز نہیں ہیں۔ کسی جواب کی آخری تاریخ یا سیکیورٹی سرٹیفیکیشن کا وعدہ نہیں کیا گیا ہے۔

<a id="report-privately"></a>
## نجی طور پر رپورٹ کریں۔

کمزوریوں، غیر محفوظ بلند رویے، غیر ارادی تباہ کن تبدیلیوں، یا حساس ڈیٹا کی نمائش کے لیے، ریپوزٹری کی **سیکیورٹی → Report a vulnerability** خصوصیت **جب یہ فعال ہو**: [نجی رپورٹ](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new) استعمال کریں۔

**ابتدائی سیٹ اپ:** مینٹینر کو پبلک ریپوزٹری بنانے کے بعد پرائیویٹ ویلنریبلٹی رپورٹنگ کو فعال کرنا چاہیے۔ یہ فائل اسے فعال نہیں کرتی ہے، اور اس سے پہلے کوئی میل باکس یا نجی چینل موجود ہونے کا دعوی نہیں کیا گیا ہے۔

اگر بٹن دستیاب نہیں ہے، تو ایک عوامی مسئلہ کھولیں جس میں صرف یہ ہو: "مجھے [ٹول/ورژن] سے متعلق سیکیورٹی رپورٹ کے لیے ایک نجی رابطہ چینل درکار ہے۔" استحصال کی تفصیلات، اسناد، متاثرہ راستے، لاگز یا منسلکات شامل نہ کریں۔ ان کا اشتراک کرنے سے پہلے مینٹینر کے نجی چینل فراہم کرنے کا انتظار کریں۔

پرائیویٹ رپورٹ میں، ٹول/ورژن اور ہیش، Windows/GPU/ڈرائیور ورژن، اثر، کم سے کم محفوظ تولید اور کیا بحالی کی ضرورت ہے شامل کریں۔ رازوں اور ذاتی ڈیٹا کو درست کریں؛ مقامی ریکوری فائلوں کو محفوظ کریں۔ ملکیتی ڈرائیور یا گیم DLLs اپ لوڈ نہ کریں۔ مینٹینر کے ساتھ افشاء کو مربوط کریں؛ ایک پیچ/ریلیز کے لیے نظر ثانی کی ضرورت ہوتی ہے اور یہ خودکار نہیں ہے۔
