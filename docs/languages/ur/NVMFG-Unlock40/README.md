# NVMFG Unlock40

**تجرباتی NVIDIA Multi Frame Generation GeForce RTX 40 کے لیے، ایک مرکزی کنٹرولر اور فی گیم کے انتخاب کے ساتھ۔**

[0.1.1 اور اسٹیٹس ڈاؤن لوڈ کریں۔](../docs/downloads.md#nvmfg-unlock40) · [تنصیب](#installation) · [اپ اسٹریم](#upstream-and-modifications) · [لائسنس](LICENSES/README.md)

<a id="overview-and-purpose"></a>
## جائزہ اور مقصد

NVMFG Unlock40 禅堂 Zendo (RevoluSound Team) کی طرف سے آزادانہ طور پر تیار کردہ ایپلیکیشن ہے۔ یہ ایک Windows کنٹرولر، ایک مقامی پرت، ایک پروفائل مددگار اور گیم/Streamline SDK مینجمنٹ کو یکجا کرتا ہے۔ یہ ان گیمز کو نشانہ بناتا ہے جو پہلے سے ہی NVIDIA DLSS Frame Generation اور ہم آہنگ NVIDIA رن ٹائمز کو مربوط کرتے ہیں۔

[RTX40MFG-Unlock](https://github.com/dashdogy/RTX40MFG-Unlock) سے کام کا موازنہ کرنے اور اسے بہتر بنانے کے لیے مشورہ کیا گیا۔ موجودہ مقامی پرت مشترکہ اور موافقت پذیر اجزاء پر مشتمل ہے، ذیل میں انفرادی طور پر کریڈٹ کیا گیا ہے۔ یہ حوالہ پوری NVMFG ایپلیکیشن کو اس پروجیکٹ کا fork نہیں بناتا ہے۔

یہ تجرباتی MFG رویے کو مرکزی طور پر مربوط کرنے، گیم کے لیے مخصوص انتخاب کو یاد رکھنے، اور رن ٹائم اپ ڈیٹس اور بیک اپس کو مرئی رکھنے کے لیے موجود ہے۔ یہ DLSS Frame Generation کو ہر گیم میں شامل نہیں کرتا ہے یا صوابدیدی FSR نفاذ کو تبدیل نہیں کرتا ہے۔

تیار امیدوار **0.1.1** ہے، بشمول SDK-لسٹ بصری تصحیح اندرونی طور پر UI2 کے طور پر ریکارڈ کی گئی ہے۔ عوامی ورژن 0.1.1 رہتا ہے۔ اس کے عین مطابق ہیش اس امیدوار کو پرانی مقامی تعمیرات سے ممتاز کرتے ہیں۔

<a id="features"></a>
## خصوصیات

- مرکزی فعال/غیر فعال کنٹرول اور اختیاری Windows ٹرے اسٹارٹ اپ۔
- Dynamic MFG کے درمیان فی گیم سلیکشن، گیم کی سیٹنگ اور سپورٹڈ فکسڈ ملٹی پلائر۔
- مشاہدہ شدہ V-Sync آن/آف ریاستوں کے لیے الگ یاد کردہ انتخاب۔
- Dynamic NVIDIA کا موڈ استعمال کرتا ہے۔ V-Sync آف ہونے پر اسے معطل کر دیا جاتا ہے، ایک الگ ان-گیم/مقررہ انتخاب کے ساتھ۔
- گیم مینو رہنمائی اور مستقل اخراج؛ DLSS FG کے بغیر گیمز کنٹرول میں رہتی ہیں۔
- گیم کی دریافت، پیرنٹ فولڈر کا انتخاب، تلاش، گروپ بندی اور گیم فائلوں کو حذف کیے بغیر ہٹانا۔
- Streamline SDK ڈاؤن لوڈ/درآمد، تصدیق شدہ مقامی کیش، واضح انتخاب، فی گیم بیک اپ اور بحالی۔
- مقامی فراہم کنندہ کی توثیق، فی سیشن تشخیص، عالمی پروفائل جرنل اور تنازعات سے آگاہ ریکوری۔
- 34 انٹرفیس زبانیں اور چار تھیمز۔

گیم میں ایف جی کو آف کرنا اسے بند رکھتا ہے۔ 2x سے 6x تک کے فکسڈ انتخاب گیم/مینو/رن ٹائم پر منحصر ہیں۔ وہ وعدہ نہیں ہیں کہ ہر مجموعہ کام کرتا ہے۔ کنٹرولر V-Sync کا مشاہدہ کرتا ہے اور صارف کے لیے V-Sync یا VRR سیٹ نہیں کرتا ہے۔

<a id="installation"></a>
## تنصیب

1. [امیدوار کی حیثیت اور لائسنسنگ نوٹ](../docs/downloads.md#nvmfg-unlock40) پڑھیں۔
2. `NVMFGUnlock40-0.1.1-Setup-x64.exe` یا `NVMFGUnlock40-0.1.1-Portable-x64.zip` ڈاؤن لوڈ کریں جب اس کی ریلیز دستیاب ہو۔
3. SHA-256 چیک کریں اور ساتھ میں نوٹس رکھیں۔ .NET Framework 4.8 انسٹال کریں اگر Windows پہلے سے فراہم نہیں کرتا ہے۔
4. سیٹ اپ چلائیں، یا **پوری** پورٹیبل زپ کو قابل تحریر مقامی فولڈر میں نکالیں۔
5. `NVMFGUnlock40.exe` لانچ کریں؛ `agent`، `driver`، `engine` اور `Licenses` کو فراہم کردہ ترتیب میں رکھیں۔

`driver` نامی فولڈر میں یوزر اسپیس مددگار ہوتے ہیں، کرنل ڈرائیور نہیں۔ مطابقت کو مجبور کرنے کے لیے صرف مرکزی EXE کو کاپی نہ کریں یا فراہم کنندہ ہیش کو تبدیل نہ کریں۔ موجودہ EXE غیر دستخط شدہ ہیں۔

<a id="usage"></a>
## استعمال

1. کنٹرولر کو غیر فعال کے ساتھ شروع کریں۔ ایک گیم یا پیرنٹ فولڈر شامل کریں اور اصل تنصیبات کا انتخاب کریں۔
2. ہر گیم کی MFG سیٹنگز کا جائزہ لیں۔ جواب دیں کہ اس کا مینو کیا پیش کرتا ہے۔ جواب فی گیم محفوظ کیا جاتا ہے۔
3. Dynamic یا عالمی سطح پر ان گیم سیٹنگ کا انتخاب کریں، پھر ضرورت کے مطابق فی گیم کے اہل انتخاب کو ایڈجسٹ کریں۔
4. کنٹرولر کو صرف اس وقت فعال کریں جب آپ اسے استعمال کرنے کا ارادہ رکھتے ہوں۔ یہ ریکوری جرنل کے ساتھ چھ عالمی NVIDIA پروفائل سیٹنگز کو عارضی طور پر تبدیل کر سکتا ہے۔
5. ایک اہل گیم لانچ کریں اور اس کا اپنا DLSS Frame Generation فعال کریں۔ V-Sync-آف انتخاب کے لیے کسی بھی درخواست پر عمل کریں۔
6. ان گیمز کے لیے استثنیٰ کا استعمال کریں جن کا آپ انتظام نہیں کرنا چاہتے۔ کسی گیم کو ہٹانے سے ایک اخراج ریکارڈ ہوتا ہے اور اس کی فائلوں/بیک اپ کو محفوظ کیا جاتا ہے۔
7. مکمل ہونے پر ایپلیکیشن کا مکمل چھوڑنا/غیر فعال اور ریکوری فلو استعمال کریں۔

مین ونڈو کو بند کرنے سے کنٹرولر ٹرے میں رہ سکتا ہے۔ گیم میں پہلے سے بھری ہوئی ڈی ایل ایل گیم کے باہر ہونے تک موجود رہتی ہے۔ کنٹرولر کو غیر فعال کرنا ان لوڈ کی گارنٹی نہیں ہے۔ دیکھ بھال یا اپ ڈیٹس سے پہلے متاثرہ گیمز کو بند کر دیں۔

**Streamline SDKs:** NVIDIA SDK صفحہ پر، ایک آفیشل ورژن ڈاؤن لوڈ کریں یا ہم آہنگ مقامی SDK درآمد کریں۔ ایک تصدیق شدہ کاپی درآمد کریں؛ **Use this version** اسے منتخب کرتا ہے، اور **Uninstall** اس کیش شدہ کاپی کو ہٹا دیتا ہے۔ غائب Streamline DLLs کو ایک آفیشل NVIDIA SDK سے پورا کیا جا سکتا ہے، ماخذ دکھایا گیا ہے۔ یہ NGX ماڈل کو ڈاؤن لوڈ/تبدیل نہیں کرتا ہے۔ گیم بند کریں، مطلوبہ گیم اپ ڈیٹ منتخب کریں، اور اس کا اصل بیک اپ برقرار رکھیں۔ گیم فائلوں کو واپس لانے کے لیے، اس کی بیک اپ بحالی کا استعمال کریں، نہ کہ کیشے کا Uninstall بٹن۔

<a id="update-and-uninstall"></a>
## اپ ڈیٹ اور ان انسٹال کریں۔

متاثرہ گیمز بند کریں۔ NVMFG کو غیر فعال/چھوڑ دیں اور اپ ڈیٹ کرنے سے پہلے کسی بھی زیر التواء NVIDIA سیٹنگ ریکوری کو حل کریں۔ موجودہ شناخت کے ساتھ اگلا سیٹ اپ انسٹال کریں، یا نئے پورٹیبل کو ایک تازہ فولڈر میں نکالیں۔ ریاست/بیک اپ کو برقرار رکھیں۔

اَن انسٹال کرنے سے پہلے، ایپلیکیشن کے ذریعے مطلوبہ گیم SDK بیک اپ اور NVIDIA سیٹنگز کو بحال کریں، پھر گیمز بند کریں اور کنٹرولر کو چھوڑ دیں۔ سیٹ اپ کے لیے Windows **Installed apps** استعمال کریں، یا ضروری فائلوں کو محفوظ کرنے کے بعد بند پورٹیبل فولڈر کو ہٹا دیں۔ سیٹ اپ کو غیر مسدود کرنے کے لیے ایک فعال ریکوری جرنل کو دستی طور پر حذف نہ کریں۔

مقامی گیم رن ٹائم بیک اپ `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups` استعمال کرتے ہیں۔ MFG ترتیبات/SDK ڈیٹا `%LOCALAPPDATA%\RtxMfg` استعمال کرتا ہے؛ سیشن آؤٹ پٹ ایپلیکیشن کے ساتھ `Sessions` کے تحت ہے۔ ان فائلوں میں گیم کے راستے شامل ہو سکتے ہیں۔ ان کو بغیر ترمیم کے پوسٹ نہ کریں۔

<a id="known-limitations"></a>
## معلوم حدود

- تجرباتی مقامی پیچ کریش یا بصری نمونے کا سبب بن سکتے ہیں۔ ایک غیر حل شدہ Bodycam کریش ڈویلپمنٹ ہسٹری میں درج ہے۔
- کنٹرول شدہ پیش کنندہ ٹیسٹ ہر گیم، ڈرائیور یا اینٹی چیٹ کے لیے سرٹیفیکیشن نہیں ہیں۔
- تیار کردہ فریم نئے ان پٹ نمونے نہیں بناتے ہیں۔ اس مرکز کی طرف سے کسی ناپی گئی تاخیر یا کارکردگی کے حصول کا وعدہ نہیں کیا گیا ہے۔
- متعدد فریم جنریشن ٹولز/اوورلیز متصادم ہو سکتے ہیں۔ ایپلی کیشن کی رپورٹوں میں ماڈیولز کا مشاہدہ کیا گیا ہے بغیر کسی بقائے باہمی کے ہر منظر نامے کو ثابت کیا گیا ہے۔
- کمپیٹیبلٹی مینی فیسٹ ایک پتہ لگانے میں مدد ہے، نہ کہ مکمل ٹیسٹ شدہ گیمز کی فہرست۔
- مکمل NVIDIA SDK شرائط اور حل نہ ہونے والی تکنیکی حد بندی [اصل](../docs/provenance.md) میں دستاویزی رہتی ہے۔
