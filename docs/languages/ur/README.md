# NV Laboratory

**NV Tools از 禅堂 Zendo (RevoluSound Team)۔** NVIDIA ڈرائیور پروفائلز، ڈرائیور کی تنصیب، تجرباتی Multi Frame Generation اور RTSS فریم کی حدوں کے لیے چار آزاد Windows یوٹیلیٹیز۔

[اوزار حاصل کریں۔](docs/downloads.md) · [تنصیب](docs/installation.md) · [مطابقت اور مدد](docs/support.md) · [کریڈٹ اور لائسنس](THIRD_PARTY_NOTICES.md)

> **NVRasterPulse کو RTSS کی ضرورت ہے۔** پہلے [Guru3D سے RivaTuner Statistics Server](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) انسٹال کریں۔ RTSS کو اس کی FPS حدود کے کام کرنے کے لیے چلنا چاہیے۔ اسے الگ سے ڈاؤن لوڈ کیا جاتا ہے۔

<a id="start-here"></a>
## یہاں سے شروع کریں۔

1. اوپر ایک ٹول چنیں۔ ہر ایک آزادانہ طور پر کام کرتا ہے؛ پورے سویٹ کو انسٹال کرنا غیر ضروری ہے۔
2. اس کے تقاضے پڑھیں اور انسٹال کردہ ایپ کے لیے **سیٹ اپ**، یا علیحدہ فولڈر کے لیے **پورٹ ایبل** کا انتخاب کریں۔
3. جب اس کی ریلیز شائع ہو جائے تو، نامزد کردہ ایپلیکیشن اثاثہ ڈاؤن لوڈ کریں، اس کے ساتھ دیے گئے نوٹس کو پڑھیں اور اس کا SHA-256 کا موازنہ کریں۔
4. ڈرائیور، ڈسپلے سیٹنگ، NVIDIA پروفائل یا گیم رن ٹائم تبدیل کرنے سے پہلے بیک اپ رکھیں۔

دستاویزات انہی 34 زبانوں میں دستیاب ہیں جن میں NV ایپلیکیشنز ہر گائیڈ کے اوپری حصے میں سلیکٹر کے ذریعے دستیاب ہیں۔ GitHub خود بخود براؤزر کی زبان کے ذریعہ README کا انتخاب نہیں کرتا ہے۔ دستاویزات کی زبان اور درخواست کی اپنی زبان کی ترتیب الگ الگ ہیں۔

<a id="provenance-and-ownership"></a>
## اصل اور ملکیت

یہ مرکز دستاویزات اور مرتب کردہ ایپلیکیشنز تقسیم کرتا ہے۔ درخواست کا سورس کوڈ نجی طور پر رکھا جاتا ہے۔ اپ اسٹریم پروجیکٹس اپنی تصنیف اور لائسنس برقرار رکھتے ہیں۔ نجی ذریعہ کی تقسیم ان شرائط کی جگہ نہیں لیتی ہے۔

- Profile Inspector fork Orbmu2k کا MIT لائسنس برقرار رکھتا ہے اور واضح طور پر ایک fork کے طور پر پہچانا جاتا ہے۔
- NVDriverForge کی اپنی بائنری تقسیم کی شرائط ہیں اور اس میں الگ سے لائسنس یافتہ رن ٹائم/ٹول کے اجزاء شامل ہیں۔
- NVMFG Unlock40 ایک آزادانہ طور پر تیار کردہ ایپلیکیشن ہے۔ موازنہ اور تطہیر کے لیے RTX40MFG-Unlock سے مشورہ کیا گیا۔ مشترکہ مقامی اجزاء اپنے MIT کریڈٹ کو برقرار رکھتے ہیں۔ MinHook اور NVIDIA SDK شرائط الگ رہیں۔
- NVRasterPulse فراہم کردہ MIT لائسنس کو برقرار رکھتا ہے اور Profile Inspector سے حاصل کردہ UI کو کریڈٹ کرتا ہے۔ RTSS ایک مطلوبہ بیرونی پروگرام ہے۔

[مکمل اجزاء کی میز](THIRD_PARTY_NOTICES.md)، [فائل کی بنیاد اور تبدیلیاں](docs/provenance.md)، اور [لائسنس کی گنجائش](../../../LICENSE) دیکھیں۔
