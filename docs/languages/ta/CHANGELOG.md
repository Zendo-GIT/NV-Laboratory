# சேஞ்ச்லாக்

இந்த மையம் [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)ஐப் பின்பற்றுகிறது. பயன்பாட்டின் பதிப்புகள் மற்றும் வெளியீட்டு தேதிகள் சுயாதீனமானவை. கீழே தயாரிக்கப்பட்ட தொகுப்புகள் அவற்றின் உண்மையான வெளியீட்டுத் தேதிகளை அந்தந்த GitHub வெளியீடுகளில் பெறுகின்றன.

## [வெளியிடப்படவில்லை]

<a id="changed"></a>
### மாற்றப்பட்டது

- NVDriverForge 0.1.4க்கான மையத்தையும் அனைத்து 34 ஆவண மொழிகளையும் புதுப்பிக்கவும்,
NVMFG Unlock40 0.2.3 மற்றும் NVRasterPulse 0.2, 2026-09-18 அன்று தயாரிக்கப்பட்டது.
- NVDriverForge: தயார்நிலை சரிபார்ப்புகள், சொந்த சுயவிவர காப்புப்பிரதிகள் மற்றும் பாதுகாக்கப்பட்ட மீட்பு,
கூறு வழிகாட்டுதல், மீண்டும் பயன்படுத்தக்கூடிய விருப்பத்தேர்வுகள், இயக்கி கருவிகள், விரிவான முடிவுகள், உள்ளூர் ஆதரவு அறிக்கைகள் மற்றும் தனி பயன்பாட்டு புதுப்பிப்புகள்.
- NVMFG: பல கோப்புறை கண்டுபிடிப்பு, நிலையான நூலக தற்காலிக சேமிப்பு, கவனிக்கப்பட்ட MFG செயல்பாடு,
இயக்க நேரத் திறன் தகவல், அடுத்த வெளியீட்டு விலக்கு, உள்ளூர் கண்டறிதல், விருப்பப் பரிமாற்றம் மற்றும் விருப்பப் பயன்பாட்டு புதுப்பிப்புகள்.
- NVRasterPulse: உள்ளமைவு கண்டறிதல், FPS பரிந்துரைகள், இடைநிறுத்தம்/தொடக்கம்,
ஒரு நிலை செயல்தவிர், தேர்ந்தெடுக்கப்பட்ட சுயவிவர இறக்குமதி/ஏற்றுமதி, பிடித்தவை மற்றும் மறைக்கப்பட்ட உள்ளீடுகள்.
- தொகுப்பு ஹாஷ்கள், வெளியீட்டு குறிப்புகள் மற்றும் சொந்த-கூறு ஆதார வரைபடத்தைப் புதுப்பிக்கவும்.
ஏற்கனவே வெளியிடப்பட்ட Profile Inspector 3.0.2.3/setup-r2 சொத்துக்களை மாற்றாமல் வைத்திருங்கள்.

<a id="fixed"></a>
### சரி செய்யப்பட்டது

- NVMFG கேம் தேர்வு/கணக்குகள், Ctrl+D கையாளுதல் மற்றும் நிறைவு செய்திகள்;
கேம் கண்டறிதலில் இருந்து Wallpaper Engine விலக்கப்பட்டுள்ளது. தனித்தனியாக அறிவிக்கப்பட்ட 0.1.1 மறுசீரமைப்பு அடைப்பு மீண்டும் உருவாக்கப்படாமல் உள்ளது மேலும் அது சரி செய்யப்பட்டது எனக் கூறப்படவில்லை.

பக்கத்தைப் பாதுகாக்கும் தேர்வாளர்கள், நிலையான அறிவிப்பாளர்கள் மற்றும் மொழிபெயர்ப்பு கவரேஜ் மெட்டாடேட்டா.

தனி RevoluSound Team இணைப்புகள்.

படிக்க மட்டுமே ஆவண சரிபார்ப்பு. விண்ணப்ப ஆதாரங்கள் தனிப்பட்டதாக இருக்கும்.
- முதல் பொது குறிச்சொற்கள்: `nvpi-v3.0.2.3`, `nvdriverforge-v0.1.3`,
`nvmfg-unlock40-v0.1.1` மற்றும் `nvrasterpulse-v0.1`.
