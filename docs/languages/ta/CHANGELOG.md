### சேர்க்கப்பட்டது

- 34 NV பயன்பாட்டு மொழிகளில் ஹப், முழுமையான திட்ட வழிகாட்டிகள் மற்றும் களஞ்சிய ஆவணங்கள்.
- பக்கத்தைப் பாதுகாக்கும் மொழித் தேர்வாளர்கள், மொழிபெயர்ப்பு கவரேஜ் மெட்டாடேட்டா மற்றும் நிலையான உள் அறிவிப்பாளர்கள்.
- அப்ஸ்ட்ரீம் வரவுகள், முழு பொருந்தக்கூடிய அறிவிப்புகள் மற்றும் கோப்பு ஆதாரம்.
- RTSS தேவை மற்றும் NVRasterPulseக்கான அதிகாரப்பூர்வ பதிவிறக்க இணைப்பு.
- தனி RevoluSound Team இணைப்புகள்.
- தயாரிக்கப்பட்ட முதல்-வெளியீட்டு தொகுப்பு பட்டியல், SHA-256 சரிபார்ப்பு மற்றும் கைமுறை வெளியீட்டு நடைமுறை.
- பிழை/அம்ச வடிவங்கள், பங்களிப்பு மற்றும் பாதுகாப்பு வழிமுறைகள்.
- படிக்க மட்டுமேயான ஆவணங்கள் மற்றும் வெளியீடு-எல்லைச் சரிபார்ப்புகள்.

### சரி செய்யப்பட்டது

- NVIDIA Profile Inspector – NV Tools Fork அமைவு திருத்தம் 2 இப்போது பகிரப்பட்டதைக் காட்டுகிறது
நேரடியாக தொடங்கப்படும் போது 34-மொழி தேர்வி. வெளிப்படையான மொழி மற்றும் அமைதியான பகிர்தல் ஆகியவை பாதுகாக்கப்படுகின்றன; எடிட்டர் மற்றும் போர்ட்டபிள் தொகுப்பு மாறாமல் உள்ளது.

வரலாற்று பொது வெளியீட்டு தேதிகள் எதுவும் புனரமைக்கப்படவில்லை. விண்ணப்பதாரர் விண்ணப்பப் பதிப்புகள் 3.0.2.3, 0.1.3, 0.1.1 மற்றும் 0.1; அவர்களின் வெளியீட்டு குறிப்புகள் அவற்றின் சொந்த எதிர்கால வெளியீடுகளுடன் இணைக்கப்பட்டுள்ளன. 2026-09-09 அன்று தயாரிப்பது GitHub வெளியீட்டு தேதி அல்ல.
