# NVMFG Unlock40

** GeForce RTX 40க்கான பரிசோதனை NVIDIA Multi Frame Generation, மையக் கட்டுப்படுத்தி மற்றும் ஒரு விளையாட்டு தேர்வுகள்.**

[0.2.3 & நிலையைப் பதிவிறக்கவும்](../docs/downloads.md#nvmfg-unlock40) · [நிறுவல்](#installation) · [அப்ஸ்ட்ரீம்](#upstream-and-modifications) · [உரிமங்கள்](LICENSES/README.md)

<a id="overview-and-purpose"></a>
## கண்ணோட்டம் மற்றும் நோக்கம்

NVMFG Unlock40 என்பது 禅堂 Zendo (RevoluSound Team) ஆல் சுயாதீனமாக உருவாக்கப்பட்ட பயன்பாடாகும். இது Windows கட்டுப்படுத்தி, ஒரு நேட்டிவ் லேயர், ஒரு சுயவிவர உதவி மற்றும் கேம்/Streamline SDK மேலாண்மை ஆகியவற்றை ஒருங்கிணைக்கிறது. இது ஏற்கனவே NVIDIA DLSS Frame Generation மற்றும் இணக்கமான NVIDIA இயக்க நேரங்களை ஒருங்கிணைக்கும் கேம்களை குறிவைக்கிறது.

[RTX40MFG-Unlock](https://github.com/dashdogy/RTX40MFG-Unlock) பணியை ஒப்பிட்டு செம்மைப்படுத்த ஆலோசனை செய்யப்பட்டது. தற்போதைய நேட்டிவ் லேயரில் பகிரப்பட்ட மற்றும் மாற்றியமைக்கப்பட்ட கூறுகள் உள்ளன, தனித்தனியாக கீழே வரவு வைக்கப்பட்டுள்ளது. இந்த குறிப்பு முழு NVMFG பயன்பாட்டையும் அந்த திட்டத்தின் fork ஆக மாற்றாது.

சோதனை MFG நடத்தையை மையமாக ஒருங்கிணைக்கவும், கேம் சார்ந்த தேர்வுகளை நினைவில் கொள்ளவும், இயக்க நேர புதுப்பிப்புகள் மற்றும் காப்புப்பிரதிகளைக் காணவும் இது உள்ளது. இது ஒவ்வொரு கேமிலும் DLSS Frame Generation ஐ சேர்க்காது அல்லது தன்னிச்சையான FSR செயல்படுத்தலை மாற்றாது.

தற்போதைய தொகுப்பு **0.2.3**. இது நிலையான விளையாட்டு நூலகம், செயல்பாடு மற்றும் திறன் தகவல், உள்ளூர் கண்டறிதல் மற்றும் திருத்தப்பட்ட தேர்வு/முன்னேற்ற நடத்தை ஆகியவற்றைச் சேர்க்கிறது. [பதிவிறக்கங்கள்](../docs/downloads.md#nvmfg-unlock40) சரியான கோப்புகள் மற்றும் ஹாஷ்களை அடையாளம் காட்டுகிறது.

## அம்சங்கள்

- மத்திய இயக்கு/முடக்கு கட்டுப்பாடு மற்றும் விருப்பமான Windows தட்டு தொடக்கம்.
- Dynamic MFG இடையே ஒரு விளையாட்டு தேர்வு, கேமின் அமைப்பு மற்றும் ஆதரிக்கப்படும் நிலையான பெருக்கிகள்.
- கவனிக்கப்பட்ட V-Sync ஆன்/ஆஃப் நிலைகளுக்கு தனித்தனியாக நினைவில் வைக்கப்படும் தேர்வுகள்.
- Dynamic NVIDIA இன் பயன்முறையைப் பயன்படுத்துகிறது; V-Sync முடக்கத்தில் இருக்கும் போது அது இடைநிறுத்தப்பட்டு, ஒரு தனி விளையாட்டு/நிலையான விருப்பத்துடன்.
- கேம்-மெனு வழிகாட்டுதல் மற்றும் தொடர்ச்சியான விலக்குகள்; DLSS FG இல்லாத கேம்கள் கட்டுப்பாட்டில் இருக்கும்.
- கேம் கண்டுபிடிப்பு, பெற்றோர்-கோப்புறை தேர்வு, தேடல், குழுவாக்கம் மற்றும் கேம் கோப்புகளை நீக்காமல் அகற்றுதல்.
- Streamline SDK பதிவிறக்கம்/இறக்குமதி, சரிபார்க்கப்பட்ட உள்ளூர் கேச், வெளிப்படையான தேர்வு, ஒவ்வொரு கேம் காப்பு மற்றும் மறுசீரமைப்பு.
- நேட்டிவ் வழங்குநர் சரிபார்ப்பு, ஒவ்வொரு அமர்விற்கும் கண்டறிதல், உலகளாவிய சுயவிவர இதழ் மற்றும் மோதல் விழிப்புணர்வு மீட்பு.
- 34 இடைமுக மொழிகள் மற்றும் நான்கு கருப்பொருள்கள்.

விளையாட்டில் FG ஐ முடக்குவது அதைத் தடுக்கிறது. 2x முதல் 6x வரையிலான நிலையான தேர்வுகள் கேம்/மெனு/இயக்க நேரத்தைப் பொறுத்தது; ஒவ்வொரு கலவையும் செயல்படும் என்று அவை வாக்குறுதி அளிக்கவில்லை. கட்டுப்படுத்தி V-Sync ஐக் கவனிக்கிறது மற்றும் பயனருக்கு V-Sync அல்லது VRR ஐ அமைக்கவில்லை.

<a id="installation"></a>
## நிறுவல்

1. [வேட்பாளர் நிலை மற்றும் உரிமக் குறிப்பு](../docs/downloads.md#nvmfg-unlock40) ஐப் படிக்கவும்.
2. அதன் வெளியீடு கிடைக்கும்போது `NVMFGUnlock40-0.2.3-Setup-x64.exe` அல்லது `NVMFGUnlock40-0.2.3-Portable-x64.zip` ஐப் பதிவிறக்கவும்.
3. SHA-256 ஐ சரிபார்த்து, அதனுடன் உள்ள அறிவிப்புகளை வைத்திருங்கள். Windows ஏற்கனவே வழங்கவில்லை என்றால் .NET Framework 4.8 ஐ நிறுவவும்.
4. அமைவை இயக்கவும் அல்லது **முழு** போர்ட்டபிள் ஜிப்பை எழுதக்கூடிய உள்ளூர் கோப்புறையில் பிரித்தெடுக்கவும்.
5. `NVMFGUnlock40.exe` ஐ துவக்கவும்; `agent`, `driver`, `engine` மற்றும் `Licenses` ஆகியவற்றை வழங்கப்பட்ட தளவமைப்பில் வைக்கவும்.

`driver` என பெயரிடப்பட்ட கோப்புறையில் பயனர் இட உதவியாளர்கள் உள்ளனர், கர்னல் இயக்கி அல்ல. முக்கிய EXE ஐ மட்டும் நகலெடுக்க வேண்டாம் அல்லது இணக்கத்தன்மையை கட்டாயப்படுத்த வழங்குநர் ஹாஷை மாற்ற வேண்டாம். தற்போதைய EXEகள் கையொப்பமிடப்படவில்லை.

## பயன்பாடு

1. கட்டுப்படுத்தி முடக்கப்பட்ட நிலையில் தொடங்கவும். கேம் அல்லது பெற்றோர் கோப்புறையைச் சேர்த்து, உண்மையான நிறுவல்களைத் தேர்ந்தெடுக்கவும்.
2. ஒவ்வொரு கேமின் MFG அமைப்புகளையும் மதிப்பாய்வு செய்யவும். அதன் மெனு என்ன வழங்குகிறது என்று பதிலளிக்கவும்; பதில் ஒரு விளையாட்டுக்கு சேமிக்கப்படுகிறது.
3. Dynamic அல்லது கேம்-இன்-கேம் அமைப்பை உலகளவில் தேர்வுசெய்து, தேவைக்கேற்ப தகுதியான ஒரு விளையாட்டுத் தேர்வுகளை சரிசெய்யவும்.
4. கட்டுப்படுத்தியைப் பயன்படுத்த விரும்பும் போது மட்டுமே அதை இயக்கவும். இது ஆறு உலகளாவிய NVIDIA சுயவிவர அமைப்புகளை மீட்டெடுப்பு இதழுடன் தற்காலிகமாக மாற்றலாம்.
5. தகுதியான விளையாட்டைத் தொடங்கி அதன் சொந்த DLSS Frame Generation ஐ இயக்கவும். V-Sync-ஆஃப் தேர்வுக்கான எந்தவொரு கோரிக்கையையும் பின்பற்றவும்.
6. நீங்கள் நிர்வகிக்க விரும்பாத கேம்களுக்கு விலக்குகளைப் பயன்படுத்தவும். ஒரு விளையாட்டை அகற்றுவது ஒரு விலக்கைப் பதிவுசெய்து அதன் கோப்புகள்/காப்புப்பிரதிகளைப் பாதுகாக்கிறது.
7. பயன்பாட்டின் முழு வெளியேறுதல்/முடக்குதல் மற்றும் முடிந்ததும் மீட்பு ஓட்டத்தைப் பயன்படுத்தவும்.

பிரதான சாளரத்தை மூடுவது கட்டுப்படுத்தியை தட்டில் விடலாம். கேமில் ஏற்கனவே ஏற்றப்பட்ட டிஎல்எல் கேம் வெளியேறும் வரை அங்கேயே இருக்கும்; கட்டுப்படுத்தியை முடக்குவது இறக்கும் உத்தரவாதம் அல்ல. பராமரிப்பு அல்லது புதுப்பிப்புகளுக்கு முன் பாதிக்கப்பட்ட கேம்களை மூடு.

**Streamline SDKs:** NVIDIA SDK பக்கத்தில், அதிகாரப்பூர்வ பதிப்பைப் பதிவிறக்கவும் அல்லது இணக்கமான உள்ளூர் SDK ஐ இறக்குமதி செய்யவும். சரிபார்க்கப்பட்ட நகலை இறக்குமதி செய்கிறது; **Use this version** அதைத் தேர்ந்தெடுத்து, **Uninstall** அந்த தற்காலிகச் சேமிப்பு நகலை நீக்குகிறது. விடுபட்ட Streamline DLLகளை அதிகாரப்பூர்வ NVIDIA SDK இல் இருந்து கூடுதலாகக் காட்டப்படும் மூலத்துடன் சேர்க்கலாம். இது NGX மாதிரியை பதிவிறக்கம் செய்யாது/மாற்றாது. விளையாட்டை மூடி, உத்தேசித்துள்ள கேம் புதுப்பிப்பைத் தேர்ந்தெடுத்து, அதன் அசல் காப்புப்பிரதியைத் தக்க வைத்துக் கொள்ளுங்கள். கேம் கோப்புகளை மாற்றியமைக்க, அதன் காப்புப் பிரதி மீட்டமைப்பைப் பயன்படுத்தவும், தேக்ககத்தின் Uninstall பொத்தான் அல்ல.

## நூலகம், கண்டறிதல் மற்றும் புதுப்பிப்புகள்

**தொடர்ச்சியான நூலகம்:** ஒரு ஸ்கேன் தொடங்கும் முன், வெவ்வேறு டிரைவ்கள் உட்பட பல கேம் கோப்புறைகளைத் தேர்ந்தெடுக்கவும். முன்னேற்றம் தெரியும் மற்றும் ரத்து கிடைக்கும். முதல் ஸ்கேன் செய்த பிறகு, ஒரு உள்ளூர் கேச் ஒவ்வொரு கேம் கோப்புறையிலும் நடக்காமல் துவக்கத்தில் நூலகத்தை மீட்டெடுக்கிறது. மாற்றங்களைக் கண்டறிய அல்லது மற்றொரு கோப்புறையைச் சேர்க்க புதுப்பிக்கவும். பராமரிப்பு நடவடிக்கைகள் இன்னும் பாதிக்கப்பட்ட கோப்புகளை மறுமதிப்பீடு செய்கின்றன; காப்பு கண்காணிப்பு செயலில் உள்ளது. கேச் `%LOCALAPPDATA%\RtxMfg\library-cache.json` இல் சேமிக்கப்பட்டுள்ளது.

**தேர்வு:** Ctrl+A அனைத்தையும் தேர்ந்தெடுக்கிறது மற்றும் Ctrl+D செயலில் உள்ள கேம்கள் அல்லது காப்புப்பிரதிகள் தாவலை அழிக்கிறது. எந்த விளையாட்டும் தானாகவே தேர்ந்தெடுக்கப்படவில்லை. செயல்பாட்டு புதுப்பிப்புகள் மற்றும் புதுப்பிப்புகள் இனி பேய் தேர்வுகள் அல்லது சீரற்ற எண்ணிக்கையை உருவாக்காது.

**செயல்பாடு மற்றும் இணக்கத்தன்மை:** ஒரு விளையாட்டுக்கான MFG தகவல் புதிய மேலடுக்கு இல்லாமல் NGX அவதானிப்புகளிலிருந்து வருகிறது. இது காட்டப்படும் பிரேம்களின் உடல் எண்ணிக்கை அல்ல. Dynamic-with-V-Sync ஆதரவு இயக்க நேர திறன்களிலிருந்து வருகிறது; அறியப்படாத திறன் பதிப்பு எண்ணிலிருந்து ஊகிக்கப்படவில்லை. பயன்பாடு V-Sync அல்லது VRR ஆக மாறாது. V-Sync முடக்கத்தில், Dynamic இடைநிறுத்தப்பட்டுள்ளது; நிலையான அல்லது விளையாட்டு-கட்டுப்படுத்தப்பட்ட தேர்வுகள் தனித்தனியாக இருக்கும்.

**அடுத்த துவக்கம்:** தற்காலிக விலக்கு அடுத்த கேம் துவக்கத்தில் பேட்ச் செய்வதைத் தவிர்த்து, வெளியேறிய பிறகு இயல்பான நிர்வாகத்தை மீட்டெடுக்கிறது. கேமில் ஏற்கனவே ஏற்றப்பட்ட DLL ஐ அகற்ற முடியாது: அந்த கேமை மூடிவிட்டு மறுதொடக்கம் செய்யுங்கள். Wallpaper Engine ஒரு டெஸ்க்டாப் பயன்பாடாக அங்கீகரிக்கப்பட்டுள்ளது; இந்த திருத்தம் உண்மையில் புறக்கணிக்கப்பட்ட விளையாட்டுகளுக்கான பாதுகாப்பைப் பாதுகாக்கிறது.

**விருப்பத்தேர்வுகள் மற்றும் ஆதரவு:** விருப்பத்தேர்வு இறக்குமதி/ஏற்றுமதிக்கு கேம் கோப்புறைகளை கைமுறையாக மீண்டும் இணைக்க வேண்டும். அறிமுகத்தில் உள்ள உள்ளூர் கண்டறிதல் தனிப்பட்ட தகவல்களை வடிகட்டுகிறது மற்றும் NVAPI பிழைக் குறியீடுகள் அல்லது முரண்பாடு வகைகளைப் புகாரளிக்கிறது. பகிர்வதற்கு முன் அதை மதிப்பாய்வு செய்யவும்; எதுவும் தானாக பதிவேற்றப்படவில்லை.

** பயன்பாட்டு புதுப்பிப்புகள்:** ஒரு விருப்பமான காசோலை வெளியீட்டு குறிப்புகளைக் காண்பிக்கும் மற்றும் அதிகாரப்பூர்வ அமைப்பை வழங்குகிறது. GitHub அளவு மற்றும் SHA-256 மெட்டாடேட்டாவிற்கு எதிராக வெளிப்படையான பதிவிறக்கம் சரிபார்க்கப்பட்டது; நிறுவலை நீங்களே தொடங்குங்கள். 0.2.3 பதிப்பு, அர்த்தமுள்ள பிழைகள் மற்றும் முடிவுகளைப் பாதுகாக்கும் போது நிறைவு செய்யப்பட்ட முன்னேற்றச் செய்திகளையும் அழிக்கிறது. பொதுப் பதிப்பான 0.1.1 இலிருந்து மாற்றங்களைச் சேர்த்தல் அடங்கும்.

## புதுப்பித்து நிறுவல் நீக்கவும்

பாதிக்கப்பட்ட விளையாட்டுகளை மூடு. NVMFG ஐ முடக்கு/வெளியேறு மற்றும் புதுப்பிக்கும் முன் நிலுவையில் உள்ள NVIDIA அமைப்புகளை மீட்டெடுக்கவும். ஏற்கனவே உள்ள அடையாளத்துடன் அடுத்த அமைப்பை நிறுவவும் அல்லது புதிய போர்ட்டபிளை புதிய கோப்புறையில் பிரித்தெடுக்கவும்; நிலை/காப்புப்பிரதிகளைத் தக்கவைத்துக்கொள்.

நிறுவல் நீக்குவதற்கு முன், விரும்பிய கேம் SDK காப்புப்பிரதிகள் மற்றும் NVIDIA அமைப்புகளை பயன்பாட்டின் மூலம் மீட்டெடுக்கவும், பின்னர் கேம்களை மூடிவிட்டு கன்ட்ரோலரை விட்டு வெளியேறவும். அமைப்பதற்கு Windows **Installed apps** ஐப் பயன்படுத்தவும் அல்லது தேவையான கோப்புகளைப் பாதுகாத்த பிறகு மூடிய போர்ட்டபிள் கோப்புறையை அகற்றவும். அமைவைத் தடுப்பதற்கு செயலில் உள்ள மீட்புப் பத்திரிகையை கைமுறையாக நீக்க வேண்டாம்.

உள்ளூர் கேம்-இயக்க நேர காப்புப்பிரதிகள் `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups` ஐப் பயன்படுத்துகின்றன. MFG அமைப்புகள்/SDK தரவு பயன்பாடு `%LOCALAPPDATA%\RtxMfg`; அமர்வு வெளியீடு பயன்பாட்டிற்கு அருகில் `Sessions` இன் கீழ் உள்ளது. இந்தக் கோப்புகளில் விளையாட்டுப் பாதைகள் இருக்கலாம். அவற்றைத் திருத்தாமல் பதிவிடாதீர்கள்.

<a id="known-limitations"></a>
## அறியப்பட்ட வரம்புகள்

- அறிக்கையிடப்பட்ட 0.1.1 செயல்படுத்தல்/மீட்டமைத்தல்/நிறுவல் நீக்கம் அடைப்பு மீண்டும் உருவாக்கப்படாமல் உள்ளது மற்றும் அதன் காரணம் தெரியவில்லை. இந்த வெளியீடு அதை சரிசெய்வதாகக் கூறவில்லை. தோல்விக்குப் பிறகு, மீட்பு இதழைப் பாதுகாத்து, உள்ளூர் நோயறிதலைச் சரிபார்க்கவும்; மீட்பு தரவை நீக்க கட்டாயப்படுத்த வேண்டாம்.
- பரிசோதனை பூர்வீக இணைப்புகள் விபத்துக்கள் அல்லது காட்சி கலைப்பொருட்களை ஏற்படுத்தும்; ஒரு தீர்க்கப்படாத Bodycam செயலிழப்பு வளர்ச்சி வரலாற்றில் பதிவு செய்யப்பட்டுள்ளது.
- கட்டுப்படுத்தப்பட்ட ரெண்டரர் சோதனைகள் ஒவ்வொரு கேம், டிரைவர் அல்லது ஏமாற்று எதிர்ப்புக்கான சான்றிதழ் அல்ல.
- உருவாக்கப்பட்ட சட்டங்கள் புதிய உள்ளீட்டு மாதிரிகளை உருவாக்காது; இந்த மையத்தால் அளவிடப்பட்ட தாமதம் அல்லது செயல்திறன் ஆதாயம் எதுவும் உறுதியளிக்கப்படவில்லை.
- பல பிரேம்-ஜெனரேஷன் கருவிகள்/மேற்பரப்புகள் முரண்படலாம். பயன்பாட்டு அறிக்கைகள் ஒவ்வொரு சகவாழ்வு சூழ்நிலையையும் நிரூபிக்காமல் தொகுதிகளை கவனிக்கின்றன.

- முழு NVIDIA SDK விதிமுறைகள் மற்றும் தீர்க்கப்படாத தொழில்நுட்ப வரம்பு கட்டுப்பாடு ஆகியவை [ஆதாரம்](../docs/provenance.md) இல் ஆவணப்படுத்தப்பட்டுள்ளன.

## அடிக்கடி கேட்கப்படும் கேள்விகள்

**இதில் NVIDIA DLLகள் அல்லது மாடல்கள் உள்ளதா?** இயக்கி, NGX வழங்குநர்/மாடல் அல்லது Streamline இயக்க நேரம் சேர்க்கப்படவில்லை. வெளிப்படையான SDK பதிவிறக்கங்கள் NVIDIA இலிருந்து வருகின்றன.

**V-Sync முடக்கத்தில் Dynamic வேலை செய்கிறதா?** அந்த நிலையில் அது இடைநிறுத்தப்பட்டுள்ளது. கேமில் உள்ள அமைப்பை அல்லது அந்த கேமின் தனி நிலைக்குத் தகுதியான நிலையான பெருக்கியைத் தேர்வு செய்யவும்.

**இது ReShade/OptiScaler/FSR தொகுப்பா?** இல்லை. இந்த தயாரிப்பு தொகுப்பின் ஒரு பகுதியாக அவை தொகுக்கப்படவில்லை அல்லது அனுப்பப்படவில்லை.

**மாற்றியமைக்கப்பட்ட ஆதாரங்கள் பொதுவா?** தொகுக்கப்பட்ட தொகுப்புகள் மற்றும் தேவையான வரவுகள்/ உரிமங்கள் வழங்கப்பட்டுள்ளன. இது மூன்றாம் தரப்பினரின் உரிமைகள் அல்லது கட்டுப்பாடுகளை அகற்றாது.
