# NVIDIA Profile Inspector – NV Tools Fork

** [Orbmu2k மூலம் NVIDIA Profile Inspector](https://github.com/Orbmu2k/nvidiaProfileInspector) இன் சுயாதீன fork, கூடுதல் காட்சி கட்டுப்பாடுகளுடன்.** முன்னாள் திட்டப் பெயர்: **NVPI Custom**.

[பதிவிறக்கம் & வெளியீட்டு நிலை](../docs/downloads.md#nvidia-profile-inspector) · [நிறுவல்](#installation) · [அப்ஸ்ட்ரீம் மற்றும் மாற்றங்கள்](#upstream-and-changes) · [உரிமம்](../../../../NVIDIA-Profile-Inspector/LICENSE)

<a id="overview"></a>
## கண்ணோட்டம்

ஒவ்வொரு பயன்பாட்டிற்கான அமைப்புகள் உட்பட, NVIDIA இயக்கி சுயவிவரங்களை பயன்பாடு திருத்துகிறது. இந்த fork செயலில் உள்ள Windows காட்சிக்கான **ஸ்கிரீன்** எடிட்டரைச் சேர்க்கிறது: தீர்மானம், புதுப்பிப்பு விகிதம், வெளியீட்டு வண்ண அமைப்புகள், HDR மற்றும் நிறுவப்பட்ட ICC/WCS சுயவிவர சங்கங்கள்.

சுயவிவர எடிட்டரில் தொடர்புடைய காட்சிக் கட்டுப்பாடுகளைக் கொண்டு வரவும், முன்னோட்டம், உறுதிப்படுத்தல் மற்றும் மறுசீரமைப்பு முடிவுகளை தெளிவாக்கவும் இது உள்ளது. இது புதிய வன்பொருள் திறன்களை நிறுவாது.

முதல் வேட்பாளர் **3.0.2.3**, செப்டம்பர் 9, 2026 முதல் சுத்தப்படுத்தப்பட்ட தனித்த துணைக் கட்டமைப்பைப் பயன்படுத்துகிறார். அதன் தற்போதைய இயங்கக்கூடியது `nvidiaProfileInspector.exe`; நிறுவி மற்றும் சில உள் லேபிள்கள் இன்னும் `NVPI Custom NV` என்று கூறுகின்றன. மேலே உள்ள பொதுத் தலைப்பு fork ஐ நிறுவல் அடையாளத்தை மாற்றாமல் அல்லது Orbmu2k இன் அதிகாரப்பூர்வ வெளியீடு என்று பாசாங்கு செய்யாமல் அடையாளப்படுத்துகிறது.

<a id="features"></a>
## அம்சங்கள்

- தற்போதுள்ள அப்ஸ்ட்ரீம் சுயவிவர உலாவல், பயன்பாட்டு சங்கங்கள், அமைப்பு திருத்தங்கள் மற்றும் சுயவிவர இறக்குமதி/ஏற்றுமதி.
- காட்சி, பயன்முறை, Hz, RGB/YCbCr, வண்ண ஆழம், வரம்பு மற்றும் வண்ண அளவிற்கான **திரை** உரையாடல்.
- Windows HDR கட்டுப்பாடு மற்றும் நிறுவப்பட்ட ICC/WCS சங்கத் தேர்வு.
- **கீப்** / **ரிவர்ட்** மற்றும் காலாவதியான மறுசீரமைப்புடன் கூடிய 15-வினாடி காட்சி முன்னோட்டம்.
- பயன்முறை/HDR மாற்றங்கள் மற்றும் மறுசீரமைப்பு தோல்விகளைப் புகாரளித்ததை மீண்டும் படிக்கவும்.
- HDR இன் தனி அறிக்கை, ACM/WCG மற்றும் சிக்னல் வண்ண ஆழத்துடன் கூடிய SDR.
- தகுதியான தனித்தனியாக நிறுவப்பட்ட நகலுக்கான NVRasterPulse துவக்கி.

<a id="installation"></a>
## நிறுவல்

1. [பதிவிறக்க பக்கம்](../docs/downloads.md#nvidia-profile-inspector)ஐத் திறந்து வெளியீட்டு நிலையைச் சரிபார்க்கவும்.
2. அமைவு அல்லது கையடக்க சொத்தைப் பதிவிறக்கி அதன் SHA-256 வெளியீட்டு மேனிஃபெஸ்டுடன் ஒப்பிடவும்.
3. அமைப்பதற்கு, `NVPI-CustomNV-3.0.2.3-Setup-r2.exe` ஐ இயக்கவும், ஒரு மொழியைத் தேர்ந்தெடுத்து நிறுவியைப் பின்தொடரவும். இது அதன் சொந்த குறுக்குவழி மற்றும் நிறுவல் நீக்கியை உருவாக்குகிறது.
4. கையடக்கத்திற்கு, முழு ZIP ஐ புதிய எழுதக்கூடிய கோப்புறையில் பிரித்தெடுக்கவும். `Reference.xml`, EXE உள்ளமைவு மற்றும் அனைத்து அறிவிப்புகளையும் இயங்கக்கூடியவற்றுக்கு அருகில் வைக்கவும்.
5. `nvidiaProfileInspector.exe` ஐ துவக்கவும்.

எடிட்டரை மட்டும் நிறுவுவது சுயவிவரத்தைப் பயன்படுத்தாது அல்லது GPU இயக்கியை நிறுவாது. துணை தனித்தனியாக நிறுவுகிறது, `.nip` சங்கங்களை எடுத்துக் கொள்ளாது மற்றும் உள்நுழையும்போது தொடக்கத்தை இயக்காது. தற்போதுள்ள பைனரிகள் கையொப்பமிடப்படவில்லை.

<a id="usage"></a>
## பயன்பாடு

**நிறுவி திருத்தம் 2** மற்ற கருவிகளைப் போலவே சொந்த 34-மொழி தேர்வியைச் சேர்க்கிறது, மவுஸ்/கீபோர்டு வழிசெலுத்தல், ஒளி/இருண்ட தோற்றம் மற்றும் ரத்துசெய்தல். தேர்வு அமைப்புக்கு பொருந்தும்; இது NVPI எடிட்டரை மொழிபெயர்க்காது. ஒரு வெளிப்படையான `/LANG=fr` வாதம் அல்லது அமைதியான பயன்முறை ஏற்கனவே மொழியை வழங்கும் அழைப்பாளர்களுக்கான தேர்வைத் தவிர்க்கிறது.

**டிரைவர் சுயவிவரங்கள்:** ஒரு சுயவிவரத்தைத் தேர்ந்தெடுத்து, காப்புப்பிரதியை ஏற்றுமதி செய்யவும், பின்னர் உத்தேசிக்கப்பட்ட அமைப்புகளை மட்டும் திருத்தி அவற்றைப் பயன்படுத்தவும். எந்த விளையாட்டு சுயவிவரத்தைப் பெறுகிறது என்பதை பயன்பாட்டுச் சங்கங்கள் தீர்மானிக்கின்றன. சேமிக்கப்பட்ட மதிப்பு ஒவ்வொரு இயக்கி அல்லது விளையாட்டு பயன்படுத்துகிறது என்பதற்கு ஆதாரம் அல்ல.

**காட்சிக் கட்டுப்பாடுகள்:** திறந்து **திரை**, காட்சி மற்றும் கோரப்பட்ட மதிப்புகளைத் தேர்வுசெய்து, முன்னோட்டத்தைத் தொடங்கவும். 15 வினாடிகளுக்குள் ** வைத்திரு** என்பதைத் தேர்ந்தெடுப்பதற்கு முன் படத்தைச் சரிபார்க்கவும். **திரும்பப்** பயன்படுத்தவும், உறுதிப்படுத்தலை மூடவும் அல்லது மீட்டெடுப்பைக் கோருவதற்கு காலாவதியாகிவிடவும். ஏதேனும் தோல்விச் செய்தியைப் படிக்கவும்: வெற்றிகரமான API அழைப்பு மட்டும் மறுசீரமைப்புக்கான ஆதாரம் அல்ல.

ஒரு ICC தேர்வு நிறுவப்பட்ட சுயவிவர சங்கத்தை மாற்றுகிறது; இது ICC கோப்பை உருவாக்கவோ, அளவீடு செய்யவோ அல்லது மறுபகிர்வு செய்யவோ இல்லை. HDR, ACM/WCG, RGB/YCbCr மற்றும் bpc ஆகியவை பைப்லைனின் வெவ்வேறு அம்சங்களை விவரிக்கின்றன. புதிய சுயாதீன ஏசிஎம் சுவிட்ச் வழங்கப்படவில்லை.

**NVRasterPulse:** பாதுகாக்கப்பட்ட உரிமை மற்றும் அனுமதிகளுடன் நிரல் கோப்புகளுக்குக் கீழே தனித்தனியாக பதிவுசெய்யப்பட்ட கணினி அளவிலான நிறுவலை கருவிப்பட்டி பொத்தான் ஏற்றுக்கொள்கிறது. கையடக்க நகல் அல்லது பயனர் எழுதக்கூடிய/இணைக்கப்பட்ட பாதை இந்த உயர்த்தப்பட்ட துவக்கியால் மறுக்கப்படலாம். அப்படியானால் NVRasterPulse ஐ அதன் சொந்த குறுக்குவழியைப் பயன்படுத்தி திறக்கவும். NVRasterPulse ஐப் பயன்படுத்த [RTSS ஐ தனியாக நிறுவவும்](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/).

## புதுப்பித்து நிறுவல் நீக்கவும்

புதுப்பிக்கும் முன் எடிட்டரை மூடு. ஏற்றுமதி செய்யப்பட்ட சுயவிவரங்களை வைத்து புதிய fork வெளியீட்டைப் பதிவிறக்கவும்; அதே துணை அடையாளத்தை நிறுவவும் அல்லது போர்ட்டபிள் கோப்புகளை புதிய கோப்புறையில் பிரித்தெடுக்கவும். பழைய `Reference.xml` ஐ புதிய எக்ஸிகியூட்டபிள் உடன் கலக்க வேண்டாம். தொகுக்கப்பட்ட அப்ஸ்ட்ரீம் புதுப்பிப்பு-சரிபார்ப்பு ஒடுக்கம் இந்த fork க்கு சொந்தமானது.

நிறுவப்பட்ட நகலுக்கு, Windows Installed apps மற்றும் அதன் நிறுவல் நீக்கியைப் பயன்படுத்தவும். கையடக்கத்திற்கு, அதை மூடிவிட்டு, உங்கள் ஏற்றுமதிகள் பாதுகாப்பாக இருக்கும்போது பிரித்தெடுக்கப்பட்ட கோப்புறையை அகற்றவும். எடிட்டரை அகற்றுவது இயக்கி சுயவிவரத் திருத்தங்கள், காட்சி விருப்பத்தேர்வுகள், NVRasterPulse அல்லது RTSS ஆகியவற்றை செயல்தவிர்க்க முடியாது. அகற்றும் முன் விரும்பிய அமைப்புகளை மீட்டெடுக்கவும்.

<a id="known-limitations"></a>
## அறியப்பட்ட வரம்புகள்

- 15-வினாடி உறுதிப்படுத்தல் என்பது ஒவ்வொரு ஓட்டுனர் விபத்து, மின் இழப்பு அல்லது கட்டாயப் பணிநிறுத்தம் ஆகியவற்றின் கண்காணிப்பு அல்ல.
- சில வண்ணம்/ஆழம்/புதுப்பிப்பு சேர்க்கைகள் `NVAPI_NOT_SUPPORTED`ஐ வழங்கும்.
- மென்பொருள் ரீட்-பேக் என்பது பேனல் பிட் ஆழம், வண்ணத் துல்லியம் அல்லது தாமதத்தை அளவிடாது.
- திரை அமைப்புகள் தற்போதைய Windows காட்சியைப் பாதிக்கின்றன; இந்த உரையாடல் ஒரு விளையாட்டு காட்சி முன்னமைவுகளை உருவாக்காது.
- செயல்திறன், ஏமாற்று எதிர்ப்பு அல்லது உலகளாவிய HDR பொருந்தக்கூடிய உத்தரவாதம் இல்லை.

**NVDriverForge க்கு இந்த எடிட்டர் தேவையா?** எண். NVDriverForge இன் விருப்பமான Custom NV முன்னமைவு அதன் சொந்த ஒருங்கிணைப்பைப் பயன்படுத்துகிறது. எடிட்டரை நிறுவுவது ஒரு தனி தேர்வாகும்.

**இந்த fork க்கு RTSS கட்டாயமா?** எண். RTSS என்பது NVRasterPulse இன் FPS வரம்புக்கு அவசியமானது, சுயவிவரம் அல்லது திரையை திருத்துவதற்கு அல்ல.

**ஆதாரம் எங்கே?** மாற்றியமைக்கப்பட்ட பயன்பாட்டு ஆதாரம் தனிப்பட்ட முறையில் பராமரிக்கப்படுகிறது. MIT அறிவிப்பு மற்றும் அப்ஸ்ட்ரீம் களஞ்சியம் வழங்கப்பட்டுள்ளன; MIT க்கு மாற்றியமைக்கப்பட்ட மூலத்தை வெளியிடத் தேவையில்லை.
