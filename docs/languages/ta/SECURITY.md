# பாதுகாப்பு

இந்தக் கொள்கை NV Tools பயன்பாட்டு தொகுப்புகள் மற்றும் இந்த விநியோக மையத்தை உள்ளடக்கியது. ஒவ்வொரு கருவியின் சமீபத்திய வெளியிடப்பட்ட பதிப்பைப் பாதிக்கும் அறிக்கைகளுக்கு பராமரிப்பாளர் முன்னுரிமை அளிக்கிறார். தயார் செய்யப்பட்ட வேட்பாளர்கள் அறிவிக்கப்பட்ட ஆதரவு நிலையான வெளியீடு அல்ல. பதில் காலக்கெடு அல்லது பாதுகாப்பு சான்றிதழ் உறுதியளிக்கப்படவில்லை.

<a id="report-privately"></a>
## தனிப்பட்ட முறையில் புகாரளிக்கவும்

பாதிப்புகள், பாதுகாப்பற்ற உயர்ந்த நடத்தை, திட்டமிடப்படாத அழிவு மாற்றங்கள் அல்லது உணர்திறன் தரவு வெளிப்பாடு ஆகியவற்றிற்கு, களஞ்சியத்தின் **பாதுகாப்பு → Report a vulnerability** அம்சம் **இயக்கப்படும்போது**: [தனிப்பட்ட அறிக்கை](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new) ஐப் பயன்படுத்தவும்.

**ஆரம்ப அமைப்பு:** பொது களஞ்சியத்தை உருவாக்கிய பிறகு பராமரிப்பாளர் தனிப்பட்ட பாதிப்பு அறிக்கையை இயக்க வேண்டும். இந்தக் கோப்பு அதைச் செயல்படுத்தவில்லை, அதற்கு முன் எந்த அஞ்சல் பெட்டி அல்லது தனிப்பட்ட சேனல் இருப்பதாகக் கூறப்படவில்லை.

பொத்தான் கிடைக்கவில்லை எனில், பொதுச் சிக்கலை மட்டும் திறக்கவும்: "[கருவிகள்/பதிப்பு] தொடர்பான பாதுகாப்பு அறிக்கைக்கு எனக்கு ஒரு தனிப்பட்ட தொடர்பு சேனல் தேவை." சுரண்டல் விவரங்கள், நற்சான்றிதழ்கள், பாதிக்கப்பட்ட பாதைகள், பதிவுகள் அல்லது இணைப்புகளைச் சேர்க்க வேண்டாம். தனிப்பட்ட சேனலைப் பகிர்வதற்கு முன் பராமரிப்பாளர் வழங்கும் வரை காத்திருக்கவும்.

தனிப்பட்ட அறிக்கையில், கருவி/பதிப்பு மற்றும் ஹாஷ், Windows/GPU/இயக்கி பதிப்புகள், தாக்கம், குறைந்தபட்ச பாதுகாப்பான இனப்பெருக்கம் மற்றும் மீட்பு தேவையா என்பதைச் சேர்க்கவும். ரகசியங்கள் மற்றும் தனிப்பட்ட தரவைத் திருத்தவும்; உள்ளூர் மீட்பு கோப்புகளை சேமிக்கவும். தனியுரிம இயக்கி அல்லது கேம் டிஎல்எல்களைப் பதிவேற்ற வேண்டாம். பராமரிப்பாளருடன் வெளிப்படுத்தலை ஒருங்கிணைத்தல்; ஒரு பேட்ச்/வெளியீட்டிற்கு மதிப்பாய்வு தேவை மற்றும் தானாக இல்லை.
