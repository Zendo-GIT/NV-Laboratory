<a id="nvdriverforge"></a>
# NVDriverForge

** தெளிவான கூறு தேர்வுகள் மற்றும் விருப்ப அமைப்புகளுடன் NVIDIA இயக்கி நிறுவலைத் தயாரிக்கவும்.**

[0.1.3 & நிலையைப் பதிவிறக்கவும்](../docs/downloads.md#nvdriverforge) · [நிறுவல்](#installation) · [கடன்கள்](#credits-and-upstream) · [உரிமம்](../../../../NVDriverForge/LICENSE)

<a id="overview-and-purpose"></a>
## கண்ணோட்டம் மற்றும் நோக்கம்

NVDriverForge அசல் NVIDIA இயக்கி தொகுப்பின் மூலம் உங்களுக்கு வழிகாட்டுகிறது: இயக்கியைத் தேர்வுசெய்து, அதன் கூறுகளை ஆய்வு செய்து, விருப்ப மாற்றங்களை மதிப்பாய்வு செய்து, நிறுவலை உறுதிப்படுத்தவும். அந்தத் தெரிவுகளைப் புரிந்துகொள்ளக்கூடியதாகவும், நிறுவல், சலுகை பெற்ற செயல்பாடுகள் மற்றும் மீட்புத் தகவலை ஒன்றாக வைத்திருக்கவும் இது உள்ளது.

இது NVCleanstall இன் பணிப்பாய்வு மூலம் ஈர்க்கப்பட்ட ஒரு சுயாதீனமான பயன்பாடாகும். இது NVCleanstall ஐ சேர்க்கவில்லை அல்லது முழுமையான அம்ச சமநிலையை கோரவில்லை.

<a id="features"></a>
## அம்சங்கள்

- NVIDIA Game Ready / Studio தேடுதல் மற்றும் பதிவிறக்கங்கள்; கையேடு வீழ்ச்சியுடன் விருப்ப ஹாட்ஃபிக்ஸ் கண்டுபிடிப்பு.
- அசல் தொகுப்பு, ஹாஷ்கள், NVIDIA கையொப்பங்கள், வெளிப்பாடுகள் மற்றும் இணக்கமான INF உள்ளீடுகளின் பகுப்பாய்வு.
- சார்புகளுடன் கூடிய கூறு தேர்வு மற்றும் அறியப்படாத கூறுகளைப் பாதுகாத்தல்.
- பதிப்பு 0.1.3 தேர்ந்தெடுக்கப்பட்ட விருப்பமான NVIDIA கூறுகளைத் தவிர்க்கக்கூடியதாக வைத்திருக்கிறது மற்றும் கண்டுபிடிப்பிலிருந்து சரிபார்க்கப்பட்ட சரிபார்க்கப்படாத கூறுகளை மட்டும் விலக்குகிறது. ஏற்கனவே-தற்போதைய அல்லது பொருந்தாத விருப்ப இயக்க நேரங்கள் இனி முக்கியமான கூறுகளாக கட்டாயப்படுத்தப்படாது.
- நிறுவல் தோல்வி சுருக்கங்கள் மற்றும் அனைத்து 34 மொழிகளிலும் விரிவான பதிவுகளுக்கான அணுகலை அழிக்கவும்.
- வெளிப்படையான நிறுவல் உறுதிப்படுத்தல், பாதுகாக்கப்பட்ட நிலை மற்றும் ஏற்கனவே உள்ள இயக்கி-ஸ்டோர் தொகுப்புகளின் ஏற்றுமதி.
- ப்ரீஃப்லைட் காசோலைகள், ஜர்னல்கள் மற்றும் மோதல்-விழிப்புணர்வு மீட்பு ஆகியவற்றுடன் விருப்ப மேம்பட்ட அமைப்புகள்.
- விருப்பத்தேர்வு **Custom NV** பெயரிடப்பட்ட தேர்வுகள் மற்றும் விளக்கங்கள், தனி SILK வலிமை தேர்வு மற்றும் இணக்கத்தன்மை சோதனைகள் உட்பட.
- விருப்பமான சரியான பதிப்பு NVENC இணைப்பு பதிவிறக்கங்கள்; மூல உறுதி மற்றும் இலக்கு பைட்டுகள் சரிபார்க்கப்படுகின்றன.
- கருவிகள் திரையில் இருந்து Profile Inspector fork இன் தனி, விருப்பமான நிறுவல்.
- விருப்பமான நிறுவப்பட்ட-பயனர் புதுப்பிப்புகள், 34 இடைமுக மொழிகள் மற்றும் நான்கு தீம்கள்.

MPO, DLSS இண்டிகேட்டர், Ansel, NVIDIA ஆடியோ ஸ்லீப், MSI, குறுக்கீடு கொள்கை/முன்னுரிமை, HDCP, டிஸ்ப்ளே-கன்டெய்னர் ஸ்டார்ட்அப் மற்றும் தகுதியான டெலிமெட்ரி சேவை ஆகியவற்றுடன் தொடர்புடைய மேம்பட்ட விருப்பங்கள் உள்ளன. ஒவ்வொன்றுக்கும் அதன் சொந்த முன்நிபந்தனைகள் மற்றும் விளைவுகள் உள்ளன; இவை உலகளாவிய செயல்திறன் மேம்பாடுகள் அல்ல.

<a id="installation"></a>
## நிறுவல்

1. [பதிவிறக்கங்கள்](../docs/downloads.md#nvdriverforge) ஐப் பார்வையிடவும் மற்றும் வெளியீடு வெளியிடப்பட்டதை உறுதிப்படுத்தவும்.
2. நிறுவலுக்கு `NVDriverForge-Setup.exe` அல்லது சிறிய பயன்பாட்டிற்கு `NVDriverForge.exe` என்பதைத் தேர்ந்தெடுக்கவும்.
3. SHA-256 ஐ வெளியீட்டின் `SHA256SUMS.txt` உடன் ஒப்பிடுக.
4. ஒவ்வொரு பயனருக்கும் நிறுவல் மற்றும் நிலையான நிறுவல் நீக்கிக்கான அமைப்பை இயக்கவும் அல்லது போர்ட்டபிள் EXE ஐ எழுதக்கூடிய கோப்புறையில் வைத்து திறக்கவும்.

போர்ட்டபிள் அதன் இயக்க நேரம் மற்றும் அதன் விருப்ப நிறுவி ஆகியவற்றை உள்ளடக்கியது. NVDriverForge ஐ நிறுவுவது GPU இயக்கியை நிறுவாது. அதன் EXEகள் தற்போது கையொப்பமிடப்படவில்லை.

<a id="usage"></a>
## பயன்பாடு

1. **இயக்கி:** NVIDIA இலிருந்து பதிவிறக்கவும் அல்லது அசல் NVIDIA நிறுவி EXE ஐத் தேர்ந்தெடுக்கவும். பகுப்பாய்வு முடிக்கட்டும்.
2. **கூறுகள்:** விளக்கங்கள் மற்றும் தேவையான சார்புகளை மதிப்பாய்வு செய்யவும். அறியப்படாத கூறுகள் தக்கவைக்கப்படுகின்றன.
3. ** கிறுக்கல்கள்:** தேவையற்ற விருப்பங்களை மாற்றாமல் விடவும். எதையும் தேர்ந்தெடுப்பதற்கு முன் விளைவுகள் மற்றும் வர்த்தக பரிமாற்றங்களைப் படிக்கவும்.
4. ** மதிப்பாய்வு:** சரியான இயக்கி, கூறுகள் மற்றும் விருப்ப செயல்பாடுகளைச் சரிபார்த்து, பின்னர் நிறுவலை உறுதிப்படுத்தவும்.
5. நீங்கள் தேர்ந்தெடுத்த செயல்பாட்டிற்கு மட்டும் UACஐ ஏற்கவும். பாதுகாக்கப்பட்ட வேலை மீட்பு வழிமுறைகளை வைத்திருங்கள்.
6. புதிய இயக்கிக்கு மறுதொடக்கம் தேவைப்பட்டால், அறிவிக்கப்பட்ட நிலையைப் பின்பற்றவும். ஒத்திவைக்கப்பட்ட செயல்பாடுகளை மறுதொடக்கம் செய்த பிறகு வெளிப்படையான விண்ணப்பம் தேவைப்படுகிறது.

Custom NV மாறாமல் தொடங்குகிறது. தனிப்பட்ட பெயரிடப்பட்ட மதிப்புகளைத் தேர்வு செய்யவும் அல்லது வழங்கப்பட்ட முன்னமைவு மற்றும் அதன் விலக்குகளை மதிப்பாய்வு செய்யவும். அதன் இரண்டு தகவல் உள் துறைகள் சுயாதீனமாக எழுதப்படவில்லை. சரிபார்க்கப்பட்ட புதிய இயக்கி பணிப்பாய்வுகளில் மட்டுமே அமைப்புகள் பயன்படுத்தப்படும், முன்னோட்டத்தைத் திறக்காது. தனி NVPI எடிட்டரை நிறுவ வேண்டிய அவசியமில்லை.

விருப்பமான NVENC பணியானது பின் செய்யப்பட்ட keylase கமிட்டிலிருந்து இணக்கமான தரவைப் பதிவிறக்குகிறது. இது இரண்டு இயக்கி டிஎல்எல்களை மாற்றுகிறது மற்றும் அவற்றின் கையொப்பங்களை செல்லாததாக்குகிறது; அதை Windows, குறியாக்கிகள், DRM அல்லது ஏமாற்று-எதிர்ப்பு நிராகரிக்கலாம். NVDriverForge இல் அத்தகைய தரவு அல்லது NVIDIA DLL உட்பொதிக்கப்படவில்லை. [ஆதாரம் மற்றும் உரிம வரம்புகள்](../docs/provenance.md).

விருப்பத்தேர்வுகள் மொழி, தீம் மற்றும் விருப்ப நிறுவப்பட்ட-பயனர் புதுப்பிப்பு சரிபார்ப்புகளைக் கட்டுப்படுத்துகின்றன. நிறுவப்பட்ட பின்னணி சரிபார்ப்பு பணியை போர்ட்டபிள் உருவாக்கவில்லை. கருவிகள் மற்றும் மீட்பு நான்கு நிறுவல் படிகளிலிருந்து தனித்தனியாக இருக்கும்.

## புதுப்பித்து நிறுவல் நீக்கவும்

NVDriverForge ஐ மூடி, அடுத்த அதிகாரப்பூர்வ தொகுப்பைப் பெற்று அதன் ஹாஷைச் சரிபார்க்கவும். நிறுவப்பட்ட புதுப்பிப்புக்கு அதே அமைவு அடையாளத்தைப் பயன்படுத்தவும்; மூடிய கையடக்க EXE ஐ புதியதாக மாற்றவும். அமைப்புகளையும் பாதுகாக்கப்பட்ட வேலைகளையும் வைத்திருங்கள்.

Windows இலிருந்து Uninstall **Installed apps**. இது பயன்பாட்டையும் அதன் புதுப்பிப்பு பணியையும் நீக்குகிறது, NVIDIA இயக்கி அல்ல. அமைப்புகள், பதிவுகள் மற்றும் காப்புப்பிரதிகள் உள்ளன. விரும்பினால், ஆவணப்படுத்தப்பட்ட மீட்பு ஓட்டத்தின் மூலம் மேம்பட்ட/NVENC மாற்றங்களை மீட்டெடுக்கவும் ** பயன்பாட்டை அகற்றுவதற்கு முன்**. மறுசீரமைப்பு மற்றொரு கருவியிலிருந்து முரண்பட்ட மாற்றங்களை மறுக்கிறது.

உள்ளூர் தரவு `%LOCALAPPDATA%\NVDriverForge` இன் கீழ் உள்ளது; பாதுகாக்கப்பட்ட வேலைகள் மற்றும் டிரைவர் ஏற்றுமதிகள் `%PROGRAMDATA%\NVDriverForge\Jobs` இன் கீழ் உள்ளன. போர்ட்டபிள் பயன்பாடு உள்ளூர் தரவையும் உருவாக்குகிறது. இயக்கி-ஸ்டோர் ஏற்றுமதி என்பது கணினிப் படம் அல்லது முழு சுயவிவர காப்புப்பிரதி அல்ல.

<a id="known-limitations"></a>
## அறியப்பட்ட வரம்புகள்

- வன்பொருள் சேர்க்கைகள்/INF எடிட்டிங், மறுஉருவாக்கம் செய்யப்பட்ட NVIDIA கையொப்பங்கள், ஏமாற்று-இணக்கமான ராஜினாமா அல்லது தானியங்கி கையொப்பமிடாத-எச்சரிக்கை ஏற்பு.
- முழுமையான டெலிமெட்ரி/விளம்பர நீக்கம், மெலிதான-பேக்கேஜ் ஏற்றுமதி அல்லது முந்தைய இயக்கிக்கு தானாக முழு திரும்புதல் இல்லை.
- இயக்கி நிறுவல், துவக்க மீட்பு மற்றும் விருப்ப சுயவிவர எழுதுதல் ஆகியவை ஹப் தணிக்கை மூலம் உண்மையான கணினிகளில் முழுமையாக சரிபார்க்கப்படவில்லை.
- ரெஜிஸ்ட்ரி ரீட்-பேக் என்பது உண்மையான HDCP, செயல்திறன் அல்லது தாமத விளைவுகளுக்கான ஆதாரம் அல்ல.
- கையொப்பச் சரிபார்ப்புகள் உள்நாட்டில் கிடைக்கும் Windows நம்பிக்கையைப் பயன்படுத்துகின்றன; ஆன்லைன் ரத்து செய்யப்படவில்லை.
- 34 மொழிகள் உள்ளன, ஆனால் முழு நேட்டிவ்-ஸ்பீக்கர்/அணுகல் சோதனை முழுமையடையாமல் உள்ளது.

## அடிக்கடி கேட்கப்படும் கேள்விகள்

**அமைவு ஒரு கிராபிக்ஸ் இயக்கியை நிறுவுகிறதா?** இல்லை. அதற்கு பயன்பாட்டின் தனி பகுப்பாய்வு, மதிப்பாய்வு, உறுதிப்படுத்தல் மற்றும் உயர்ந்த நிறுவல் செயல்முறை தேவை.

**எனக்கு NVCleanstall அல்லது NVPI தேவையா?** எண். NVCleanstall என்பது உத்வேகம் மட்டுமே. Profile Inspector துணையானது ஒரு சுயாதீன விருப்ப எடிட்டராகும்.

**இது ஒவ்வொரு NVIDIA இயக்கியையும் சிறியதா அல்லது வேகமாக்குமா?** இல்லை. தேர்ந்தெடுக்கப்பட்ட கூறுகள் மற்றும் முன்நிபந்தனைகள் எதை மாற்றலாம் என்பதைத் தீர்மானிக்கின்றன; அளவிடப்பட்ட லாபம் எதுவும் உறுதியளிக்கப்படவில்லை.

**ஆதாரங்கள் எங்கே?** விண்ணப்பம் சார்ந்த ஆதாரம் மற்றும் தனிப்பட்ட சோதனைகள் தனித்தனியாக பராமரிக்கப்படுகின்றன. பண்புக்கூறு/உரிமமாக்கலுக்குத் தேவையான ஆவணங்கள், பைனரிகள் மற்றும் மூன்றாம் தரப்பு மூல இணைப்புகளை இந்த மையம் வழங்குகிறது.
