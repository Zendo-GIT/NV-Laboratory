# NV Laboratory

**禅堂 Zendo (RevoluSound Team) மூலம் NV Tools.** NVIDIA இயக்கி சுயவிவரங்கள், இயக்கி நிறுவல், சோதனை Multi Frame Generation மற்றும் RTSS சட்ட வரம்புகளுக்கான நான்கு சுயாதீன Windows பயன்பாடுகள்.

[கருவிகளைப் பெறுங்கள்](docs/downloads.md) · [நிறுவல்](docs/installation.md) · [இணக்கம் மற்றும் உதவி](docs/support.md) · [கடன்கள் மற்றும் உரிமங்கள்](THIRD_PARTY_NOTICES.md)

> **NVRasterPulseக்கு RTSS தேவை.** முதலில் [Guru3D இலிருந்து RivaTuner Statistics Server](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/)ஐ நிறுவவும். RTSS அதன் FPS வரம்புகளுக்கு வேலை செய்ய வேண்டும். இது தனியாக பதிவிறக்கம் செய்யப்படுகிறது.

## இங்கே தொடங்குங்கள்

1. மேலே ஒரு கருவியைத் தேர்ந்தெடுக்கவும். ஒவ்வொன்றும் சுயாதீனமாக வேலை செய்கின்றன; முழு தொகுப்பையும் நிறுவுவது தேவையற்றது.
2. அதன் தேவைகளைப் படித்து, நிறுவப்பட்ட பயன்பாட்டிற்கு **அமைவு** அல்லது தனி கோப்புறைக்கு **போர்ட்டபிள்** என்பதைத் தேர்ந்தெடுக்கவும்.
3. அதன் வெளியீடு வெளியிடப்பட்டதும், பெயரிடப்பட்ட பயன்பாட்டுச் சொத்தைப் பதிவிறக்கம் செய்து, அதனுடன் உள்ள அறிவிப்புகளைப் படித்து அதன் SHA-256 ஐ ஒப்பிடவும்.
4. இயக்கி, காட்சி அமைப்பு, NVIDIA சுயவிவரம் அல்லது கேம் இயக்க நேரத்தை மாற்றும் முன் காப்புப்பிரதிகளை வைத்திருக்கவும்.

ஒவ்வொரு வழிகாட்டியின் மேற்புறத்திலும் உள்ள தேர்வி மூலம் NV பயன்பாடுகள் உள்ள அதே 34 மொழிகளில் ஆவணங்கள் கிடைக்கும். உலாவி மொழி மூலம் GitHub தானாகவே README ஐத் தேர்ந்தெடுக்காது. ஆவண மொழியும் பயன்பாட்டின் சொந்த மொழி அமைப்பும் தனித்தனியாக உள்ளன.

<a id="provenance-and-ownership"></a>
## ஆதாரம் மற்றும் உரிமை

இந்த மையம் ஆவணங்கள் மற்றும் தொகுக்கப்பட்ட பயன்பாடுகளை விநியோகிக்கிறது. பயன்பாட்டு மூலக் குறியீடு தனிப்பட்ட முறையில் பராமரிக்கப்படுகிறது. அப்ஸ்ட்ரீம் திட்டங்கள் தங்கள் படைப்புரிமை மற்றும் உரிமங்களைத் தக்கவைத்துக்கொள்கின்றன; தனியார் மூல விநியோகம் அந்த விதிமுறைகளை மாற்றாது.

- Profile Inspector fork ஆனது Orbmu2k இன் MIT உரிமத்தைத் தக்கவைத்து, fork என வெளிப்படையாக அடையாளப்படுத்தப்படுகிறது.
- NVDriverForge அதன் சொந்த பைனரி விநியோக விதிமுறைகளைக் கொண்டுள்ளது மற்றும் தனித்தனியாக உரிமம் பெற்ற இயக்க நேரம்/கருவி கூறுகளை உள்ளடக்கியது.
- NVMFG Unlock40 ஒரு சுயாதீனமாக உருவாக்கப்பட்ட பயன்பாடு ஆகும். RTX40MFG-Unlock ஒப்பீடு மற்றும் சுத்திகரிப்புக்காக ஆலோசிக்கப்பட்டது; பகிரப்பட்ட சொந்த கூறுகள் தங்கள் MIT வரவுகளைத் தக்கவைத்துக்கொள்கின்றன. MinHook மற்றும் NVIDIA SDK விதிமுறைகள் தனித்தனியாக இருக்கும்.
- NVRasterPulse வழங்கப்பட்ட MIT உரிமத்தைத் தக்கவைத்து, Profile Inspector-பெறப்பட்ட UIஐ வரவு வைக்கிறது. RTSS என்பது அவசியமான வெளிப்புற நிரலாகும்.

[முழுமையான கூறு அட்டவணை](THIRD_PARTY_NOTICES.md), [கோப்பு ஆதாரம் மற்றும் மாற்றங்கள்](docs/provenance.md) மற்றும் [உரிமம் நோக்கம்](../../../LICENSE) ஆகியவற்றைப் பார்க்கவும்.
