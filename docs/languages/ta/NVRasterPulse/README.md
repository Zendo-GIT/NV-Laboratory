# NVRasterPulse

**ஒவ்வொரு பயன்பாட்டிற்கும் FPS வரம்புகள் RivaTuner Statistics Server மூலம்.**

> **முதலில் RTSS ஐ நிறுவவும்.** NVRasterPulseக்கு [RivaTuner Statistics Server (RTSS), Guru3D இலிருந்து பதிவிறக்கம் செய்யப்பட்டது](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) தேவை. வரம்புகளைச் செயல்படுத்த RTSS இயங்க வேண்டும். RTSS நிறுவி, ஹூக் DLL அல்லது SDK தொகுக்கப்படவில்லை.

[0.2 & நிலையைப் பதிவிறக்கவும்](../docs/downloads.md#nvrasterpulse) · [நிறுவல்](#installation) · [வரம்புகள் எவ்வாறு செயல்படுகின்றன](#usage) · [உரிமம்](../../../../NVRasterPulse/LICENSE)

<a id="overview-and-purpose"></a>
## கண்ணோட்டம் மற்றும் நோக்கம்

NVRasterPulse என்பது RTSS சட்ட வரம்புகளை இயங்கக்கூடிய பெயரில் நிர்வகிப்பதற்கான ஒரு சிறிய Windows இடைமுகமாகும். RTSS வரம்பைச் செய்கிறது. NVRasterPulse தொடர்புடைய சுயவிவர மதிப்புகள், காப்புப்பிரதிகள் மற்றும் மறுஏற்றம் கோரிக்கைகளை, தட்டு அணுகல் மற்றும் நிலையான தேர்வுகளுடன் நிர்வகிக்கிறது.

முழு RTSS சுயவிவரத்தையும் மாற்றாமல் அல்லது அதன் மேலடுக்கு அமைப்புகளைத் தொந்தரவு செய்யாமல், ஒரு விளையாட்டுக்கான சரியான வரம்புகளை எளிதாகத் திருத்துவதற்கு இது உள்ளது. பதிப்பு **0.2** உள்ளமைவு கண்டறிதல், FPS உதவி, இடைநிறுத்தம், செயல்தவிர் மற்றும் சுயவிவரப் பகிர்வு ஆகியவற்றைச் சேர்க்கிறது.

<a id="features"></a>
## அம்சங்கள்

- இயங்கும் பயன்பாட்டைத் தேர்ந்தெடுக்கவும் அல்லது அதை கைமுறையாகச் சேர்க்கவும்.
- FPS வரம்புகளை 1 முதல் 1000 வரை, மூன்று தசம இடங்கள் வரை சேமிக்கவும்.
- உள்ளிடப்பட்ட மதிப்புகளின் சரியான பகுத்தறிவு குறியாக்கம்: 59.94 2997/50 ஆகிறது.
- ஃப்ரண்ட் எட்ஜ் ஒத்திசைவு உள்ளமைவு (`SyncLimiter=1`) செயலில் காத்திருப்புடன் (`PassiveWait=0`).
- இயங்கக்கூடிய சுயவிவர புதுப்பிப்புகள், தானியங்கி காப்புப்பிரதிகள் மற்றும் அணு எழுத்துகள்.
- பிற சுயவிவர உள்ளடக்கத்தை வைத்திருக்கும் போது வரம்பு மீறல்களை அகற்றுதல்.
- RTSS நிறுவல் கண்டறிதல், கைமுறை பாதை தேர்வு மற்றும் வெளிப்படையான துவக்கம்/மறுஏற்றம்.
- ஒற்றை நிகழ்வு தட்டு செயல்பாடு, விருப்பமான நிறுவப்பட்ட தொடக்கம், 34 மொழிகள் மற்றும் நான்கு தீம்கள்.
- வழக்கமான விலகல் மற்றும் **வெளியேறு + RTSS** செயல்களைப் பிரிக்கவும்.

<a id="installation"></a>
## நிறுவல்

1. **[Guru3D இலிருந்து RTSS ஐப் பதிவிறக்கி நிறுவவும்](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/).**
2. [NVRasterPulse பதிவிறக்கங்கள்](../docs/downloads.md#nvrasterpulse) ஐத் திறந்து, வெளியீட்டு இருப்பை சரிபார்க்கவும்.
3. `NVRasterPulse-0.2-win-x64-Setup.exe` அல்லது `NVRasterPulse-0.2-win-x64-portable.zip` மற்றும் அறிவிப்புகள்/செக்ஸம்களைப் பதிவிறக்கவும்.
4. SHA-256 ஐ ஒப்பிடுக. அமைவை இயக்கவும் அல்லது முழு போர்ட்டபிள் ஜிப்பையும் எழுதக்கூடிய உள்ளூர் கோப்புறையில் பிரித்தெடுக்கவும்.
5. `NVRasterPulse.exe`ஐத் திறக்கவும். RTSS காணவில்லை எனில், **RTSS** ஐப் பதிவிறக்கி, அதை நிறுவி, **மீண்டும் சரிபார்க்கவும்** அல்லது `RTSS.exe` ஐ கைமுறையாகத் தேர்ந்தெடுக்கவும்.
6. RTSS அதன் இயல்பான குறுக்குவழியைப் பயன்படுத்தி அல்லது NVRasterPulse இன் RTSS பொத்தானைப் பயன்படுத்தி அதைத் தொடங்கவும்.

விருப்ப நினைவூட்டலை முடக்குவது முன்தேவையான சரிபார்ப்பைத் தவிர்க்காது. ஒரு அமைதியான Windows தட்டு தொடக்கமானது, இந்தச் சரிபார்ப்பைக் காண்பிக்கும் முன் பிரதான சாளரம் திறக்கும் வரை காத்திருக்கிறது. அமைப்பு NVRasterPulse ஐ மட்டும் நிறுவுகிறது. அதன் EXEகள் கையொப்பமிடப்படவில்லை.

<a id="usage"></a>
## பயன்பாடு

1. இயங்கும் பயன்பாட்டைத் தேர்ந்தெடுக்கவும் அல்லது அதன் கேம் EXE இல் உலாவவும்.
2. 1 முதல் 1000 FPS வரையிலான வரம்பை உள்ளிடவும், தேவைப்பட்டால் ஒரு பகுதியளவு மதிப்பும் அடங்கும்.
3. அறிக்கையிடப்பட்ட முடிவைச் சேமித்து சரிபார்க்கவும். இயங்கக்கூடிய RTSS சுயவிவரத்தை NVRasterPulse புதுப்பித்து மீண்டும் ஏற்றுமாறு கோருகிறது.
4. RTSS இயங்குவதை உறுதிசெய்து, உத்தேசிக்கப்பட்ட விளையாட்டின் நடத்தையைச் சரிபார்க்கவும்.

சுயவிவரங்கள் `Game.exe.cfg` போன்ற **செயல்படுத்தக்கூடிய பெயர்** மூலம் முக்கியப்படுத்தப்படுகின்றன. `Game.exe` கொண்ட இரண்டு வெவ்வேறு கோப்புறைகள் ஒரே RTSS சுயவிவரத்தைப் பகிர்ந்து கொள்கின்றன; முழு பாதையையும் சேமிப்பது இந்த மோதலை அகற்றாது.

சேமித்தல் ஃப்ரண்ட் எட்ஜ் ஒத்திசைவு மற்றும் செயலில் காத்திருப்பு ஆகியவற்றைப் பயன்படுத்துகிறது. செயலில் காத்திருப்பு CPU பயன்பாட்டை அதிகரிக்கலாம். மாற்று `LimitTime` புலங்கள் நடுநிலையாக்கப்பட்டுள்ளன. ஏற்கனவே உள்ள கருத்துகள், மேலடுக்கு அமைப்புகள் மற்றும் `EnableHooking=0` ஆகியவை பாதுகாக்கப்படுகின்றன. RTSS உலகளாவிய சுயவிவரம் மாற்றப்படவில்லை.

NVRasterPulse இன் வரம்பு மீறல்களை அகற்ற குப்பைச் செயலைப் பயன்படுத்தவும். இது முழு RTSS சுயவிவரத்தையும் நீக்காது. RTSS Global அல்லது மற்றொரு கருவியிலிருந்து பெறப்பட்ட வரம்பு அதன் பிறகும் பொருந்தும்.

**மூடுதல் மற்றும் வெளியேறுதல்:** பிரதான சாளரம் தட்டில் மறைக்கப்படலாம். இயல்பான ** வெளியேறு** RTSS இயங்கும் மற்றும் சேமிக்கப்பட்ட வரம்புகளை அப்படியே விட்டுவிடும். **Quit + RTSS** நடப்பு அமர்வில் பொருந்தக்கூடிய RTSS செயல்முறையை சாதாரணமாக மூடுமாறு கோருகிறது, எட்டு வினாடிகள் வரை காத்திருக்கிறது மற்றும் அதை கட்டாயப்படுத்தி கொல்லாது. இரண்டு நிகழ்வுகளிலும் சேமிக்கப்பட்ட வரம்புகள் இருக்கும்.

பயன்பாட்டில் மொழி மற்றும் தீம் தேர்ந்தெடுக்கப்பட்டது. Windows உள்நுழைவில் தொடங்குவது விருப்பமானது மற்றும் நிறுவப்பட்ட நகலை நோக்கமாகக் கொண்டது. தகவல் பொத்தான் பொதுவான செயல்களை விளக்குகிறது.

## நோயறிதல் மற்றும் சுயவிவர கருவிகள்

கூடுதல் கருவிகளுக்கான செயல்கள் மெனுவைத் திறக்கவும். அவை RTSS குளோபல், மேலடுக்கு அமைப்புகள் மற்றும் விலக்குகளைப் பாதுகாக்கின்றன.

** கண்டறிதல்:** உள்ளூர்/பயனுள்ள வரம்புகளை ஆய்வு செய்தல், RTSS நிறுத்தப்பட்டது, இயங்கக்கூடியது, கண்டறியப்படாத சாளரம், முடக்கப்பட்ட ஹூக்கிங், பரம்பரை, இடைநிறுத்தப்பட்ட வரம்புகள், போட்டியிடும் அமைப்புகள் மற்றும் நகல் இயங்கக்கூடிய பெயர்கள். இந்த படிக்க-மட்டும் சரிபார்ப்பு உள்ளமைவை விவரிக்கிறது; இது ஒரு கேம் RTSS ஆல் இணைக்கப்பட்டதை நிரூபிக்கவில்லை அல்லது அதன் FPS ஐ அளவிடவில்லை.

**FPS உதவியாளர்:** காட்சியைத் தேர்ந்தெடுத்து VRR/G-Sync, V-Sync, Reflex மற்றும் Frame Generation ஆகியவற்றை நீங்களே அறிவிக்கவும். வட்டமான புதுப்பிப்பு அதிர்வெண் Windows இலிருந்து வருகிறது. Reflex அல்லது Frame Generation செயலில் இருந்தால் அல்லது தெரியவில்லை என்றால், தானியங்கி தொப்பி வழங்கப்படாது. V-Sync ஆன் மற்றும் Reflex/FG ஆஃப் உள்ள VRRக்கு, ஹியூரிஸ்டிக் குறைந்தது 3 FPS அல்லது புதுப்பிப்பு விகிதத்தில் தோராயமாக 2% கழிக்கிறது. இது அளவிடப்பட்ட உகந்ததல்ல. பரிந்துரையைப் பயன்படுத்துவது வரைவை நிரப்புகிறது; **சேமி** ஒரு தனி செயலாகவே உள்ளது.

**இடைநிறுத்தி மீண்டும் தொடங்கவும்:** தேர்ந்தெடுக்கப்பட்ட நிரலின் தொப்பியை இடைநிறுத்தி, அதன் முந்தைய வரம்பு புலங்களை மீட்டமைக்கவும். மற்றொரு கருவி மூலம் முரண்பட்ட மாற்றங்கள் தெளிவற்ற விண்ணப்பத்தைத் தடுக்கின்றன. ஒரு உள்ளீட்டை மறைப்பது அதன் தொப்பியை இடைநிறுத்தாது.

** செயல்தவிர்:** அந்த நிரலுக்கான ஆறு நிர்வகிக்கப்பட்ட வரம்பு புலங்களில் கடைசி மாற்றத்தை மீட்டமைக்கவும். ஒரு நிலை உள்ளது; இது RTSS ஐ மீட்டெடுக்காது. முரண்பட்ட வெளிப்புற மாற்றங்கள் மறுக்கப்படுகின்றன. கோப்பு காப்புப்பிரதிகள் தனித்தனியாக இருக்கும்.

**பகிர் சுயவிவரங்கள்:** தேர்ந்தெடுக்கப்பட்ட சுயவிவரங்களை `.nvrp` கோப்பிற்கு ஏற்றுமதி செய்யவும். இறக்குமதி ஒரு மாதிரிக்காட்சியைக் காட்டுகிறது மற்றும் ஏற்கனவே உள்ள தொப்பிகளை முன்னிருப்பாகத் தேர்வு செய்யாமல் விட்டுவிடும். கோப்பில் முழுமையான பாதைகள் அல்லது ஸ்கிரிப்டுகள் இல்லாமல், இயங்கக்கூடிய பெயர்கள், வரம்புகள் மற்றும் நிலைகள் மட்டுமே உள்ளன. உங்கள் தேர்வை மதிப்பாய்வு செய்து விண்ணப்பிக்கவும். I/O பிழையானது சில சுயவிவரங்களை ஏற்கனவே பயன்படுத்தியிருக்கலாம்; முடிவு அவற்றை அடையாளம் கண்டு, ஒவ்வொன்றும் அதன் செயல்தவிர்க்க வைக்கிறது. ஒரே மாதிரியான இயங்கக்கூடிய பெயர்கள் இன்னும் அதே RTSS சுயவிவரத்தைக் குறிக்கின்றன.

**பிடித்தவை மற்றும் மறைக்கப்பட்ட உள்ளீடுகள்:** பயனுள்ள நிரல்களை முதலில் பின் செய்யவும், தேவையற்ற உள்ளீடுகளை மறைத்து அவற்றை பிரத்யேக உரையாடலில் மீட்டெடுக்கவும். இந்த தேர்வுகள் தொடரும். மூடிய பிடித்தமானது இயங்கும் பயன்பாடாகத் தோன்றாது.

## புதுப்பித்து நிறுவல் நீக்கவும்

NVRasterPulse இலிருந்து வெளியேறி, புதிய பதிப்பைப் பதிவிறக்கிச் சரிபார்த்து, அதன் அமைப்பை இயக்கவும் அல்லது போர்ட்டபிளைப் புதிய கோப்புறையில் பிரித்தெடுக்கவும். அமைப்புகள் மற்றும் RTSS காப்புப்பிரதிகளைப் பாதுகாக்கவும். RTSS புதுப்பிப்புகள் தனி மற்றும் Guru3D இலிருந்து வந்தவை.

நிறுவப்பட்ட நகலை அகற்ற, Windows **Installed apps** ஐப் பயன்படுத்தவும். கையடக்கத்திற்கு, வெளியேறி, உங்கள் காப்புப்பிரதிகள் பாதுகாப்பாக இருக்கும்போது பிரித்தெடுக்கப்பட்ட கோப்புறையை அகற்றவும். NVRasterPulse ஐ நிறுவல் நீக்குவதன் மூலம் சேமிக்கப்பட்ட RTSS வரம்புகள் அகற்றப்படாது: முதலில் உத்தேசிக்கப்பட்ட வரம்பு மீறல்களை அகற்றவும். RTSS அதன் சொந்த நிறுவல் நீக்கி உள்ளது.

உள்ளூர் மாநிலம்: `%LOCALAPPDATA%\NVRasterPulse`. தானியங்கி RTSS காப்புப்பிரதிகள்: `%LOCALAPPDATA%\NVRasterPulse\Backups\RTSS`. பழைய `%LOCALAPPDATA%\RTSSProfileBridge` இடம் இடம்பெயர்வதற்குப் படிக்கப்படலாம். இந்தக் கோப்புகள் தனிப்பட்ட இயங்கக்கூடிய பாதைகளைக் கொண்டிருக்கலாம் மற்றும் பொதுவில் இடுகையிடக்கூடாது.

<a id="known-limitations"></a>
## அறியப்பட்ட வரம்புகள்

- RTSS தொப்பியைச் செய்கிறது. சேமிக்கப்பட்ட மதிப்பு அல்லது வெற்றிகரமான மறுஏற்றம் கோரிக்கையானது அளவிடப்பட்ட பிரேம் நேர முடிவு அல்ல.
- ஒரே பெயரில் இயங்கக்கூடியவை சுயவிவரத்தைப் பகிரும்.
- மற்றொரு உலகளாவிய/ஒரு-விளையாட்டு வரம்பு முடிவை பாதிக்கலாம்; உள்ளூர் மேலெழுதலை முடக்குவது மரபுவழி தொப்பியை அகற்றாது.
- வேண்டுமென்றே முடக்கப்பட்ட RTSS ஹூக் முடக்கப்பட்டுள்ளது.
- செயலில் காத்திருப்பு CPU/பவர் ட்ரேட்-ஆஃப் உள்ளது.
- யுனிவர்சல் கேம், ஏமாளி எதிர்ப்பு அல்லது முடிவில் இருந்து இறுதி தாமத சரிபார்ப்பு இல்லை.
- முந்தைய சோதனை சுயாதீன வரம்பு இயந்திரம் தொகுக்கப்படவில்லை அல்லது அனுப்பப்படவில்லை.
- தானியங்கு காப்புப்பிரதிகள் ஒரு கிளிக் முழு காப்பு-மீட்டமைப்பு இடைமுகத்தைக் குறிக்காது.

RTSS காப்புப்பிரதியை கைமுறையாக மீட்டமைத்தால், முதலில் RTSS ஐ மூடிவிட்டு, தற்போதைய சுயவிவரத்தை உத்தேசித்துள்ள காப்புப்பிரதியுடன் மாற்றுவதற்கு முன் பாதுகாக்கவும். இது தொடர்பில்லாத சுயவிவரத் திருத்தங்களை மேலெழுதலாம்; கோப்பு மற்றும் தேதியை சரிபார்க்கவும். [பகிரப்பட்ட ஆதரவு](../docs/support.md).

## அடிக்கடி கேட்கப்படும் கேள்விகள்

**எனக்கும் MSI ஆஃப்டர்பர்னர் தேவையா?** NVRasterPulseக்கு RTSS தேவை; இது ஆஃப்டர்பர்னர் பயன்பாட்டைப் பொறுத்தது அல்ல. RTSS விநியோகஸ்தரின் நிறுவல் விருப்பங்களைப் பின்பற்றவும்.

**RTSS இயங்காமல் இதைப் பயன்படுத்தலாமா?** நிறுவல் கண்டறியப்பட்டவுடன் நீங்கள் சுயவிவரங்களை நிர்வகிக்கலாம், ஆனால் கட்டுப்படுத்துவதற்கு RTSS இயக்க வேண்டும்.

** வெளியேறுவது அல்லது நிறுவல் நீக்குவது தொப்பிகளை அகற்றுமா?** இல்லை. NVRasterPulse ஐ அகற்றும் முன், விரும்பிய வரம்பு மேலெழுதலை வெளிப்படையாக அகற்றவும்.

**இது RTSS இன் fork?** இல்லை. இது ஒரு சுயாதீன சுயவிவர மேலாளர்; RTSS ஆதாரம் அல்லது இயங்கக்கூடியது இணைக்கப்படவில்லை.
