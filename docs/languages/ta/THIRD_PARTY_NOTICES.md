## கடமைகள் மற்றும் எல்லைகள்

**MIT கூறுகள்:** பதிப்புரிமை, அனுமதி உரை மற்றும் மறுப்பு ஆகியவற்றை நகல்களுடன் வைத்திருக்கிறது. அவர்களின் உரிமத்திற்கு மாற்றியமைக்கப்பட்ட மூலத்தை வெளியிட தேவையில்லை. பயன்பாட்டு ஆதாரம் தனிப்பட்ட முறையில் பராமரிக்கப்படும்போதும் அசல் படைப்புரிமை பாதுகாக்கப்படுகிறது.

**MinHook/HDE:** பைனரி ஆவணங்களில் அறிவிப்புகள், நிபந்தனைகள் மற்றும் மறுப்புகளை பாதுகாக்கவும். முழு ஒருங்கிணைந்த அறிவிப்பு வழங்கப்படுகிறது.

**7-Zip:** LGPL/BSD/unRAR அறிவிப்புகளைப் பாதுகாத்து, சரியான மாற்றப்படாத மூலத்திற்கான அணுகலை வழங்கவும். முழு LGPL உடன் மூலக் காப்பகம் மேலே இணைக்கப்பட்டுள்ளது. unRAR கட்டுப்பாடு தொடர்புடைய டிகம்ப்ரஷன் குறியீட்டிற்குப் பொருந்தும்; இது ஒரு போர்வை MIT சார்பு அல்ல. ஆசிரியரின் [விநியோகம் அடிக்கடி கேட்கப்படும் கேள்விகள்](https://www.7-zip.org/faq.html) ஐப் பார்க்கவும்.

**Inno Setup:** தேவையான இன்ஜின் பதிப்புரிமை/இணையதள அறிவிப்புகளைப் பாதுகாத்து, பொருந்தும் இடங்களில் மூல மாற்றங்களைக் குறிக்கவும். மாற்றப்படாத இயந்திரத்தின் வரவுகள் நிறுவிகளில் இருக்கும். மாற்றியமைக்கப்பட்ட பட்டியல்கள் அசல் மூல அறிவிப்புகளைத் தக்கவைத்துக்கொள்கின்றன; பெயர்கள் இங்கே குறியிடப்பட்டுள்ளன.

**NVIDIA பொருள்:** Streamline ஒருங்கிணைப்பு தலைப்புகளுக்கான MIT உரிமம் ஒவ்வொரு SDK கோப்பையும் உள்ளடக்காது. அதன் அறிவிப்பு Nsight Perf SDK பொருளை வெளிப்படையாகப் பிரிக்கிறது; இந்த உற்பத்தி இலக்கில் பொருள் பயன்படுத்தப்படவில்லை. NGX தலைப்புகள் NVIDIA இன் தனியுரிம RTX SDK விதிமுறைகளின் கீழ் உள்ளன. அவர்களின் முழு உரையும் [அசல்-பைட் நகல்](../../../NVMFG-Unlock40/LICENSES/NVIDIA-RTX-SDK.original.txt) உடன் சேர்க்கப்பட்டுள்ளது. என்விஎம்எஃப்ஜியின் பயன்பாட்டிற்கான தொழில்நுட்ப வரம்புகள் தொடர்பான பிரிவு 4(டி) இன் கட்டுப்பாடு தீர்க்கப்படாமல் உள்ளது. மற்றொரு மோடின் இருப்பிலிருந்து உறுதியான அனுமதி எதுவும் பெறப்படவில்லை.

**வெளிப்புற அறியப்படாத/தனியுரிமை கூறுகள்:** RTSS, NVCleanstall, NVIDIA இயக்கிகள், மாடல்கள் மற்றும் keylase பேட்ச் தரவு ஆகியவை தயாரிக்கப்பட்ட ஹப் சொத்துக்களில் தொகுக்கப்படவில்லை. இணைப்புகள் அவற்றின் உண்மையான உரிமையாளர்களை அடையாளம் காணும். பயனரால் தூண்டப்பட்ட பதிவிறக்கம் ஒரு கூறுகளை மீண்டும் உரிமம் பெறாது.

கருவிகள் Windows வழங்கிய APIகள் மற்றும் எழுத்துருக்களைப் பயன்படுத்துகின்றன. இந்த Git களஞ்சியத்தில் Windows SDK/compiler/font கோப்பு எதுவும் நகலெடுக்கப்படவில்லை. உருவாக்க கருவிகள் மற்றும் தனிப்பட்ட சோதனைகள் விநியோகத்திற்கு வெளியே உள்ளன. இயக்க நேர-உள் கூறு அறிவிப்புகள் வெளியீட்டாளருக்கு மறுஒதுக்கீடு செய்யப்படுவதற்குப் பதிலாக முழுமையான Microsoft அறிவிப்புக் கோப்பில் இருக்கும்.
