# பதிவிறக்கங்கள்

ஒரு நிரலைத் தேர்ந்தெடுத்து **அமைவு** அல்லது **போர்ட்டபிள்**. ஒவ்வொரு கருவியின் வெளியீட்டுப் பக்கமும் தற்போதைய கிடைக்கும் தன்மை, வெளியீட்டு தேதி மற்றும் வெளியீட்டுக் குறிப்புகளைக் காட்டுகிறது. பராமரிப்பாளர் தொடர்புடைய சொத்துக்களை வெளியிடும்போது நேரடி இணைப்புகள் செயல்படும். விண்ணப்ப மூலமானது தனிப்பட்டதாகவே இருக்கும். உங்கள் பதிவிறக்கத்துடன் `Licenses-and-Credits.zip` மற்றும் `SHA256SUMS.txt` ஆகியவற்றை வைத்திருக்கவும். GitHub இன் **Source code (zip)** பொத்தானில் மைய ஆவணங்கள் உள்ளன.

> **NVRasterPulse க்கு RTSS தேவை.** [Guru3D இலிருந்து RivaTuner Statistics Server](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) தனித்தனியாக நிறுவி FPS வரம்புக்கு இயக்கவும்.
