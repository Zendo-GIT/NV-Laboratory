# இணக்கம் மற்றும் சரிசெய்தல்

இவர்கள் தயார் செய்யப்பட்ட விண்ணப்பதாரர்கள், அனைத்து Windows, GPU, டிரைவர் மற்றும் கேம் சேர்க்கைகளுக்கான சான்றிதழ் மேட்ரிக்ஸ் அல்ல.

| கருவி | Windows / இயக்க நேரம் | வன்பொருள் / வெளிப்புற சார்பு | கவனிப்பு தேவைப்படும் செயல்பாடுகள் |
| --- | --- | --- | --- |
| NVPI fork 3.0.2.3 | Windows 10/11 x64, .NET கட்டமைப்பு 4.8 | இணக்கமான NVIDIA இயக்கி/காட்சி | சுயவிவரம் முன்னோட்டங்களை எழுதுகிறது மற்றும் காண்பிக்கும் |
| NVDriverForge 0.1.4 | Windows 10 பில்ட் 19041+ / 11 x64; .NET/WPF சேர்க்கப்பட்டுள்ளது | இணக்கமான NVIDIA இயக்கி தொகுப்பு | உயர்த்தப்பட்ட நிறுவல், மேம்பட்ட அமைப்புகள், விருப்பத்தேர்வு NVENC |
| NVMFG Unlock40 0.2.3 | Windows 10/11 x64; .NET/WPF சேர்க்கப்பட்டுள்ளது, கட்டமைப்பு 4.8 உதவியாளர்கள் | RTX 40, தகுதியான DLSS FG கேம் மற்றும் பின் செய்யப்பட்ட வழங்குநர் | நேட்டிவ் இன்-கேம் பேட்ச்சிங், உலகளாவிய சுயவிவர இதழ், SDK கேம் புதுப்பிப்புகள் |
| NVRasterPulse 0.2 | Windows 10/11 x64, .NET கட்டமைப்பு 4.8 | RTSS நிறுவப்பட்டது; தொப்பிகளுக்காக ஓடுகிறது | RTSS ஒரு இயங்கக்கூடிய சுயவிவர மாற்றங்கள் |

ARM64 தொகுப்பு எதுவும் தயாரிக்கப்படவில்லை. காட்சி/API கிடைக்கும் தன்மை மற்றும் பழைய Windows பதிப்புகள் தனிப்பட்ட அம்சங்களைக் கட்டுப்படுத்தலாம். உலகளாவிய குறைந்தபட்ச NVIDIA அல்லது RTSS பதிப்பு எதுவும் கண்டுபிடிக்கப்படவில்லை. சரியான NVMFG வழங்குநர் ஹாஷ் [ஆதாரம்](provenance.md) இல் உள்ளது.

## பிழையைப் புகாரளிக்கும் முன்

நீங்கள் திறந்த சரியான இயங்கக்கூடிய/பதிப்பைக் கண்டறியவும். முந்தைய நிறுவப்பட்ட நகல், புதிதாகப் பதிவிறக்கப்பட்ட ZIP பதிப்பின் பதிப்பாக இருக்க வேண்டிய அவசியமில்லை. இனப்பெருக்கம் படிகள், எதிர்பார்க்கப்படும் முடிவு மற்றும் உண்மையான முடிவு ஆகியவற்றை பதிவு செய்யவும். ரெண்டரிங்/கட்டுப்படுத்துதல் சிக்கல்களுக்கு, கேம் பதிப்பு, காட்சி புதுப்பிப்பு, FG/V-Sync/VRR நிலை மற்றும் வேறு ஏதேனும் வரம்பு அல்லது மேலடுக்கு ஆகியவை அடங்கும்.

[பிழை வடிவம்](https://github.com/Zendo-GIT/NV-Laboratory/issues/new?template=bug-report.yml) ஐப் பயன்படுத்தவும். முழு தனிப்பட்ட டெவலப்மெண்ட் கோப்புறை, இயக்கி காப்பகம், மாடல், கேம் டிஎல்எல், ரெஜிஸ்ட்ரி டம்ப் அல்லது மதிப்பாய்வு செய்யப்படாத பதிவு சேகரிப்பு ஆகியவற்றை ஒருபோதும் இணைக்க வேண்டாம்.

| பிரச்சனை | முதல் காசோலைகள் |
| --- | --- |
| தவறான பயன்பாட்டு பதிப்பு | EXE அடையாளத்தை உறுதிசெய்து ஹாஷை வெளியிடவும்; மாற்றுவதற்கு முன் பழைய நகலை மூடவும். |
| இயக்க நேரம்/தொடக்கப் பிழை | தேவையான Framework 4.8 ஐ நிறுவவும் அல்லது வழங்கப்பட்ட அனைத்து சிறிய துணை கோப்புறைகளையும் தக்கவைக்கவும். |
| UAC ரத்துசெய்யப்பட்டது | நோக்கம் கொண்ட செயல்பாட்டை மட்டும் மீண்டும் முயற்சிக்கவும்; ரத்துசெய்தல் வெற்றிகரமான நிறுவல் அல்ல. |
| ஹாஷ்/கையொப்பம் பொருந்தவில்லை | அந்த வேட்பாளரைப் பயன்படுத்துவதை நிறுத்திவிட்டு, எதிர்பார்க்கப்படும் அதிகாரப்பூர்வ பைட்டுகளைப் பெறுங்கள். |
| NVPI வண்ணம்/முறை நிராகரிக்கப்பட்டது | உண்மையான காட்சி/இயக்கியால் ஆதரிக்கப்படும் கலவையை மீட்டமைத்து பயன்படுத்தவும். |
| NVDF காப்புப்பிரதி அல்லது மீட்பு தோல்வி | பாதுகாக்கப்பட்ட வேலை மற்றும் RECOVERY.txt; பத்திரிகையை அழிக்கவோ அல்லது முரண்பட்ட எழுத்துகளை கட்டாயப்படுத்தவோ வேண்டாம். |
| NVMFG நிலுவையிலுள்ள அமைப்புகள் | மற்ற கருவிகளிலிருந்து மாற்றங்களைப் பாதுகாத்து, மூடப்பட்ட கேம்கள் மூலம் மீட்டெடுப்பைத் தீர்க்கவும். |
| RP தொப்பி எந்த விளைவையும் ஏற்படுத்தாது | RTSS ஐ இயக்கவும், உண்மையான கேம் EXE ஐ அடையாளம் காணவும், ஹூக் நிலை மற்றும் போட்டியிடும் வரம்புகளை ஆய்வு செய்யவும். |
| RP தொப்பி அகற்றப்பட்ட பிறகும் நீடிக்கும் | RTSS குளோபல் ஆய்வு; அகற்றுதல் உள்ளூர் வரம்பு மீறல்களை மட்டும் மாற்றுகிறது. |

NVDriverForge ஒரு முன்னோட்ட உள்ளூர் JSON அறிக்கையை வழங்குகிறது; NVMFG பற்றி ஒரு கண்டறியும் வழங்குகிறது. இந்த வடிகட்டப்பட்ட அறிக்கைகளை ஒரு முழுமையான பதிவுக் காப்பகத்திற்குத் தேர்ந்தெடுத்து, பகிர்வதற்கு முன் அவற்றைச் சரிபார்க்கவும். NVMFG 0.1.1 இல் புகாரளிக்கப்பட்ட மறுசீரமைப்பு அடைப்புக்கு இன்னும் உறுதியான காரணம் இல்லை; அதன் ஜர்னலைப் பாதுகாத்து, கிடைக்கக்கூடிய பிழைக் குறியீட்டைப் பதிவுசெய்யவும். NVRasterPulse 0.2 ஆனது FPS ஐ அளவிடாமல், அதன் செயல்கள் மெனுவில் உள்ளமைவு கண்டறிதல்களை வழங்குகிறது.

## பதிவுகள் மற்றும் தனியுரிமை

| கருவி | மதிப்பாய்வு செய்ய உள்ளூர் தரவு, மொத்தமாக பதிவேற்றம் செய்யாது |
| --- | --- |
| NVDF | `%LOCALAPPDATA%\NVDriverForge`; பாதுகாக்கப்பட்ட வேலைகள் `%PROGRAMDATA%\NVDriverForge\Jobs` |
| என்விஎம்எஃப்ஜி | `%LOCALAPPDATA%\RtxMfg`; காப்புப்பிரதிகள் `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`; EXE க்கு அருகில் `Sessions` |
| RP | `%LOCALAPPDATA%\NVRasterPulse`; அதன் கீழே `Backups\RTSS` |
| NVPI | நீங்கள் தேர்ந்தெடுத்த ஏற்றுமதிகள் மற்றும் காட்டப்படும் பிழை; உலகளாவிய பதிவு பாதை கண்டுபிடிக்கப்படவில்லை |

நீங்கள் பகிரும் உரை/படங்களிலிருந்து கணக்குப் பெயர்கள், வீட்டுக் கோப்பகங்கள், கேம்-லைப்ரரி பாதைகள், சாதன அடையாளங்காட்டிகள், டோக்கன்கள் மற்றும் தொடர்பில்லாத சாளரங்களை அகற்றவும். மீட்டெடுப்பதற்காக அசல்களை தனிப்பட்ட முறையில் வைத்திருங்கள். பொதுப் பிரச்சினைகள் அனைவருக்கும் தெரியும்.

பாதிப்பு, ஆபத்தான சலுகை பெற்ற நடத்தை அல்லது திட்டமிடப்படாத அழிவுச் செயல்பாட்டிற்கு, விவரங்களைப் பொதுவில் இடுகையிடுவதற்குப் பதிலாக [SECURITY.md](../SECURITY.md) ஐப் பின்பற்றவும்.

## என்ன சரிபார்க்கப்பட்டது

ஹப் தயாரிப்பிற்காக, நிலையான பேலோட்/ஜிப்/ஹாஷ்/மெட்டாடேட்டா ஸ்கேன் மற்றும் ஆவணச் சரிபார்ப்புகள் இயக்கப்பட்டன. தற்போதுள்ள தனியார் பயன்பாட்டு உருவாக்கம்/அலகு/UI சோதனைகள் வரலாற்று, தேதியிட்ட சான்றுகள். இந்த தயாரிப்பின் ஒரு பகுதியாக இயக்கி நிறுவல், காட்சி மாற்றம், நேரடி RTSS செயல்பாடு அல்லது கேம் பெஞ்ச்மார்க் எதுவும் செய்யப்படவில்லை.

"கண்டறியப்பட்டது", "எழுதப்பட்டது", "மீண்டும் ஏற்றப்பட்டது", "கிடைக்கும் திறன்" மற்றும் "கேமில் அளவிடப்பட்டது" ஆகியவை வெவ்வேறு முடிவுகள். நீங்கள் கவனித்ததை தெரிவிக்கவும்.
