# களஞ்சிய கட்டமைப்பு மற்றும் பராமரிப்பு

NV Laboratory என்பது பொது **ஆவணங்கள் மற்றும் பைனரி-விநியோக மையம்**. இது பயன்பாட்டு மூலத்தைக் கொண்டிருக்கவில்லை. நான்கு திட்டங்களும் தனித்தனி கட்ட மரங்கள், பதிப்புகள், அடையாளங்கள் மற்றும் சொத்துக்களை வெளியிடுகின்றன. அவர்களின் தனிப்பட்ட வளர்ச்சி வரலாறு இந்த Git களஞ்சியத்தில் இறக்குமதி செய்யப்படவில்லை.

## உள்ளூர் சோதனைகள்

களஞ்சிய மூலத்திலிருந்து:

```text
python tools/validate_repository.py
```

Python 3.10 அல்லது புதியது போதுமானது. காசோலை கோப்புகள், உள்ளூர் மார்க் டவுன் இணைப்புகள், தேவையான அறிவிப்புகள்/RTSS இணைப்புகள், வெளியீட்டு மெட்டாடேட்டா மற்றும் வெளியீட்டு எல்லைகள் ஆகியவற்றைப் படிக்கிறது. இது மென்பொருளை இயக்காது, சார்புகளை நிறுவாது அல்லது பிணையத்தைத் தொடர்பு கொள்ளாது.

GitHub பணிப்பாய்வு புஷ், புல் கோரிக்கை அல்லது கைமுறையாக அனுப்புதல் ஆகியவற்றில் படிக்க-மட்டும் உள்ளடக்க அனுமதியுடன் இதே சரிபார்ப்பை இயக்குகிறது. செக் அவுட் என்பது தணிக்கை செய்யப்பட்ட உறுதியுடன் பின் செய்யப்பட்டுள்ளது மற்றும் நற்சான்றிதழ்கள் தொடராது. வெளியீடு அல்லது வரிசைப்படுத்தல் வேலை எதுவும் உள்ளமைக்கப்படவில்லை.

<a id="maintain-the-boundary"></a>
## எல்லையை பராமரிக்கவும்

ஆங்கிலக் குறிப்பு, பிரெஞ்சு வழிகாட்டிகள் மற்றும் பாதிக்கப்பட்ட மொழிபெயர்ப்புகளை ஒன்றாகப் புதுப்பிக்கவும். வடிவமைத்தல்-மட்டும் ஒப்பீடுகளிலிருந்து கணிசமான மாற்றங்களை தனித்தனியாக வைத்திருங்கள். உண்மையான வேட்பாளர் ஹாஷ்களை பதிவு செய்யவும், அப்ஸ்ட்ரீம் கமிட் குறிப்புகள் மற்றும் உரிமங்கள்; ஒரு திட்டத்தின் பிரபலத்திலிருந்து உரிமத்தை ஒருபோதும் ஊகிக்க வேண்டாம்.

புதிய பதிப்பான வெளியீட்டு சொத்துகளைப் பயன்படுத்தவும் மற்றும் மாற்றப்பட்ட பைனரிகள், காப்பகங்கள் மற்றும் உட்பொதிக்கப்பட்ட அறிவிப்புகளை மீண்டும் தணிக்கை செய்யவும். இந்தக் களஞ்சியத்திற்கு வெளியே தனிப்பட்ட காப்புப்பிரதிகளைப் பாதுகாக்கவும். தனிப்பட்ட பயன்பாட்டு மூலத்தை அல்லது உள்ளூர் உருவாக்க கோப்புறைகளை இறக்குமதி செய்ய பொது பணிப்பாய்வுகளைப் பயன்படுத்த வேண்டாம்.

தனிப்பட்ட திட்டத்தில் இயங்கும் செயல்பாட்டு பயன்பாட்டு மாற்றத்திற்கு பொருத்தமான சோதனைகள். இயக்கி நிறுவிகளை மீண்டும் இயக்க வேண்டாம் அல்லது ஆவணப் புதுப்பிப்புக்காக உண்மையான சுயவிவரங்களை எழுத வேண்டாம். [கைமுறையாக வெளியிடும் செயல்முறை](releasing.md).
