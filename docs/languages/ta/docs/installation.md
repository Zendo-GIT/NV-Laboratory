# நிறுவல் வழிகாட்டி

[பதிவிறக்கங்கள்](downloads.md) உடன் தொடங்கவும், இது வெளியீட்டு நிலை மற்றும் சரியான சொத்துப் பெயர்களைப் பதிவு செய்கிறது. இவை தனித்தனி கருவிகள்: உங்களுக்கு தேவையானவற்றை மட்டும் நிறுவவும்.

> வரம்புகளைப் பயன்படுத்த RTSS இயங்க வேண்டும்; இது NV Tools இல் சேர்க்கப்படவில்லை.

## பதிவிறக்கவும், சரிபார்க்கவும், நிறுவவும்

1. தேர்ந்தெடுக்கப்பட்ட வெளியிடப்பட்ட வெளியீட்டில், அதன் பெயரிடப்பட்ட பயன்பாட்டுச் சொத்து, ZIP மற்றும் SHA256SUMS.txt அறிவிப்புகளைப் பதிவிறக்கவும்.
2. [SHA-256 உதாரணம்](downloads.md#sha-256)ஐ, உண்மையான பதிவிறக்கம் செய்யப்பட்ட கோப்புப் பெயருடன் பயன்படுத்தவும்.
3. அமைப்பதற்கு, சாதாரண நிறுவியைப் பின்பற்றவும். போர்ட்டபிள் ஜிப்க்கு, எல்லாவற்றையும் புதிய உள்ளூர் எழுதக்கூடிய கோப்புறையில் பிரித்தெடுக்கவும்; ZIP உள்ளே இருந்து இயக்க வேண்டாம்.
4. பயன்பாட்டின் சொந்த EXE ஐத் திறக்கவும். அதனுடன் உள்ள உரிமம்/உள்ளமைவு/தரவு கோப்புகளை வைத்திருங்கள்.
5. அமைப்புகள் அல்லது கணினி செயல்பாடுகளை இயக்கும் முன் அந்த கருவியின் பயன்பாட்டு வழிமுறைகளைப் படிக்கவும்.

தற்போதைய பைனரிகள் கையொப்பமிடப்படவில்லை. பொருந்தக்கூடிய ஹாஷ் எதிர்பார்க்கப்படும் பைட்டுகளை உறுதிப்படுத்துகிறது; இது ஒரு பாதுகாப்பு அல்லது பொருந்தக்கூடிய சான்றிதழ் அல்ல. ஒரு எச்சரிக்கையை அடக்குவதற்காக Windows பாதுகாப்பு பாதுகாப்புகளை முடக்க வேண்டாம்.

NVDF அல்லது அதன் விருப்பமான NVPI துணையை நிறுவுவது GPU இயக்கியை நிறுவுவதில் இருந்து வேறுபட்டது. NVPI துணை அதன் தற்போதைய உள் நிறுவல் பெயரை வைத்திருக்கிறது. அதன் உயர்த்தப்பட்ட RasterPulse பொத்தானுக்கு ஒரு பாதுகாக்கப்பட்ட கணினி அளவிலான நிறுவல் தேவைப்படுகிறது; மற்ற RP பிரதிகள் அவற்றின் சொந்த குறுக்குவழிகள் மூலம் திறக்கப்படலாம்.

NVMFG சோதனையானது மற்றும் [ஆவணப்படுத்தப்பட்ட NVIDIA SDK உரிம இருப்பு](provenance.md) உள்ளது. NVIDIA இயக்கி, NGX வழங்குநர்/மாடல் அல்லது கேம் Streamline இயக்க நேரம் சேர்க்கப்படவில்லை. தேர்ந்தெடுக்கப்பட்ட SDK பதிவிறக்கங்கள் மற்றும் கேம் புதுப்பிப்புகள் வெளிப்படையான தனி செயல்பாடுகள்.

## மொழி மற்றும் புதுப்பிப்புகள்

ஆவணப்படுத்தலுக்கு README இன் 34-மொழி தேர்வியைப் பயன்படுத்தவும். NVDF, NVMFG மற்றும் RP ஆகியவை அவற்றின் சொந்த 34-மொழி UI அமைப்பைக் கொண்டுள்ளன; NVPI அதன் தற்போதைய மொழி ஆதரவை வைத்திருக்கிறது. சில நிறுவி தொழில்நுட்ப சரங்கள் மீண்டும் ஆங்கிலத்திற்கு வரும்.

புதுப்பிக்கும் போது கருவியின் நிறுவல் அடையாளத்தை வைத்திருங்கள். முதலில் அதை மூடி, காப்புப்பிரதிகளைப் பாதுகாக்கவும். NVMFGக்கு, பாதிக்கப்பட்ட கேம்களை மூடிவிட்டு, நிலுவையில் உள்ள சுயவிவர மீட்டெடுப்பைத் தீர்க்கவும். சிறிய புதுப்பிப்புகளுக்கு, வெளியீடுகளை இணைப்பதை விட புதிய கோப்புறையைப் பயன்படுத்தவும்.

## ஒரு கருவியை அகற்றுதல்

ஒரு பயன்பாட்டை நிறுவல் நீக்குவது அதன் அமைப்புகளை தானாக செயல்தவிர்ப்பது அல்ல.

- **NVPI:** தேவைப்பட்டால் அகற்றும் முன் உத்தேசிக்கப்பட்ட சுயவிவரங்கள்/காட்சி அமைப்புகளை மீட்டெடுக்கவும்.
- **NVDF:** மேம்பட்ட/NVENC மாற்றங்களை மீட்டெடுக்க விரும்பினால் முதலில் மீட்டெடுப்பைப் பயன்படுத்தவும். Uninstall கிராபிக்ஸ் இயக்கி, அமைப்புகள் மற்றும் காப்புப்பிரதிகளை விட்டு வெளியேறுகிறது.
- **NVMFG:** கேம்களை மூடவும், கன்ட்ரோலரை முடக்கவும் / வெளியேறவும், NVIDIA மீட்டெடுப்பைத் தீர்க்கவும் மற்றும் அகற்றுவதற்கு முன் விரும்பிய கேம் SDK காப்புப்பிரதிகளை மீட்டெடுக்கவும்.
- **RP:** திட்டமிடப்பட்ட வரம்பு மேலெழுதலை முதலில் அகற்றவும். Uninstall சேமிக்கப்பட்ட RTSS தொப்பிகளை அழிக்காது அல்லது RTSS ஐ அகற்றாது.

துல்லியமான தரவு இருப்பிடங்கள் மற்றும் வரம்புகளுக்கு ஒவ்வொரு [திட்ட வழிகாட்டி](../README.md#projects) ஐப் பார்க்கவும் அல்லது மீட்புப் படி தோல்வியுற்றால் [ஆதரவு](support.md).
