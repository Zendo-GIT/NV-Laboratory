<a id="nvdriverforge"></a>
## NVDriverForge

சுயாதீன C#/.NET 8/WPF பயன்பாடு; பயனர் எதிர்கொள்ளும் பணிப்பாய்வு ஒரு பகுதியாக NVCleanstall ஆல் ஈர்க்கப்பட்டுள்ளது. உற்பத்தி பேலோடில் NVCleanstall ஆதாரம்/பைனரி எதுவும் அடையாளம் காணப்படவில்லை. இது அந்த தனியுரிம பயன்பாட்டின் fork ஆக குறிப்பிடப்படவில்லை.

அசல் திட்டப் பணிகளில் கூறு பகுப்பாய்வு/தேர்வு, பாதுகாக்கப்பட்ட நிறுவல் வேலைகள், காப்புப்பிரதிகள் மற்றும் பரிவர்த்தனை மீட்பு, NVIDIA பட்டியல் பதிவிறக்கங்கள், புதுப்பிப்புகள், உள்ளூர் விளக்கங்கள், விருப்ப மேம்பட்ட/NVENC பணிப்பாய்வுகள் மற்றும் நிறுவி பூட்ஸ்ட்ராப் ஆகியவை அடங்கும்.

மரபுவழி/தழுவல் கூறுகள்: நான்கு NVPI தீம் தட்டுகள், நீட்டிக்கப்பட்ட NVAPI DRS இடைமுகக் குறிப்பு மற்றும் தனித்தனியாக விருப்பத்தேர்வு MIT NVPI துணை. Custom NV முன்னமைவின் தேர்வு UI மற்றும் அனுமதிக்கப்பட்ட பரிவர்த்தனை ஒருங்கிணைப்பு ஆகியவை NVDriverForgeக்கு சொந்தமானது; முன்னமைவு அதிகாரப்பூர்வ NVIDIA பரிந்துரை அல்ல.

7-Zip 26.03, .NET/WPF 8.0.31 மற்றும் Inno Setup ஆகியவை அவற்றின் சொந்த விதிமுறைகளின் கீழ் பயன்படுத்தப்படும் மாற்றப்படாத வெளிப்புற கூறுகளாக உள்ளன. keylase NVENC தரவு உட்பொதிக்கப்படவில்லை; பயனர் இணக்கமான பதிவிறக்கத்தைக் கோரும் போது ஒரு சரியான உறுதி தேர்வு செய்யப்பட்டு சரிபார்க்கப்படுகிறது. அந்த அப்ஸ்ட்ரீம் தரவுக்கு மறுபகிர்வு உரிமம் எதுவும் நிறுவப்படவில்லை.

## NVMFG Unlock40

NVMFG Unlock40 ஆனது 禅堂 Zendo (RevoluSound Team) ஆல் சுயாதீனமாக உருவாக்கப்பட்டது. பராமரிப்பாளர் RTX40MFG-Unlock ஐ ஒப்பிடுவதற்கும் சுத்திகரிப்பதற்கும் பயன்படுத்தினார். பயன்பாடு முழுவதுமாக அதன் fork என வழங்கப்படவில்லை. தற்போதைய நேட்டிவ் லேயரில் பகிரப்பட்ட/தழுவிய கூறுகளுக்கான கிரெடிட்களை இந்த வேறுபாடு அகற்றாது.

ஒப்பீடு குறிப்பு: dashdogy/RTX40MFG-Unlock, Michael Robles, MIT, உறுதி `4e776d068f91b4a665425542bb005dd57cc3d891`. தனிப்பட்ட நேட்டிவ்-இன்ஜின் மரத்தில் 48 ஒப்பிடப்பட்ட கோப்புகள் உள்ளன: 35 வடிவமைப்பு-மட்டும் வேறுபாடுகள், 4 மாற்றியமைக்கப்பட்ட கோப்புகள் மற்றும் 9 குறிப்பு பாதையில் இல்லை. [முழுமையான ஒப்பீடு](../../../provenance/nvmfg-source-provenance.json).

மாற்றியமைக்கப்பட்ட பரம்பரை கோப்புகள்: `entry_detour.h`, `patcher.cpp`, `temporal_interval_trace.cpp`, `temporal_interval_trace.h`. கூடுதல் பாதைகளில் `game_selection.*`, `ngx_bootstrap.*`, `ngx_capability.h`, `presentation_tracker.h`, `vsync_observer.*` மற்றும் தக்கவைக்கப்பட்ட அப்ஸ்ட்ரீம் உரிமம் ஆகியவை அடங்கும்.

உற்பத்தி C++ அலகுகள்: பேட்சர், midpoint_fix, dlssg_provider_policy, entry_detour, nvidia_mfg_policy, temporal_interval_trace, ngx_bootstrap, game_selection மற்றும் vsync_observer; கூடுதலாக entry_detour சட்டசபை மற்றும் MinHook தாங்கல்/கொக்கி/டிராம்போலைன்/HDE64. பரம்பரை ReShade முன்பக்கம், மரபு ஷிம் வளங்கள் மற்றும் பயன்படுத்தப்படாதவை CMake இலக்குகள் இந்த உற்பத்தி தொகுப்பின் பகுதியாக இல்லை.

பொருந்தும் கூறுகள் இணைப்பு/வழங்குபவர் கொள்கை மற்றும் தற்காலிக வேலைகளை உள்ளடக்கியது; அவற்றின் பதிப்புரிமை மற்றும் அனுமதி அறிவிப்புகள் அப்படியே இருக்கும். மத்திய NGX/பூட்ஸ்டார்ப்/கண்ட்ரோலர் ஒருங்கிணைப்பு, ஒரு விளையாட்டு V-Sync கையாளுதல், அமர்வு கண்டறிதல் மற்றும் Windows பயன்பாடு/SDK/பேக்கப் பணிப்பாய்வு ஆகியவை 禅堂 Zendo (RevoluSound Team) இன் திட்டப்பணிகளாகும். மேலே உள்ள எண்ணிக்கையானது மூன்றாம் தரப்பு மற்றும் பயன்படுத்தப்படாத கோப்புகள் உள்ளிட்ட கோப்புகளை விவரிக்கிறது, படைப்பு சதவீதம் அல்லது திட்டத்தின் யோசனையின் காலவரிசை அல்ல.

உதவியாளர் NVPI இன் NvapiDrsWrapper மற்றும் NativeArrayHelper ஐ ஒரு தனி அசெம்பிளியாக மாற்றியமைத்து, திட்டத்தால் எழுதப்பட்ட சுயவிவர தர்க்கத்துடன். பழைய வளர்ச்சி போலி பாதை விலக்கப்பட்டுள்ளது. பகிரப்பட்ட குடும்பத் தட்டுகள் NVPI இலிருந்து வந்தவை.

## NVRasterPulse

சுயாதீன RTSS சுயவிவர மேலாளர் NVPI-பெறப்பட்ட களஞ்சியத்தில் உருவாக்கப்பட்டது. பரம்பரை MIT UI ஆதாரங்கள்/தட்டுகள் மற்றும் திட்ட தோற்றம் ஆகியவை வரவு வைக்கப்படும். MIT உரிமத்தை தயாரிப்பு பயன்பாடு வெளிப்படையாகப் பயன்படுத்துகிறது.

திட்டப்பணி: துல்லியமான RTSS சுயவிவரப் பாகுபடுத்தல்/எழுத்துகள் மற்றும் பகுதியளவு குறியாக்கம், காப்புப் பிரதிகள், மேலெழுதுதல் அகற்றுதல், ரீலோட் பிரிட்ஜ், முன்தேவை கண்டறிதல், கச்சிதமான UI, தட்டு வாழ்க்கைச் சுழற்சி, தொடக்கக் கட்டுப்பாடுகள் மற்றும் உள்ளூர்மயமாக்கல். RTSS உண்மையான வரம்பைச் செய்கிறது.

RTSS ஆதாரம், ஹூக் DLL, SDK அல்லது நிறுவி தொகுக்கப்படவில்லை. ஏற்கனவே உள்ள பயனர் தேர்ந்தெடுத்த RTSS நிறுவலில் ஏற்றுமதியை பிரிட்ஜ் அழைக்கிறது. NVIDIA இயக்கி தொகுப்பு, சொந்த பரிசோதனை வரம்பு, ஃப்ரேம்பேசர், MinHook, ReShade அல்லது DLSS இயக்க நேரம் இந்த தொகுப்பில் இல்லை.

## சொத்துக்கள், உருவாக்கப்பட்ட தரவு மற்றும் கருவிகள்

[சொத்து வரவுகள்](../assets/README.md) ஏற்கனவே உள்ள இடைமுக முன்னோட்டங்கள் மற்றும் NVPI அமைவுத் தேர்வியை அடையாளம் காட்டுகிறது. அவற்றில் உள்ள கற்பனை மதிப்புகள் பெயரிடப்பட்டுள்ளன. கேம்/நெக்ஸஸ் சொத்து, தனிப்பட்ட சுயவிவரம், தனிப்பட்ட ICC, கார்ப்பரேட் NVIDIA லோகோ அல்லது எழுத்துருக் கோப்பு நகலெடுக்கப்படவில்லை.

NVMFG இல் உருவாக்கப்பட்ட கேம் பொருந்தக்கூடிய பெயர்கள் ஒரு கண்டறிதல் உதவி, சோதனை ஆதாரம் அல்ல. உருவாக்கப்பட்ட நிறுவி பட்டியல்கள் [மொழிபெயர்ப்பாளர் அறிவிப்புகள்](../../../../licenses/INSTALLER-TRANSLATORS.md) இல் வரவு வைக்கப்பட்டுள்ளன. முழுமையான பாதைகளுடன் உருவாக்கப்பட்ட உருவாக்க பதிவுகள் தனிப்பட்டதாகவே இருக்கும்.

தனியார் உருவாக்க கருவிகளில் .NET அடங்கும் SDK/எம்.எஸ்.பில்ட், விஷுவல் Studio C++/MASM, Windows SDK, PowerShell, Inno Setup மற்றும் Python தணிக்கை ஸ்கிரிப்டுகள். அவற்றின் தொகுப்பிகள், தலைப்புகள், சோதனை ஓட்டங்கள் மற்றும் பிழைத்திருத்த சொத்துக்கள் விநியோகிக்கப்படவில்லை. நிலையான வெளியீடு CRT கீழே உள்ளது Microsoftபொருந்தக்கூடிய கருவித்தொகுப்பு விதிமுறைகள்.

## சரிபார்ப்பின் நோக்கம்

Git ஆப்ஜெக்ட் தரவுத்தளங்கள் மற்றும் இணைக்கப்பட்ட அடைவு இலக்குகளைத் தவிர்த்து, உள்ளூர் தணிக்கையானது மூன்று வளர்ச்சி வேர்களில் உள்ள அனைத்து கோப்புகளையும் பட்டியலிட்டது. செயலில் உள்ள ஆதாரம்/டாக்ஸ் ஸ்கேன் செய்யப்பட்டது; வரலாற்று கட்டிடங்கள் கண்டுபிடிக்கப்பட்டு விலக்கப்பட்டன. தேர்ந்தெடுக்கப்பட்ட ஜிப்கள் மற்றும் தற்போதைய பேலோடுகள் ஸ்கேன் செய்யப்பட்டு ஹாஷ் செய்யப்பட்டன; கூடுதல் ஆய்வுக்காக .NET மூட்டைகள் சுருக்கப்பட்டன. அந்த ஆரம்ப தணிக்கை எந்த தயாரிப்பு, நிறுவி, விளையாட்டு, RTSS செயல்முறை அல்லது இயக்கி இயங்கவில்லை.

பிந்தைய NVPI அமைப்பு திருத்தம் 2 பகிரப்பட்ட Inno கட்டுப்பாடுகள் மற்றும் பூட்ஸ்ட்ராப்பைப் பயன்படுத்தி முழுமையான மொழித் தேர்வை சரிசெய்கிறது. ஒளி/அடர்ந்த தனிப்பட்ட சாதனங்கள் சரிபார்க்கப்பட்ட மவுஸ் மற்றும் விசைப்பலகை வழிசெலுத்தல் மற்றும் அனைத்து 34 வெளிப்படையான மொழி குறியீடுகள். உண்மையான அமைவுத் தேர்வானது ஒருபோதும் காட்டப்படாத தனிப்பட்ட டெஸ்க்டாப்பில் திறக்கப்பட்டு, நிறுவலுக்கு முன் ரத்துசெய்யப்பட்டது. அதன் ஏழு பயன்பாட்டுக் கோப்புகள் மற்றும் போர்ட்டபிள் ஜிப் மாறாமல் உள்ளது. NVDriverForge 0.1.3 திருத்தப்பட்ட துணையை உள்ளடக்கியது மற்றும் இன்னும் முன்னோக்கி `/LANG`.

NVDriverForge 0.1.3 2026-09-10 அன்று நிறைவடைந்தது. அதன் தனிப்பட்ட சரிபார்ப்பு அறிக்கையில் 366 பயன்பாட்டுச் சோதனைகள், 118 துணைச் சரிபார்ப்புகள், 32 அமைவுச் சரிபார்ப்புகள், 156 சொந்த ஒப்பீடுகள் மற்றும் 34 மொழி-பரிவர்த்தனை வழக்குகள் பதிவு செய்யப்பட்டுள்ளன. பாதுகாக்கப்பட்ட கூறு-தேர்வு பிழையானது அதன் பேலோடை மாற்றாமலோ அல்லது இயக்கியை நிறுவாமலோ அசல் இயக்கி தொகுப்பிற்கு எதிராக மீண்டும் இயக்கப்பட்டது. இவை தேதியிடப்பட்ட தயாரிப்பு-குழு முடிவுகள், இந்த ஆவணப் புதுப்பித்தலின் மூலம் மீண்டும் இயக்கப்படும் சோதனைகள் அல்லது வெற்றிகரமான உண்மையான இயக்கி நிறுவலின் ஆதாரம் அல்ல.
