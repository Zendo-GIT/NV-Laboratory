# பங்களிக்கிறது

NV Laboratory ஆனது 禅堂 Zendo (RevoluSound Team) ஆல் பராமரிக்கப்படுகிறது. எது ஏற்றுக்கொள்ளப்பட்டது மற்றும் வெளியிடப்பட்டது என்பதை பராமரிப்பவர் தீர்மானிக்கிறார். ஒரு சிக்கலைத் திறப்பது அல்லது கோரிக்கையை இழுப்பது என்பது பங்களிப்பு ஏற்றுக்கொள்ளப்பட்டது அல்லது விநியோகத்திற்காக அங்கீகரிக்கப்பட்டது என்று அர்த்தமல்ல.

பிழை அல்லது அம்சப் படிவத்தைப் பயன்படுத்தி நிரல்/பதிப்பைக் கண்டறியவும். ஏற்கனவே உள்ள சிக்கல்களை முதலில் தேடுங்கள். பெரிய பங்களிப்பைத் தயாரிப்பதற்கு முன் கணிசமான மாற்றங்களைப் பற்றி விவாதிக்கவும். பாதுகாப்பு விஷயங்களுக்கு, [SECURITY.md](SECURITY.md)ஐப் பின்தொடரவும்.

இந்த பொது மையத்தில் ஆவணங்கள், அறிவிப்புகள், வெளியீட்டு மெட்டாடேட்டா மற்றும் களஞ்சிய சரிபார்ப்பு ஆகியவை உள்ளன. விண்ணப்ப ஆதாரம் மற்றும் சோதனைகள் தனிப்பட்ட முறையில் பராமரிக்கப்படுகின்றன. சிதைக்கப்பட்ட குறியீடு, தனிப்பட்ட ஆதாரம், நற்சான்றிதழ்கள், பயனர் சுயவிவரங்கள் அல்லது இயங்கக்கூடிய பேலோடுகளைச் சமர்ப்பிக்க வேண்டாம்.

ஆவணப்படுத்தல் PRகள் 34 மொழிகள் மற்றும் வழிசெலுத்தலை சீரமைக்க வேண்டும், கட்டளை/கோப்பு/தயாரிப்பு பெயர்களை பாதுகாக்க வேண்டும் மற்றும் உண்மையான நடத்தையை விவரிக்க வேண்டும். புதிய ஸ்கிரீன் ஷாட்கள் உங்கள் சொந்த, பதிப்பு அடையாளம் காணப்பட்ட மற்றும் தனிப்பட்ட விவரங்கள் இல்லாமல் இருக்க வேண்டும்; செயற்கை தரவு லேபிளிடப்பட வேண்டும். ஒவ்வொரு புதிய மூன்றாம் தரப்பு சொத்துக்கும் ஆதாரம் மற்றும் அனுமதி வழங்கவும்.

UTF-8, LF, படிக்கக்கூடிய மார்க் டவுன் மற்றும் சிறிய கவனம் மாற்றங்களைப் பயன்படுத்தவும். Python வேலிடேட்டர் நிலையான நூலகத்தை மட்டுமே பயன்படுத்துகிறது. அதன் தற்போதைய பாணியைப் பொருத்து, தேவையற்ற சார்புகளைத் தவிர்த்து, இயக்கவும்:

```text
python tools/validate_repository.py
```

வெளியீட்டு மெட்டாடேட்டா மாற்றங்களுக்கு, தணிக்கை செய்யப்பட்ட பைனரிகளில் இருந்து சரியான பதிப்பு/குறிச்சொல், கோப்பு அளவுகள் மற்றும் SHA-256 ஆகியவற்றைச் சேர்த்து, பதிவிறக்கப் பக்கங்களை சீரமைத்து வைக்கவும். பயன்பாட்டு மாற்றங்களுக்கு பாதிக்கப்பட்ட நடத்தைக்கு பொருத்தமான தனிப்பட்ட உருவாக்கம்/சோதனைகள் தேவை; ஆவணச் சரிபார்ப்பு என்பது பயன்பாட்டுச் சோதனை அல்ல. வரலாற்று சோதனை முடிவுகள் அல்லது ஆதாயங்களை ஒருபோதும் கண்டுபிடிக்க வேண்டாம்.

அசல் ஹப் மெட்டீரியலைப் பங்களிப்பதன் மூலம், [உரிமம்](../../../LICENSE) இல் அதன் நோக்கமுள்ள MIT உரிமத்தை ஒப்புக்கொள்கிறீர்கள். மூன்றாம் தரப்பு அறிவிப்புகளை வைத்து உங்கள் மாற்றங்களை அடையாளம் காணவும்; அப்ஸ்ட்ரீம் உரிமத்தை மாற்ற வேண்டாம். ஏற்றுக்கொள்வதும் வெளியிடுவதும் பராமரிப்பாளர் முடிவுகளாகவே இருக்கும்.
