# Keamanan

Kebijakan ini mencakup paket aplikasi NV Tools dan hub distribusi ini. Pengelola memprioritaskan laporan yang memengaruhi versi terbaru setiap alat yang dipublikasikan. Kandidat yang disiapkan bukanlah rilis stabil yang didukung dan diumumkan. Tidak ada tenggat waktu respons atau sertifikasi keamanan yang dijanjikan.

<a id="report-privately"></a>
## Laporkan secara pribadi

Untuk kerentanan, peningkatan perilaku tidak aman, perubahan destruktif yang tidak disengaja, atau paparan data sensitif, gunakan fitur **Keamanan → Report a vulnerability** repositori **saat diaktifkan**: [laporan pribadi](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new).

**Penyiapan awal:** pengelola harus mengaktifkan pelaporan kerentanan pribadi setelah membuat repositori publik. File ini tidak mengaktifkannya, dan tidak ada kotak surat atau saluran pribadi yang diklaim ada sebelum itu.

Jika tombol tidak tersedia, buka Masalah publik yang hanya berisi: “Saya memerlukan saluran kontak pribadi untuk laporan keamanan mengenai [alat/versi].” Jangan sertakan detail eksploitasi, kredensial, jalur yang terpengaruh, log, atau lampiran. Tunggu hingga pengelola menyediakan saluran pribadi sebelum membagikannya.

Dalam laporan pribadi, sertakan alat/versi dan hash, versi Windows/GPU/driver, dampak, reproduksi aman minimal, dan apakah diperlukan pemulihan. Menyunting rahasia dan data pribadi; melestarikan file pemulihan lokal. Jangan unggah driver berpemilik atau DLL game. Mengkoordinasikan pengungkapan dengan pengelola; patch/rilis memerlukan peninjauan dan tidak otomatis.


[Dokumentasi pelaporan pribadi GitHub](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
