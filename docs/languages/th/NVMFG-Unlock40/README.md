# NVMFG Unlock40

**ทดลอง NVIDIA Multi Frame Generation สำหรับ GeForce RTX 40 พร้อมตัวควบคุมส่วนกลางและตัวเลือกต่อเกม**

[ดาวน์โหลด 0.2.3 และสถานะ](../docs/downloads.md#nvmfg-unlock40) · [การติดตั้ง](#installation) · [ต้นน้ำ](#upstream-and-modifications) · [ใบอนุญาต](LICENSES/README.md)

<a id="overview-and-purpose"></a>
## ภาพรวมและวัตถุประสงค์

NVMFG Unlock40 เป็นแอปพลิเคชันที่พัฒนาขึ้นอย่างอิสระโดย 禅堂 Zendo (RevoluSound Team) โดยผสมผสานคอนโทรลเลอร์ Windows, เลเยอร์ดั้งเดิม, ตัวช่วยโปรไฟล์ และการจัดการเกม/Streamline SDK โดยกำหนดเป้าหมายเกมที่รวม NVIDIA DLSS Frame Generation และรันไทม์ NVIDIA ที่เข้ากันได้อยู่แล้ว

[RTX40MFG-Unlock](https://github.com/dashdogy/RTX40MFG-Unlock) ได้รับการปรึกษาเพื่อเปรียบเทียบและปรับปรุงงาน เลเยอร์เนทิฟปัจจุบันมีส่วนประกอบที่ใช้ร่วมกันและปรับเปลี่ยน โดยให้เครดิตทีละรายการด้านล่าง การอ้างอิงนี้ไม่ได้ทำให้แอปพลิเคชัน NVMFG ทั้งหมดเป็น fork ของโปรเจ็กต์นั้น

มีไว้เพื่อประสานงานพฤติกรรม MFG ทดลองจากส่วนกลาง จดจำตัวเลือกเฉพาะเกม และมองเห็นการอัปเดตรันไทม์และการสำรองข้อมูล ไม่ได้เพิ่ม DLSS Frame Generation ให้กับทุกเกมหรือแปลงการใช้งาน FSR ตามอำเภอใจ

แพ็คเกจปัจจุบันคือ **0.2.3** โดยเพิ่มไลบรารีเกม ข้อมูลกิจกรรมและความสามารถ การวินิจฉัยในเครื่อง และพฤติกรรมการเลือก/ความคืบหน้าที่แก้ไขแล้ว [ดาวน์โหลด](../docs/downloads.md#nvmfg-unlock40) ระบุไฟล์และแฮชที่แน่นอน

<a id="features"></a>
## คุณสมบัติ

- การควบคุมการเปิด/ปิดใช้งานจากส่วนกลางและการเริ่มการทำงานของถาดเสริม Windows
- การเลือกต่อเกมระหว่าง Dynamic MFG การตั้งค่าของเกมและตัวคูณคงที่ที่รองรับ
- แยกตัวเลือกที่จดจำไว้สำหรับสถานะเปิด/ปิด V-Sync ที่สังเกตได้
- Dynamic ใช้โหมดของ NVIDIA; จะถูกระงับเมื่อปิด V-Sync โดยมีตัวเลือกในเกม/ตายตัวแยกต่างหาก
- คำแนะนำเมนูเกมและการยกเว้นอย่างต่อเนื่อง เกมที่ไม่มี DLSS FG จะยังคงอยู่ในการควบคุม
- การค้นพบเกม การเลือกโฟลเดอร์พาเรนต์ การค้นหา การจัดกลุ่ม และการลบโดยไม่ต้องลบไฟล์เกม
- Streamline ดาวน์โหลด/นำเข้า SDK, แคชในเครื่องที่ตรวจสอบแล้ว, การเลือกที่ชัดเจน, การสำรองข้อมูลและการกู้คืนต่อเกม
- การตรวจสอบผู้ให้บริการดั้งเดิม การวินิจฉัยต่อเซสชัน บันทึกโปรไฟล์ส่วนกลาง และการกู้คืนโดยคำนึงถึงข้อขัดแย้ง
- 34 ภาษาอินเทอร์เฟซและสี่ธีม

การปิด FG ในเกมจะเป็นการปิดมัน ตัวเลือกคงที่ตั้งแต่ 2x ถึง 6x ขึ้นอยู่กับเกม/เมนู/รันไทม์ ไม่ใช่คำมั่นสัญญาว่าทุกชุดค่าผสมจะได้ผล คอนโทรลเลอร์สังเกต V-Sync และไม่ได้ตั้งค่า V-Sync หรือ VRR สำหรับผู้ใช้

<a id="installation"></a>
## การติดตั้ง

1. อ่าน [สถานะของผู้สมัครและบันทึกใบอนุญาต](../docs/downloads.md#nvmfg-unlock40)
2. ดาวน์โหลด `NVMFGUnlock40-0.2.3-Setup-x64.exe` หรือ `NVMFGUnlock40-0.2.3-Portable-x64.zip` เมื่อวางจำหน่าย
3. ตรวจสอบ SHA-256 และเก็บประกาศที่แนบมาด้วย ติดตั้ง .NET Framework 4.8 หาก Windows ยังไม่ได้จัดเตรียมไว้ให้
4. เรียกใช้การตั้งค่า หรือแตกไฟล์ ZIP แบบพกพา **ทั้งหมด** ไปยังโฟลเดอร์ในเครื่องที่เขียนได้
5. เปิดตัว `NVMFGUnlock40.exe`; เก็บ `agent`, `driver`, `engine` และ `Licenses` ในรูปแบบที่ให้มา

โฟลเดอร์ชื่อ `driver` มีตัวช่วยพื้นที่ผู้ใช้ ไม่ใช่ไดรเวอร์เคอร์เนล อย่าคัดลอกเฉพาะ EXE หลักหรือเปลี่ยนแฮชของผู้ให้บริการเพื่อบังคับใช้ความเข้ากันได้ EXE ปัจจุบันไม่ได้ลงนาม

<a id="usage"></a>
## การใช้งาน

1. เริ่มต้นด้วยการปิดใช้งานคอนโทรลเลอร์ เพิ่มเกมหรือโฟลเดอร์พาเรนต์แล้วเลือกการติดตั้งจริง
2. ตรวจสอบการตั้งค่า MFG ของแต่ละเกม ตอบว่ามีเมนูอะไรบ้าง คำตอบจะถูกเก็บไว้ต่อเกม
3. เลือก Dynamic หรือการตั้งค่าในเกมทั่วโลก จากนั้นปรับตัวเลือกที่มีสิทธิ์ต่อเกมตามต้องการ
4. เปิดใช้งานคอนโทรลเลอร์เฉพาะเมื่อคุณตั้งใจจะใช้เท่านั้น สามารถเปลี่ยนการตั้งค่าโปรไฟล์ NVIDIA ทั่วโลกได้ชั่วคราว 6 รายการพร้อมบันทึกการกู้คืน
5. เปิดตัวเกมที่มีสิทธิ์และเปิดใช้งาน DLSS Frame Generation ของตัวเอง ปฏิบัติตามคำร้องขอตัวเลือกการปิด V-Sync
6. ใช้การยกเว้นสำหรับเกมที่คุณไม่ต้องการจัดการ การลบเกมจะบันทึกการยกเว้นและเก็บรักษาไฟล์/ข้อมูลสำรองของเกม
7. ใช้ขั้นตอนการปิด/ปิดใช้งานและการกู้คืนแบบเต็มของแอปพลิเคชันเมื่อดำเนินการเสร็จสิ้น

การปิดหน้าต่างหลักอาจทำให้ตัวควบคุมอยู่ในถาด DLL ที่โหลดเข้าไปในเกมแล้วจะยังคงอยู่ที่นั่นจนกว่าเกมจะออก การปิดใช้งานคอนโทรลเลอร์ไม่ใช่การรับประกันการยกเลิกการโหลด ปิดเกมที่ได้รับผลกระทบก่อนการบำรุงรักษาหรือการอัปเดต

**Streamline SDKs:** บนหน้า NVIDIA SDK ให้ดาวน์โหลดเวอร์ชันอย่างเป็นทางการหรือนำเข้า SDK ในเครื่องที่เข้ากันได้ การนำเข้าจะจัดเก็บสำเนาที่ตรวจสอบแล้ว **Use this version** เลือก และ **Uninstall** จะลบสำเนาที่เก็บไว้นั้นออก Streamline DLL ที่หายไปสามารถเสริมได้จาก NVIDIA SDK อย่างเป็นทางการ โดยมีแหล่งที่มาแสดงอยู่ สิ่งนี้ไม่ดาวน์โหลด/แทนที่รุ่น NGX ปิดเกม เลือกการอัปเดตเกมที่ต้องการ และเก็บข้อมูลสำรองดั้งเดิมไว้ หากต้องการแปลงไฟล์เกมกลับ ให้ใช้การคืนค่าการสำรองข้อมูล ไม่ใช่ปุ่ม Uninstall ของแคช

<a id="library-diagnostics-and-updates"></a>
## ไลบรารี การวินิจฉัย และการอัพเดต

**ไลบรารีถาวร:** เลือกโฟลเดอร์เกมหลายโฟลเดอร์ รวมถึงไดรฟ์ที่แตกต่างกัน ก่อนที่จะเริ่มการสแกนหนึ่งครั้ง ความคืบหน้าสามารถมองเห็นได้และสามารถยกเลิกได้ หลังจากการสแกนครั้งแรก แคชในเครื่องจะกู้คืนไลบรารีเมื่อเปิดใช้งานโดยไม่ต้องเดินไปทุกโฟลเดอร์เกม รีเฟรชเพื่อค้นหาการเปลี่ยนแปลงหรือเพิ่มโฟลเดอร์อื่น การดำเนินการบำรุงรักษายังคงตรวจสอบไฟล์ที่ได้รับผลกระทบอีกครั้ง การตรวจสอบการสำรองข้อมูลยังคงทำงานอยู่ แคชถูกเก็บไว้ที่ `%LOCALAPPDATA%\RtxMfg\library-cache.json`

**การเลือก:** Ctrl+A เลือกทั้งหมด และ Ctrl+D จะล้างแท็บเกมหรือข้อมูลสำรองที่ใช้งานอยู่ ไม่มีเกมใดถูกเลือกโดยอัตโนมัติ การอัปเดตและการรีเฟรชกิจกรรมจะไม่สร้างการเลือกผีหรือจำนวนที่ไม่สอดคล้องกันอีกต่อไป

**กิจกรรมและความเข้ากันได้:** ข้อมูล MFG ต่อเกมมาจากการสังเกตของ NGX โดยไม่มีโอเวอร์เลย์ใหม่ ไม่ใช่การนับจำนวนเฟรมที่แสดงจริง การสนับสนุน Dynamic-with-V-Sync มาจากความสามารถรันไทม์ ความสามารถที่ไม่รู้จักไม่ได้อนุมานจากหมายเลขเวอร์ชัน แอปพลิเคชันจะเปลี่ยนทั้ง V-Sync หรือ VRR เมื่อปิด V-Sync Dynamic จะยังคงถูกระงับ ตัวเลือกคงที่หรือควบคุมเกมจะแยกจากกัน

**การเปิดตัวครั้งต่อไป:** การยกเว้นชั่วคราวจะข้ามการแพตช์เมื่อเปิดตัวเกมครั้งถัดไป และคืนค่าการจัดการตามปกติหลังจากออกจากเกม ไม่สามารถลบ DLL ที่โหลดไว้แล้วในเกมได้: ปิดแล้วรีสตาร์ทเกมนั้น Wallpaper Engine ได้รับการยอมรับว่าเป็นแอปพลิเคชันเดสก์ท็อป การแก้ไขนี้จะรักษาการป้องกันสำหรับเกมที่ถูกละเลยจริง ๆ

**การตั้งค่าและการสนับสนุน:** การตั้งค่าการนำเข้า/ส่งออกจำเป็นต้องมีการเชื่อมโยงโฟลเดอร์เกมใหม่ด้วยตนเอง การวินิจฉัยเฉพาะที่ใน About จะกรองข้อมูลส่วนตัวและรายงานที่มี รหัสข้อผิดพลาด NVAPI หรือหมวดหมู่ข้อขัดแย้ง ตรวจสอบก่อนที่จะแบ่งปัน ไม่มีอะไรถูกอัพโหลดโดยอัตโนมัติ

**การอัปเดตแอปพลิเคชัน:** การตรวจสอบเพิ่มเติมจะแสดงบันทึกประจำรุ่นและเสนอการตั้งค่าอย่างเป็นทางการ การดาวน์โหลดที่ชัดเจนจะถูกตรวจสอบกับขนาด GitHub และข้อมูลเมตา SHA-256 คุณเริ่มการติดตั้งด้วยตัวเอง เวอร์ชัน 0.2.3 ยังล้างข้อความความคืบหน้าที่เสร็จสมบูรณ์ ในขณะเดียวกันก็รักษาข้อผิดพลาดและผลลัพธ์ที่สำคัญไว้ การเพิ่มเติมเหล่านี้รวมถึงการเปลี่ยนแปลงตั้งแต่เวอร์ชันสาธารณะ 0.1.1

<a id="update-and-uninstall"></a>
## อัปเดตและถอนการติดตั้ง

ปิดเกมที่ได้รับผลกระทบ ปิดใช้งาน/ออกจาก NVMFG และแก้ไขการกู้คืนการตั้งค่า NVIDIA ที่ค้างอยู่ก่อนที่จะอัปเดต ติดตั้งการตั้งค่าถัดไปด้วยข้อมูลประจำตัวที่มีอยู่ หรือแตกไฟล์พกพาใหม่ลงในโฟลเดอร์ใหม่ รักษาสถานะ / การสำรองข้อมูล

ก่อนที่จะถอนการติดตั้ง ให้คืนค่าการสำรองข้อมูล SDK ของเกมที่ต้องการและการตั้งค่า NVIDIA ผ่านแอปพลิเคชัน จากนั้นปิดเกมและออกจากคอนโทรลเลอร์ ใช้ Windows **Installed apps** สำหรับการตั้งค่า หรือลบโฟลเดอร์แบบพกพาที่ปิดไว้หลังจากเก็บไฟล์ที่จำเป็นไว้ อย่าลบสมุดรายวันการกู้คืนที่ใช้งานอยู่ด้วยตนเองเพื่อเลิกบล็อกการตั้งค่า

การสำรองข้อมูลรันไทม์เกมในเครื่องใช้ `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups` การตั้งค่า MFG/ข้อมูล SDK ใช้ `%LOCALAPPDATA%\RtxMfg`; เอาต์พุตเซสชันอยู่ภายใต้ `Sessions` ข้างแอปพลิเคชัน ไฟล์เหล่านี้สามารถมีเส้นทางเกมได้ อย่าโพสต์โดยไม่ปกปิด

<a id="known-limitations"></a>
## ข้อจำกัดที่ทราบ

- การอุดตันการเปิดใช้งาน/การฟื้นฟู/การถอนการติดตั้ง 0.1.1 ที่รายงานยังคงไม่เกิดขึ้นซ้ำ และไม่ทราบสาเหตุของปัญหา รุ่นนี้ไม่ได้อ้างว่าจะแก้ไขได้ หลังจากเกิดความล้มเหลว ให้เก็บรักษาเจอร์นัลการกู้คืนและตรวจสอบการวินิจฉัยในเครื่อง อย่าบังคับให้ลบข้อมูลการกู้คืน
- แพตช์ดั้งเดิมแบบทดลองอาจทำให้เกิดการขัดข้องหรือภาพผิดปกติ ข้อขัดข้องของ Bodycam ที่ไม่ได้รับการแก้ไขจะถูกบันทึกไว้ในประวัติการพัฒนา
- การทดสอบเรนเดอร์แบบควบคุมไม่ได้รับการรับรองสำหรับทุกเกม ไดรเวอร์ หรือโปรแกรมป้องกันการโกง
- เฟรมที่สร้างขึ้นไม่ได้สร้างตัวอย่างอินพุตใหม่ ไม่มีการรับประกันเวลาแฝงที่วัดได้หรือประสิทธิภาพที่เพิ่มขึ้นจากฮับนี้
- เครื่องมือสร้างเฟรม/โอเวอร์เลย์หลายรายการอาจขัดแย้งกัน แอปพลิเคชันรายงานโมดูลที่สังเกตได้โดยไม่ต้องพิสูจน์ทุกสถานการณ์การอยู่ร่วมกัน
- รายการความเข้ากันได้เป็นตัวช่วยในการตรวจจับ ไม่ใช่รายชื่อเกมที่ทดสอบโดยสมบูรณ์
- ข้อกำหนด NVIDIA SDK ฉบับเต็มและข้อจำกัดทางเทคนิคที่ยังไม่ได้รับการแก้ไขยังคงมีบันทึกไว้ใน [ที่มา](../docs/provenance.md)

<a id="faq"></a>
## คำถามที่พบบ่อย

**รวม NVIDIA DLL หรือรุ่นต่างๆ ไว้ด้วยหรือไม่** ไม่มีไดรเวอร์, ผู้ให้บริการ/รุ่น NGX หรือรันไทม์ Streamline รวมอยู่ด้วย การดาวน์โหลด SDK ที่ชัดเจนมาจาก NVIDIA

**Dynamic ใช้งานได้เมื่อปิด V-Sync หรือไม่** จะถูกระงับในสถานะนั้น เลือกการตั้งค่าในเกมหรือตัวคูณคงที่ที่มีสิทธิ์สำหรับสถานะแยกต่างหากของเกมนั้น

**นี่คือแพ็คเกจ ReShade/OptiScaler/FSR หรือไม่** ไม่ใช่ สิ่งเหล่านี้ไม่ได้ถูกรวบรวมหรือจัดส่งโดยเป็นส่วนหนึ่งของแพ็คเกจที่ใช้งานจริงนี้

**แหล่งที่มาที่แก้ไขเปิดเผยต่อสาธารณะหรือไม่** ไม่ได้ มีการจัดเตรียมแพ็คเกจที่คอมไพล์และเครดิต/ใบอนุญาตที่จำเป็นไว้ให้ สิ่งนี้ไม่ได้ลบสิทธิ์หรือข้อจำกัดของบุคคลที่สาม

## ต้นน้ำและการปรับเปลี่ยน

การอ้างอิงการเปรียบเทียบและส่วนประกอบดั้งเดิมที่ใช้ร่วมกัน: **RTX40MFG-Unlock โดย Michael Robles / dashdogy**, การอ้างอิงคอมมิต `4e776d068f91b4a665425542bb005dd57cc3d891`, MIT [พื้นที่เก็บข้อมูล](https://github.com/dashdogy/RTX40MFG-Unlock) · [ดาวน์โหลดต้นฉบับ](https://github.com/dashdogy/RTX40MFG-Unlock/releases).

การเปรียบเทียบแหล่งที่มาจะระบุการแพตช์ที่ใช้ร่วมกัน การจัดการผู้ให้บริการ/นโยบาย การแก้ไขชั่วคราว และส่วนประกอบทางอ้อมที่ใช้ MinHook ประกาศ MIT และ BSD ของพวกเขาจะยังคงอยู่ การเปรียบเทียบที่สมบูรณ์ยังรวมไฟล์ที่อยู่นอกเป้าหมายการผลิตด้วย

แอปพลิเคชันเดสก์ท็อป คอนโทรลเลอร์ และเวิร์กโฟลว์การจัดการ SDK ได้รับการพัฒนาโดย 禅堂 Zendo (RevoluSound Team) งานโปรเจ็กต์ประกอบด้วยการโหลดจากส่วนกลาง, การรวมบูตสแตรปของ NGX, การเลือกผู้ให้บริการที่ได้รับการตรวจสอบ, การประสานงานระหว่างเกม/V-Sync และการวินิจฉัยเซสชัน คู่มือแหล่งที่มาจะแยกการทำงานออกจากส่วนประกอบที่ใช้ร่วมกัน การเปรียบเทียบไฟล์เพียงอย่างเดียวไม่ได้เกิดขึ้นเมื่อผู้เขียนคนใดคนหนึ่งมีแนวคิด

ตัวช่วยโปรไฟล์จะปรับ wrapper MIT NVAPI จาก Profile Inspector ของ Orbmu2k [ที่มาโดยละเอียดและขอบเขตองค์ประกอบ](../docs/provenance.md).
