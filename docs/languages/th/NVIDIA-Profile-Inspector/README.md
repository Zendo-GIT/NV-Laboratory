# NVIDIA Profile Inspector – NV Tools Fork

**fork อิสระของ [NVIDIA Profile Inspector โดย Orbmu2k](https://github.com/Orbmu2k/nvidiaProfileInspector) พร้อมส่วนควบคุมการแสดงผลเพิ่มเติม** ชื่อโปรเจ็กต์เดิม: **NVPI Custom**

[สถานะการดาวน์โหลดและเผยแพร่](../docs/downloads.md#nvidia-profile-inspector) · [การติดตั้ง](#installation) · [ต้นน้ำและการเปลี่ยนแปลง](#upstream-and-changes) · [ใบอนุญาต](../../../../NVIDIA-Profile-Inspector/LICENSE)

<a id="overview"></a>
## ภาพรวม

แอปพลิเคชันแก้ไขโปรไฟล์ไดรเวอร์ NVIDIA รวมถึงการตั้งค่าแต่ละแอปพลิเคชัน fork นี้ยังเพิ่มตัวแก้ไข **หน้าจอ** สำหรับจอแสดงผล Windows ที่ใช้งานอยู่: ความละเอียด อัตรารีเฟรช การตั้งค่าสีของเอาต์พุต HDR และการเชื่อมโยงโปรไฟล์ ICC/WCS ที่ติดตั้งไว้

มีไว้เพื่อนำการควบคุมการแสดงผลที่เกี่ยวข้องมาสู่เครื่องมือแก้ไขโปรไฟล์ และเพื่อให้ผลลัพธ์การแสดงตัวอย่าง การยืนยัน และการกู้คืนชัดเจนยิ่งขึ้น มันไม่ได้สร้างความสามารถด้านฮาร์ดแวร์ใหม่

ตัวเลือกแรกคือ **3.0.2.3** โดยใช้ build เดี่ยวแบบสแตนด์อโลนที่ล้างแล้วตั้งแต่วันที่ 9 กันยายน 2026 ไฟล์ปฏิบัติการที่มีอยู่ยังคงเป็น `nvidiaProfileInspector.exe` ตัวติดตั้งและป้ายกำกับภายในบางอันยังคงบอกว่า `NVPI Custom NV` ชื่อสาธารณะด้านบนระบุ fork โดยไม่ต้องเปลี่ยนข้อมูลประจำตัวการติดตั้งหรือแสร้งทำเป็นว่าเป็นรุ่นอย่างเป็นทางการของ Orbmu2k

<a id="features"></a>
## คุณสมบัติ

- การเรียกดูโปรไฟล์อัปสตรีมที่มีอยู่ การเชื่อมโยงแอปพลิเคชัน การตั้งค่าการแก้ไข และการนำเข้า/ส่งออกโปรไฟล์
- กล่องโต้ตอบ **หน้าจอ** สำหรับการแสดงผล โหมด Hz RGB/YCbCr ความลึกของสี ช่วง และการวัดสี
- Windows HDR ควบคุมและติดตั้งการเลือกการเชื่อมโยง ICC/WCS
- การแสดงตัวอย่างการแสดงผล 15 วินาทีพร้อม **Keep** / **Revert** และการกู้คืนการหมดเวลา
- การอ่านย้อนกลับของการเปลี่ยนแปลงโหมด/HDR และรายงานความล้มเหลวในการกู้คืน
- การรายงานแยกของ HDR, SDR พร้อม ACM/WCG และความลึกของสีของสัญญาณ
- ตัวเรียกใช้งาน NVRasterPulse สำหรับสำเนาที่ติดตั้งแยกต่างหากที่เข้าเกณฑ์

<a id="compatibility"></a>
## ความเข้ากันได้

| ความต้องการ | รายละเอียด |
| --- | --- |
| ระบบ | Windows 10/11 x64 พร้อมไดรเวอร์ NVIDIA ที่เข้ากันได้ |
| รันไทม์ | [.NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48) จัดทำโดย Windows หรือติดตั้งแยกต่างหาก |
| สิทธิ์ | ตัวแก้ไขร้องขอการเข้าถึงของผู้ดูแลระบบเมื่อเปิด |
| จอแสดงผล | โหมดจริงและการผสมสีขึ้นอยู่กับ GPU, ไดรเวอร์, จอแสดงผล, สายเคเบิล และ Windows API |
| เครื่องมือเสริม | NVRasterPulse สำหรับการจัดการขีดจำกัด RTSS ทั้งไม่จำเป็นต้องใช้ RTSS สำหรับโปรแกรมแก้ไขหน้าจอ |
| ภาษา | ตั้งค่า: ตัวเลือก 34 ภาษา ตัวแก้ไขยังคงรองรับภาษาที่มีอยู่ |

ไม่มีไดรเวอร์สากลขั้นต่ำหรือเมทริกซ์การสนับสนุนที่ได้รับการยืนยันสำหรับ GPU ทุกตัว ตัวเลือก bpc ที่มีอยู่ของกล่องโต้ตอบเป็นการร้องขอ ไม่ใช่ชุดค่าผสมที่ได้รับการรับรอง การควบคุม HDR สมัยใหม่และทางเลือก Windows รุ่นเก่ามีความสามารถที่แตกต่างกัน

<a id="installation"></a>
## การติดตั้ง

1. เปิด [หน้าดาวน์โหลด](../docs/downloads.md#nvidia-profile-inspector) และตรวจสอบสถานะการเผยแพร่
2. ดาวน์โหลดการตั้งค่าหรือสินทรัพย์แบบพกพา และเปรียบเทียบ SHA-256 กับ Release Manifest
3. สำหรับการตั้งค่า ให้รัน `NVPI-CustomNV-3.0.2.3-Setup-r2.exe` เลือกภาษาและติดตามตัวติดตั้ง มันสร้างทางลัดและโปรแกรมถอนการติดตั้งของตัวเอง
4. สำหรับพกพา ให้แยก ZIP ที่สมบูรณ์ไปยังโฟลเดอร์ที่เขียนได้ใหม่ เก็บ `Reference.xml` การกำหนดค่า EXE และประกาศทั้งหมดไว้ข้างไฟล์ปฏิบัติการ
5. เปิดตัว `nvidiaProfileInspector.exe`

การติดตั้งตัวแก้ไขเพียงอย่างเดียวจะไม่ใช้โปรไฟล์หรือติดตั้งไดรเวอร์ GPU ตัวช่วยจะติดตั้งแยกกัน ไม่ใช้การเชื่อมโยง `.nip` และไม่เปิดใช้งานการเริ่มต้นระบบเมื่อลงชื่อเข้าใช้ ไบนารีที่มีอยู่ไม่ได้ลงนาม

<a id="usage"></a>
## การใช้งาน

**ตัวติดตั้งฉบับปรับปรุง 2** เพิ่มตัวเลือกภาษาท้องถิ่น 34 ภาษาเหมือนกับเครื่องมืออื่นๆ พร้อมด้วยการนำทางด้วยเมาส์/คีย์บอร์ด ลักษณะสว่าง/มืด และการยกเลิก ตัวเลือกนี้ใช้กับการตั้งค่า มันไม่ได้แปลเอดิเตอร์ NVPI อาร์กิวเมนต์ `/LANG=fr` ที่ชัดเจนหรือโหมดเงียบจะข้ามการเลือกสำหรับผู้โทรที่มีภาษาอยู่แล้ว

**โปรไฟล์ไดรเวอร์:** เลือกโปรไฟล์ ส่งออกข้อมูลสำรอง จากนั้นแก้ไขเฉพาะการตั้งค่าที่ต้องการแล้วนำไปใช้ การเชื่อมโยงแอปพลิเคชันจะกำหนดว่าเกมใดจะได้รับโปรไฟล์ ค่าที่เก็บไว้ไม่ใช่ข้อพิสูจน์ว่าทุกไดรเวอร์หรือเกมใช้ค่าดังกล่าว

**การควบคุมการแสดงผล:** เปิด **หน้าจอ** เลือกการแสดงผลและค่าที่ร้องขอ จากนั้นเริ่มดูตัวอย่าง ตรวจสอบภาพก่อนเลือก **เก็บ** ภายใน 15 วินาที ใช้ **เปลี่ยนกลับ** ปิดการยืนยันหรือปล่อยให้หมดอายุเพื่อขอการกู้คืน อ่านข้อความแสดงข้อผิดพลาด: การเรียก API ที่สำเร็จเพียงอย่างเดียวไม่สามารถพิสูจน์การกู้คืนได้

การเลือก ICC จะเปลี่ยนการเชื่อมโยงโปรไฟล์ที่ติดตั้ง มันไม่สร้าง ปรับเทียบ หรือแจกจ่ายไฟล์ ICC อีกครั้ง HDR, ACM/WCG, RGB/YCbCr และ bpc อธิบายแง่มุมต่างๆ ของไปป์ไลน์ ไม่มีสวิตช์ ACM อิสระตัวใหม่มาให้

**NVRasterPulse:** ปุ่มแถบเครื่องมือยอมรับการติดตั้งทั้งระบบที่ลงทะเบียนแยกต่างหากด้านล่างไฟล์โปรแกรมพร้อมความเป็นเจ้าของและการอนุญาตที่ได้รับการคุ้มครอง สำเนาแบบพกพาหรือเส้นทางที่ผู้ใช้เขียนได้/ลิงก์อาจถูกปฏิเสธโดยตัวเรียกใช้งานที่ยกระดับนี้ ในกรณีดังกล่าวให้เปิด NVRasterPulse โดยใช้ทางลัดของตัวเอง [ติดตั้ง RTSS แยกกัน](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) เพื่อใช้ NVRasterPulse

<a id="update-and-uninstall"></a>
## อัปเดตและถอนการติดตั้ง

ปิดตัวแก้ไขก่อนที่จะอัปเดต เก็บโปรไฟล์ที่ส่งออกไว้และดาวน์โหลด fork Release ใหม่ ติดตั้งโดยใช้ข้อมูลเฉพาะตัวเดียวกันหรือแตกไฟล์พกพาลงในโฟลเดอร์ใหม่ อย่าผสม `Reference.xml` เก่ากับไฟล์ปฏิบัติการใหม่ การระงับการตรวจสอบการอัปเดตอัปสตรีมแบบรวมเป็นของ fork นี้

สำหรับสำเนาที่ติดตั้ง ให้ใช้ Windows **Installed apps** และโปรแกรมถอนการติดตั้ง สำหรับอุปกรณ์พกพา ให้ปิดและลบโฟลเดอร์ที่แยกออกมาเมื่อการส่งออกของคุณปลอดภัย การลบตัวแก้ไขจะไม่ **ไม่** ยกเลิกการแก้ไขโปรไฟล์ไดรเวอร์ การตั้งค่าการแสดงผล NVRasterPulse หรือ RTSS คืนค่าการตั้งค่าที่ต้องการก่อนที่จะลบ

<a id="known-limitations"></a>
## ข้อจำกัดที่ทราบ

- การยืนยัน 15 วินาทีไม่ใช่การเฝ้าระวังอุบัติเหตุของผู้ขับขี่ การสูญเสียพลังงาน หรือการบังคับปิดเครื่องทุกครั้ง
- การผสมสี/ความลึก/รีเฟรชบางค่าจะส่งคืน `NVAPI_NOT_SUPPORTED`
- การอ่านกลับด้วยซอฟต์แวร์ไม่ได้วัดความลึกของบิตของแผง ความแม่นยำของสี หรือความหน่วง
- การตั้งค่าหน้าจอส่งผลต่อการแสดงผล Windows ปัจจุบัน กล่องโต้ตอบนี้ไม่ได้สร้างการตั้งค่าการแสดงผลล่วงหน้าต่อเกม
- ไม่มีประสิทธิภาพ ป้องกันการโกง หรือรับประกันความเข้ากันได้สากลของ HDR

| โหมดการแสดงผลที่ร้องขอถูกปฏิเสธ | เปลี่ยนกลับและทดสอบโหมดที่นำเสนอโดย Windows/NVIDIA สำหรับจอแสดงผลนั้น อ่านข้อผิดพลาดให้ถูกต้องและหลีกเลี่ยงการเปลี่ยนแปลงแบบซ่อนเร้นซ้ำๆ |

## คำถามที่พบบ่อย

**NVDriverForge ต้องใช้โปรแกรมแก้ไขนี้หรือไม่** ไม่ ค่าที่ตั้งล่วงหน้าเสริม Custom NV ของ NVDriverForge ใช้การผสานรวมของตัวเอง การติดตั้งตัวแก้ไขเป็นทางเลือกแยกต่างหาก

**จำเป็นต้องใช้ RTSS สำหรับ fork นี้หรือไม่** ไม่ RTSS จำเป็นสำหรับตัวจำกัด FPS ของ NVRasterPulse ไม่ใช่สำหรับโปรไฟล์หรือการแก้ไขหน้าจอ

**แหล่งที่มาอยู่ที่ไหน** แหล่งที่มาของแอปพลิเคชันที่แก้ไขจะได้รับการดูแลแบบส่วนตัว มีการแจ้งเตือน MIT และที่เก็บอัพสตรีมไว้ MIT ไม่ต้องการการเผยแพร่แหล่งที่แก้ไข

## ต้นน้ำและการเปลี่ยนแปลง

อัปสตรีม: [Orbmu2k/nvidiaProfileInspector](https://github.com/Orbmu2k/nvidiaProfileInspector), การอ้างอิงคอมมิต `592d962cca8827efe8859461a84267755595064a` [ดาวน์โหลดต้นฉบับ](https://github.com/Orbmu2k/nvidiaProfileInspector/releases).

รับมา: ตัวแก้ไขโปรไฟล์, การทำงานร่วมกันของ NVAPI, ข้อมูลอ้างอิง, ทรัพยากร UI และธีม 禅堂 Zendo (RevoluSound Team) เพิ่มหรือปรับเปลี่ยนบริการการแสดงผล ธุรกรรม HDR/ICC การยืนยัน/อ่านกลับ 15 วินาที เค้าโครงแถบเครื่องมือ และลักษณะการเปิดใช้ RasterPulse ตัวช่วยที่ล้างแล้วไม่รวมจุดจำลองการพัฒนา/จุดเข้าทดสอบ ใช้ตัวเรียกใช้งานภายนอกที่ได้รับการป้องกัน และจัดเตรียมตัวติดตั้งแยกต่างหาก แพ็คเกจการพัฒนา NVPI/RasterPulse ที่รวมกันแบบเก่าไม่เหมาะกับฮับนี้
