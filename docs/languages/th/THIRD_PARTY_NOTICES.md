**Inno Setup:** รักษาลิขสิทธิ์เครื่องยนต์/ประกาศเว็บไซต์ที่จำเป็น และทำเครื่องหมายการเปลี่ยนแปลงแหล่งที่มาตามความเหมาะสม เครดิตของเอ็นจิ้นที่ยังไม่ได้แก้ไขยังคงอยู่ในตัวติดตั้ง แค็ตตาล็อกดัดแปลงจะเก็บประกาศแหล่งที่มาดั้งเดิมไว้ ชื่อจะถูกจัดทำดัชนีไว้ที่นี่

**วัสดุ NVIDIA:** ใบอนุญาต MIT สำหรับส่วนหัวการรวม Streamline ไม่ครอบคลุมทุกไฟล์ SDK ประกาศจะแยกวัสดุ Nsight Perf SDK อย่างชัดเจน วัสดุนั้นไม่ได้ใช้ในเป้าหมายการผลิตนี้ ส่วนหัว NGX อยู่ภายใต้เงื่อนไข RTX SDK ที่เป็นกรรมสิทธิ์ของ NVIDIA เพิ่มข้อความฉบับเต็มแล้ว พร้อมด้วย [สำเนาไบต์ต้นฉบับ](../../../NVMFG-Unlock40/LICENSES/NVIDIA-RTX-SDK.original.txt) ข้อจำกัดของส่วนที่ 4(d) ที่เกี่ยวข้องกับข้อจำกัดทางเทคนิคยังคงไม่ได้รับการแก้ไขสำหรับการใช้งานของ NVMFG ไม่มีการอนุมานการอนุญาตที่ยืนยันจากการมีอยู่ของ mod อื่น

**ส่วนประกอบภายนอกที่ไม่รู้จัก/เป็นกรรมสิทธิ์:** ไดรเวอร์ RTSS, NVCleanstall, NVIDIA รุ่น และข้อมูลแพตช์ keylase ไม่ได้รวมอยู่ในสินทรัพย์ฮับที่เตรียมไว้ ลิงค์ระบุเจ้าของที่แท้จริง การดาวน์โหลดที่กระตุ้นโดยผู้ใช้ไม่ได้ให้สิทธิ์ใช้งานส่วนประกอบอีกครั้ง
