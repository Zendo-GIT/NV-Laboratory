# NVRasterPulse

**ขีดจำกัด FPS ต่อแอปพลิเคชันจนถึง RivaTuner Statistics Server**

> **ติดตั้ง RTSS ก่อน** NVRasterPulse ต้องใช้ [RivaTuner Statistics Server (RTSS) ดาวน์โหลดจาก Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) RTSS ต้องรันอยู่เพื่อบังคับใช้ขีดจำกัด ไม่มีตัวติดตั้ง RTSS, hook DLL หรือ SDK รวมอยู่ด้วย

[ดาวน์โหลด 0.1 และสถานะ](../docs/downloads.md#nvrasterpulse) · [การติดตั้ง](#installation) · [ขีดจำกัดทำงานอย่างไร](#usage) · [ใบอนุญาต](../../../../NVRasterPulse/LICENSE)

<a id="overview-and-purpose"></a>
## ภาพรวมและวัตถุประสงค์

NVRasterPulse เป็นอินเทอร์เฟซ Windows ขนาดกะทัดรัดสำหรับจัดการขีดจำกัดเฟรมของ RTSS ตามชื่อที่เรียกใช้งานได้ RTSS ดำเนินการจำกัด NVRasterPulse จัดการค่าโปรไฟล์ การสำรองข้อมูล และคำขอโหลดซ้ำที่สอดคล้องกัน ด้วยการเข้าถึงถาดและตัวเลือกแบบถาวร

มีไว้เพื่อให้แก้ไขขีดจำกัดต่อเกมได้ง่ายขึ้นโดยไม่ต้องเปลี่ยนโปรไฟล์ RTSS ทั้งหมดหรือรบกวนการตั้งค่าโอเวอร์เลย์ ตัวเลือก **0.1** ปัจจุบันคือรุ่นวันที่ 9 กันยายน 2026 โดยมีการตรวจสอบการติดตั้ง RTSS ที่จำเป็น

<a id="features"></a>
## คุณสมบัติ

- เลือกแอปพลิเคชันที่รันอยู่หรือเพิ่มไฟล์ปฏิบัติการด้วยตนเอง
- บันทึกขีดจำกัดของ FPS ตั้งแต่ 1 ถึง 1,000 โดยมีทศนิยมสูงสุดสามตำแหน่ง
- การเข้ารหัสเหตุผลที่แน่นอนของค่าที่ป้อน: 59.94 กลายเป็น 2997/50
- การกำหนดค่า Front Edge Sync (`SyncLimiter=1`) พร้อมการรอที่ใช้งานอยู่ (`PassiveWait=0`)
- การอัปเดตโปรไฟล์ต่อการดำเนินการ การสำรองข้อมูลอัตโนมัติ และการเขียนแบบอะตอมมิก
- การลบการแทนที่ตัวจำกัดออกในขณะที่ยังคงเนื้อหาโปรไฟล์อื่นๆ ไว้
- การตรวจจับการติดตั้ง RTSS การเลือกพาธด้วยตนเอง และการเปิดใช้/โหลดซ้ำอย่างชัดเจน
- การใช้งานถาดอินสแตนซ์เดียว การเริ่มต้นการติดตั้งแบบติดตั้งเพิ่มเติม 34 ภาษาและสี่ธีม
- แยกการดำเนินการออกปกติและ **ออก + RTSS**

<a id="compatibility"></a>
## ความเข้ากันได้

| ความต้องการ | รายละเอียด |
| --- | --- |
| ระบบ | Windows 10/11 x64 |
| รันไทม์ | [.NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48) ติดตั้งแยกต่างหากหากจำเป็น |
| ซอฟต์แวร์ที่จำเป็น | RTSS พร้อม `RTSS.exe` ซึ่งเป็นไดเร็กทอรี `Profiles` ที่ตรงกันและรองรับโปรไฟล์/โหลดซ้ำที่เข้ากันได้ |
| GPU | ความเข้ากันได้ของ RTSS จะเป็นตัวกำหนดขีดจำกัด ตัวจัดการโปรไฟล์นี้ไม่จำเป็นต้องมีการสร้าง RTX โดยเฉพาะ |
| สิทธิ์ | แอปพลิเคชันปัจจุบันร้องขอการเข้าถึงของผู้ดูแลระบบ ต้องเข้าถึงโฟลเดอร์โปรไฟล์ RTSS ที่เลือกได้ |
| เกมส์ | ขึ้นอยู่กับการรองรับการเชื่อมต่อของ RTSS และข้อจำกัดของแต่ละเกม ไม่มีการรับประกันการต่อต้านการโกง |

ไม่มีเวอร์ชันขั้นต่ำเฉพาะของ RTSS ที่ได้รับการรับรองสำหรับทุกฟังก์ชันโดยการตรวจสอบจากฮับนี้ ใช้การเผยแพร่ปัจจุบันอย่างเป็นทางการและรายงานเวอร์ชันที่แน่นอนหากคีย์โปรไฟล์/การโหลดซ้ำไม่ทำงาน RTSS ที่ติดตั้งแต่หยุดทำงานผ่านการตรวจสอบการติดตั้ง จากนั้นจะต้องเริ่มดำเนินการเพื่อจำกัดตามความเป็นจริง

<a id="installation"></a>
## การติดตั้ง

1. **[ดาวน์โหลดและติดตั้ง RTSS จาก Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/).**
2. เปิด [ดาวน์โหลด NVRasterPulse](../docs/downloads.md#nvrasterpulse) และตรวจสอบความพร้อมใช้งานของ Release
3. ดาวน์โหลด `NVRasterPulse-0.1-win-x64-Setup.exe` หรือ `NVRasterPulse-0.1-win-x64-portable.zip` รวมถึงประกาศ/เช็คซัม
4. เปรียบเทียบ SHA-256 เรียกใช้การตั้งค่าหรือแยก ZIP แบบพกพาทั้งหมดไปยังโฟลเดอร์ในเครื่องที่เขียนได้
5. เปิด `NVRasterPulse.exe` หากไม่มี RTSS ให้ใช้ **ดาวน์โหลด RTSS** ติดตั้ง จากนั้น **ตรวจสอบอีกครั้ง** หรือเลือก `RTSS.exe` ด้วยตนเอง
6. เริ่ม RTSS โดยใช้ทางลัดปกติหรือปุ่ม RTSS ของ NVRasterPulse หากหยุดไว้

การปิดตัวเตือนที่เป็นทางเลือกจะไม่ข้ามการตรวจสอบข้อกำหนดเบื้องต้น การเริ่มต้นถาด Windows แบบเงียบจะรอจนกระทั่งหน้าต่างหลักเปิดขึ้นก่อนที่จะแสดงการตรวจสอบนี้ การตั้งค่าจะติดตั้ง NVRasterPulse เท่านั้น EXE ของมันไม่ได้ลงนาม

<a id="usage"></a>
## การใช้งาน

1. เลือกแอปพลิเคชันที่ต้องการรันหรือเรียกดูเกม EXE
2. ป้อนขีดจำกัดระหว่าง 1 ถึง 1,000 FPS รวมถึงค่าเศษส่วนด้วย หากจำเป็น
3. บันทึกและตรวจสอบผลการรายงาน NVRasterPulse อัพเดตโปรไฟล์ RTSS ของโปรแกรมเรียกทำงานและขอให้โหลดซ้ำ
4. ยืนยันว่า RTSS กำลังทำงานอยู่และตรวจสอบพฤติกรรมในเกมที่ต้องการ

โปรไฟล์จะถูกคีย์โดย **ชื่อที่เรียกใช้งานได้** เช่น `Game.exe.cfg` สองโฟลเดอร์ที่แตกต่างกันที่มี `Game.exe` แชร์โปรไฟล์ RTSS เดียวกัน การจัดเก็บเส้นทางแบบเต็มไม่ได้ลบการชนกันนี้

การบันทึกใช้ Front Edge Sync และการรอที่ใช้งานอยู่ การรอที่ใช้งานอยู่อาจเพิ่มการใช้งาน CPU ฟิลด์สำรอง `LimitTime` จะถูกทำให้เป็นกลาง ความคิดเห็นที่มีอยู่ การตั้งค่าโอเวอร์เลย์ และ `EnableHooking=0` จะยังคงอยู่ โปรไฟล์ RTSS Global ไม่มีการเปลี่ยนแปลง

ใช้การดำเนินการถังขยะเพื่อลบการแทนที่ตัวจำกัดของ NVRasterPulse จะไม่ลบโปรไฟล์ RTSS ทั้งหมด ขีดจำกัดที่สืบทอดมาจาก RTSS Global หรือเครื่องมืออื่นอาจยังคงใช้ในภายหลัง

**การปิดและออก:** หน้าต่างหลักสามารถซ่อนไว้ที่ถาดได้ ปกติ **ออก** ปล่อยให้ RTSS ทำงานและขีดจำกัดที่บันทึกไว้ยังคงอยู่ **ออก + RTSS** ขอการปิดกระบวนการ RTSS ที่ตรงกันตามปกติในเซสชันปัจจุบัน รอสูงสุดแปดวินาที และไม่บังคับปิดกระบวนการ ขีดจำกัดที่เก็บไว้จะยังคงอยู่ในทั้งสองกรณี

มีการเลือกภาษาและธีมในแอป การเริ่มต้นใช้งานด้วยการลงชื่อเข้าใช้ Windows เป็นทางเลือกและมีไว้สำหรับสำเนาที่ติดตั้ง ปุ่มข้อมูลอธิบายการดำเนินการทั่วไป

<a id="update-and-uninstall"></a>
## อัปเดตและถอนการติดตั้ง

ออกจาก NVRasterPulse ดาวน์โหลดและตรวจสอบเวอร์ชันใหม่ จากนั้นเรียกใช้การตั้งค่าหรือแตกไฟล์พกพาลงในโฟลเดอร์ใหม่ รักษาการตั้งค่าและการสำรองข้อมูล RTSS การอัปเดต RTSS แยกจากกันและมาจาก Guru3D

หากต้องการลบสำเนาที่ติดตั้ง ให้ใช้ Windows **Installed apps** สำหรับพกพา ให้ออกแล้วลบโฟลเดอร์ที่แตกออกมาเมื่อข้อมูลสำรองของคุณปลอดภัย ขีดจำกัดของ RTSS ที่บันทึกไว้จะไม่ถูกลบออกโดยการถอนการติดตั้ง NVRasterPulse: ให้ลบการแทนที่ตัวจำกัดที่ต้องการออกก่อน RTSS มีโปรแกรมถอนการติดตั้งของตัวเอง

สถานะท้องถิ่น: `%LOCALAPPDATA%\NVRasterPulse` การสำรองข้อมูล RTSS อัตโนมัติ: `%LOCALAPPDATA%\NVRasterPulse\Backups\RTSS` ตำแหน่ง `%LOCALAPPDATA%\RTSSProfileBridge` เก่ากว่าอาจถูกอ่านเพื่อการโอนย้าย ไฟล์เหล่านี้อาจมีพาธปฏิบัติการส่วนบุคคล และไม่ควรโพสต์แบบสาธารณะ

<a id="known-limitations"></a>
## ข้อจำกัดที่ทราบ

- RTSS ดำเนินการปิดฝา ค่าที่บันทึกไว้หรือคำขอโหลดซ้ำที่สำเร็จไม่ใช่ผลลัพธ์ของเฟรมไทม์ที่วัดได้
- ไฟล์ปฏิบัติการที่มีชื่อเดียวกันแชร์โปรไฟล์
- ตัวจำกัดระดับโลก/ต่อเกมตัวอื่นอาจส่งผลต่อผลลัพธ์ การปิดใช้งานการแทนที่ในเครื่องจะไม่ลบ cap ที่สืบทอดมา
- hook RTSS ที่จงใจปิดใช้งานยังคงปิดใช้งานอยู่
- การรอที่ใช้งานอยู่มี CPU/การแลกเปลี่ยนพลังงาน
- ไม่มีเกมสากล การป้องกันการโกง หรือการตรวจสอบความหน่วงจากต้นทางถึงปลายทาง
- ลิมิตเตอร์อิสระรุ่นทดลองก่อนหน้านี้ไม่ได้ถูกรวบรวมหรือจัดส่ง
- การสำรองข้อมูลอัตโนมัติไม่ได้หมายความถึงอินเทอร์เฟซการคืนค่าการสำรองข้อมูลแบบเต็มเพียงคลิกเดียว

<a id="troubleshooting"></a>
## การแก้ไขปัญหา

| อาการ | การดำเนินการ |
| --- | --- |
| สิ่งที่จำเป็นต้องมี RTSS ยังคงเปิดอยู่ | เลือก `RTSS.exe` จริงและโฟลเดอร์ Profiles ที่ตรงกัน จากนั้นตรวจสอบอีกครั้ง |
| บันทึกขีดจำกัดแล้ว แต่ไม่มีผลกระทบ | เริ่ม RTSS; ตรวจสอบ EXE/โปรไฟล์เกม สิทธิ์อนุญาต และข้อจำกัดอื่นๆ ของเกมที่ถูกต้อง |
| บันทึกล้มเหลว | ตรวจสอบสิทธิ์ของโฟลเดอร์และรักษาข้อผิดพลาด/ข้อมูลสำรองที่แสดงไว้ |
| ขีดจำกัดยังคงอยู่หลังจากการลบออก | ตรวจสอบ RTSS Global และเครื่องมืออื่นๆ การดำเนินการถังขยะจะลบการแทนที่ตัวจำกัดในเครื่องเท่านั้น |
| สองเกมได้รับขีดจำกัดเท่ากัน | ตรวจสอบว่าชื่อไฟล์ที่ปฏิบัติการได้เหมือนกันหรือไม่ |
| ออก + RTSS ปล่อยให้ RTSS เปิดอยู่ | ปิด RTSS ตามปกติด้วยตัวคุณเอง คำสั่งนี้จงใจหลีกเลี่ยงการบังคับยุติ |

หากกู้คืนข้อมูลสำรอง RTSS ด้วยตนเอง ให้ปิด RTSS ก่อนและรักษาโปรไฟล์ปัจจุบันไว้ก่อนที่จะแทนที่ด้วยข้อมูลสำรองที่ต้องการ การดำเนินการนี้สามารถเขียนทับการแก้ไขโปรไฟล์ที่ไม่เกี่ยวข้องได้ ตรวจสอบไฟล์และวันที่ [การสนับสนุนร่วมกัน](../docs/support.md).

<a id="faq"></a>
## คำถามที่พบบ่อย

**ฉันจำเป็นต้องมี MSI Afterburner ด้วยหรือไม่** NVRasterPulse ต้องใช้ RTSS; มันไม่ได้ขึ้นอยู่กับแอพพลิเคชั่น Afterburner ปฏิบัติตามตัวเลือกการติดตั้งของผู้จัดจำหน่าย RTSS

**ฉันสามารถใช้สิ่งนี้โดยไม่ใช้ RTSS ได้หรือไม่** คุณสามารถจัดการโปรไฟล์ได้เมื่อตรวจพบการติดตั้ง แต่ RTSS จะต้องทำงานเพื่อจำกัด

**การเลิกใช้งานหรือการถอนการติดตั้งจะลบตัวพิมพ์ใหญ่ออกหรือไม่** ไม่ การลบตัวจำกัดที่ต้องการจะแทนที่อย่างชัดเจนก่อนที่จะลบ NVRasterPulse

**นี่คือ fork ของ RTSS หรือไม่** ไม่ เป็นผู้จัดการโปรไฟล์อิสระ ไม่มีแหล่งที่มาหรือปฏิบัติการของ RTSS รวมอยู่ด้วย
