<a id="nvdriverforge"></a>
# NVDriverForge

**เตรียมการติดตั้งไดรเวอร์ NVIDIA โดยมีตัวเลือกส่วนประกอบที่ชัดเจนและการตั้งค่าเสริม**

[ดาวน์โหลด 0.1.3 และสถานะ](../docs/downloads.md#nvdriverforge) · [การติดตั้ง](#installation) · [เครดิต](#credits-and-upstream) · [ใบอนุญาต](../../../../NVDriverForge/LICENSE)

<a id="overview-and-purpose"></a>
## ภาพรวมและวัตถุประสงค์

NVDriverForge จะแนะนำแพ็คเกจไดรเวอร์ NVIDIA ดั้งเดิมให้กับคุณ: เลือกไดรเวอร์ ตรวจสอบส่วนประกอบ ตรวจสอบการปรับแต่งเพิ่มเติม จากนั้นยืนยันการติดตั้ง มีไว้เพื่อทำให้ตัวเลือกเหล่านั้นสามารถเข้าใจได้ และเก็บข้อมูลการติดตั้ง การดำเนินการพิเศษ และการกู้คืนไว้ด้วยกัน

เป็นแอปพลิเคชันที่พัฒนาขึ้นอย่างอิสระโดยได้รับแรงบันดาลใจส่วนหนึ่งจากขั้นตอนการทำงานของ NVCleanstall ไม่รวม NVCleanstall หรืออ้างสิทธิ์ความเท่าเทียมกันของคุณลักษณะโดยสมบูรณ์

<a id="features"></a>
## คุณสมบัติ

- การค้นหาและดาวน์โหลด NVIDIA Game Ready / Studio; การค้นพบโปรแกรมแก้ไขด่วนเสริมพร้อมทางเลือกด้วยตนเอง
- การวิเคราะห์แพ็คเกจดั้งเดิม แฮช ลายเซ็น NVIDIA รายการ และรายการ INF ที่เข้ากันได้
- การเลือกส่วนประกอบที่มีการขึ้นต่อกันและการเก็บรักษาส่วนประกอบที่ไม่รู้จัก
- เวอร์ชัน 0.1.3 ช่วยให้ส่วนประกอบเสริม NVIDIA ที่เลือกสามารถข้ามได้ และยกเว้นเฉพาะส่วนประกอบที่ไม่ได้ตรวจสอบที่ผ่านการตรวจสอบแล้วจากการค้นพบ รันไทม์เสริมที่เป็นปัจจุบันหรือไม่เหมาะสมจะไม่ถูกบังคับในฐานะส่วนประกอบที่สำคัญอีกต่อไป
- ล้างข้อมูลสรุปความล้มเหลวในการติดตั้งและเข้าถึงบันทึกโดยละเอียดใน 34 ภาษา
- การยืนยันการติดตั้งที่ชัดเจน การจัดเตรียมที่ได้รับการป้องกัน และการส่งออกแพ็คเกจร้านค้าไดร์เวอร์ที่มีอยู่
- การตั้งค่าขั้นสูงเพิ่มเติม พร้อมการตรวจสอบล่วงหน้า บันทึกประจำวัน และการกู้คืนโดยคำนึงถึงข้อขัดแย้ง
- ตัวเลือกล่วงหน้า **Custom NV** เสริมพร้อมตัวเลือกที่ระบุชื่อและคำอธิบาย รวมถึงการเลือกความแรงของ SILK ที่แยกต่างหากและการตรวจสอบความเข้ากันได้
- ดาวน์โหลดแพตช์ NVENC เวอร์ชันที่แน่นอนที่เป็นตัวเลือก มีการตรวจสอบการคอมมิตแหล่งที่มาและไบต์เป้าหมาย
- การติดตั้งเสริม Profile Inspector fork แยกต่างหากจากหน้าจอเครื่องมือ
- การตรวจสอบการอัปเดตผู้ใช้ที่ติดตั้งเพิ่มเติม ภาษาอินเทอร์เฟซ 34 ภาษา และธีมสี่ธีม

ตัวเลือกขั้นสูงที่มีให้ ได้แก่ MPO, ตัวบ่งชี้ DLSS, Ansel, การพักเสียงของ NVIDIA, MSI, นโยบาย/ลำดับความสำคัญขัดจังหวะ, HDCP, การเริ่มใช้คอนเทนเนอร์จอแสดงผล และบริการตรวจวัดทางไกลแบบเดิมที่มีสิทธิ์ แต่ละอันมีข้อกำหนดเบื้องต้นและเอฟเฟกต์ของตัวเอง สิ่งเหล่านี้ไม่ใช่การปรับปรุงประสิทธิภาพที่เป็นสากล

<a id="installation"></a>
## การติดตั้ง

1. ไปที่ [ดาวน์โหลด](../docs/downloads.md#nvdriverforge) และยืนยันว่าเผยแพร่ Release แล้ว
2. เลือก `NVDriverForge-Setup.exe` สำหรับการติดตั้ง หรือ `NVDriverForge.exe` สำหรับการใช้งานแบบพกพา
3. เปรียบเทียบ SHA-256 กับ `SHA256SUMS.txt` ของรีลีส
4. เรียกใช้โปรแกรมติดตั้งสำหรับการติดตั้งต่อผู้ใช้และโปรแกรมถอนการติดตั้งมาตรฐาน หรือวาง EXE แบบพกพาในโฟลเดอร์ที่เขียนได้และเปิดขึ้นมา

อุปกรณ์พกพาประกอบด้วยรันไทม์และตัวติดตั้งเสริม การติดตั้ง NVDriverForge ไม่ได้ติดตั้งไดรเวอร์ GPU ขณะนี้ EXE ยังไม่ได้ลงนาม

<a id="usage"></a>
## การใช้งาน

1. **ไดรเวอร์:** ดาวน์โหลดจาก NVIDIA หรือเลือกตัวติดตั้ง NVIDIA ดั้งเดิม EXE ปล่อยให้การวิเคราะห์เสร็จสิ้น
2. **ส่วนประกอบ:** คำอธิบายการตรวจสอบและการขึ้นต่อกันที่จำเป็น ส่วนประกอบที่ไม่รู้จักจะถูกเก็บไว้
3. **การปรับแต่ง:** คงตัวเลือกที่ไม่ต้องการไว้เหมือนเดิม อ่านเอฟเฟกต์และการแลกเปลี่ยนก่อนเลือกสิ่งใด
4. **การตรวจสอบ:** ตรวจสอบไดรเวอร์ ส่วนประกอบ และการทำงานเสริมที่แน่นอน จากนั้นยืนยันการติดตั้ง
5. ยอมรับ UAC สำหรับการดำเนินการที่คุณเลือกเท่านั้น เก็บคำแนะนำการกู้คืนของงานที่ได้รับการป้องกันไว้
6. หากจำเป็นต้องรีสตาร์ทไดรเวอร์ใหม่ ให้ปฏิบัติตามสถานะที่รายงาน การดำเนินการที่เลื่อนออกไปจำเป็นต้องมีประวัติการทำงานที่ชัดเจนหลังจากรีสตาร์ทครั้งนั้น

Custom NV เริ่มต้นไม่มีการเปลี่ยนแปลง เลือกค่าที่กำหนดชื่อแต่ละรายการหรือตรวจสอบค่าที่ตั้งล่วงหน้าที่ให้มาและการยกเว้น ช่องข้อมูลภายในสองช่องไม่ได้เขียนแยกกัน การตั้งค่าจะมีผลเฉพาะในเวิร์กโฟลว์ไดรเวอร์ใหม่ที่ได้รับการยืนยันเท่านั้น โดยไม่มีการเปิดการแสดงตัวอย่าง ไม่จำเป็นต้องติดตั้งโปรแกรมแก้ไข NVPI แยกต่างหาก

งานเสริม NVENC จะดาวน์โหลดข้อมูลที่เข้ากันได้จากการคอมมิต keylase ที่ปักหมุดไว้ โดยจะเปลี่ยนแปลง DLL ไดรเวอร์สองตัวและทำให้ลายเซ็นเป็นโมฆะ Windows, ตัวเข้ารหัส, DRM หรือโปรแกรมป้องกันการโกงสามารถปฏิเสธได้ ไม่มีข้อมูลดังกล่าวหรือ NVIDIA DLL ถูกฝังอยู่ใน NVDriverForge [ขีดจำกัดแหล่งที่มาและใบอนุญาต](../docs/provenance.md).

การตั้งค่าควบคุมภาษา ธีม และการตรวจสอบการอัปเดตผู้ใช้ที่ติดตั้งเพิ่มเติม อุปกรณ์พกพาไม่ได้สร้างงานตรวจสอบพื้นหลังที่ติดตั้งไว้ เครื่องมือและการกู้คืนจะแยกจากขั้นตอนการติดตั้งสี่ขั้นตอน

<a id="update-and-uninstall"></a>
## อัปเดตและถอนการติดตั้ง

ปิด NVDriverForge รับแพ็คเกจอย่างเป็นทางการถัดไป และตรวจสอบแฮชของมัน ใช้ข้อมูลประจำตัวการตั้งค่าเดียวกันสำหรับการอัปเดตที่ติดตั้ง แทนที่ EXE แบบพกพาแบบปิดด้วยอันใหม่ เก็บการตั้งค่าและงานที่ได้รับการป้องกันไว้

Uninstall จาก Windows **Installed apps** โดยจะลบแอปและงานอัปเดต ไม่ใช่ไดรเวอร์ NVIDIA การตั้งค่า บันทึก และการสำรองข้อมูลยังคงอยู่ หากต้องการ ให้กู้คืนการเปลี่ยนแปลงขั้นสูง/NVENC ผ่านขั้นตอนการกู้คืนที่บันทึกไว้ **ก่อนที่จะ** ลบแอป การคืนค่าปฏิเสธการเปลี่ยนแปลงที่ขัดแย้งกันจากเครื่องมืออื่น

ข้อมูลในตัวเครื่องอยู่ภายใต้ `%LOCALAPPDATA%\NVDriverForge`; งานที่ได้รับการคุ้มครองและการส่งออกไดรเวอร์อยู่ภายใต้ `%PROGRAMDATA%\NVDriverForge\Jobs` การใช้งานแบบพกพายังสร้างข้อมูลในเครื่องด้วย การส่งออกที่เก็บไดรเวอร์ไม่ใช่อิมเมจระบบหรือการสำรองข้อมูลโปรไฟล์แบบเต็ม

<a id="known-limitations"></a>
## ข้อจำกัดที่ทราบ

- ไม่มีการเพิ่มฮาร์ดแวร์/การแก้ไข INF, ลายเซ็น NVIDIA ที่สร้างขึ้นใหม่, การลาออกที่เข้ากันได้กับระบบป้องกันการโกง หรือการยอมรับคำเตือนที่ไม่ได้ลงนามโดยอัตโนมัติ
- ไม่มีการลบข้อมูลทางไกล/โฆษณาอย่างสมบูรณ์ การส่งออกแพ็คเกจแบบบาง หรือการย้อนกลับแบบเต็มอัตโนมัติไปยังไดรเวอร์ก่อนหน้า
- การติดตั้งไดรเวอร์ การกู้คืนการบูต และการเขียนโปรไฟล์เสริมยังไม่ได้รับการตรวจสอบอย่างครอบคลุมบนเครื่องจริงโดยการตรวจสอบของฮับ
- การอ่านกลับรีจิสทรีไม่ใช่ข้อพิสูจน์ถึงผลกระทบที่เกิดขึ้นจริงของ HDCP ประสิทธิภาพ หรือความหน่วง
- การตรวจสอบลายเซ็นใช้ความน่าเชื่อถือ Windows ที่หาได้ในเครื่อง ไม่ได้ดำเนินการเพิกถอนออนไลน์
- มี 34 ภาษา แต่การทดสอบเจ้าของภาษา/การเข้าถึงเต็มรูปแบบยังคงไม่สมบูรณ์

<a id="troubleshooting"></a>
## การแก้ไขปัญหา

| อาการ | การดำเนินการ |
| --- | --- |
| แคตตาล็อกออนไลน์ไม่พร้อมใช้งาน | เลือกแพ็คเกจดั้งเดิมจาก [ดาวน์โหลดไดรเวอร์ NVIDIA](https://www.nvidia.com/en-us/drivers/) อย่าทดแทนรุ่น GPU ที่อยู่ใกล้เคียง |
| การค้นหาโปรแกรมแก้ไขด่วนไม่พร้อมใช้งาน | ใช้ [NVIDIA's Game Ready ฟอรัมไดรเวอร์](https://www.nvidia.com/en-us/geforce/forums/game-ready-drivers/13/) และตรวจสอบแพ็คเกจจริง |
| การติดตั้ง NVIDIA ล้มเหลว | อ่านสรุปความล้มเหลวและเปิดบันทึกโดยละเอียด ส่วนประกอบเสริมที่มีอยู่แล้วหรือใช้งานไม่ได้ยังคงสามารถข้ามได้ใน 0.1.3 การติดตั้งที่ล้มเหลวไม่ทำให้เกิดการปรับแต่งเพิ่มเติมหรือโฟลว์สำเร็จ/รีสตาร์ท |
| ลายเซ็น/แฮช/การสำรองข้อมูลล้มเหลว | หยุดการติดตั้งนั้นและเก็บข้อผิดพลาดไว้ รับแพ็คเกจเดิมอีกครั้งหากเกิดความเสียหาย |
| ตัวเลือกไม่พร้อมใช้งาน | อ่านเหตุผลด้านฮาร์ดแวร์ ส่วนประกอบ หรือไดรเวอร์เป้าหมาย เก็บไว้ไม่เปลี่ยนแปลง |
| รีสตาร์ทหรืองานยังค้างอยู่ | ใช้คำแนะนำในการกู้คืนงานและประวัติย่อที่ชัดเจน อย่าลบบันทึกประจำวันของมัน |
| ฟื้นฟูความขัดแย้ง | รัฐอื่นแตกต่างจากธุรกรรมที่บันทึกไว้ เก็บรักษาไว้และขอความช่วยเหลือแทนที่จะบังคับกู้คืน |

สำหรับรายงาน ให้รวมเวอร์ชันเครื่องมือที่เลือก Windows, GPU ไดรเวอร์ และขั้นตอนที่ทำซ้ำได้ ตรวจทานเส้นทางและรายละเอียดส่วนบุคคลจากบันทึก [สนับสนุน](../docs/support.md).

<a id="faq"></a>
## คำถามที่พบบ่อย

**โปรแกรมติดตั้งจะติดตั้งไดรเวอร์กราฟิกหรือไม่** ไม่ ซึ่งจำเป็นต้องมีการวิเคราะห์ ตรวจทาน ยืนยัน และกระบวนการติดตั้งระดับสูงแยกต่างหากของแอปพลิเคชัน

**ฉันจำเป็นต้องมี NVCleanstall หรือ NVPI หรือไม่** ไม่ใช่ NVCleanstall เป็นเพียงแรงบันดาลใจเท่านั้น ตัวช่วย Profile Inspector เป็นตัวแก้ไขเสริมอิสระ

**ทำให้ไดรเวอร์ NVIDIA ทุกตัวมีขนาดเล็กลงหรือเร็วขึ้นหรือไม่** ไม่ ส่วนประกอบและข้อกำหนดเบื้องต้นที่เลือกจะกำหนดสิ่งที่สามารถเปลี่ยนแปลงได้ ไม่มีการสัญญาว่าจะได้รับกำไรที่วัดได้

**แหล่งที่มาอยู่ที่ไหน** แหล่งที่มาเฉพาะแอปพลิเคชันและการทดสอบส่วนตัวจะได้รับการดูแลแยกกัน ฮับนี้จัดเตรียมเอกสาร ไบนารี และลิงก์แหล่งที่มาของบุคคลที่สามที่จำเป็นสำหรับการระบุแหล่งที่มา/การออกใบอนุญาต

<a id="credits-and-upstream"></a>
## เครดิตและต้นน้ำ

แอปพลิเคชันดั้งเดิม เวิร์กโฟลว์ ธุรกรรม การแปลเป็นภาษาท้องถิ่น บูตสแตรป และการปรับเปลี่ยน: 禅堂 Zendo (RevoluSound Team)

- [NVCleanstall / TechPowerUp](https://www.techpowerup.com/download/techpowerup-nvcleanstall/): แรงบันดาลใจเวิร์กโฟลว์; ไม่มีแหล่งที่มาหรือไบนารีนำเข้า
- [NVIDIA Profile Inspector / Orbmu2k](https://github.com/Orbmu2k/nvidiaProfileInspector): ธีม MIT, การอ้างอิงอินเทอร์เฟซ NVAPI แบบขยาย และแพ็คเกจ fork ที่แยกจากกัน
- [7-Zip / Igor Pavlov](https://www.7-zip.org/): เครื่องมือสกัดที่ไม่มีการแก้ไข
- [Microsoft .NET](https://github.com/dotnet/runtime) และ [WPF](https://github.com/dotnet/wpf): รันไทม์แบบรวม
- [Inno Setup](https://jrsoftware.org/isinfo.php): กลไกการติดตั้งดั้งเดิมและคำแปลที่น่าเชื่อถือ
- [keylase/nvidia-patch](https://github.com/keylase/nvidia-patch): แหล่งข้อมูลเสริม NVENC ภายนอก; ไม่ได้จัดตั้งใบอนุญาตการแจกจ่ายซ้ำ
- [NVIDIA](https://www.nvidia.com/en-us/drivers/): ดาวน์โหลดไดรเวอร์ภายนอกและติดตั้งไลบรารี NVAPI/NVML
