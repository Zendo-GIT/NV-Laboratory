# บันทึกการเปลี่ยนแปลง

ฮับนี้เป็นไปตาม [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) เวอร์ชันของแอปพลิเคชันและวันที่เผยแพร่มีความเป็นอิสระ แพ็คเกจที่เตรียมไว้ด้านล่างจะได้รับวันที่เผยแพร่ตามจริงในการเผยแพร่ GitHub ที่เกี่ยวข้อง

<a id="unreleased"></a>
## [ยังไม่ได้เผยแพร่]

<a id="changed"></a>
### มีการเปลี่ยนแปลง

- รีเฟรชฮับและภาษาเอกสารทั้งหมด 34 ภาษาสำหรับ NVDriverForge 0.1.4
NVMFG Unlock40 0.2.3 และ NVRasterPulse 0.2 จัดทำขึ้นเมื่อ 2026-09-18
- NVDriverForge: การตรวจสอบความพร้อม การสำรองข้อมูลโปรไฟล์ดั้งเดิม และการกู้คืนที่มีการป้องกัน
คำแนะนำส่วนประกอบ การตั้งค่าที่ใช้ซ้ำได้ ชุดไดรเวอร์ ผลลัพธ์โดยละเอียด รายงานการสนับสนุนในพื้นที่ และการอัปเดตแอปพลิเคชันแยกต่างหาก
- NVMFG: การค้นพบหลายโฟลเดอร์, แคชไลบรารี่ถาวร, กิจกรรม MFG ที่สังเกตได้,
ข้อมูลความสามารถรันไทม์ การยกเว้นการเปิดตัวครั้งถัดไป การวินิจฉัยเฉพาะที่ การถ่ายโอนการตั้งค่า และการอัปเดตแอปพลิเคชันเสริม
- NVRasterPulse: การวินิจฉัยการกำหนดค่า, คำแนะนำ FPS, หยุดชั่วคราว/ดำเนินการต่อ
เลิกทำระดับหนึ่ง เลือกนำเข้า/ส่งออกโปรไฟล์ รายการโปรด และรายการที่ซ่อนอยู่
- รีเฟรชแฮชของแพ็คเกจ บันทึกประจำรุ่น และแผนผังที่มาของส่วนประกอบดั้งเดิม
คงสินทรัพย์ Profile Inspector 3.0.2.3/setup-r2 ที่เผยแพร่แล้วไว้ไม่เปลี่ยนแปลง

<a id="fixed"></a>
### แก้ไขแล้ว

- การเลือก/นับเกม NVMFG การจัดการ Ctrl+D และข้อความความคืบหน้าที่เสร็จสมบูรณ์
Wallpaper Engine ไม่รวมอยู่ในการตรวจจับเกม การอุดตันในการฟื้นฟู 0.1.1 ที่รายงานแยกต่างหากยังคงไม่เกิดขึ้นซ้ำและไม่ได้อ้างว่าได้รับการแก้ไขแล้ว

<a id="initial-public-hub--2026-09-10"></a>
## [ศูนย์กลางสาธารณะเริ่มต้น] – 10-2026-09-10

<a id="added"></a>
### เพิ่มแล้ว

- คู่มือโครงการสี่รายการและเอกสารพื้นที่เก็บข้อมูลใน 34 ภาษาด้วย
ตัวเลือกการรักษาหน้า จุดยึดที่เสถียร และข้อมูลเมตาความครอบคลุมของการแปล
- เครดิตส่วนประกอบ ใบอนุญาตดั้งเดิม แหล่งที่มา ข้อกำหนด RTSS และ
แยกลิงก์ RevoluSound Team
- แพ็คเกจการเผยแพร่ด้วยตนเอง ค่า SHA-256 แบบฟอร์มปัญหา นโยบายความปลอดภัย และ
การตรวจสอบเอกสารแบบอ่านอย่างเดียว แหล่งที่มาของแอปพลิเคชันยังคงเป็นส่วนตัว
- แท็กสาธารณะแรก: `nvpi-v3.0.2.3`, `nvdriverforge-v0.1.3`,
`nvmfg-unlock40-v0.1.1` และ `nvrasterpulse-v0.1`.

<a id="included-fixes"></a>
### รวมการแก้ไข

- ตัวติดตั้ง Profile Inspector ฉบับที่ 2: ตัวเลือก 34 ภาษาแบบสแตนด์อโลน
ตัวแก้ไขและเพย์โหลดแบบพกพาไม่เปลี่ยนแปลง
- NVDriverForge 0.1.3: แก้ไขการจัดการส่วนประกอบเสริมและการแปลเป็นภาษาท้องถิ่น
สรุปความล้มเหลวพร้อมรันไทม์ที่อัปเดตและแพ็คเกจที่แสดงร่วม

วันที่ข้างต้นเป็นประวัติฮับสาธารณะที่ได้รับการตรวจสอบ ไม่ใช่วันที่พัฒนาใหม่
