<a id="changelog"></a>
# บันทึกการเปลี่ยนแปลง

ฮับนี้เป็นไปตาม [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) รายการอธิบายพื้นที่เก็บข้อมูลนี้ เวอร์ชันของแอปพลิเคชันมีความเป็นอิสระ

<a id="unreleased"></a>
## [ยังไม่ได้เผยแพร่]

<a id="added"></a>
### เพิ่มแล้ว

- ฮับ คู่มือโครงการฉบับสมบูรณ์ และเอกสารพื้นที่เก็บข้อมูลในภาษาแอปพลิเคชัน 34 NV
- ตัวเลือกภาษาที่เก็บรักษาหน้า ข้อมูลเมตาที่ครอบคลุมการแปล และจุดยึดภายในที่เสถียร
- เครดิตขั้นต้น ประกาศที่เกี่ยวข้องฉบับสมบูรณ์ และที่มาของไฟล์
- ข้อกำหนด RTSS และลิงก์ดาวน์โหลดอย่างเป็นทางการสำหรับ NVRasterPulse
- แยกลิงค์ RevoluSound Team
- แค็ตตาล็อกบรรจุภัณฑ์รุ่นแรกที่จัดเตรียมไว้ การตรวจสอบ SHA-256 และขั้นตอนการปล่อยด้วยตนเอง
- แบบฟอร์มข้อบกพร่อง/ฟีเจอร์ การให้ความช่วยเหลือ และคำแนะนำด้านความปลอดภัย
- เอกสารแบบอ่านอย่างเดียวและการตรวจสอบขอบเขตการตีพิมพ์

<a id="changed"></a>
### มีการเปลี่ยนแปลง

- ขณะนี้การระบุแหล่งที่มาของ NVMFG แยกแยะความแตกต่างของแอปพลิเคชันที่พัฒนาขึ้นอย่างอิสระ
การอ้างอิงการเปรียบเทียบ/การปรับแต่ง และส่วนประกอบดั้งเดิมที่ใช้ร่วมกันตามจริง   ลิขสิทธิ์ ใบอนุญาต และการเปรียบเทียบไฟล์ที่มีอยู่ยังคงไม่เปลี่ยนแปลง
- ตัวเลือก NVDriverForge อัปเดตเป็น 0.1.3: แก้ไขการจัดการส่วนประกอบเสริม
ความล้มเหลวที่แปลเป็นภาษาท้องถิ่นที่อ่านได้และแพ็คเกจรันไทม์/สหายที่อัปเดต

<a id="fixed"></a>
### แก้ไขแล้ว

- การตั้งค่า NVIDIA Profile Inspector – NV Tools Fork การแก้ไข 2 ตอนนี้แสดงการแชร์
ตัวเลือก 34 ภาษาเมื่อเปิดตัวโดยตรง ภาษาที่ชัดเจนและการส่งต่อโดยไม่โต้ตอบจะถูกเก็บรักษาไว้ ตัวแก้ไขและแพ็คเกจพกพาไม่มีการเปลี่ยนแปลง

ไม่มีการสร้างวันที่เผยแพร่ต่อสาธารณะในอดีตขึ้นมาใหม่ เวอร์ชันของแอปพลิเคชันที่ผู้สมัครคือ 3.0.2.3, 0.1.3, 0.1.1 และ 0.1; บันทึกประจำรุ่นของพวกเขาจะแนบไปกับการเปิดตัวในอนาคตของพวกเขาเอง การเตรียมการในวันที่ 09-09-2026 ไม่ใช่วันวางจำหน่าย GitHub
