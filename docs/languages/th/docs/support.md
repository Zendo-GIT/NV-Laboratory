<a id="compatibility-and-troubleshooting"></a>
# ความเข้ากันได้และการแก้ไขปัญหา

สิ่งเหล่านี้คือตัวเลือกที่เตรียมไว้ ไม่ใช่เมทริกซ์การรับรองสำหรับ Windows, GPU, ไดรเวอร์และชุดเกมทั้งหมด

| เครื่องมือ | Windows / รันไทม์ | ฮาร์ดแวร์ / การพึ่งพาภายนอก | การดำเนินงานที่ต้องการการดูแล |
| --- | --- | --- | --- |
| NVPI fork 3.0.2.3 | Windows 10/11 x64, .NET Framework 4.8 | ไดรเวอร์/จอแสดงผล NVIDIA ที่เข้ากันได้ | เขียนโปรไฟล์และแสดงตัวอย่าง |
| NVDriverForge 0.1.4 | Windows 10 รุ่น 19041+ / 11 x64; รวม .NET/WPF แล้ว | แพ็คเกจไดรเวอร์ NVIDIA ที่เข้ากันได้ | การติดตั้งแบบยกระดับ การตั้งค่าขั้นสูง ตัวเลือก NVENC |
| NVMFG Unlock40 0.2.3 | Windows 10/11x64; รวม .NET/WPF, ตัวช่วย Framework 4.8 | RTX 40 เกม DLSS FG ที่มีสิทธิ์และผู้ให้บริการที่ปักหมุดไว้ | การแพทช์ในเกมแบบเนทีฟ บันทึกโปรไฟล์ทั่วโลก การอัปเดตเกม SDK |
| NVRasterPulse 0.2 | Windows 10/11 x64, .NET Framework 4.8 | ติดตั้ง RTSS; วิ่งเพื่อหมวก | RTSS การเปลี่ยนแปลงโปรไฟล์ต่อการดำเนินการ |

ไม่มีการเตรียมแพ็คเกจ ARM64 ความพร้อมใช้งานของจอแสดงผล/API และ Windows เวอร์ชันเก่าสามารถจำกัดคุณสมบัติแต่ละรายการได้ ไม่มีการคิดค้นเวอร์ชัน NVIDIA หรือ RTSS สากลขั้นต่ำ แฮชของผู้ให้บริการ NVMFG ที่แน่นอนอยู่ใน [ที่มา](provenance.md)

<a id="before-reporting-a-bug"></a>
## ก่อนที่จะรายงานข้อผิดพลาด

ระบุไฟล์ปฏิบัติการ/เวอร์ชันที่คุณเปิด สำเนาที่ติดตั้งไว้ก่อนหน้านี้ไม่จำเป็นต้องเป็นเวอร์ชันของ ZIP ที่ดาวน์โหลดใหม่ บันทึกขั้นตอนการทำซ้ำ ผลลัพธ์ที่คาดหวัง และผลลัพธ์ที่เกิดขึ้นจริง สำหรับปัญหาการเรนเดอร์/การจำกัด ให้รวมเวอร์ชันเกม การรีเฟรชจอแสดงผล สถานะ FG/V-Sync/VRR และตัวจำกัดหรือโอเวอร์เลย์อื่นๆ

ใช้ [แบบฟอร์มข้อผิดพลาด](https://github.com/Zendo-GIT/NV-Laboratory/issues/new?template=bug-report.yml) ห้ามแนบโฟลเดอร์การพัฒนาส่วนตัว ไฟล์เก็บถาวรไดรเวอร์ โมเดล DLL เกม ดัมพ์รีจิสทรี หรือคอลเลกชันบันทึกที่ไม่ได้รับการตรวจสอบเด็ดขาด

| ปัญหา | การตรวจสอบครั้งแรก |
| --- | --- |
| เวอร์ชันแอปพลิเคชันไม่ถูกต้อง | ยืนยันข้อมูลประจำตัว EXE และแฮชที่เผยแพร่ ปิดสำเนาเก่าก่อนที่จะเปลี่ยน |
| ข้อผิดพลาดรันไทม์/การเริ่มต้นระบบ | ติดตั้ง Framework 4.8 ที่จำเป็นหรือเก็บโฟลเดอร์ย่อยแบบพกพาที่ให้มาทั้งหมด |
| UAC ถูกยกเลิก | ลองเฉพาะการดำเนินการที่ต้องการอีกครั้งเท่านั้น การยกเลิกการติดตั้งไม่สำเร็จ |
| แฮช/ลายเซ็นไม่ตรงกัน | หยุดใช้ผู้สมัครนั้นและรับไบต์อย่างเป็นทางการที่คาดหวัง |
| สี/โหมด NVPI ถูกปฏิเสธ | เปลี่ยนกลับและใช้การผสมผสานที่สนับสนุนโดยจอแสดงผล/ไดรเวอร์จริง |
| การสำรองข้อมูลหรือการกู้คืน NVDF ล้มเหลว | รักษางานที่ได้รับการป้องกันและ RECOVERY.txt; อย่าลบเจอร์นัลหรือบังคับการเขียนที่ขัดแย้งกัน |
| การตั้งค่าที่รอดำเนินการของ NVMFG | แก้ไขการกู้คืนเมื่อปิดเกม โดยคงการเปลี่ยนแปลงจากเครื่องมืออื่นไว้ |
| ฝาปิด RP ไม่มีผลกระทบ | เรียกใช้ RTSS ระบุ EXE ของเกมจริง ตรวจสอบสถานะ hook และขีดจำกัดการแข่งขัน |
| ฝาปิด RP ยังคงอยู่หลังจากการถอดออก | ตรวจสอบ RTSS ทั่วโลก การลบการเปลี่ยนแปลงจะแทนที่ตัวจำกัดในเครื่องเท่านั้น |

NVDriverForge นำเสนอรายงาน JSON ในเครื่องที่สามารถดูตัวอย่างได้ NVMFG นำเสนอการวินิจฉัยใน About ต้องการให้รายงานที่กรองแล้วเหล่านี้เก็บถาวรบันทึกที่สมบูรณ์ และตรวจสอบก่อนแชร์ การอุดตันในการฟื้นฟูที่รายงานบน NVMFG 0.1.1 ยังคงไม่มีสาเหตุที่แน่ชัด เก็บรักษาบันทึกประจำวันและบันทึกรหัสข้อผิดพลาดที่มีอยู่ NVRasterPulse 0.2 มีการวินิจฉัยการกำหนดค่าในเมนูการดำเนินการ โดยไม่ต้องวัด FPS

<a id="logs-and-privacy"></a>
## บันทึกและความเป็นส่วนตัว

| เครื่องมือ | ข้อมูลท้องถิ่นที่ต้องตรวจสอบ ไม่ใช่อัปโหลดการขายส่ง |
| --- | --- |
| NVDF | `%LOCALAPPDATA%\NVDriverForge`; งานที่ได้รับการคุ้มครอง `%PROGRAMDATA%\NVDriverForge\Jobs` |
| NVMFG | `%LOCALAPPDATA%\RtxMfg`; การสำรองข้อมูล `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`; `Sessions` ข้าง EXE |
| RP | `%LOCALAPPDATA%\NVRasterPulse`; `Backups\RTSS` ด้านล่างครับ |
| NVPI | การส่งออกที่คุณเลือกและข้อผิดพลาดที่แสดง ไม่มีเส้นทางบันทึกสากลที่คิดค้นขึ้น |

ลบชื่อบัญชี โฮมไดเร็กทอรี เส้นทางไลบรารีเกม ตัวระบุอุปกรณ์ โทเค็น และหน้าต่างที่ไม่เกี่ยวข้องออกจากข้อความ/รูปภาพที่คุณแชร์ เก็บต้นฉบับไว้เป็นส่วนตัวเพื่อการกู้คืน ปัญหาสาธารณะจะปรากฏแก่ทุกคน

สำหรับช่องโหว่ พฤติกรรมสิทธิพิเศษที่เป็นอันตราย หรือการดำเนินการทำลายล้างโดยไม่ได้ตั้งใจ โปรดติดตาม [SECURITY.md](../SECURITY.md) แทนที่จะโพสต์รายละเอียดต่อสาธารณะ

<a id="what-has-been-verified"></a>
## สิ่งที่ได้รับการตรวจสอบแล้ว

สำหรับการเตรียมฮับ การสแกนเพย์โหลด/ZIP/แฮช/เมตาดาต้าแบบคงที่ และการตรวจสอบเอกสารประกอบ การทดสอบบิวด์/หน่วย/UI แอปพลิเคชันส่วนตัวที่มีอยู่นั้นเป็นหลักฐานในอดีตและลงวันที่ ไม่มีการติดตั้งไดรเวอร์ การเปลี่ยนแปลงการแสดงผล การดำเนินการสดของ RTSS หรือการวัดประสิทธิภาพเกม ซึ่งเป็นส่วนหนึ่งของการเตรียมการนี้

“ตรวจพบ”, “เขียน”, “โหลดซ้ำ”, “ความสามารถที่มีอยู่” และ “วัดผลในเกม” เป็นผลลัพธ์ที่แตกต่างกัน รายงานว่าอันไหนที่คุณสังเกตเห็น
