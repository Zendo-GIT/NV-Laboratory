# สถาปัตยกรรมพื้นที่เก็บข้อมูลและการบำรุงรักษา

NV Laboratory เป็น **เอกสารและศูนย์กลางการกระจายไบนารี** สาธารณะ ไม่มีแหล่งที่มาของแอปพลิเคชัน โปรเจ็กต์ทั้งสี่ยังคงรักษาแผนผังบิวด์ เวอร์ชัน ข้อมูลประจำตัว และสินทรัพย์ที่เผยแพร่แยกกัน ประวัติการพัฒนาส่วนตัวของพวกเขาจะไม่ถูกนำเข้าไปยังที่เก็บ Git นี้

<a id="layout"></a>
## เค้าโครง

| ที่ตั้ง | วัตถุประสงค์ |
| --- | --- |
| README.md / README.fr.md | จุดเริ่มต้นภาษาอังกฤษ/ฝรั่งเศส |
| สี่โฟลเดอร์โครงการ | คำแนะนำฉบับสมบูรณ์และประกาศต้นฉบับที่เกี่ยวข้อง |
| เอกสาร | การดาวน์โหลด ความเข้ากันได้ ที่มา การพัฒนา และขั้นตอนการเผยแพร่ |
| เอกสาร/releases.json | ข้อมูลเมตาของผู้สมัคร/การเผยแพร่ ขนาด และแฮชที่ได้รับการตรวจสอบแล้ว |
| เอกสาร/ที่มา | การเปรียบเทียบไฟล์/แฮช ไม่มีรหัสแอปพลิเคชัน |
| ใบอนุญาต | แบ่งปันข้อความของบุคคลที่สามแบบเต็มและเครดิตผู้แปลการติดตั้ง |
| สินทรัพย์ | ตัวอย่าง UI ที่ได้รับการตรวจสอบแล้วและแหล่งที่มา |
| .github | แบบฟอร์มการออกและการตรวจสอบเอกสารแบบอ่านอย่างเดียว |
| เครื่องมือ/validate_repository.py | การตรวจสอบขอบเขตสิ่งพิมพ์และลิงก์ของห้องสมุดมาตรฐาน |

ภาษาอังกฤษยังคงเป็นค่าเริ่มต้น GitHub README ลิงก์ `.fr.md` ที่อยู่ติดกันที่มีอยู่จะยังคงใช้ได้ การแปลเพิ่มเติมสะท้อนเอกสารภายใต้ `docs/languages/<code>`; ตัวเลือกภาษาจะคงหน้าเดิมไว้เมื่อเปลี่ยนภาษา แค็ตตาล็อก `docs/languages/catalog.json` บันทึกภาษาทั้งหมด 34 ภาษาและลายนิ้วมือต้นทาง GitHub จะไม่เลือก README ตามภาษาของเบราว์เซอร์โดยอัตโนมัติ ดู [ดัชนีภาษาและนโยบายการแปล](../../README.md)

## เทคโนโลยีการประยุกต์ใช้งาน

| โปรแกรม | เทคโนโลยีส่วนตัว | การกระจายสินค้า |
| --- | --- | --- |
| NVPI fork | C#, WPF, .NET Framework 4.8, NVAPI/Windows การทำงานร่วมกัน | ทำโฟลเดอร์พกพาให้สมบูรณ์และแยก Inno Setup |
| NVDriverForge | C#, WPF, .NET 8; บูตสแตรป C ++ ดั้งเดิม; กระบวนการ 7-Zip | EXE และการตั้งค่าแบบพกพาที่มีอยู่ในตัวเอง |
| NVMFG Unlock40 | C#/WPF .NET 8, ตัวช่วย Framework 4.8, โปรแกรม C++20/MASM/MinHook | ต้นไม้แบบพกพาและการตั้งค่า |
| NVRasterPulse | กรอบงาน C#/WPF 4.8; การรวมโปรไฟล์/การโหลดซ้ำของ RTSS; บูตสแตรปดั้งเดิม | ต้นไม้แบบพกพาและการตั้งค่า |

การชำระเงินสาธารณะนี้ไม่สามารถสร้างแอปพลิเคชันใหม่ได้ ไฟล์เก็บถาวร “Source code” อัตโนมัติเป็นสแน็ปช็อตฮับ ลิงก์ต้นทางต้นทางไม่ได้แสดงถึงแหล่งที่มาที่แก้ไขส่วนตัวทุกประการ CI สาธารณะตรวจสอบพื้นที่เก็บข้อมูลนี้เท่านั้น

<a id="local-checks"></a>
## การตรวจสอบในท้องถิ่น

จากรูทของที่เก็บ:

```text
python tools/validate_repository.py
```

Python 3.10 หรือใหม่กว่าก็เพียงพอแล้ว เช็คจะอ่านไฟล์ ลิงก์ Markdown ในเครื่อง ประกาศที่จำเป็น/ลิงก์ RTSS เมตาดาต้าการเผยแพร่ และขอบเขตการเผยแพร่ มันไม่ได้รันซอฟต์แวร์ ติดตั้งการพึ่งพา หรือติดต่อกับเครือข่าย

เวิร์กโฟลว์ GitHub รันการตรวจสอบเดียวกันนี้โดยมีสิทธิ์อ่านเนื้อหาแบบอ่านอย่างเดียวเมื่อมีการร้องขอแบบพุช พุล หรือการจัดส่งด้วยตนเอง การชำระเงินถูกปักหมุดไว้ที่คอมมิตที่ได้รับการตรวจสอบแล้ว และไม่มีข้อมูลรับรองอยู่ ไม่มีการกำหนดค่างานการเปิดตัวหรือการปรับใช้

<a id="maintain-the-boundary"></a>
## รักษาขอบเขต

อัปเดตข้อมูลอ้างอิงภาษาอังกฤษ คู่มือภาษาฝรั่งเศส และคำแปลที่ได้รับผลกระทบร่วมกัน แยกการเปลี่ยนแปลงที่สำคัญออกจากการเปรียบเทียบเฉพาะการจัดรูปแบบเท่านั้น บันทึกแฮชของผู้สมัครจริง การอ้างอิงต้นทางและใบอนุญาต ไม่เคยอนุมานใบอนุญาตจากความนิยมของโครงการ

ใช้เนื้อหาที่เผยแพร่เวอร์ชันใหม่และตรวจสอบไบนารีที่เปลี่ยนแปลง เอกสารสำคัญ และประกาศที่ฝังอยู่อีกครั้ง เก็บรักษาข้อมูลสำรองส่วนตัวไว้นอกพื้นที่เก็บข้อมูลนี้ อย่าใช้เวิร์กโฟลว์สาธารณะเพื่อนำเข้าแหล่งที่มาของแอปพลิเคชันส่วนตัวหรือโฟลเดอร์บิลด์ในเครื่อง

การทดสอบที่เหมาะสมกับการเปลี่ยนแปลงแอปพลิเคชันที่ทำงานในโครงการส่วนตัว อย่ารันโปรแกรมติดตั้งไดรเวอร์อีกครั้งหรือเขียนโปรไฟล์จริงสำหรับการอัพเดตเอกสาร [ขั้นตอนการปล่อยด้วยตนเอง](releasing.md).
