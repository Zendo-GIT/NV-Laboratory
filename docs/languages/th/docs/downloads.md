# ดาวน์โหลด

เลือกโปรแกรมและ **ตั้งค่า** หรือ **พกพา** หน้าการเผยแพร่ของเครื่องมือแต่ละรายการจะแสดงความพร้อมในปัจจุบัน วันที่เผยแพร่ และบันทึกประจำรุ่น ลิงก์โดยตรงจะทำงานเมื่อผู้ดูแลเผยแพร่เนื้อหาที่เกี่ยวข้อง แหล่งที่มาของแอปพลิเคชันยังคงเป็นส่วนตัว เก็บ `Licenses-and-Credits.zip` และ `SHA256SUMS.txt` ไว้พร้อมกับการดาวน์โหลด ปุ่ม **Source code (zip)** ของ GitHub มีเอกสารประกอบฮับ

> **NVRasterPulse ต้องใช้ RTSS** ติดตั้ง [RivaTuner Statistics Server จาก Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) แยกต่างหาก และเรียกใช้เพื่อจำกัด FPS
