- ਬੱਗ/ਵਿਸ਼ੇਸ਼ਤਾ ਫਾਰਮ, ਯੋਗਦਾਨ ਅਤੇ ਸੁਰੱਖਿਆ ਨਿਰਦੇਸ਼।
