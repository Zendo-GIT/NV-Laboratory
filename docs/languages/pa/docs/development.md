# ਰਿਪੋਜ਼ਟਰੀ ਆਰਕੀਟੈਕਚਰ ਅਤੇ ਰੱਖ-ਰਖਾਅ

NV Laboratory ਇੱਕ ਜਨਤਕ **ਦਸਤਾਵੇਜ਼ ਅਤੇ ਬਾਈਨਰੀ-ਵੰਡ ਹੱਬ** ਹੈ। ਇਸ ਵਿੱਚ ਐਪਲੀਕੇਸ਼ਨ ਸਰੋਤ ਸ਼ਾਮਲ ਨਹੀਂ ਹੈ। ਚਾਰ ਪ੍ਰੋਜੈਕਟ ਵੱਖਰੇ ਬਿਲਡ ਟ੍ਰੀ, ਸੰਸਕਰਣ, ਪਛਾਣ ਅਤੇ ਰੀਲੀਜ਼ ਸੰਪਤੀਆਂ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖਦੇ ਹਨ। ਉਹਨਾਂ ਦਾ ਨਿੱਜੀ ਵਿਕਾਸ ਇਤਿਹਾਸ ਇਸ Git ਰਿਪੋਜ਼ਟਰੀ ਵਿੱਚ ਆਯਾਤ ਨਹੀਂ ਕੀਤਾ ਗਿਆ ਹੈ।

<a id="local-checks"></a>
## ਸਥਾਨਕ ਜਾਂਚ

ਰਿਪੋਜ਼ਟਰੀ ਰੂਟ ਤੋਂ:

```text
python tools/validate_repository.py
```

Python 3.10 ਜਾਂ ਨਵਾਂ ਕਾਫ਼ੀ ਹੈ। ਚੈੱਕ ਫਾਈਲਾਂ, ਸਥਾਨਕ ਮਾਰਕਡਾਊਨ ਲਿੰਕ, ਲੋੜੀਂਦੇ ਨੋਟਿਸ/RTSS ਲਿੰਕ, ਰੀਲੀਜ਼ ਮੈਟਾਡੇਟਾ ਅਤੇ ਪ੍ਰਕਾਸ਼ਨ ਸੀਮਾਵਾਂ ਨੂੰ ਪੜ੍ਹਦਾ ਹੈ। ਇਹ ਸੌਫਟਵੇਅਰ ਨੂੰ ਲਾਗੂ ਨਹੀਂ ਕਰਦਾ, ਨਿਰਭਰਤਾ ਸਥਾਪਤ ਨਹੀਂ ਕਰਦਾ ਜਾਂ ਕਿਸੇ ਨੈੱਟਵਰਕ ਨਾਲ ਸੰਪਰਕ ਨਹੀਂ ਕਰਦਾ।

GitHub ਵਰਕਫਲੋ ਪੁਸ਼, ਪੁੱਲ ਬੇਨਤੀ ਜਾਂ ਮੈਨੂਅਲ ਡਿਸਪੈਚ 'ਤੇ ਸਿਰਫ਼-ਪੜ੍ਹਨ ਲਈ ਸਮੱਗਰੀ ਦੀ ਇਜਾਜ਼ਤ ਨਾਲ ਇਹੀ ਜਾਂਚ ਚਲਾਉਂਦਾ ਹੈ। ਚੈੱਕਆਉਟ ਨੂੰ ਇੱਕ ਆਡਿਟ ਕੀਤੀ ਪ੍ਰਤੀਬੱਧਤਾ ਨਾਲ ਪਿੰਨ ਕੀਤਾ ਗਿਆ ਹੈ ਅਤੇ ਪ੍ਰਮਾਣ ਪੱਤਰਾਂ ਨੂੰ ਕਾਇਮ ਨਹੀਂ ਰੱਖਦਾ ਹੈ। ਕੋਈ ਰੀਲੀਜ਼ ਜਾਂ ਡਿਪਲਾਇਮੈਂਟ ਜੌਬ ਕੌਂਫਿਗਰ ਨਹੀਂ ਕੀਤੀ ਗਈ ਹੈ।

<a id="maintain-the-boundary"></a>
## ਸੀਮਾ ਨੂੰ ਕਾਇਮ ਰੱਖੋ

ਅੰਗਰੇਜ਼ੀ ਸੰਦਰਭ, ਫ੍ਰੈਂਚ ਗਾਈਡਾਂ ਅਤੇ ਪ੍ਰਭਾਵਿਤ ਅਨੁਵਾਦਾਂ ਨੂੰ ਇਕੱਠੇ ਅਪਡੇਟ ਕਰੋ। ਅਸਲ ਤਬਦੀਲੀਆਂ ਨੂੰ ਸਿਰਫ਼-ਸਿਰਫ਼ ਫਾਰਮੈਟਿੰਗ ਤੁਲਨਾਵਾਂ ਤੋਂ ਵੱਖ ਰੱਖੋ। ਅਸਲ ਉਮੀਦਵਾਰ ਹੈਸ਼, ਅੱਪਸਟਰੀਮ ਕਮਿਟ ਹਵਾਲੇ ਅਤੇ ਲਾਇਸੰਸ ਰਿਕਾਰਡ ਕਰੋ; ਕਿਸੇ ਪ੍ਰੋਜੈਕਟ ਦੀ ਪ੍ਰਸਿੱਧੀ ਤੋਂ ਕਦੇ ਵੀ ਲਾਇਸੈਂਸ ਦਾ ਅੰਦਾਜ਼ਾ ਨਾ ਲਗਾਓ।

ਤਾਜ਼ਾ ਸੰਸਕਰਣ ਰੀਲੀਜ਼ ਸੰਪਤੀਆਂ ਦੀ ਵਰਤੋਂ ਕਰੋ ਅਤੇ ਬਦਲੀਆਂ ਗਈਆਂ ਬਾਈਨਰੀਆਂ, ਪੁਰਾਲੇਖਾਂ ਅਤੇ ਏਮਬੈਡਡ ਨੋਟਿਸਾਂ ਦਾ ਮੁੜ-ਆਡਿਟ ਕਰੋ। ਇਸ ਰਿਪੋਜ਼ਟਰੀ ਦੇ ਬਾਹਰ ਨਿੱਜੀ ਬੈਕਅੱਪ ਸੁਰੱਖਿਅਤ ਕਰੋ। ਨਿੱਜੀ ਐਪਲੀਕੇਸ਼ਨ ਸਰੋਤ ਜਾਂ ਸਥਾਨਕ ਬਿਲਡ ਫੋਲਡਰਾਂ ਨੂੰ ਆਯਾਤ ਕਰਨ ਲਈ ਜਨਤਕ ਵਰਕਫਲੋ ਦੀ ਵਰਤੋਂ ਨਾ ਕਰੋ।

ਪ੍ਰਾਈਵੇਟ ਪ੍ਰੋਜੈਕਟ ਵਿੱਚ ਚੱਲਣ ਵਾਲੇ ਕਾਰਜਸ਼ੀਲ ਐਪਲੀਕੇਸ਼ਨ ਤਬਦੀਲੀ ਲਈ ਉਚਿਤ ਟੈਸਟ। ਡ੍ਰਾਈਵਰ ਇੰਸਟੌਲਰਾਂ ਨੂੰ ਦੁਬਾਰਾ ਨਾ ਚਲਾਓ ਜਾਂ ਦਸਤਾਵੇਜ਼ੀ ਅੱਪਡੇਟ ਲਈ ਅਸਲ ਪ੍ਰੋਫਾਈਲਾਂ ਨਾ ਲਿਖੋ। [ਮੈਨੁਅਲ ਰੀਲੀਜ਼ ਪ੍ਰਕਿਰਿਆ](releasing.md)।
