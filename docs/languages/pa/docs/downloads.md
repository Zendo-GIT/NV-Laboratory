# ਡਾਊਨਲੋਡ

ਇੱਕ ਪ੍ਰੋਗਰਾਮ ਚੁਣੋ ਅਤੇ ਜਾਂ ਤਾਂ **ਸੈਟਅੱਪ** ਜਾਂ **ਪੋਰਟੇਬਲ**। ਹਰੇਕ ਟੂਲ ਦਾ ਰੀਲੀਜ਼ ਪੰਨਾ ਮੌਜੂਦਾ ਉਪਲਬਧਤਾ, ਪ੍ਰਕਾਸ਼ਨ ਮਿਤੀ ਅਤੇ ਰੀਲੀਜ਼ ਨੋਟਸ ਦਿਖਾਉਂਦਾ ਹੈ। ਡਾਇਰੈਕਟ ਲਿੰਕ ਉਦੋਂ ਕੰਮ ਕਰਦੇ ਹਨ ਜਦੋਂ ਮੇਨਟੇਨਰ ਸੰਬੰਧਿਤ ਸੰਪਤੀਆਂ ਨੂੰ ਪ੍ਰਕਾਸ਼ਿਤ ਕਰਦਾ ਹੈ। ਐਪਲੀਕੇਸ਼ਨ ਸਰੋਤ ਨਿੱਜੀ ਰਹਿੰਦਾ ਹੈ। ਆਪਣੇ ਡਾਊਨਲੋਡ ਨਾਲ `Licenses-and-Credits.zip` ਅਤੇ `SHA256SUMS.txt` ਰੱਖੋ। GitHub ਦੇ **Source code (zip)** ਬਟਨ ਵਿੱਚ ਹੱਬ ਦਸਤਾਵੇਜ਼ ਸ਼ਾਮਲ ਹਨ।

> **NVRasterPulse ਨੂੰ RTSS ਦੀ ਲੋੜ ਹੈ।** [Guru3D ਤੋਂ RivaTuner Statistics Server](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) ਨੂੰ ਵੱਖਰੇ ਤੌਰ 'ਤੇ ਸਥਾਪਿਤ ਕਰੋ ਅਤੇ ਇਸਨੂੰ FPS ਸੀਮਿਤ ਕਰਨ ਲਈ ਚਲਾਓ।
