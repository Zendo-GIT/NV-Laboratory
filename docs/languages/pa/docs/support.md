# ਅਨੁਕੂਲਤਾ ਅਤੇ ਸਮੱਸਿਆ ਨਿਪਟਾਰਾ

ਇਹ ਤਿਆਰ ਕੀਤੇ ਉਮੀਦਵਾਰ ਹਨ, ਨਾ ਕਿ ਸਾਰੇ Windows, GPU, ਡਰਾਈਵਰ ਅਤੇ ਗੇਮ ਸੰਜੋਗਾਂ ਲਈ ਪ੍ਰਮਾਣੀਕਰਣ ਮੈਟਰਿਕਸ।

| ਟੂਲ | Windows / ਰਨਟਾਈਮ | ਹਾਰਡਵੇਅਰ / ਬਾਹਰੀ ਨਿਰਭਰਤਾ | ਦੇਖਭਾਲ ਦੀ ਲੋੜ ਵਾਲੇ ਓਪਰੇਸ਼ਨ |
| --- | --- | --- | --- |
| NVPI fork 3.0.2.3 | Windows 10/11 x64, .NET ਫਰੇਮਵਰਕ 4.8 | ਅਨੁਕੂਲ NVIDIA ਡਰਾਈਵਰ/ਡਿਸਪਲੇ | ਪ੍ਰੋਫਾਈਲ ਲਿਖਦਾ ਹੈ ਅਤੇ ਪੂਰਵਦਰਸ਼ਨ ਪ੍ਰਦਰਸ਼ਿਤ ਕਰਦਾ ਹੈ |
| NVDriverForge 0.1.4 | Windows 10 ਬਿਲਡ 19041+ / 11 x64; .NET/WPF ਸ਼ਾਮਲ ਹੈ | ਅਨੁਕੂਲ NVIDIA ਡਰਾਈਵਰ ਪੈਕੇਜ | ਐਲੀਵੇਟਿਡ ਸਥਾਪਨਾ, ਉੱਨਤ ਸੈਟਿੰਗਾਂ, ਵਿਕਲਪਿਕ NVENC |
| NVMFG Unlock40 0.2.3 | Windows 10/11 x64; .NET/WPF ਸ਼ਾਮਲ, ਫਰੇਮਵਰਕ 4.8 ਸਹਾਇਕ | RTX 40, ਯੋਗ DLSS FG ਗੇਮ ਅਤੇ ਪਿੰਨ ਕੀਤਾ ਪ੍ਰਦਾਤਾ | ਨੇਟਿਵ ਇਨ-ਗੇਮ ਪੈਚਿੰਗ, ਗਲੋਬਲ ਪ੍ਰੋਫਾਈਲ ਜਰਨਲ, SDK ਗੇਮ ਅੱਪਡੇਟ |

## ਬੱਗ ਦੀ ਰਿਪੋਰਟ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ

ਤੁਹਾਡੇ ਦੁਆਰਾ ਖੋਲ੍ਹੇ ਗਏ ਸਹੀ ਐਗਜ਼ੀਕਿਊਟੇਬਲ/ਵਰਜਨ ਦੀ ਪਛਾਣ ਕਰੋ। ਇੱਕ ਪਿਛਲੀ ਸਥਾਪਿਤ ਕਾਪੀ ਜ਼ਰੂਰੀ ਤੌਰ 'ਤੇ ਇੱਕ ਨਵੀਂ ਡਾਊਨਲੋਡ ਕੀਤੀ ਜ਼ਿਪ ਦਾ ਸੰਸਕਰਣ ਨਹੀਂ ਹੈ। ਪ੍ਰਜਨਨ ਦੇ ਪੜਾਅ, ਅਨੁਮਾਨਿਤ ਨਤੀਜਾ ਅਤੇ ਅਸਲ ਨਤੀਜਾ ਰਿਕਾਰਡ ਕਰੋ। ਰੈਂਡਰਿੰਗ/ਸੀਮਿਤ ਮੁੱਦਿਆਂ ਲਈ, ਗੇਮ ਵਰਜ਼ਨ, ਡਿਸਪਲੇ ਰਿਫ੍ਰੈਸ਼, FG/V-Sync/VRR ਸਟੇਟ ਅਤੇ ਕੋਈ ਹੋਰ ਲਿਮਿਟਰ ਜਾਂ ਓਵਰਲੇ ਸ਼ਾਮਲ ਕਰੋ।

[ਬੱਗ ਫਾਰਮ](https://github.com/Zendo-GIT/NV-Laboratory/issues/new?template=bug-report.yml) ਦੀ ਵਰਤੋਂ ਕਰੋ। ਕਦੇ ਵੀ ਪੂਰੇ ਪ੍ਰਾਈਵੇਟ ਡਿਵੈਲਪਮੈਂਟ ਫੋਲਡਰ, ਡਰਾਈਵਰ ਆਰਕਾਈਵ, ਮਾਡਲ, ਗੇਮ DLL, ਰਜਿਸਟਰੀ ਡੰਪ ਜਾਂ ਅਣ-ਸਮੀਖਿਆ ਕੀਤੇ ਲੌਗ ਕਲੈਕਸ਼ਨ ਨੂੰ ਨੱਥੀ ਨਾ ਕਰੋ।

| ਸਮੱਸਿਆ | ਪਹਿਲੀ ਜਾਂਚ |
| --- | --- |
| ਗਲਤ ਐਪਲੀਕੇਸ਼ਨ ਸੰਸਕਰਣ | EXE ਪਛਾਣ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ ਅਤੇ ਹੈਸ਼ ਜਾਰੀ ਕਰੋ; ਬਦਲਣ ਤੋਂ ਪਹਿਲਾਂ ਪੁਰਾਣੀ ਕਾਪੀ ਬੰਦ ਕਰੋ। |
| ਰਨਟਾਈਮ/ਸਟਾਰਟਅੱਪ ਗਲਤੀ | ਲੋੜੀਂਦਾ ਫਰੇਮਵਰਕ 4.8 ਸਥਾਪਿਤ ਕਰੋ ਜਾਂ ਸਾਰੇ ਸਪਲਾਈ ਕੀਤੇ ਪੋਰਟੇਬਲ ਸਬਫੋਲਡਰ ਬਰਕਰਾਰ ਰੱਖੋ। |
| UAC ਰੱਦ ਕੀਤਾ ਗਿਆ | ਸਿਰਫ਼ ਇੱਛਤ ਕਾਰਵਾਈ ਦੀ ਮੁੜ ਕੋਸ਼ਿਸ਼ ਕਰੋ; ਰੱਦ ਕਰਨਾ ਸਫਲ ਇੰਸਟਾਲੇਸ਼ਨ ਨਹੀਂ ਹੈ। |
| ਹੈਸ਼/ਦਸਤਖਤ ਬੇਮੇਲ | ਉਸ ਉਮੀਦਵਾਰ ਦੀ ਵਰਤੋਂ ਕਰਨਾ ਬੰਦ ਕਰੋ ਅਤੇ ਸੰਭਾਵਿਤ ਅਧਿਕਾਰਤ ਬਾਈਟਸ ਪ੍ਰਾਪਤ ਕਰੋ। |
| NVPI ਰੰਗ/ਮੋਡ ਨੂੰ ਅਸਵੀਕਾਰ ਕੀਤਾ ਗਿਆ | ਵਾਪਿਸ ਕਰੋ ਅਤੇ ਅਸਲ ਡਿਸਪਲੇ/ਡਰਾਈਵਰ ਦੁਆਰਾ ਸਮਰਥਿਤ ਸੁਮੇਲ ਦੀ ਵਰਤੋਂ ਕਰੋ। |

| RP ਕੈਪ ਦਾ ਕੋਈ ਪ੍ਰਭਾਵ ਨਹੀਂ ਹੈ | RTSS ਚਲਾਓ, ਅਸਲੀ ਗੇਮ EXE ਦੀ ਪਛਾਣ ਕਰੋ, ਹੁੱਕ ਸਟੇਟ ਅਤੇ ਪ੍ਰਤੀਯੋਗੀ ਸੀਮਾਵਾਂ ਦੀ ਜਾਂਚ ਕਰੋ। |
| RP ਕੈਪ ਹਟਾਉਣ ਤੋਂ ਬਾਅਦ ਬਰਕਰਾਰ ਰਹਿੰਦਾ ਹੈ | RTSS ਗਲੋਬਲ ਦੀ ਜਾਂਚ ਕਰੋ; ਹਟਾਉਣ ਨਾਲ ਲੋਕਲ ਲਿਮਿਟਰ ਓਵਰਰਾਈਡ ਬਦਲਦਾ ਹੈ। |

NVDriverForge ਇੱਕ ਪੂਰਵਦਰਸ਼ਨਯੋਗ ਸਥਾਨਕ JSON ਰਿਪੋਰਟ ਪੇਸ਼ ਕਰਦਾ ਹੈ; NVMFG ਬਾਰੇ ਵਿੱਚ ਇੱਕ ਡਾਇਗਨੌਸਟਿਕ ਦੀ ਪੇਸ਼ਕਸ਼ ਕਰਦਾ ਹੈ। ਇਹਨਾਂ ਫਿਲਟਰ ਕੀਤੀਆਂ ਰਿਪੋਰਟਾਂ ਨੂੰ ਇੱਕ ਸੰਪੂਰਨ ਲੌਗ ਆਰਕਾਈਵ ਵਿੱਚ ਤਰਜੀਹ ਦਿਓ ਅਤੇ ਸਾਂਝਾ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਉਹਨਾਂ ਦੀ ਜਾਂਚ ਕਰੋ। NVMFG 0.1.1 'ਤੇ ਰਿਪੋਰਟ ਕੀਤੀ ਗਈ ਬਹਾਲੀ ਦੀ ਰੁਕਾਵਟ ਦਾ ਅਜੇ ਵੀ ਕੋਈ ਸਥਾਪਿਤ ਕਾਰਨ ਨਹੀਂ ਹੈ; ਇਸ ਦੇ ਜਰਨਲ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖੋ ਅਤੇ ਕਿਸੇ ਵੀ ਉਪਲਬਧ ਗਲਤੀ ਕੋਡ ਨੂੰ ਰਿਕਾਰਡ ਕਰੋ। NVRasterPulse 0.2, FPS ਨੂੰ ਮਾਪੇ ਬਿਨਾਂ, ਇਸਦੇ ਐਕਸ਼ਨ ਮੀਨੂ ਵਿੱਚ ਸੰਰਚਨਾ ਡਾਇਗਨੌਸਟਿਕਸ ਦੀ ਪੇਸ਼ਕਸ਼ ਕਰਦਾ ਹੈ।

## ਲੌਗਸ ਅਤੇ ਗੋਪਨੀਯਤਾ

| ਟੂਲ | ਸਮੀਖਿਆ ਕਰਨ ਲਈ ਸਥਾਨਕ ਡੇਟਾ, ਥੋਕ ਅਪਲੋਡ ਨਹੀਂ |
| --- | --- |
| NVDF | `%LOCALAPPDATA%\NVDriverForge`; ਸੁਰੱਖਿਅਤ ਨੌਕਰੀਆਂ `%PROGRAMDATA%\NVDriverForge\Jobs` |
| NVMFG | `%LOCALAPPDATA%\RtxMfg`; ਬੈਕਅੱਪ `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`; EXE ਦੇ ਕੋਲ `Sessions` |
| RP | `%LOCALAPPDATA%\NVRasterPulse`; ਇਸਦੇ ਹੇਠਾਂ `Backups\RTSS` |
| NVPI | ਤੁਹਾਡੇ ਚੁਣੇ ਹੋਏ ਨਿਰਯਾਤ ਅਤੇ ਪ੍ਰਦਰਸ਼ਿਤ ਗਲਤੀ; ਕੋਈ ਖੋਜਿਆ ਯੂਨੀਵਰਸਲ ਲੌਗ ਮਾਰਗ ਨਹੀਂ |

ਤੁਹਾਡੇ ਦੁਆਰਾ ਸਾਂਝੇ ਕੀਤੇ ਟੈਕਸਟ/ਚਿੱਤਰਾਂ ਤੋਂ ਖਾਤੇ ਦੇ ਨਾਮ, ਹੋਮ ਡਾਇਰੈਕਟਰੀਆਂ, ਗੇਮ-ਲਾਇਬ੍ਰੇਰੀ ਮਾਰਗ, ਡਿਵਾਈਸ ਪਛਾਣਕਰਤਾ, ਟੋਕਨ ਅਤੇ ਗੈਰ-ਸੰਬੰਧਿਤ ਵਿੰਡੋਜ਼ ਨੂੰ ਹਟਾਓ। ਰਿਕਵਰੀ ਲਈ ਮੂਲ ਨੂੰ ਨਿੱਜੀ ਤੌਰ 'ਤੇ ਰੱਖੋ। ਜਨਤਕ ਮੁੱਦੇ ਹਰ ਕਿਸੇ ਨੂੰ ਦਿਖਾਈ ਦਿੰਦੇ ਹਨ।

ਕਿਸੇ ਕਮਜ਼ੋਰੀ, ਖ਼ਤਰਨਾਕ ਵਿਸ਼ੇਸ਼ ਅਧਿਕਾਰ ਵਾਲੇ ਵਿਵਹਾਰ ਜਾਂ ਅਣਇੱਛਤ ਵਿਨਾਸ਼ਕਾਰੀ ਕਾਰਵਾਈ ਲਈ, ਜਨਤਕ ਤੌਰ 'ਤੇ ਵੇਰਵੇ ਪੋਸਟ ਕਰਨ ਦੀ ਬਜਾਏ [SECURITY.md](../SECURITY.md) ਦੀ ਪਾਲਣਾ ਕਰੋ।

## ਕੀ ਤਸਦੀਕ ਕੀਤਾ ਗਿਆ ਹੈ

ਹੱਬ ਦੀ ਤਿਆਰੀ ਲਈ, ਸਥਿਰ ਪੇਲੋਡ/ਜ਼ਿਪ/ਹੈਸ਼/ਮੇਟਾਡੇਟਾ ਸਕੈਨ ਅਤੇ ਦਸਤਾਵੇਜ਼ੀ ਜਾਂਚਾਂ ਚਲਾਈਆਂ ਗਈਆਂ ਸਨ। ਮੌਜੂਦਾ ਪ੍ਰਾਈਵੇਟ ਐਪਲੀਕੇਸ਼ਨ ਬਿਲਡ/ਯੂਨਿਟ/UI ਟੈਸਟ ਇਤਿਹਾਸਕ, ਮਿਤੀ ਸਬੂਤ ਹਨ। ਇਸ ਤਿਆਰੀ ਦੇ ਹਿੱਸੇ ਵਜੋਂ ਕੋਈ ਡਰਾਈਵਰ ਇੰਸਟਾਲ, ਡਿਸਪਲੇਅ ਬਦਲਾਅ, ਲਾਈਵ RTSS ਓਪਰੇਸ਼ਨ ਜਾਂ ਗੇਮ ਬੈਂਚਮਾਰਕ ਨਹੀਂ ਕੀਤਾ ਗਿਆ ਸੀ।

“ਖੋਜਿਆ ਗਿਆ”, “ਲਿਖਿਆ”, “ਰੀਲੋਡ ਕੀਤਾ ਗਿਆ”, “ਸਮਰੱਥਾ ਉਪਲਬਧ” ਅਤੇ “ਖੇਡ ਵਿੱਚ ਮਾਪੀ ਗਈ” ਵੱਖ-ਵੱਖ ਨਤੀਜੇ ਹਨ। ਰਿਪੋਰਟ ਕਰੋ ਕਿ ਤੁਸੀਂ ਕਿਸ ਨੂੰ ਦੇਖਿਆ ਹੈ।
