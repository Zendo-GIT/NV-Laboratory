## ਡਾਊਨਲੋਡ ਕਰੋ, ਪੁਸ਼ਟੀ ਕਰੋ, ਸਥਾਪਿਤ ਕਰੋ

1. ਚੁਣੀ ਗਈ ਪ੍ਰਕਾਸ਼ਿਤ ਰੀਲੀਜ਼ 'ਤੇ, ਇਸਦੀ ਨਾਮਿਤ ਐਪਲੀਕੇਸ਼ਨ ਸੰਪਤੀ, ਨੋਟਿਸ ZIP ਅਤੇ SHA256SUMS.txt ਨੂੰ ਡਾਊਨਲੋਡ ਕਰੋ।
2. [SHA-256 ਉਦਾਹਰਨ](downloads.md#sha-256) ਦੀ ਵਰਤੋਂ ਕਰੋ, ਅਸਲ ਡਾਊਨਲੋਡ ਕੀਤੀ ਫਾਈਲ ਨਾਮ ਦੇ ਨਾਲ।
3. ਸੈੱਟਅੱਪ ਲਈ, ਸਧਾਰਨ ਇੰਸਟਾਲਰ ਦੀ ਪਾਲਣਾ ਕਰੋ। ਪੋਰਟੇਬਲ ਜ਼ਿਪ ਲਈ, ਹਰ ਚੀਜ਼ ਨੂੰ ਇੱਕ ਨਵੇਂ ਸਥਾਨਕ ਲਿਖਣਯੋਗ ਫੋਲਡਰ ਵਿੱਚ ਐਕਸਟਰੈਕਟ ਕਰੋ; ਜ਼ਿਪ ਦੇ ਅੰਦਰੋਂ ਨਾ ਦੌੜੋ।
4. ਐਪਲੀਕੇਸ਼ਨ ਦਾ ਆਪਣਾ EXE ਖੋਲ੍ਹੋ। ਲਾਇਸੈਂਸ/ਸੰਰਚਨਾ/ਡਾਟਾ ਫਾਈਲਾਂ ਨਾਲ ਰੱਖੋ।
5. ਸੈਟਿੰਗਾਂ ਜਾਂ ਸਿਸਟਮ ਓਪਰੇਸ਼ਨਾਂ ਨੂੰ ਸਮਰੱਥ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਉਸ ਟੂਲ ਦੀ ਵਰਤੋਂ ਨਿਰਦੇਸ਼ ਪੜ੍ਹੋ।

ਵਰਤਮਾਨ ਬਾਈਨਰੀਆਂ ਹਸਤਾਖਰਿਤ ਨਹੀਂ ਹਨ। ਇੱਕ ਮੇਲ ਖਾਂਦਾ ਹੈਸ਼ ਸੰਭਾਵਿਤ ਬਾਈਟਾਂ ਦੀ ਪੁਸ਼ਟੀ ਕਰਦਾ ਹੈ; ਇਹ ਇੱਕ ਸੁਰੱਖਿਆ ਜਾਂ ਅਨੁਕੂਲਤਾ ਸਰਟੀਫਿਕੇਟ ਨਹੀਂ ਹੈ। ਸਿਰਫ਼ ਇੱਕ ਚੇਤਾਵਨੀ ਨੂੰ ਦਬਾਉਣ ਲਈ Windows ਸੁਰੱਖਿਆ ਸੁਰੱਖਿਆ ਨੂੰ ਅਯੋਗ ਨਾ ਕਰੋ।

NVDF ਜਾਂ ਇਸਦੇ ਵਿਕਲਪਿਕ NVPI ਸਾਥੀ ਨੂੰ ਸਥਾਪਤ ਕਰਨਾ GPU ਡਰਾਈਵਰ ਨੂੰ ਸਥਾਪਤ ਕਰਨ ਤੋਂ ਵੱਖਰਾ ਹੈ। NVPI ਸਾਥੀ ਆਪਣਾ ਮੌਜੂਦਾ ਅੰਦਰੂਨੀ ਇੰਸਟਾਲੇਸ਼ਨ ਨਾਮ ਰੱਖਦਾ ਹੈ। ਇਸਦੇ ਐਲੀਵੇਟਿਡ ਰਾਸਟਰਪਲਸ ਬਟਨ ਲਈ ਇੱਕ ਸੁਰੱਖਿਅਤ ਸਿਸਟਮ-ਵਿਆਪਕ ਸਥਾਪਨਾ ਦੀ ਲੋੜ ਹੈ; ਹੋਰ RP ਕਾਪੀਆਂ ਉਹਨਾਂ ਦੇ ਆਪਣੇ ਸ਼ਾਰਟਕੱਟ ਦੁਆਰਾ ਖੋਲ੍ਹੀਆਂ ਜਾ ਸਕਦੀਆਂ ਹਨ।

NVMFG ਪ੍ਰਯੋਗਾਤਮਕ ਹੈ ਅਤੇ ਇਸ ਵਿੱਚ [ਦਸਤਾਵੇਜ਼ੀ NVIDIA SDK ਲਾਇਸੰਸਿੰਗ ਰਿਜ਼ਰਵ](provenance.md) ਹੈ। ਕੋਈ NVIDIA ਡਰਾਈਵਰ, NGX ਪ੍ਰਦਾਤਾ/ਮਾਡਲ ਜਾਂ ਗੇਮ Streamline ਰਨਟਾਈਮ ਸ਼ਾਮਲ ਨਹੀਂ ਹੈ। ਚੁਣੇ ਗਏ SDK ਡਾਉਨਲੋਡਸ ਅਤੇ ਗੇਮ ਅੱਪਡੇਟ ਸਪੱਸ਼ਟ ਤੌਰ 'ਤੇ ਵੱਖਰੇ ਓਪਰੇਸ਼ਨ ਹਨ।

## ਭਾਸ਼ਾ ਅਤੇ ਅੱਪਡੇਟ

ਦਸਤਾਵੇਜ਼ਾਂ ਲਈ README ਦੇ 34-ਭਾਸ਼ਾ ਚੋਣਕਾਰ ਦੀ ਵਰਤੋਂ ਕਰੋ। NVDF, NVMFG ਅਤੇ RP ਦੀ ਆਪਣੀ 34-ਭਾਸ਼ਾ UI ਸੈਟਿੰਗ ਹੈ; NVPI ਆਪਣਾ ਮੌਜੂਦਾ ਭਾਸ਼ਾ ਸਮਰਥਨ ਰੱਖਦਾ ਹੈ। ਕੁਝ ਇੰਸਟੌਲਰ ਤਕਨੀਕੀ ਸਤਰ ਅੰਗਰੇਜ਼ੀ ਵਿੱਚ ਵਾਪਸ ਆਉਂਦੇ ਹਨ।

ਅੱਪਡੇਟ ਕਰਨ ਵੇਲੇ ਇੱਕ ਟੂਲ ਦੀ ਇੰਸਟਾਲੇਸ਼ਨ ਪਛਾਣ ਰੱਖੋ। ਪਹਿਲਾਂ ਇਸਨੂੰ ਬੰਦ ਕਰੋ ਅਤੇ ਬੈਕਅੱਪ ਸੁਰੱਖਿਅਤ ਕਰੋ। NVMFG ਲਈ, ਪ੍ਰਭਾਵਿਤ ਗੇਮਾਂ ਨੂੰ ਬੰਦ ਕਰੋ ਅਤੇ ਲੰਬਿਤ ਪ੍ਰੋਫਾਈਲ ਰਿਕਵਰੀ ਨੂੰ ਹੱਲ ਕਰੋ। ਪੋਰਟੇਬਲ ਅੱਪਡੇਟ ਲਈ, ਰੀਲੀਜ਼ਾਂ ਨੂੰ ਜੋੜਨ ਦੀ ਬਜਾਏ ਇੱਕ ਤਾਜ਼ਾ ਫੋਲਡਰ ਦੀ ਵਰਤੋਂ ਕਰੋ।

## ਇੱਕ ਸੰਦ ਨੂੰ ਹਟਾਉਣਾ

ਕਿਸੇ ਐਪਲੀਕੇਸ਼ਨ ਨੂੰ ਅਣਇੰਸਟੌਲ ਕਰਨਾ ਇਸ ਦੀਆਂ ਸੈਟਿੰਗਾਂ ਨੂੰ ਆਪਣੇ ਆਪ ਅਨਡੂ ਨਹੀਂ ਕਰ ਰਿਹਾ ਹੈ।

- **NVPI:** ਲੋੜ ਪੈਣ 'ਤੇ ਹਟਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਉਦੇਸ਼ਿਤ ਪ੍ਰੋਫਾਈਲਾਂ/ਡਿਸਪਲੇ ਸੈਟਿੰਗਾਂ ਨੂੰ ਬਹਾਲ ਕਰੋ।
- **NVDF:** ਜੇਕਰ ਤੁਸੀਂ ਉੱਨਤ/NVENC ਤਬਦੀਲੀਆਂ ਨੂੰ ਬਹਾਲ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ ਤਾਂ ਪਹਿਲਾਂ ਰਿਕਵਰੀ ਦੀ ਵਰਤੋਂ ਕਰੋ। Uninstall ਗ੍ਰਾਫਿਕਸ ਡਰਾਈਵਰ, ਸੈਟਿੰਗਾਂ ਅਤੇ ਬੈਕਅੱਪ ਛੱਡਦਾ ਹੈ।
- **NVMFG:** ਗੇਮਾਂ ਨੂੰ ਬੰਦ ਕਰੋ, ਕੰਟਰੋਲਰ ਨੂੰ ਅਯੋਗ/ਛੱਡੋ, NVIDIA ਰਿਕਵਰੀ ਨੂੰ ਹੱਲ ਕਰੋ ਅਤੇ ਹਟਾਉਣ ਤੋਂ ਪਹਿਲਾਂ ਲੋੜੀਂਦੀ ਗੇਮ SDK ਬੈਕਅੱਪ ਨੂੰ ਬਹਾਲ ਕਰੋ।
- **RP:** ਪਹਿਲਾਂ ਇੱਛਤ ਲਿਮਿਟਰ ਓਵਰਰਾਈਡਾਂ ਨੂੰ ਹਟਾਓ। Uninstall ਸੁਰੱਖਿਅਤ ਕੀਤੇ RTSS ਕੈਪਸ ਨੂੰ ਨਹੀਂ ਮਿਟਾਉਂਦਾ ਹੈ ਜਾਂ RTSS ਨੂੰ ਨਹੀਂ ਹਟਾਉਂਦਾ ਹੈ।

ਸਟੀਕ ਡੇਟਾ ਟਿਕਾਣਿਆਂ ਅਤੇ ਸੀਮਾਵਾਂ ਲਈ ਹਰੇਕ [ਪ੍ਰੋਜੈਕਟ ਗਾਈਡ](../README.md#projects), ਜਾਂ [ਸਮਰਥਨ](support.md) ਨੂੰ ਦੇਖੋ ਜੇਕਰ ਕੋਈ ਰਿਕਵਰੀ ਕਦਮ ਅਸਫਲ ਹੁੰਦਾ ਹੈ।
