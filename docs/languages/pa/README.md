# NV Laboratory

**禅堂 Zendo (RevoluSound Team) ਦੁਆਰਾ NV Tools।** NVIDIA ਡਰਾਈਵਰ ਪ੍ਰੋਫਾਈਲਾਂ, ਡਰਾਈਵਰ ਸਥਾਪਨਾ, ਪ੍ਰਯੋਗਾਤਮਕ Multi Frame Generation ਅਤੇ RTSS ਫਰੇਮ ਸੀਮਾਵਾਂ ਲਈ ਚਾਰ ਸੁਤੰਤਰ Windows ਉਪਯੋਗਤਾਵਾਂ।

[ਸੰਦ ਪ੍ਰਾਪਤ ਕਰੋ](docs/downloads.md) · [ਇੰਸਟਾਲੇਸ਼ਨ](docs/installation.md) · [ਅਨੁਕੂਲਤਾ ਅਤੇ ਮਦਦ](docs/support.md) · [ਕ੍ਰੈਡਿਟ ਅਤੇ ਲਾਇਸੰਸ](THIRD_PARTY_NOTICES.md)

> **NVRasterPulse ਨੂੰ RTSS ਦੀ ਲੋੜ ਹੈ।** ਪਹਿਲਾਂ [Guru3D ਤੋਂ RivaTuner Statistics Server](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) ਨੂੰ ਸਥਾਪਿਤ ਕਰੋ। RTSS ਇਸ ਦੀਆਂ FPS ਸੀਮਾਵਾਂ ਦੇ ਕੰਮ ਕਰਨ ਲਈ ਚੱਲ ਰਿਹਾ ਹੋਣਾ ਚਾਹੀਦਾ ਹੈ। ਇਸ ਨੂੰ ਵੱਖਰੇ ਤੌਰ 'ਤੇ ਡਾਊਨਲੋਡ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।

## ਇੱਥੇ ਸ਼ੁਰੂ ਕਰੋ

1. ਉੱਪਰ ਇੱਕ ਟੂਲ ਚੁਣੋ। ਹਰ ਇੱਕ ਸੁਤੰਤਰ ਤੌਰ 'ਤੇ ਕੰਮ ਕਰਦਾ ਹੈ; ਪੂਰੇ ਸੂਟ ਨੂੰ ਸਥਾਪਿਤ ਕਰਨਾ ਬੇਲੋੜਾ ਹੈ।
2. ਇਸਦੀਆਂ ਲੋੜਾਂ ਨੂੰ ਪੜ੍ਹੋ ਅਤੇ ਇੱਕ ਸਥਾਪਿਤ ਐਪ ਲਈ **ਸੈੱਟਅੱਪ**, ਜਾਂ ਇੱਕ ਵੱਖਰੇ ਫੋਲਡਰ ਲਈ **ਪੋਰਟੇਬਲ** ਚੁਣੋ।
3. ਜਦੋਂ ਇਸਦੀ ਰੀਲੀਜ਼ ਪ੍ਰਕਾਸ਼ਿਤ ਹੋ ਜਾਂਦੀ ਹੈ, ਨਾਮਿਤ ਐਪਲੀਕੇਸ਼ਨ ਸੰਪਤੀ ਨੂੰ ਡਾਉਨਲੋਡ ਕਰੋ, ਨਾਲ ਦਿੱਤੇ ਨੋਟਿਸਾਂ ਨੂੰ ਪੜ੍ਹੋ ਅਤੇ ਇਸਦੇ SHA-256 ਦੀ ਤੁਲਨਾ ਕਰੋ।
4. ਡਰਾਈਵਰ, ਡਿਸਪਲੇ ਸੈਟਿੰਗ, NVIDIA ਪ੍ਰੋਫਾਈਲ ਜਾਂ ਗੇਮ ਰਨਟਾਈਮ ਬਦਲਣ ਤੋਂ ਪਹਿਲਾਂ ਬੈਕਅੱਪ ਰੱਖੋ।

ਹਰੇਕ ਗਾਈਡ ਦੇ ਸਿਖਰ 'ਤੇ ਚੋਣਕਾਰ ਦੁਆਰਾ NV ਐਪਲੀਕੇਸ਼ਨਾਂ ਦੇ ਰੂਪ ਵਿੱਚ ਦਸਤਾਵੇਜ਼ੀ 34 ਭਾਸ਼ਾਵਾਂ ਵਿੱਚ ਉਪਲਬਧ ਹੈ। GitHub ਬ੍ਰਾਊਜ਼ਰ ਭਾਸ਼ਾ ਦੁਆਰਾ ਆਪਣੇ ਆਪ ਇੱਕ README ਦੀ ਚੋਣ ਨਹੀਂ ਕਰਦਾ ਹੈ। ਦਸਤਾਵੇਜ਼ੀ ਭਾਸ਼ਾ ਅਤੇ ਐਪਲੀਕੇਸ਼ਨ ਦੀ ਆਪਣੀ ਭਾਸ਼ਾ ਸੈਟਿੰਗ ਵੱਖਰੀ ਹੈ।

<a id="provenance-and-ownership"></a>
## ਉਤਪਤੀ ਅਤੇ ਮਲਕੀਅਤ

ਇਹ ਹੱਬ ਦਸਤਾਵੇਜ਼ਾਂ ਅਤੇ ਕੰਪਾਇਲ ਕੀਤੀਆਂ ਐਪਲੀਕੇਸ਼ਨਾਂ ਨੂੰ ਵੰਡਦਾ ਹੈ। ਐਪਲੀਕੇਸ਼ਨ ਸਰੋਤ ਕੋਡ ਨੂੰ ਨਿੱਜੀ ਤੌਰ 'ਤੇ ਰੱਖਿਆ ਜਾਂਦਾ ਹੈ। ਅੱਪਸਟਰੀਮ ਪ੍ਰੋਜੈਕਟਾਂ ਨੇ ਆਪਣੀ ਲੇਖਕਤਾ ਅਤੇ ਲਾਇਸੰਸ ਬਰਕਰਾਰ ਰੱਖੇ ਹਨ; ਨਿੱਜੀ ਸਰੋਤ ਵੰਡ ਉਹਨਾਂ ਸ਼ਰਤਾਂ ਨੂੰ ਨਹੀਂ ਬਦਲਦੀ।

- Profile Inspector fork ਨੇ Orbmu2k ਦਾ MIT ਲਾਇਸੰਸ ਬਰਕਰਾਰ ਰੱਖਿਆ ਹੈ ਅਤੇ ਸਪੱਸ਼ਟ ਤੌਰ 'ਤੇ fork ਵਜੋਂ ਪਛਾਣਿਆ ਗਿਆ ਹੈ।
- NVDriverForge ਦੀਆਂ ਆਪਣੀਆਂ ਬਾਈਨਰੀ ਵੰਡ ਸ਼ਰਤਾਂ ਹਨ ਅਤੇ ਇਸ ਵਿੱਚ ਵੱਖਰੇ ਤੌਰ 'ਤੇ ਲਾਇਸੰਸਸ਼ੁਦਾ ਰਨਟਾਈਮ/ਟੂਲ ਕੰਪੋਨੈਂਟ ਸ਼ਾਮਲ ਹਨ।
- NVMFG Unlock40 ਇੱਕ ਸੁਤੰਤਰ ਤੌਰ 'ਤੇ ਵਿਕਸਤ ਐਪਲੀਕੇਸ਼ਨ ਹੈ। ਤੁਲਨਾ ਅਤੇ ਸੁਧਾਰ ਲਈ RTX40MFG-Unlock ਦੀ ਸਲਾਹ ਲਈ ਗਈ ਸੀ; ਸਾਂਝੇ ਮੂਲ ਹਿੱਸੇ ਆਪਣੇ MIT ਕ੍ਰੈਡਿਟ ਬਰਕਰਾਰ ਰੱਖਦੇ ਹਨ। MinHook ਅਤੇ NVIDIA SDK ਦੀਆਂ ਸ਼ਰਤਾਂ ਵੱਖਰੀਆਂ ਹਨ।
- NVRasterPulse ਸਪਲਾਈ ਕੀਤੇ MIT ਲਾਇਸੰਸ ਨੂੰ ਬਰਕਰਾਰ ਰੱਖਦਾ ਹੈ ਅਤੇ Profile Inspector-ਪ੍ਰਾਪਤ UI ਨੂੰ ਕ੍ਰੈਡਿਟ ਕਰਦਾ ਹੈ। RTSS ਇੱਕ ਲੋੜੀਂਦਾ ਬਾਹਰੀ ਪ੍ਰੋਗਰਾਮ ਹੈ।

[ਪੂਰੀ ਭਾਗ ਸਾਰਣੀ](THIRD_PARTY_NOTICES.md), [ਫਾਈਲ ਪ੍ਰੋਵੇਨੈਂਸ ਅਤੇ ਬਦਲਾਅ](docs/provenance.md), ਅਤੇ [ਲਾਇਸੰਸ ਦਾ ਘੇਰਾ](../../../LICENSE) ਦੇਖੋ।
