# Přispívání

NV Laboratory je spravován 禅堂 Zendo (RevoluSound Team). Správce rozhoduje o tom, co bude přijato a uvolněno. Otevření žádosti o vydání nebo stažení neznamená, že je příspěvek přijat nebo povolen k distribuci.

Použijte formulář chyby nebo funkce a identifikujte program/verzi. Nejprve vyhledejte existující problémy. Před přípravou velkého příspěvku prodiskutujte podstatné změny. Pokud jde o bezpečnostní záležitosti, postupujte podle [SECURITY.md](SECURITY.md).

Toto veřejné centrum obsahuje dokumentaci, upozornění, metadata vydání a ověření úložiště. Zdroj aplikace a testy jsou spravovány soukromě. Neodesílejte dekompilovaný kód, soukromý zdroj, přihlašovací údaje, uživatelské profily nebo spustitelné datové části.

Dokumentace PR by měla udržovat 34 jazykové protějšky a navigaci zarovnané, zachovávat názvy příkazů/souborů/produktů a popisovat skutečné chování. Nové snímky obrazovky musí být vaše vlastní, s identifikací verze a bez osobních údajů; syntetické údaje musí být označeny. U každého nového díla třetí strany uveďte původ a povolení.

Používejte UTF-8, LF, čitelný Markdown a malé cílené změny. Validátor Python používá pouze standardní knihovnu. Přizpůsobte jeho stávajícímu stylu, vyhněte se zbytečným závislostem a spusťte:

```text
python tools/validate_repository.py
```

Pro změny metadat vydání zahrňte přesnou verzi/značku, velikosti souborů a SHA-256 z auditovaných binárních souborů a udržujte stránky ke stažení zarovnané. Změny aplikací vyžadují soukromé sestavení/testy vhodné pro ovlivněné chování; kontrola dokumentace není test aplikace. Nikdy si nevymýšlejte historické výsledky testů nebo zisky.

Přispěním originálního materiálu rozbočovače souhlasíte s jeho rozsahem licence MIT v [LICENCE](../../../LICENSE). Uchovávejte upozornění třetích stran a identifikujte své změny; nenahrazují upstream licenci. Přijetí a zveřejnění zůstávají rozhodnutími správce.
