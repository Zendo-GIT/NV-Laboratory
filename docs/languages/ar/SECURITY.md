# الأمن

تغطي هذه السياسة حزم تطبيق NV Tools ومركز التوزيع هذا. يقوم المشرف بإعطاء الأولوية للتقارير التي تؤثر على أحدث إصدار منشور لكل أداة. المرشحين المجهزين ليسوا إصدارًا ثابتًا مدعومًا معلنًا. لا يتم الوعد بموعد نهائي للرد أو شهادة أمنية.

<a id="report-privately"></a>
## الإبلاغ على القطاع الخاص

بالنسبة للثغرات الأمنية، أو السلوك المرتفع غير الآمن، أو التغييرات المدمرة غير المقصودة، أو التعرض للبيانات الحساسة، استخدم ميزة **الأمان → Report a vulnerability** الخاصة بالمستودع **عند تمكينها**: [تقرير خاص](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new).

**الإعداد الأولي:** يجب على المشرف تمكين الإبلاغ عن الثغرات الأمنية الخاصة بعد إنشاء المستودع العام. لا يقوم هذا الملف بتمكينه، ولا تتم المطالبة بوجود أي صندوق بريد أو قناة خاصة قبل ذلك الوقت.

إذا كان الزر غير متاح، فافتح إصدارًا عامًا يحتوي فقط على: "أحتاج إلى قناة اتصال خاصة للحصول على تقرير أمني يتعلق بـ [الأداة/الإصدار]". لا تقم بتضمين تفاصيل الاستغلال أو بيانات الاعتماد أو المسارات المتأثرة أو السجلات أو المرفقات. انتظر حتى يقوم المشرف بتوفير قناة خاصة قبل مشاركتها.

في التقرير الخاص، قم بتضمين الأداة/الإصدار والتجزئة، وإصدارات Windows/GPU/برنامج التشغيل، والتأثير، والحد الأدنى من النسخ الآمن، وما إذا كانت هناك حاجة إلى الاسترداد. تنقيح الأسرار والبيانات الشخصية؛ الحفاظ على ملفات الاسترداد المحلية. لا تقم بتحميل برنامج تشغيل خاص أو ملفات DLL الخاصة باللعبة. تنسيق الإفصاح مع المشرف؛ يتطلب التصحيح/الإصدار المراجعة وليس تلقائيًا.


[GitHub وثائق التقارير الخاصة](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
