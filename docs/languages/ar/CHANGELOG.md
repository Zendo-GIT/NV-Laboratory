# سجل التغيير

يتبع هذا المحور [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). تصف الإدخالات هذا المستودع؛ إصدارات التطبيق مستقلة.

<a id="unreleased"></a>
## [غير منشورة]

<a id="added"></a>
### تمت الإضافة

- Hub وأدلة المشروع الكاملة ووثائق المستودع بـ 34 لغة تطبيق NV.
- محددات اللغة التي تحافظ على الصفحة، والبيانات الوصفية لتغطية الترجمة، والمثبتات الداخلية المستقرة.
- الاعتمادات الأولية والإشعارات الكاملة المعمول بها ومصدر الملف.
- متطلبات RTSS ورابط التنزيل الرسمي لـ NVRasterPulse.
- روابط RevoluSound Team منفصلة.
- تم إعداد كتالوج حزمة الإصدار الأول والتحقق من SHA-256 وإجراءات الإصدار اليدوي.
- نماذج الأخطاء/الميزات والمساهمة والتعليمات الأمنية.
- وثائق للقراءة فقط وفحوصات حدود النشر.

<a id="changed"></a>
### تغيرت

- إن إسناد NVMFG يميز الآن التطبيق الذي تم تطويره بشكل مستقل،
مرجع المقارنة/التحسين، والمكونات الأصلية المشتركة الفعلية.   تظل حقوق النشر والتراخيص ومقارنات الملفات الحالية سليمة.
- تم تحديث مرشح NVDriverForge إلى 0.1.3: تصحيح معالجة المكونات الاختيارية،
حالات فشل محلية قابلة للقراءة ووقت تشغيل محدث/حزمة مصاحبة.

<a id="fixed"></a>
### ثابت

- تعرض مراجعة الإعداد NVIDIA Profile Inspector – NV Tools Fork 2 الآن الملفات المشتركة
محدد 34 لغة عند إطلاقه مباشرة. يتم الحفاظ على اللغة الصريحة وإعادة التوجيه الصامت؛ المحرر والحزمة المحمولة لم تتغير.

لم يتم إعادة بناء أي تواريخ إصدار عامة تاريخية. إصدارات التطبيق المرشح هي 3.0.2.3 و0.1.3 و0.1.1 و0.1؛ يتم إرفاق ملاحظات الإصدار الخاصة بهم بإصداراتهم المستقبلية. التحضير بتاريخ 09-09-2026 ليس تاريخ إصدار GitHub.
