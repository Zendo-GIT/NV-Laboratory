<a id="compatibility-and-troubleshooting"></a>
# التوافق واستكشاف الأخطاء وإصلاحها

هؤلاء هم المرشحون المجهزون، وليسوا مصفوفة اعتماد لجميع مجموعات Windows وGPU وبرامج التشغيل والألعاب.

| أداة | Windows / وقت التشغيل | الأجهزة / التبعية الخارجية | العمليات التي تحتاج إلى رعاية |
| --- | --- | --- | --- |
| NVPI fork 3.0.2.3 | Windows 10/11 x64، .NET Framework 4.8 | برنامج تشغيل/شاشة NVIDIA متوافق | يكتب الملف الشخصي ويعرض المعاينات |
| NVDriverForge 0.1.2 | Windows 10 الإصدار 19041+ / 11 x64; تم تضمين .NET/WPF | حزمة برامج التشغيل المتوافقة مع NVIDIA | تثبيت مرتفع، إعدادات متقدمة، NVENC اختياري |
| NVMFG Unlock40 0.1.1 | Windows 10/11x64; تم تضمين ‎.NET/WPF، ومساعدي Framework 4.8 | RTX 40، لعبة DLSS FG المؤهلة والمزود المثبت | التصحيح الأصلي داخل اللعبة، ومجلة الملفات الشخصية العالمية، وتحديثات اللعبة SDK |
| NVRasterPulse 0.1 | Windows 10/11 x64، .NET Framework 4.8 | تم تثبيت RTSS؛ الركض للقبعات | RTSS تغييرات ملف التعريف القابلة للتنفيذ |

لم يتم إعداد حزمة ARM64. يمكن أن يؤدي توفر العرض/واجهة برمجة التطبيقات (API) وإصدارات Windows القديمة إلى تقييد الميزات الفردية. لم يتم اختراع إصدار الحد الأدنى العالمي NVIDIA أو RTSS. تجزئة موفر NVMFG الدقيق موجودة في [المصدر](provenance.md).

<a id="before-reporting-a-bug"></a>
## قبل الإبلاغ عن الخلل

حدد الملف القابل للتنفيذ/الإصدار الدقيق الذي فتحته. النسخة المثبتة السابقة ليست بالضرورة نسخة ZIP التي تم تنزيلها حديثًا. سجل خطوات الاستنساخ والنتيجة المتوقعة والنتيجة الفعلية. بالنسبة لمشكلات العرض/التحديد، قم بتضمين إصدار اللعبة وتحديث العرض وحالة FG/V-Sync/VRR وأي محدد أو تراكب آخر.

استخدم [نموذج الخلل](https://github.com/Zendo-GIT/NV-Laboratory/issues/new?template=bug-report.yml). لا تقم مطلقًا بإرفاق مجلد تطوير خاص بالكامل أو أرشيف برنامج التشغيل أو النموذج أو ملف DLL الخاص باللعبة أو تفريغ التسجيل أو مجموعة السجلات غير المراجعة.

| مشكلة | الشيكات الأولى |
| --- | --- |
| إصدار التطبيق خاطئ | تأكيد هوية EXE وتحرير التجزئة؛ أغلق النسخة القديمة قبل الاستبدال. |
| خطأ في وقت التشغيل/بدء التشغيل | قم بتثبيت Framework 4.8 المطلوب أو احتفظ بجميع المجلدات الفرعية المحمولة المتوفرة. |
| تم إلغاء UAC | أعد محاولة العملية المقصودة فقط؛ الإلغاء ليس التثبيت الناجح. |
| عدم تطابق التجزئة/التوقيع | توقف عن استخدام هذا المرشح واحصل على البايتات الرسمية المتوقعة. |
| تم رفض اللون/الوضع NVPI | ارجع واستخدم مجموعة مدعومة من العرض/برنامج التشغيل الفعلي. |
| فشل النسخ الاحتياطي أو الاسترداد NVDF | الحفاظ على المهمة المحمية وRECOVERY.txt؛ لا تقم بمسح المجلة أو فرض عمليات الكتابة المتضاربة. |
| إعدادات NVMFG المعلقة | حل مشكلة الاسترداد مع إغلاق الألعاب، مع الحفاظ على التغييرات من الأدوات الأخرى. |
| غطاء RP ليس له أي تأثير | قم بتشغيل RTSS، وحدد ملف EXE للعبة الحقيقية، وافحص حالة الخطاف وحدود المنافسة. |
| يستمر غطاء RP بعد الإزالة | فحص RTSS عالميًا؛ إزالة التغييرات تجاوزات المحدد المحلي فقط. |

<a id="logs-and-privacy"></a>
## السجلات والخصوصية

| أداة | البيانات المحلية للمراجعة، وليس تحميلها بالجملة |
| --- | --- |
| NVDF | `%LOCALAPPDATA%\NVDriverForge`; الوظائف المحمية `%PROGRAMDATA%\NVDriverForge\Jobs` |
| نفمفج | `%LOCALAPPDATA%\RtxMfg`; النسخ الاحتياطية `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`؛ `Sessions` بجانب EXE |
| RP | `%LOCALAPPDATA%\NVRasterPulse`; `Backups\RTSS` تحته |
| NVPI | الصادرات التي اخترتها والخطأ المعروض؛ لا يوجد مسار سجل عالمي مخترع |

قم بإزالة أسماء الحسابات والدلائل الرئيسية ومسارات مكتبة الألعاب ومعرفات الأجهزة والرموز المميزة والنوافذ غير ذات الصلة من النص/الصور التي تشاركها. احتفظ بالنسخ الأصلية بشكل خاص لاستردادها. القضايا العامة مرئية للجميع.

بالنسبة لثغرة أمنية أو سلوك مميز خطير أو عملية تدميرية غير مقصودة، اتبع [SECURITY.md](../SECURITY.md) بدلاً من نشر التفاصيل علنًا.

<a id="what-has-been-verified"></a>
## ما تم التحقق منه

لإعداد المحور، تم إجراء عمليات فحص الحمولة الثابتة/الرمز البريدي/التجزئة/بيانات التعريف والتحقق من الوثائق. تعد اختبارات إنشاء/وحدة/واجهة المستخدم الخاصة بالتطبيقات الخاصة بمثابة أدلة تاريخية ومؤرخة. لم يتم إجراء أي تثبيت لبرنامج التشغيل أو تغيير العرض أو التشغيل المباشر لـ RTSS أو قياس أداء اللعبة كجزء من هذا الإعداد.

"تم الاكتشاف" و"مكتوب" و"إعادة التحميل" و"القدرة المتاحة" و"التي تم قياسها في اللعبة" هي نتائج مختلفة. قم بالإبلاغ عن أي واحد لاحظته.
