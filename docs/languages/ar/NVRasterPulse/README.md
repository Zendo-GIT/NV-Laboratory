# NVRasterPulse

**حدود FPS لكل تطبيق حتى RivaTuner Statistics Server.**

> **قم بتثبيت RTSS أولاً.** يتطلب NVRasterPulse [RivaTuner Statistics Server (RTSS)، تم تنزيله من Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/). يجب تشغيل RTSS لفرض الحدود. لم يتم تضمين أي مثبت RTSS أو ربط DLL أو SDK.

[تنزيل 0.2 والحالة](../docs/downloads.md#nvrasterpulse) · [التثبيت](#installation) · [كيف تعمل الحدود](#usage) · [الترخيص](../../../../NVRasterPulse/LICENSE)

<a id="overview-and-purpose"></a>
## نظرة عامة والغرض

NVRasterPulse عبارة عن واجهة Windows مدمجة لإدارة حدود إطار RTSS حسب الاسم القابل للتنفيذ. يقوم RTSS بإجراء التحديد. يدير NVRasterPulse قيم ملف التعريف المقابلة والنسخ الاحتياطية وطلبات إعادة التحميل، مع الوصول إلى الدرج والاختيارات المستمرة.

إنه موجود لتسهيل تعديل الحدود الدقيقة لكل لعبة دون استبدال ملف تعريف RTSS بالكامل أو إزعاج إعدادات التراكب الخاصة به. يضيف الإصدار **0.2** تشخيصات التكوين ومساعد FPS والإيقاف المؤقت والتراجع ومشاركة ملف التعريف.

<a id="features"></a>
## الميزات

- حدد تطبيقًا قيد التشغيل أو قم بإضافة الملف القابل للتنفيذ يدويًا.
- احفظ حدود FPS من 1 إلى 1000، مع ما يصل إلى ثلاث منازل عشرية.
- التشفير المنطقي الدقيق للقيم المدخلة: 59.94 يصبح 2997/50.
- تكوين Front Edge Sync (`SyncLimiter=1`) مع الانتظار النشط (`PassiveWait=0`).
- تحديثات الملف الشخصي القابلة للتنفيذ والنسخ الاحتياطي التلقائي والكتابة الذرية.
- إزالة تجاوزات المحددات مع الاحتفاظ بمحتوى الملف الشخصي الآخر.
- اكتشاف تثبيت RTSS واختيار المسار يدويًا والتشغيل/إعادة التحميل الصريح.
- تشغيل علبة مثيل واحد، بدء تشغيل اختياري مثبت، 34 لغة وأربعة سمات.
- إجراءات منفصلة للإنهاء العادي و**Quit + RTSS**.

<a id="compatibility"></a>
## التوافق

| المتطلبات | التفاصيل |
| --- | --- |
| النظام | Windows 10/11 x64 |
| وقت التشغيل | [إطار عمل صافي 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48)، يتم تثبيته بشكل منفصل إذا لزم الأمر |
| البرامج المطلوبة | RTSS مع `RTSS.exe` ودليل `Profiles` المطابق ودعم ملف التعريف/إعادة التحميل المتوافق |
| GPU | التوافق مع RTSS يحدد المحدد؛ لا يتطلب مدير ملف التعريف هذا إنشاء RTX معينًا |
| الأذونات | يطلب التطبيق الحالي وصول المسؤول؛ يجب أن يكون مجلد ملف التعريف RTSS المحدد قابلاً للوصول |
| العاب | يعتمد على دعم الربط RTSS والقيود الخاصة بكل لعبة؛ لا يوجد ضمان لمكافحة الغش |

لم يتم اعتماد أي إصدار أدنى محدد لـ RTSS لكل وظيفة من خلال تدقيق المحور هذا. استخدم التوزيع الحالي الرسمي وأبلغ عن الإصدار الدقيق إذا لم يعمل مفتاح الملف الشخصي/إعادة التحميل. يجتاز RTSS المثبت ولكن المتوقف فحص التثبيت؛ يجب بعد ذلك البدء في الحد الفعلي.

<a id="installation"></a>
## التثبيت

1. **[قم بتنزيل وتثبيت RTSS من Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/).**
2. افتح [التنزيلات NVRasterPulse](../docs/downloads.md#nvrasterpulse) وتحقق من توفر الإصدار.
3. قم بتنزيل `NVRasterPulse-0.2-win-x64-Setup.exe` أو `NVRasterPulse-0.2-win-x64-portable.zip`، بالإضافة إلى الإشعارات/المجموع الاختباري.
4. قارن SHA-256. قم بتشغيل برنامج الإعداد أو قم باستخراج ملف ZIP المحمول بالكامل إلى مجلد محلي قابل للكتابة.
5. افتح `NVRasterPulse.exe`. إذا كان RTSS مفقودًا، استخدم **تنزيل RTSS**، ثم قم بتثبيته، ثم **تحقق مرة أخرى**، أو حدد `RTSS.exe` يدويًا.
6. ابدأ تشغيل RTSS باستخدام الاختصار العادي الخاص به أو باستخدام زر NVRasterPulse الخاص بـ RTSS إذا تم إيقافه.

لا يؤدي إيقاف تشغيل التذكير الاختياري إلى تخطي التحقق من المتطلبات الأساسية. ينتظر بدء تشغيل درج Windows الصامت حتى تفتح النافذة الرئيسية قبل عرض هذا الفحص. يقوم الإعداد بتثبيت NVRasterPulse فقط. ملفات EXE الخاصة بها غير موقعة.

<a id="usage"></a>
## الاستخدام

1. حدد التطبيق قيد التشغيل المقصود أو انتقل إلى لعبته EXE.
2. أدخل حدًا يتراوح بين 1 و1000 FPS، بما في ذلك قيمة كسرية إذا لزم الأمر.
3. احفظ وتحقق من النتيجة المبلغ عنها. يقوم NVRasterPulse بتحديث ملف تعريف RTSS القابل للتنفيذ ويطلب إعادة التحميل.
4. تأكد من تشغيل RTSS وتحقق من السلوك في اللعبة المقصودة.

يتم تحديد الملفات الشخصية بواسطة **اسم قابل للتنفيذ**، مثل `Game.exe.cfg`. هناك مجلدان مختلفان يحتويان على `Game.exe` يشتركان في نفس ملف تعريف RTSS؛ تخزين المسار الكامل لا يزيل هذا الاصطدام.

يستخدم الحفظ Front Edge Sync والانتظار النشط. قد يؤدي الانتظار النشط إلى زيادة استخدام CPU. يتم تحييد حقول `LimitTime` البديلة. يتم الاحتفاظ بالتعليقات الموجودة وإعدادات التراكب و`EnableHooking=0`. لم يتم تغيير ملف التعريف العام RTSS.

استخدم إجراء المهملات لإزالة تجاوزات محددات NVRasterPulse. ولا يحذف ملف تعريف RTSS بالكامل. قد يستمر تطبيق الحد الموروث من RTSS Global أو أداة أخرى بعد ذلك.

**الإغلاق والخروج:** يمكن إخفاء النافذة الرئيسية في الدرج. عادي **Quit** يترك RTSS قيد التشغيل والحدود المحفوظة سليمة. يطلب **Quit + RTSS** إغلاقًا عاديًا لعملية RTSS المطابقة في الجلسة الحالية، وينتظر ما يصل إلى ثماني ثوانٍ ولا يوقفها بالقوة. تظل الحدود المخزنة في كلتا الحالتين.

يتم تحديد اللغة والموضوع في التطبيق. يعد بدء التشغيل عند تسجيل الدخول Windows اختياريًا ومخصصًا للنسخة المثبتة. يشرح زر المعلومات الإجراءات الشائعة.

<a id="diagnostics-and-profile-tools"></a>
## أدوات التشخيص والملف الشخصي

افتح قائمة الإجراءات للأدوات الإضافية. إنها تحافظ على RTSS Global وإعدادات التراكب والاستثناءات.

**التشخيصات:** فحص الحدود المحلية/الفعالة، وإيقاف RTSS، والملف القابل للتنفيذ المفقود، وعدم اكتشاف نافذة، والربط المعطل، والوراثة، والحدود المتوقفة مؤقتًا، والإعدادات المتنافسة، والأسماء القابلة للتنفيذ المكررة. يصف هذا الاختيار للقراءة فقط التكوين؛ لا يثبت أن اللعبة مرتبطة بـ RTSS أو تقيس FPS الخاص بها.

**مساعد FPS:** حدد الشاشة وأعلن بنفسك عن VRR/G-Sync وV-Sync وReflex وFrame Generation. يأتي تردد التحديث الدائري من Windows. إذا كان Reflex أو Frame Generation نشطًا أو غير معروف، فلن يتم عرض غطاء تلقائي. بالنسبة لـ VRR مع تشغيل V-Sync وإيقاف تشغيل Reflex/FG، فإن الاستدلال يطرح ما لا يقل عن 3 FPS أو ما يقرب من 2% من معدل التحديث. هذا ليس الأمثل المقاس. تطبيق الاقتراح يملأ المسودة؛ **حفظ** يظل إجراءً منفصلاً.

**إيقاف مؤقت واستئناف:** قم بتعليق الحد الأقصى للبرنامج المحدد، ثم قم باستعادة حقول التحديد السابقة الخاصة به. التغييرات المتعارضة بواسطة أداة أخرى تمنع السيرة الذاتية الغامضة. إخفاء الإدخال لا يؤدي إلى إيقاف الحد الأقصى له مؤقتًا.

**تراجع:** استعادة آخر تغيير تم إجراؤه على الحقول الستة المُدارة لهذا البرنامج. هناك مستوى واحد؛ هذا لا يؤدي إلى استعادة كافة RTSS. يتم رفض التغييرات الخارجية المتعارضة. تظل النسخ الاحتياطية للملفات منفصلة.

**مشاركة الملفات الشخصية:** قم بتصدير الملفات الشخصية المحددة إلى ملف `.nvrp`. يعرض الاستيراد معاينة ويترك الأحرف الاستهلالية الموجودة بدون تحديد بشكل افتراضي. يحتوي الملف على أسماء وحدود وحالات قابلة للتنفيذ فقط، بدون مسارات أو نصوص برمجية مطلقة. راجع اختيارك وقم بالتقديم. قد يؤدي خطأ الإدخال/الإخراج إلى ترك بعض الملفات الشخصية مطبقة بالفعل؛ النتيجة تحددهم ويحتفظ كل منهم بالتراجع. لا تزال الأسماء القابلة للتنفيذ المتطابقة تتناول نفس ملف تعريف RTSS.

**الإدخالات المفضلة والمخفية:** قم بتثبيت البرامج المفيدة أولاً، ثم قم بإخفاء الإدخالات غير المرغوب فيها واستعادتها في مربع الحوار المخصص. وتستمر هذه الاختيارات. لا تظهر المفضلة المغلقة كتطبيق قيد التشغيل.

<a id="update-and-uninstall"></a>
## تحديث وإلغاء التثبيت

قم بإنهاء NVRasterPulse، وقم بتنزيل الإصدار الجديد والتحقق منه، ثم قم بتشغيل الإعداد الخاص به أو قم باستخراج الجهاز المحمول إلى مجلد جديد. الحفاظ على الإعدادات والنسخ الاحتياطية RTSS. تحديثات RTSS منفصلة وتأتي من Guru3D.

لإزالة نسخة مثبتة، استخدم Windows **Installed apps**. بالنسبة للأجهزة المحمولة، قم بإنهاء الأمر ثم قم بإزالة المجلد المستخرج عندما تكون النسخ الاحتياطية الخاصة بك آمنة. لا تتم إزالة حدود RTSS المحفوظة عن طريق إلغاء تثبيت NVRasterPulse: قم بإزالة تجاوزات المحدد المقصود أولاً. لدى RTSS برنامج إلغاء التثبيت الخاص به.

الحالة المحلية: `%LOCALAPPDATA%\NVRasterPulse`. النسخ الاحتياطية التلقائية لـ RTSS: `%LOCALAPPDATA%\NVRasterPulse\Backups\RTSS`. قد تتم قراءة موقع `%LOCALAPPDATA%\RTSSProfileBridge` الأقدم للترحيل. يمكن أن تحتوي هذه الملفات على مسارات شخصية قابلة للتنفيذ ويجب عدم نشرها للعامة.

<a id="known-limitations"></a>
## القيود المعروفة

- يقوم RTSS بتنفيذ عملية الغطاء. لا تعد القيمة المحفوظة أو طلب إعادة التحميل الناجح نتيجة قياس وقت الإطار.
- تشترك الملفات التنفيذية التي تحمل الاسم نفسه في ملف تعريف.
- يمكن أن يؤثر محدد عالمي آخر لكل لعبة على النتيجة؛ لا يؤدي تعطيل التجاوز المحلي إلى إزالة الحد الأقصى الموروث.
- يظل خطاف RTSS الذي تم تعطيله عمدًا معطلاً.
- يحتوي الانتظار النشط على مقايضة CPU/الطاقة.
- لا توجد لعبة عالمية أو مكافحة الغش أو التحقق من زمن الوصول الشامل.
- لم يتم تجميع أو شحن المحرك المحدد المستقل التجريبي السابق.
- لا تتضمن النسخ الاحتياطية التلقائية واجهة استعادة النسخ الاحتياطي الكاملة بنقرة واحدة.

<a id="troubleshooting"></a>
## استكشاف الأخطاء وإصلاحها

| أعراض | العمل |
| --- | --- |
| يظل المتطلب الأساسي RTSS مفتوحًا | حدد `RTSS.exe` الفعلي ومجلد الملفات الشخصية المطابق، ثم تحقق مرة أخرى. |
| تم حفظ الحد ولكن لا يوجد تأثير | ابدأ تشغيل RTSS؛ تحقق من ملف EXE/الملف الشخصي الصحيح للعبة وأذونات الربط والمحددات الأخرى. |
| فشل الحفظ | تحقق من أذونات المجلد واحتفظ بالخطأ/النسخ الاحتياطي المعروض. |
| يبقى الحد بعد الإزالة | فحص أدوات RTSS العالمية والأدوات الأخرى؛ يؤدي إجراء سلة المهملات فقط إلى إزالة تجاوزات المحددات المحلية. |
| مباراتان تحصلان على نفس الحد | تحقق مما إذا كانت أسماء الملفات القابلة للتنفيذ متطابقة. |
| إنهاء + RTSS يترك RTSS مفتوحًا | أغلق RTSS بنفسك بشكل طبيعي؛ يتجنب هذا الأمر عمدا الإنهاء القسري. |

في حالة استعادة النسخة الاحتياطية RTSS يدويًا، أغلق RTSS أولاً واحتفظ بالملف التعريفي الحالي قبل استبداله بالنسخة الاحتياطية المقصودة. يمكن أن يؤدي هذا إلى استبدال تعديلات الملف الشخصي غير ذات الصلة؛ فحص الملف والتاريخ. [الدعم المشترك](../docs/support.md).

<a id="faq"></a>
## الأسئلة الشائعة

**هل أحتاج إلى MSI Afterburner أيضًا؟** يتطلب NVRasterPulse RTSS؛ لا يعتمد على تطبيق Afterburner. اتبع خيارات التثبيت الخاصة بموزع RTSS.

**هل يمكنني استخدام هذا دون تشغيل RTSS؟** يمكنك إدارة الملفات الشخصية بمجرد اكتشاف التثبيت، ولكن يجب تشغيل RTSS للحد.

**هل يؤدي الانسحاب أو إلغاء التثبيت إلى إزالة الأحرف الكبيرة؟** لا. قم بإزالة تجاوزات المحدد المطلوب بشكل صريح قبل إزالة NVRasterPulse.

**هل هو fork من RTSS؟** لا. إنه مدير ملفات تعريف مستقل؛ لم يتم دمج أي مصدر RTSS أو قابل للتنفيذ.

## المنبع والتعديلات والاعتمادات
