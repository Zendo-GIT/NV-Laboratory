# NVDriverForge

**قم بالتحضير لتثبيت برنامج التشغيل NVIDIA مع اختيارات المكونات الواضحة والإعدادات الاختيارية.**

[تنزيل 0.1.3 والحالة](../docs/downloads.md#nvdriverforge) · [التثبيت](#installation) · [الاعتمادات](#credits-and-upstream) · [الترخيص](../../../../NVDriverForge/LICENSE)

<a id="overview-and-purpose"></a>
## نظرة عامة والغرض

يرشدك NVDriverForge عبر حزمة برنامج التشغيل NVIDIA الأصلية: اختر برنامج التشغيل، وافحص مكوناته، وراجع التعديلات الاختيارية، ثم أكد التثبيت. إنه موجود لجعل هذه الاختيارات مفهومة والحفاظ على التثبيت والعمليات المميزة ومعلومات الاسترداد معًا.

إنه تطبيق تم تطويره بشكل مستقل مستوحى جزئيًا من سير عمل NVCleanstall. ولا يتضمن NVCleanstall أو يطالب بتكافؤ كامل للميزات.

<a id="features"></a>
## الميزات

- البحث والتنزيلات عن NVIDIA Game Ready / Studio؛ اكتشاف الإصلاح العاجل الاختياري مع الرجوع اليدوي.
- تحليل الحزمة الأصلية والتجزئة وتوقيعات NVIDIA والبيانات وإدخالات INF المتوافقة.
- اختيار المكونات مع التبعيات والحفاظ على المكونات غير المعروفة.
- الإصدار 0.1.3 يبقي مكونات NVIDIA الاختيارية المحددة قابلة للتخطي ويستبعد فقط المكونات التي لم يتم التحقق منها من الاكتشاف. لم تعد أوقات التشغيل الاختيارية الحالية أو غير القابلة للتطبيق مفروضة كمكونات مهمة.
- مسح ملخصات فشل التثبيت والوصول إلى السجلات التفصيلية بجميع اللغات الـ 34.
- تأكيد التثبيت الصريح والتدريج المحمي وتصدير حزم مخزن برامج التشغيل الموجودة.
- إعدادات متقدمة اختيارية، مع اختبارات الاختبار المبدئي، واليوميات، والاسترداد مع مراعاة التعارض.
- إعداد اختياري **Custom NV** مسبقًا مع اختيارات وتفسيرات مسماة، بما في ذلك اختيار قوة SILK المنفصل وفحوصات التوافق.
- تنزيلات تصحيح اختيارية للإصدار الدقيق NVENC؛ يتم التحقق من التزام المصدر والبايتات المستهدفة.
- تثبيت منفصل واختياري لـ Profile Inspector fork من شاشة الأدوات.
- عمليات فحص اختيارية لتحديثات المستخدم المثبتة، و34 لغة للواجهة وأربعة سمات.

تشمل الخيارات المتقدمة المتوفرة MPO ومؤشر DLSS وAnsel وNVIDIA سكون الصوت وMSI وسياسة/أولوية المقاطعة وHDCP وبدء تشغيل حاوية العرض وخدمة القياس عن بعد القديمة المؤهلة. ولكل منها متطلباته وآثاره الخاصة؛ هذه ليست تحسينات الأداء العالمية.

<a id="compatibility"></a>
## التوافق

| المتطلبات | التفاصيل |
| --- | --- |
| النظام | Windows 10 الإصدار 19041 أو الأحدث / Windows 11، x64 |
| GPU/سائق | حزمة NVIDIA المتوافقة والأجهزة المكتشفة؛ يغطي البحث التلقائي للكتالوج بشكل أساسي نماذج GeForce المعروفة |
| وقت التشغيل | .NET 8 / WPF 8.0.31 مضمن في الحزمة المجهزة بذاتها |
| الامتيازات | إعداد عادي لواجهة المستخدم/لكل مستخدم؛ يتطلب تثبيت برنامج التشغيل وتغييرات النظام وصول المسؤول |
| الشبكة | مطلوب للبحث/التنزيلات عبر الإنترنت عن NVIDIA وطلبات NVENC الصريحة؛ يمكن اختيار برنامج التشغيل الأصلي المحلي |
| الأدوات المضمنة | 7-Zip 26.03 غير المعدل، إشعارات وقت التشغيل، رفيق MIT Profile Inspector الاختياري |
| رفيق اختياري | .NET Framework 4.8 لـ Profile Inspector fork المنفصل |

لا يوجد حد أدنى تعسفي لإصدار برنامج التشغيل يغطي جميع الميزات. يجب أن يتطابق بحث Multi-GPU مع كل GPU المكتشف. يمكن أن تتطلب الطرز غير المدعومة/الاحترافية تحديد برنامج التشغيل يدويًا. يظل برنامج تثبيت NVIDIA هو المرجع النهائي للأجهزة/نظام التشغيل.

<a id="installation"></a>
## التثبيت

1. تفضل بزيارة [التنزيلات](../docs/downloads.md#nvdriverforge) وتأكد من نشر الإصدار.
2. اختر `NVDriverForge-Setup.exe` للتثبيت، أو `NVDriverForge.exe` للاستخدام المحمول.
3. قارن SHA-256 مع الإصدار `SHA256SUMS.txt`.
4. قم بتشغيل برنامج الإعداد للتثبيت لكل مستخدم وبرنامج إلغاء التثبيت القياسي، أو ضع ملف EXE المحمول في مجلد قابل للكتابة وافتحه.

يتضمن الجهاز المحمول وقت التشغيل الخاص به والمثبت الاختياري الخاص به. لا يؤدي تثبيت NVDriverForge إلى تثبيت برنامج تشغيل GPU. ملفات EXE الخاصة بها غير موقعة حاليًا.

<a id="usage"></a>
## الاستخدام

1. **برنامج التشغيل:** قم بالتنزيل من NVIDIA أو حدد برنامج التثبيت NVIDIA EXE الأصلي. دع التحليل ينتهي.
2. **المكونات:** مراجعة الأوصاف والتبعيات المطلوبة. يتم الاحتفاظ بالمكونات غير المعروفة.
3. **التعديلات:** اترك الخيارات غير المرغوب فيها دون تغيير. اقرأ التأثيرات والمقايضات قبل اختيار أي شيء.
4. **المراجعة:** تحقق من برنامج التشغيل والمكونات والعمليات الاختيارية الدقيقة، ثم قم بتأكيد التثبيت.
5. اقبل UAC فقط للعملية التي اخترتها. احتفظ بتعليمات استرداد المهمة المحمية.
6. إذا كان برنامج التشغيل الجديد يحتاج إلى إعادة تشغيل، فاتبع الحالة المبلغ عنها. تتطلب العمليات المؤجلة استئنافًا صريحًا بعد إعادة التشغيل هذه.

يبدأ Custom NV دون تغيير. اختر قيمًا فردية مسماة أو قم بمراجعة الإعداد المسبق المقدم واستثناءاته. لم تتم كتابة حقليها الداخليين المعلوماتيين بشكل مستقل. يتم تطبيق الإعدادات فقط في سير عمل برنامج التشغيل الجديد الذي تم التحقق منه، وليس من خلال فتح المعاينة أبدًا. ليس من الضروري تثبيت محرر NVPI المنفصل.

يقوم عمل NVENC الاختياري بتنزيل البيانات المتوافقة من التزام keylase المثبت. فهو يغير مكتبتي DLL لبرنامج التشغيل ويبطل توقيعهما؛ يمكن رفضه بواسطة Windows أو برامج التشفير أو DRM أو مكافحة الغش. لا توجد مثل هذه البيانات أو NVIDIA DLL مضمن في NVDriverForge. [حدود المصدر والترخيص](../docs/provenance.md).

تتحكم التفضيلات في اللغة والموضوع وعمليات التحقق الاختيارية من تحديث المستخدم المثبت. لا يقوم الجهاز المحمول بإنشاء مهمة التحقق من الخلفية المثبتة. الأدوات والاسترداد منفصلة عن خطوات التثبيت الأربع.

<a id="update-and-uninstall"></a>
## تحديث وإلغاء التثبيت

أغلق NVDriverForge، واحصل على الحزمة الرسمية التالية وتحقق من تجزئتها. استخدم نفس هوية الإعداد للتحديث المثبت؛ استبدل ملف EXE المحمول المغلق بالملف الجديد. احتفظ بالإعدادات والمهام المحمية.

Uninstall من Windows **Installed apps**. فهو يزيل التطبيق ومهمة التحديث الخاصة به، وليس برنامج التشغيل NVIDIA. تبقى الإعدادات والسجلات والنسخ الاحتياطية. إذا رغبت في ذلك، يمكنك استعادة التغييرات المتقدمة/NVENC من خلال تدفق الاسترداد الموثق **قبل** إزالة التطبيق. ترفض الاستعادة التغييرات المتعارضة من أداة أخرى.

البيانات المحلية تحت `%LOCALAPPDATA%\NVDriverForge`؛ الوظائف المحمية وصادرات برامج التشغيل ضمن `%PROGRAMDATA%\NVDriverForge\Jobs`. يؤدي الاستخدام المحمول أيضًا إلى إنشاء بيانات محلية. إن التصدير إلى متجر برامج التشغيل ليس صورة نظام أو نسخة احتياطية كاملة للملف الشخصي.

<a id="known-limitations"></a>
## القيود المعروفة

- لا توجد إضافات للأجهزة/تحرير INF، أو توقيعات NVIDIA المعاد إنشاؤها، أو الاستقالة المتوافقة مع مكافحة الغش، أو القبول التلقائي للتحذير غير الموقع.
- لا توجد إزالة كاملة للقياس عن بعد/الإعلانات، أو تصدير حزمة رفيعة أو إرجاع تلقائي كامل إلى برنامج التشغيل السابق.
- لم يتم التحقق بشكل شامل من صحة تثبيت برنامج التشغيل واسترداد التمهيد وكتابة ملف التعريف الاختياري على الأجهزة الحقيقية من خلال تدقيق المحور.
- لا تعد إعادة قراءة السجل دليلاً على تأثيرات HDCP الفعلية أو الأداء أو زمن الاستجابة.
- تستخدم عمليات التحقق من التوقيع ثقة Windows المتوفرة محليًا؛ لم يتم تنفيذ الإلغاء عبر الإنترنت.
- توجد 34 لغة، ولكن الاختبار الكامل للمتحدث الأصلي/إمكانية الوصول لا يزال غير مكتمل.

<a id="troubleshooting"></a>
## استكشاف الأخطاء وإصلاحها

| أعراض | العمل |
| --- | --- |
| الكتالوج على الانترنت غير متوفر | حدد الحزمة الأصلية من [تنزيلات برنامج التشغيل NVIDIA](https://www.nvidia.com/en-us/drivers/). لا تستبدل طراز GPU المجاور. |
| البحث عن الإصلاح العاجل غير متوفر | استخدم [منتدى برامج التشغيل NVIDIA's Game Ready](https://www.nvidia.com/en-us/geforce/forums/game-ready-drivers/13/) وتحقق من الحزمة الفعلية. |
| فشل تثبيت NVIDIA | اقرأ ملخص الفشل وافتح السجلات التفصيلية. تظل المكونات الاختيارية الحالية أو غير القابلة للتطبيق قابلة للتخطي في 0.1.3. لا تؤدي عمليات التثبيت الفاشلة إلى إجراء تعديلات اختيارية أو تدفق النجاح/إعادة التشغيل. |
| فشل التوقيع/التجزئة/النسخ الاحتياطي | أوقف هذا التثبيت واحتفظ بالخطأ؛ احصل على الحزمة الأصلية مرة أخرى في حالة تلفها. |
| الخيار غير متاح | اقرأ سبب الأجهزة أو المكونات أو برامج التشغيل المستهدفة؛ يبقيه دون تغيير. |
| إعادة التشغيل أو المهمة لا تزال معلقة | استخدم تعليمات استرداد الوظيفة والسيرة الذاتية الصريحة؛ لا تمحوا يومياتها. |
| استعادة الصراع | حالة أخرى تختلف عن المعاملة المسجلة. احتفظ بها واطلب المساعدة بدلاً من فرض الاستعادة. |

بالنسبة للتقارير، قم بتضمين إصدار الأداة المحدد، Windows، GPU، برنامج التشغيل والخطوات القابلة للتكرار؛ تنقيح المسارات والتفاصيل الشخصية من السجلات. [الدعم](../docs/support.md).

<a id="faq"></a>
## الأسئلة الشائعة

**هل يقوم برنامج الإعداد بتثبيت برنامج تشغيل الرسومات؟** لا. يتطلب ذلك إجراء تحليل منفصل ومراجعة وتأكيد وعملية تثبيت متقدمة للتطبيق.

**هل أحتاج إلى NVCleanstall أو NVPI؟** لا. NVCleanstall هو الإلهام فقط. يعد الرفيق Profile Inspector محررًا اختياريًا مستقلاً.

**هل يجعل كل برنامج تشغيل NVIDIA أصغر أم أسرع؟** لا. تحدد المكونات والمتطلبات الأساسية المحددة ما يمكن تغييره؛ لا يتم الوعد بأي مكاسب قابلة للقياس.

**أين المصادر؟** يتم الاحتفاظ بالمصدر الخاص بالتطبيق والاختبارات الخاصة بشكل منفصل. يوفر هذا المركز الوثائق والثنائيات وروابط مصدر الطرف الثالث المطلوبة للإسناد/الترخيص.

- [NVIDIA](https://www.nvidia.com/en-us/drivers/): تنزيلات برامج التشغيل الخارجية وتثبيت مكتبات NVAPI/NVML.
