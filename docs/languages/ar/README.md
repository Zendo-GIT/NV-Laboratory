# NV Laboratory

**NV Tools من 禅堂 Zendo (RevoluSound Team).** أربع أدوات مساعدة Windows مستقلة لملفات تعريف برنامج التشغيل NVIDIA وتثبيت برنامج التشغيل وحدود إطارات Multi Frame Generation وRTSS التجريبية.

[احصل على الأدوات](docs/downloads.md) · [التثبيت](docs/installation.md) · [التوافق والمساعدة](docs/support.md) · [الاعتمادات والتراخيص](THIRD_PARTY_NOTICES.md)

> **يتطلب NVRasterPulse RTSS.** قم بتثبيت [RivaTuner Statistics Server من Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) أولاً. يجب تشغيل RTSS حتى تعمل حدود FPS الخاصة به. يتم تنزيله بشكل منفصل.

<a id="start-here"></a>
## ابدأ هنا

1. اختر أداة واحدة أعلاه. كل يعمل بشكل مستقل. تثبيت المجموعة بأكملها غير ضروري.
2. اقرأ متطلباته واختر **الإعداد** لتطبيق مثبت، أو **محمول** لمجلد منفصل.
3. عند نشر الإصدار الخاص به، قم بتنزيل أصل التطبيق المحدد، واقرأ الإشعارات المصاحبة وقارن SHA-256 الخاص به.
4. احتفظ بنسخ احتياطية قبل تغيير برنامج التشغيل أو إعداد العرض أو ملف تعريف NVIDIA أو وقت تشغيل اللعبة.

يتوفر التوثيق بنفس اللغات الـ 34 المتوفرة في تطبيقات NV من خلال أداة التحديد الموجودة أعلى كل دليل. لا يقوم GitHub تلقائيًا بتحديد ملف README حسب لغة المتصفح. لغة التوثيق وإعدادات اللغة الخاصة بالتطبيق منفصلتان.

<a id="provenance-and-ownership"></a>
## المصدر والملكية

يقوم هذا المركز بتوزيع الوثائق والتطبيقات المجمعة. يتم الحفاظ على كود مصدر التطبيق بشكل خاص. تحتفظ مشاريع المنبع بتأليفها وتراخيصها؛ لا يحل توزيع المصدر الخاص محل هذه الشروط.

- يحتفظ Profile Inspector fork بترخيص Orbmu2k الخاص بـ MIT ويتم تعريفه صراحةً على أنه fork.
- يحتوي NVDriverForge على شروط التوزيع الثنائية الخاصة به ويتضمن مكونات أداة/وقت تشغيل مرخصة بشكل منفصل.
- NVMFG Unlock40 هو تطبيق تم تطويره بشكل مستقل. تمت استشارة RTX40MFG-Unlock للمقارنة والتحسين؛ تحتفظ المكونات الأصلية المشتركة بأرصدة MIT الخاصة بها. تظل مصطلحات MinHook وNVIDIA SDK منفصلة.
- يحتفظ NVRasterPulse بترخيص MIT المرفق ويعتمد واجهة المستخدم المشتقة من Profile Inspector. RTSS هو برنامج خارجي مطلوب.

راجع [جدول المكونات الكامل](THIRD_PARTY_NOTICES.md) و[مصدر الملف والتغييرات](docs/provenance.md) و[نطاق الترخيص](../../../LICENSE).
