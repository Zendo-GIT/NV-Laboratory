# NVMFG Unlock40

**NVIDIA Multi Frame Generation التجريبي لـ GeForce RTX 40، مع وحدة تحكم مركزية وخيارات لكل لعبة.**

[تنزيل 0.2.3 والحالة](../docs/downloads.md#nvmfg-unlock40) · [التثبيت](#installation) · [المنبع](#upstream-and-modifications) · [التراخيص](LICENSES/README.md)

<a id="overview-and-purpose"></a>
## نظرة عامة والغرض

NVMFG Unlock40 هو تطبيق تم تطويره بشكل مستقل بواسطة 禅堂 Zendo (RevoluSound Team). فهو يجمع بين وحدة التحكم Windows والطبقة الأصلية ومساعد الملف الشخصي وإدارة اللعبة/Streamline SDK. وهو يستهدف الألعاب التي تدمج بالفعل NVIDIA DLSS Frame Generation وأوقات تشغيل NVIDIA المتوافقة.

تمت استشارة [RTX40MFG-Unlock](https://github.com/dashdogy/RTX40MFG-Unlock) لمقارنة العمل وتحسينه. تحتوي الطبقة الأصلية الحالية على مكونات مشتركة ومُعدلة، مُدرجة بشكل فردي أدناه. لا يجعل هذا المرجع تطبيق NVMFG بأكمله fork لذلك المشروع.

إنه موجود لتنسيق سلوك MFG التجريبي مركزيًا، وتذكر الاختيارات الخاصة باللعبة، وإبقاء تحديثات وقت التشغيل والنسخ الاحتياطية مرئية. لا يضيف DLSS Frame Generation إلى كل لعبة أو يحول تطبيق FSR التعسفي.

الحزمة الحالية هي **0.2.3**. فهو يضيف مكتبة ألعاب مستمرة، ومعلومات عن النشاط والقدرات، وتشخيصات محلية، وسلوك الاختيار/التقدم المصحح. يحدد [التنزيلات](../docs/downloads.md#nvmfg-unlock40) الملفات والتجزئة الدقيقة.

<a id="features"></a>
## الميزات

- التحكم المركزي في التمكين/التعطيل وبدء تشغيل صينية Windows الاختيارية.
- الاختيار لكل لعبة بين Dynamic MFG وإعدادات اللعبة والمضاعفات الثابتة المدعومة.
- الاختيارات المنفصلة التي تم تذكرها لحالات التشغيل/الإيقاف التي تمت ملاحظتها لـ V-Sync.
- يستخدم Dynamic وضع NVIDIA؛ يتم تعليقه عند إيقاف تشغيل V-Sync، مع خيار منفصل داخل اللعبة/ثابت.
- إرشادات قائمة اللعبة والاستثناءات المستمرة؛ الألعاب التي لا تحتوي على DLSS FG تظل مسيطرة.
- اكتشاف اللعبة واختيار المجلد الأصلي والبحث والتجميع والإزالة دون حذف ملفات اللعبة.
- تنزيل/استيراد Streamline SDK، وذاكرة تخزين مؤقت محلية تم التحقق منها، واختيار واضح، ونسخ احتياطي واستعادة لكل لعبة.
- التحقق من الموفر الأصلي، والتشخيصات لكل جلسة، ومجلة الملفات الشخصية العالمية، والاسترداد المدرك للتعارض.
- 34 لغة واجهة وأربعة مواضيع.

يؤدي إيقاف تشغيل FG في اللعبة إلى إيقاف تشغيله. تعتمد الاختيارات الثابتة من 2x إلى 6x على اللعبة/القائمة/وقت التشغيل؛ فهي ليست وعدًا بأن كل مجموعة تعمل. تراقب وحدة التحكم V-Sync ولا تقوم بتعيين V-Sync أو VRR للمستخدم.

<a id="installation"></a>
## التثبيت

1. اقرأ [حالة المرشح ومذكرة الترخيص](../docs/downloads.md#nvmfg-unlock40).
2. قم بتنزيل `NVMFGUnlock40-0.2.3-Setup-x64.exe` أو `NVMFGUnlock40-0.2.3-Portable-x64.zip` عندما يكون إصداره متاحًا.
3. تحقق من SHA-256 واحتفظ بالإشعارات المصاحبة. قم بتثبيت .NET Framework 4.8 إذا لم يكن Windows يوفره بالفعل.
4. قم بتشغيل برنامج الإعداد، أو قم باستخراج ملف ZIP المحمول **بكامله** إلى مجلد محلي قابل للكتابة.
5. قم بتشغيل `NVMFGUnlock40.exe`؛ احتفظ بـ `agent` و`driver` و`engine` و`Licenses` في التخطيط المتوفر.

يحتوي المجلد المسمى `driver` على مساعدات مساحة المستخدم، وليس برنامج تشغيل kernel. لا تقم بنسخ ملف EXE الرئيسي فقط أو استبدال تجزئة الموفر لفرض التوافق. ملفات EXE الحالية غير موقعة.

<a id="usage"></a>
## الاستخدام

1. ابدأ بتعطيل وحدة التحكم. أضف لعبة أو مجلدًا رئيسيًا واختر عمليات التثبيت الفعلية.
2. قم بمراجعة إعدادات MFG الخاصة بكل لعبة. أجب عما تقدمه قائمته؛ يتم تخزين الجواب في كل لعبة.
3. اختر Dynamic أو الإعداد داخل اللعبة عالميًا، ثم اضبط الاختيارات المؤهلة لكل لعبة حسب الحاجة.
4. قم بتمكين وحدة التحكم فقط عندما تنوي استخدامها. يمكنه تغيير ستة إعدادات عامة لملف تعريف NVIDIA بشكل مؤقت، باستخدام سجل الاسترداد.
5. قم بتشغيل لعبة مؤهلة وقم بتمكين DLSS Frame Generation الخاص بها. اتبع أي طلب لاختيار V-Sync-off.
6. استخدم الاستثناءات للألعاب التي لا تريد إدارتها. تؤدي إزالة اللعبة إلى تسجيل الاستثناء والحفاظ على ملفاتها/نسخها الاحتياطية.
7. استخدم عملية الإنهاء/التعطيل والاسترداد الكاملة للتطبيق عند الانتهاء.

يمكن أن يؤدي إغلاق النافذة الرئيسية إلى ترك وحدة التحكم في الدرج. يظل ملف DLL الذي تم تحميله بالفعل في اللعبة موجودًا حتى تنتهي اللعبة؛ لا يعد تعطيل وحدة التحكم ضمانًا للتفريغ. أغلق الألعاب المتأثرة قبل الصيانة أو التحديثات.

Streamline SDKs: في صفحة NVIDIA SDK، قم بتنزيل إصدار رسمي أو قم باستيراد SDK محلي متوافق. استيراد مخازن نسخة تم التحقق منها. Use this version يحددها، و Uninstall  يزيل تلك النسخة المخزنة مؤقتًا. يمكن استكمال ملفات Streamline DLL المفقودة من NVIDIA SDK الرسمي، مع إظهار المصدر. لا يؤدي هذا إلى تنزيل/استبدال طراز NGX. أغلق اللعبة، وحدد تحديث اللعبة المقصود، واحتفظ بنسختها الاحتياطية الأصلية. لاستعادة ملفات اللعبة، استخدم استعادة النسخة الاحتياطية، وليس زر Uninstall الخاص بذاكرة التخزين المؤقت.

<a id="library-diagnostics-and-updates"></a>
## المكتبة والتشخيصات والتحديثات

**المكتبة الدائمة:** حدد العديد من مجلدات اللعبة، بما في ذلك محركات الأقراص المختلفة، قبل بدء عملية فحص واحدة. التقدم واضح والإلغاء متاح. بعد الفحص الأول، تقوم ذاكرة التخزين المؤقت المحلية باستعادة المكتبة عند التشغيل دون التنقل في كل مجلد من مجلدات اللعبة. قم بالتحديث للعثور على التغييرات أو إضافة مجلد آخر. لا تزال عمليات الصيانة تقوم بإعادة التحقق من صحة الملفات المتأثرة؛ تظل مراقبة النسخ الاحتياطي نشطة. يتم تخزين ذاكرة التخزين المؤقت في `%LOCALAPPDATA%\RtxMfg\library-cache.json`.

**التحديد:** يقوم Ctrl+A بتحديد الكل ويقوم Ctrl+D بمسح علامة التبويب "الألعاب" أو "النسخ الاحتياطية" النشطة. لم يتم تحديد أي لعبة تلقائيًا. لم تعد تحديثات النشاط وتحديثاته تؤدي إلى إنشاء تحديدات خفية أو أعداد غير متناسقة.

**النشاط والتوافق:** تأتي معلومات MFG لكل لعبة من ملاحظات NGX بدون تراكب جديد. إنه ليس عددًا فعليًا للإطارات المعروضة. يأتي دعم Dynamic-with-V-Sync من إمكانيات وقت التشغيل؛ لا يتم استنتاج القدرة غير المعروفة من رقم الإصدار. لا يغير التطبيق V-Sync ولا VRR. مع إيقاف تشغيل V-Sync، يظل Dynamic معلقًا؛ الخيارات الثابتة أو التي يتم التحكم فيها باللعبة منفصلة.

**الإطلاق التالي:** يتخطى الاستبعاد المؤقت عملية التصحيح عند إطلاق اللعبة التالية ويستعيد الإدارة العادية بعد الخروج. لا يمكن إزالة ملف DLL الذي تم تحميله بالفعل في إحدى الألعاب: أغلق تلك اللعبة وأعد تشغيلها. يتم التعرف على Wallpaper Engine كتطبيق سطح مكتب؛ يحافظ هذا التصحيح على الحماية للألعاب الفعلية التي تم تجاهلها.

**التفضيلات والدعم:** يتطلب استيراد/تصدير التفضيلات إعادة اقتران مجلدات اللعبة يدويًا. يقوم التشخيص المحلي الموجود في "حول" بتصفية المعلومات الخاصة والتقارير ورموز الخطأ NVAPI أو فئات التعارض المتوفرة. قم بمراجعتها قبل المشاركة؛ لا يتم تحميل أي شيء تلقائيًا.

**تحديثات التطبيق:** يعرض الاختيار الاختياري ملاحظات الإصدار ويقدم الإعداد الرسمي. يتم التحقق من التنزيل الصريح وفقًا لحجم GitHub وبيانات تعريف SHA-256؛ تبدأ التثبيت بنفسك. يقوم الإصدار 0.2.3 أيضًا بمسح رسائل التقدم المكتملة مع الحفاظ على الأخطاء والنتائج ذات المعنى. تتضمن هذه الإضافات التغييرات منذ الإصدار العام 0.1.1.

<a id="update-and-uninstall"></a>
## تحديث وإلغاء التثبيت

إغلاق الألعاب المتضررة. قم بتعطيل/إنهاء NVMFG وحل أي استرداد معلق لإعدادات NVIDIA قبل التحديث. قم بتثبيت الإعداد التالي بالهوية الموجودة، أو قم باستخراج الجهاز المحمول الجديد إلى مجلد جديد؛ الاحتفاظ بالحالة/النسخ الاحتياطية.

قبل إلغاء التثبيت، قم باستعادة النسخ الاحتياطية للعبة SDK وإعدادات NVIDIA من خلال التطبيق، ثم أغلق الألعاب وقم بإنهاء وحدة التحكم. استخدم Windows **Installed apps** للإعداد، أو قم بإزالة المجلد المحمول المغلق بعد الاحتفاظ بالملفات المطلوبة. لا تقم بحذف دفتر يومية الاسترداد النشط يدويًا لإلغاء حظر الإعداد.

تستخدم النسخ الاحتياطية المحلية لوقت تشغيل اللعبة `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`. تستخدم إعدادات MFG/بيانات SDK `%LOCALAPPDATA%\RtxMfg`؛ مخرجات الجلسة موجودة تحت `Sessions` بجانب التطبيق. يمكن أن تحتوي هذه الملفات على مسارات اللعبة. لا تنشرها دون تنقيح.

<a id="known-limitations"></a>
## القيود المعروفة

- يظل حظر التنشيط/الاستعادة/إلغاء التثبيت 0.1.1 الذي تم الإبلاغ عنه غير متكرر وسببه غير معروف. لا يدعي هذا الإصدار لإصلاحه. بعد الفشل، احتفظ بمجلة الاسترداد وافحص التشخيص المحلي؛ لا تفرض حذف بيانات الاسترداد.
- يمكن أن تتسبب التصحيحات الأصلية التجريبية في حدوث أعطال أو عيوب مرئية؛ يتم تسجيل تعطل Bodycam الذي لم يتم حله في سجل التطوير.
- اختبارات العارض الخاضعة للرقابة ليست شهادة لكل لعبة أو سائق أو مكافحة الغش.
- لا تقوم الإطارات التي تم إنشاؤها بإنشاء عينات إدخال جديدة؛ لا يعد هذا المركز بأي زمن استجابة أو زيادة في الأداء.
- قد تتعارض أدوات/تراكبات إنشاء الإطارات المتعددة. يقوم التطبيق بإبلاغ الوحدات النمطية التي تمت ملاحظتها دون إثبات كل سيناريوهات التعايش.
- بيان التوافق هو أداة مساعدة للكشف، وليس قائمة بالألعاب التي تم اختبارها بالكامل.
- تظل شروط NVIDIA SDK الكاملة والقيود الفنية التي لم يتم حلها موثقة في [المصدر](../docs/provenance.md).

**هل يعمل Dynamic مع إيقاف تشغيل V-Sync؟** إنه معلق في تلك الحالة. اختر الإعداد داخل اللعبة أو المضاعف الثابت المؤهل للحالة المنفصلة لتلك اللعبة.

**هل هذه حزمة ReShade/OptiScaler/FSR؟** لا. لم يتم تجميعها أو شحنها كجزء من حزمة الإنتاج هذه.

**هل المصادر المعدلة عامة؟** لا. يتم توفير الحزم المجمعة والاعتمادات/التراخيص المطلوبة. وهذا لا يلغي حقوق أو قيود الأطراف الثالثة.
