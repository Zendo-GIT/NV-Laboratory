# Turvallisuus

Tämä käytäntö kattaa NV Tools-sovelluspaketit ja tämän jakelukeskuksen. Ylläpitäjä priorisoi raportit, jotka vaikuttavat kunkin työkalun viimeisimpään julkaistuun versioon. Valmistetut ehdokkaat eivät ole ilmoitettu tuettu vakaa julkaisu. Vastausaikaa tai turvallisuustodistusta ei luvata.

<a id="report-privately"></a>
## Ilmoita yksityisesti

Käytä arkiston **Turvallisuus → Report a vulnerability**-ominaisuutta **kun se on käytössä**: [yksityinen raportti](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new).

**Alkuasetukset:** ylläpitäjän on otettava käyttöön yksityinen haavoittuvuusraportointi julkisen arkiston luomisen jälkeen. Tämä tiedosto ei ota sitä käyttöön, eikä postilaatikon tai yksityisen kanavan väitetä olevan olemassa ennen sitä.

Jos painike ei ole käytettävissä, avaa julkinen ongelma, joka sisältää vain: "Tarvitsen yksityisen yhteydenottokanavan [työkalua/versiota] koskevaa tietoturvaraporttia varten." Älä sisällytä hyväksikäytön yksityiskohtia, tunnistetietoja, vaikuttavia polkuja, lokeja tai liitteitä. Odota, että ylläpitäjä tarjoaa yksityisen kanavan, ennen kuin jaat ne.

Sisällytä yksityiseen raporttiin työkalu/versio ja hash, Windows/GPU/ohjainversiot, vaikutus, minimaalinen turvallinen kopiointi ja se, tarvitaanko palautusta. Poistaa salaisuuksia ja henkilötietoja; säilyttää paikalliset palautustiedostot. Älä lataa omaa ohjainta tai pelin DLL-tiedostoja. Koordinoi julkistaminen ylläpitäjän kanssa; Korjaus/julkaisu vaatii tarkistusta, eikä se ole automaattinen.


[GitHub yksityinen raportointidokumentaatio](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
