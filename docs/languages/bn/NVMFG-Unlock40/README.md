# NVMFG Unlock40

**GeForce RTX 40 এর জন্য পরীক্ষামূলক NVIDIA Multi Frame Generation, একটি কেন্দ্রীয় কন্ট্রোলার এবং প্রতি-গেম পছন্দ সহ।**

[0.1.1 এবং স্ট্যাটাস ডাউনলোড করুন](../docs/downloads.md#nvmfg-unlock40) · [ইনস্টলেশন](#installation) · [আপস্ট্রিম](#upstream-and-modifications) · [লাইসেন্স](LICENSES/README.md)

<a id="overview-and-purpose"></a>
## ওভারভিউ এবং উদ্দেশ্য

NVMFG Unlock40 禅堂 Zendo (RevoluSound Team) দ্বারা একটি স্বাধীনভাবে বিকশিত অ্যাপ্লিকেশন। এটি একটি Windows কন্ট্রোলার, একটি নেটিভ লেয়ার, একটি প্রোফাইল হেল্পার এবং গেম/Streamline SDK ব্যবস্থাপনাকে একত্রিত করে। এটি এমন গেমগুলিকে লক্ষ্য করে যা ইতিমধ্যেই NVIDIA DLSS Frame Generation এবং সামঞ্জস্যপূর্ণ NVIDIA রানটাইমকে একীভূত করে।

[RTX40MFG-Unlock](https://github.com/dashdogy/RTX40MFG-Unlock) কাজ তুলনা এবং পরিমার্জিত করার জন্য পরামর্শ করা হয়েছিল। বর্তমান নেটিভ লেয়ারে ভাগ করা এবং অভিযোজিত উপাদান রয়েছে, নীচে স্বতন্ত্রভাবে জমা দেওয়া হয়েছে। এই রেফারেন্সটি পুরো NVMFG অ্যাপ্লিকেশনটিকে সেই প্রকল্পের একটি fork করে না।

এটি কেন্দ্রীয়ভাবে পরীক্ষামূলক MFG আচরণের সমন্বয় করতে, গেম-নির্দিষ্ট পছন্দগুলি মনে রাখতে এবং রানটাইম আপডেট এবং ব্যাকআপগুলি দৃশ্যমান রাখতে বিদ্যমান। এটি প্রতিটি গেমে DLSS Frame Generation যোগ করে না বা একটি নির্বিচারে FSR বাস্তবায়ন রূপান্তর করে না।

প্রস্তুত প্রার্থী হল **0.1.1**, SDK-তালিকা ভিজ্যুয়াল সংশোধন সহ অভ্যন্তরীণভাবে UI2 হিসাবে রেকর্ড করা। সর্বজনীন সংস্করণ 0.1.1 থাকে; এর সঠিক হ্যাশ এই প্রার্থীকে পুরানো স্থানীয় বিল্ড থেকে আলাদা করে।

<a id="features"></a>
## বৈশিষ্ট্য

- কেন্দ্রীয় সক্ষম/অক্ষম নিয়ন্ত্রণ এবং ঐচ্ছিক Windows ট্রে স্টার্টআপ।
- Dynamic MFG, গেমের সেটিং এবং সমর্থিত ফিক্সড মাল্টিপ্লায়ারগুলির মধ্যে প্রতি-গেম নির্বাচন।
- পর্যবেক্ষিত V-Sync চালু/বন্ধ অবস্থার জন্য আলাদা মনে রাখা পছন্দ।
- Dynamic NVIDIA এর মোড ব্যবহার করে; এটি স্থগিত করা হয় যখন V-Sync বন্ধ থাকে, একটি পৃথক ইন-গেম/স্থির পছন্দ সহ।
- গেম-মেনু নির্দেশিকা এবং ক্রমাগত বর্জন; DLSS FG ছাড়া গেমগুলি নিয়ন্ত্রণে থাকে।
- গেম আবিষ্কার, প্যারেন্ট-ফোল্ডার নির্বাচন, অনুসন্ধান, গ্রুপিং এবং গেম ফাইল মুছে ফেলা ছাড়া অপসারণ।
- Streamline SDK ডাউনলোড/আমদানি, যাচাইকৃত স্থানীয় ক্যাশে, স্পষ্ট নির্বাচন, প্রতি-গেম ব্যাকআপ এবং পুনরুদ্ধার।
- নেটিভ প্রদানকারীর যাচাইকরণ, প্রতি-সেশন ডায়াগনস্টিকস, গ্লোবাল প্রোফাইল জার্নাল এবং দ্বন্দ্ব-সচেতন পুনরুদ্ধার।
- 34টি ইন্টারফেস ভাষা এবং চারটি থিম।

খেলায় FG বন্ধ করা এটি বন্ধ রাখে। 2x থেকে 6x পর্যন্ত স্থির পছন্দগুলি গেম/মেনু/রানটাইমের উপর নির্ভর করে; তারা একটি প্রতিশ্রুতি নয় যে প্রতিটি সমন্বয় কাজ করে। কন্ট্রোলার V-Sync পর্যবেক্ষণ করে এবং ব্যবহারকারীর জন্য V-Sync বা VRR সেট করে না।

<a id="installation"></a>
## ইনস্টলেশন

1. [প্রার্থীর অবস্থা এবং লাইসেন্সিং নোট](../docs/downloads.md#nvmfg-unlock40) পড়ুন।
2. `NVMFGUnlock40-0.1.1-Setup-x64.exe` বা `NVMFGUnlock40-0.1.1-Portable-x64.zip` ডাউনলোড করুন যখন এটির রিলিজ পাওয়া যায়।
3. SHA-256 চেক করুন এবং সাথে থাকা বিজ্ঞপ্তিগুলি রাখুন। .NET ফ্রেমওয়ার্ক 4.8 ইনস্টল করুন যদি Windows ইতিমধ্যে এটি প্রদান না করে থাকে।
4. সেটআপ চালান, অথবা লিখনযোগ্য স্থানীয় ফোল্ডারে **সম্পূর্ণ** পোর্টেবল জিপটি বের করুন।
5. `NVMFGUnlock40.exe` চালু করুন; `agent`, `driver`, `engine` এবং `Licenses` সরবরাহকৃত লেআউটে রাখুন।

`driver` নামের ফোল্ডারটিতে ইউজার-স্পেস হেল্পার রয়েছে, কার্নেল ড্রাইভার নয়। সামঞ্জস্যতা জোরপূর্বক শুধুমাত্র প্রধান EXE অনুলিপি বা প্রদানকারী হ্যাশ প্রতিস্থাপন করবেন না. বর্তমান EXE গুলি স্বাক্ষরবিহীন৷

<a id="usage"></a>
## ব্যবহার

1. কন্ট্রোলার অক্ষম দিয়ে শুরু করুন। একটি গেম বা একটি প্যারেন্ট ফোল্ডার যোগ করুন এবং প্রকৃত ইনস্টলেশন নির্বাচন করুন।
2. প্রতিটি গেমের MFG সেটিংস পর্যালোচনা করুন। এর মেনু কি অফার করে তার উত্তর দিন; উত্তর গেম প্রতি সংরক্ষণ করা হয়.
3. বিশ্বব্যাপী Dynamic বা ইন-গেম সেটিং বেছে নিন, তারপর প্রয়োজন অনুযায়ী গেম প্রতি যোগ্য পছন্দগুলি সামঞ্জস্য করুন।
4. আপনি যখন এটি ব্যবহার করতে চান শুধুমাত্র তখনই কন্ট্রোলার সক্ষম করুন৷ এটি একটি পুনরুদ্ধার জার্নাল সহ ছয়টি বিশ্বব্যাপী NVIDIA প্রোফাইল সেটিংস সাময়িকভাবে পরিবর্তন করতে পারে।
5. একটি যোগ্য গেম চালু করুন এবং এর নিজস্ব DLSS Frame Generation সক্ষম করুন৷ V-Sync-অফ পছন্দের জন্য যেকোনো অনুরোধ অনুসরণ করুন।
6. আপনি পরিচালনা করতে চান না এমন গেমগুলির জন্য বর্জন ব্যবহার করুন৷ একটি গেম সরানো একটি বর্জন রেকর্ড করে এবং এর ফাইল/ব্যাকআপ সংরক্ষণ করে।
7. শেষ হলে অ্যাপ্লিকেশনটির সম্পূর্ণ প্রস্থান/অক্ষম এবং পুনরুদ্ধার প্রবাহ ব্যবহার করুন।

প্রধান উইন্ডোটি বন্ধ করলে কন্ট্রোলারটি ট্রেতে চলে যেতে পারে। একটি গেমের মধ্যে ইতিমধ্যেই লোড করা একটি DLL গেমটি প্রস্থান না হওয়া পর্যন্ত সেখানে থাকে; কন্ট্রোলার নিষ্ক্রিয় করা একটি আনলোড গ্যারান্টি নয়। রক্ষণাবেক্ষণ বা আপডেটের আগে প্রভাবিত গেমগুলি বন্ধ করুন।

**Streamline SDKs:** NVIDIA SDK পৃষ্ঠায়, একটি অফিসিয়াল সংস্করণ ডাউনলোড করুন বা একটি সামঞ্জস্যপূর্ণ স্থানীয় SDK আমদানি করুন৷ আমদানি একটি যাচাইকৃত অনুলিপি সঞ্চয় করে; **Use this version** এটি নির্বাচন করে, এবং **Uninstall** সেই ক্যাশে করা অনুলিপিটি সরিয়ে দেয়। অনুপস্থিত Streamline DLLগুলিকে একটি অফিসিয়াল NVIDIA SDK থেকে সম্পূরক করা যেতে পারে, উৎস দেখানো হয়েছে৷ এটি একটি NGX মডেল ডাউনলোড/প্রতিস্থাপন করে না। গেমটি বন্ধ করুন, উদ্দেশ্যযুক্ত গেম আপডেটটি নির্বাচন করুন এবং এর আসল ব্যাকআপটি ধরে রাখুন। গেম ফাইলগুলি প্রত্যাবর্তন করতে, এর ব্যাকআপ পুনরুদ্ধার ব্যবহার করুন, ক্যাশের Uninstall বোতাম নয়।

## আপডেট এবং আনইনস্টল

প্রভাবিত গেমগুলি বন্ধ করুন। NVMFG অক্ষম/প্রস্থান করুন এবং আপডেট করার আগে যেকোনো মুলতুবি NVIDIA সেটিংস পুনরুদ্ধারের সমাধান করুন। বিদ্যমান পরিচয় সহ পরবর্তী সেটআপটি ইনস্টল করুন, বা নতুন পোর্টেবলটিকে একটি নতুন ফোল্ডারে বের করুন; রাষ্ট্র/ব্যাকআপ ধরে রাখুন।

আনইনস্টল করার আগে, অ্যাপ্লিকেশনের মাধ্যমে পছন্দসই গেম SDK ব্যাকআপ এবং NVIDIA সেটিংস পুনরুদ্ধার করুন, তারপর গেমগুলি বন্ধ করুন এবং কন্ট্রোলারটি ছেড়ে দিন। সেটআপের জন্য Windows **Installed apps** ব্যবহার করুন, অথবা প্রয়োজনীয় ফাইলগুলি সংরক্ষণ করার পরে বন্ধ পোর্টেবল ফোল্ডারটি সরান৷ সেটআপ আনব্লক করতে একটি সক্রিয় পুনরুদ্ধার জার্নাল ম্যানুয়ালি মুছবেন না।

স্থানীয় গেম-রানটাইম ব্যাকআপ `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups` ব্যবহার করে। MFG সেটিংস/SDK ডেটা `%LOCALAPPDATA%\RtxMfg` ব্যবহার করে; সেশন আউটপুট অ্যাপ্লিকেশনের পাশে `Sessions` এর অধীনে রয়েছে। এই ফাইলগুলিতে গেম পাথ থাকতে পারে। তাদের unredacted পোস্ট করবেন না.

<a id="known-limitations"></a>
## পরিচিত সীমাবদ্ধতা

- পরীক্ষামূলক নেটিভ প্যাচ ক্র্যাশ বা ভিজ্যুয়াল আর্টিফ্যাক্ট হতে পারে; একটি অমীমাংসিত Bodycam ক্র্যাশ উন্নয়ন ইতিহাসে নথিভুক্ত করা হয়েছে৷
- নিয়ন্ত্রিত রেন্ডারার পরীক্ষাগুলি প্রতিটি গেম, ড্রাইভার বা অ্যান্টি-চিটের জন্য সার্টিফিকেশন নয়।
- তৈরি ফ্রেম নতুন ইনপুট নমুনা তৈরি করে না; এই হাব দ্বারা কোন পরিমাপিত বিলম্ব বা কর্মক্ষমতা লাভের প্রতিশ্রুতি দেওয়া হয় না।
- একাধিক ফ্রেম-জেনারেশন টুল/ওভারলে বিবাদ হতে পারে। অ্যাপ্লিকেশন প্রতিটি সহাবস্থানের দৃশ্যকল্প প্রমাণ ছাড়াই পর্যবেক্ষণ মডিউল রিপোর্ট.
- সামঞ্জস্যতা ম্যানিফেস্ট একটি সনাক্তকরণ সহায়তা, সম্পূর্ণরূপে পরীক্ষিত গেমের তালিকা নয়।
- সম্পূর্ণ NVIDIA SDK শর্তাবলী এবং অমীমাংসিত প্রযুক্তিগত-সীমাবদ্ধতা [উত্স](../docs/provenance.md)-এ নথিভুক্ত রয়েছে।

## FAQ

**এতে কি NVIDIA DLL বা মডেল অন্তর্ভুক্ত আছে?** কোন ড্রাইভার, NGX প্রদানকারী/মডেল বা Streamline রানটাইম অন্তর্ভুক্ত নেই। স্পষ্ট SDK ডাউনলোডগুলি NVIDIA থেকে আসে।

**Dynamic কি V-Sync বন্ধ করে কাজ করে?** এটি সেই অবস্থায় সাসপেন্ড করা হয়েছে। সেই গেমের আলাদা অবস্থার জন্য ইন-গেম সেটিং বা একটি যোগ্য ফিক্সড মাল্টিপ্লায়ার বেছে নিন।

**এটি কি একটি ReShade/OptiScaler/FSR প্যাকেজ?** না। এগুলো এই প্রোডাকশন প্যাকেজের অংশ হিসেবে কম্পাইল করা বা পাঠানো হয়নি।

**পরিবর্তিত উৎসগুলি কি সর্বজনীন?** না। সংকলিত প্যাকেজ এবং প্রয়োজনীয় ক্রেডিট/ লাইসেন্স প্রদান করা হয়। এটি তৃতীয় পক্ষের অধিকার বা বিধিনিষেধকে সরিয়ে দেয় না।
