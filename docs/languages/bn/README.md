# NV Laboratory

**禅堂 Zendo (RevoluSound Team) দ্বারা NV Tools।** NVIDIA ড্রাইভার প্রোফাইল, ড্রাইভার ইনস্টলেশন, পরীক্ষামূলক Multi Frame Generation এবং RTSS ফ্রেম সীমার জন্য চারটি স্বাধীন Windows ইউটিলিটি।

[সরঞ্জাম পান](docs/downloads.md) · [ইনস্টলেশন](docs/installation.md) · [সামঞ্জস্য এবং সাহায্য](docs/support.md) · [ক্রেডিট এবং লাইসেন্স](THIRD_PARTY_NOTICES.md)

> **NVRasterPulse এর জন্য RTSS প্রয়োজন।** প্রথমে [Guru3D থেকে RivaTuner Statistics Server](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) ইনস্টল করুন। RTSS এর FPS সীমা কাজ করার জন্য চলমান থাকতে হবে। এটি আলাদাভাবে ডাউনলোড করা হয়।

<a id="start-here"></a>
## এখানে শুরু করুন

1. উপরে একটি টুল বাছুন. প্রতিটি স্বাধীনভাবে কাজ করে; পুরো স্যুট ইনস্টল করা অপ্রয়োজনীয়।
2. এর প্রয়োজনীয়তা পড়ুন এবং একটি ইনস্টল করা অ্যাপের জন্য **সেটআপ** বা একটি পৃথক ফোল্ডারের জন্য **পোর্টেবল** বেছে নিন।
3. যখন এটির প্রকাশ প্রকাশিত হয়, তখন নামযুক্ত অ্যাপ্লিকেশন সম্পদটি ডাউনলোড করুন, সহবর্তী বিজ্ঞপ্তিগুলি পড়ুন এবং এর SHA-256 তুলনা করুন।
4. ড্রাইভার, ডিসপ্লে সেটিং, NVIDIA প্রোফাইল বা গেম রানটাইম পরিবর্তন করার আগে ব্যাকআপ রাখুন।

প্রতিটি গাইডের শীর্ষে নির্বাচকের মাধ্যমে এনভি অ্যাপ্লিকেশনগুলির মতো একই 34টি ভাষায় ডকুমেন্টেশন উপলব্ধ। GitHub ব্রাউজারের ভাষা দ্বারা স্বয়ংক্রিয়ভাবে একটি README নির্বাচন করে না। ডকুমেন্টেশনের ভাষা এবং অ্যাপ্লিকেশনের নিজস্ব ভাষা সেটিং আলাদা।

<a id="provenance-and-ownership"></a>
## উত্স এবং মালিকানা

এই হাব ডকুমেন্টেশন এবং সংকলিত অ্যাপ্লিকেশন বিতরণ করে। অ্যাপ্লিকেশন সোর্স কোড ব্যক্তিগতভাবে রক্ষণাবেক্ষণ করা হয়. আপস্ট্রিম প্রকল্পগুলি তাদের লেখকত্ব এবং লাইসেন্স ধরে রাখে; ব্যক্তিগত উৎস বিতরণ এই শর্তাবলী প্রতিস্থাপন করে না।

- Profile Inspector fork Orbmu2k-এর MIT লাইসেন্স ধরে রাখে এবং স্পষ্টভাবে একটি fork হিসাবে চিহ্নিত।
- NVDriverForge এর নিজস্ব বাইনারি বন্টন শর্তাবলী রয়েছে এবং এতে আলাদাভাবে লাইসেন্সকৃত রানটাইম/টুল উপাদান অন্তর্ভুক্ত রয়েছে।
- NVMFG Unlock40 একটি স্বাধীনভাবে বিকশিত অ্যাপ্লিকেশন। তুলনা এবং পরিমার্জনের জন্য RTX40MFG-Unlock এর সাথে পরামর্শ করা হয়েছিল; ভাগ করা নেটিভ উপাদানগুলি তাদের MIT ক্রেডিট ধরে রাখে। MinHook এবং NVIDIA SDK পদগুলি আলাদা থাকবে৷
- NVRasterPulse সরবরাহকৃত MIT লাইসেন্স ধরে রাখে এবং Profile Inspector-প্রাপ্ত UI ক্রেডিট করে। RTSS একটি প্রয়োজনীয় বহিরাগত প্রোগ্রাম।

[সম্পূর্ণ উপাদান টেবিল](THIRD_PARTY_NOTICES.md), [ফাইলের উদ্ভব এবং পরিবর্তন](docs/provenance.md), এবং [লাইসেন্সের সুযোগ](../../../LICENSE) দেখুন।
