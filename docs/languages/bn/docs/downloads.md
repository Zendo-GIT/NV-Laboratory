# ডাউনলোড

একটি প্রোগ্রাম চয়ন করুন এবং হয় **সেটআপ** বা **পোর্টেবল**। প্রতিটি টুলের রিলিজ পৃষ্ঠা বর্তমান প্রাপ্যতা, প্রকাশনার তারিখ এবং রিলিজ নোট দেখায়। রক্ষণাবেক্ষণকারী সংশ্লিষ্ট সম্পদ প্রকাশ করলে সরাসরি লিঙ্কগুলি কাজ করে। আবেদনের উৎস ব্যক্তিগত থাকে। আপনার ডাউনলোডের সাথে `Licenses-and-Credits.zip` এবং `SHA256SUMS.txt` রাখুন। GitHub এর **Source code (zip)** বোতামে হাব ডকুমেন্টেশন রয়েছে।

> **NVRasterPulse-এর জন্য RTSS প্রয়োজন।** আলাদাভাবে [Guru3D থেকে RivaTuner Statistics Server](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) ইনস্টল করুন এবং FPS সীমিত করার জন্য এটি চালান।
