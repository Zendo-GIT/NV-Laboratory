# সামঞ্জস্য এবং সমস্যা সমাধান

এরা প্রস্তুত প্রার্থী, সমস্ত Windows, GPU, ড্রাইভার এবং গেমের সংমিশ্রণের জন্য সার্টিফিকেশন ম্যাট্রিক্স নয়।

| টুল | Windows / রানটাইম | হার্ডওয়্যার / বাহ্যিক নির্ভরতা | পরিচর্যা প্রয়োজন অপারেশন |
| --- | --- | --- | --- |
| NVPI fork 3.0.2.3 | Windows 10/11 x64, .NET ফ্রেমওয়ার্ক 4.8 | সামঞ্জস্যপূর্ণ NVIDIA ড্রাইভার/ডিসপ্লে | প্রোফাইল লেখা এবং পূর্বরূপ প্রদর্শন |
| NVDriverForge 0.1.2 | Windows 10 বিল্ড 19041+ / 11 x64; .NET/WPF অন্তর্ভুক্ত | সামঞ্জস্যপূর্ণ NVIDIA ড্রাইভার প্যাকেজ | উন্নত ইনস্টলেশন, উন্নত সেটিংস, ঐচ্ছিক NVENC |
| NVMFG Unlock40 0.1.1 | Windows 10/11 x64; .NET/WPF অন্তর্ভুক্ত, ফ্রেমওয়ার্ক 4.8 সহায়ক | RTX 40, যোগ্য DLSS FG গেম এবং পিন করা প্রদানকারী | নেটিভ ইন-গেম প্যাচিং, গ্লোবাল প্রোফাইল জার্নাল, SDK গেম আপডেট |
| NVRasterPulse 0.1 | Windows 10/11 x64, .NET ফ্রেমওয়ার্ক 4.8 | RTSS ইনস্টল করা হয়েছে; ক্যাপ জন্য দৌড়াচ্ছে | RTSS প্রতি এক্সিকিউটেবল প্রোফাইল পরিবর্তন |

কোনো ARM64 প্যাকেজ প্রস্তুত নেই। ডিসপ্লে/এপিআই প্রাপ্যতা এবং পুরানো Windows সংস্করণ পৃথক বৈশিষ্ট্য সীমিত করতে পারে। সর্বজনীন সর্বনিম্ন NVIDIA বা RTSS সংস্করণ উদ্ভাবিত হয়নি। সঠিক NVMFG প্রদানকারী হ্যাশ [উত্স](provenance.md) এ রয়েছে।

<a id="before-reporting-a-bug"></a>
## একটি বাগ রিপোর্ট করার আগে

আপনি যে সঠিক এক্সিকিউটেবল/সংস্করণটি খুলেছেন তা শনাক্ত করুন। একটি পূর্ববর্তী ইনস্টল করা অনুলিপি অগত্যা একটি নতুন ডাউনলোড করা জিপের সংস্করণ নয়৷ প্রজনন ধাপ, প্রত্যাশিত ফলাফল এবং প্রকৃত ফলাফল রেকর্ড করুন। রেন্ডারিং/সীমাবদ্ধ করার সমস্যাগুলির জন্য, গেমের সংস্করণ, ডিসপ্লে রিফ্রেশ, FG/V-Sync/VRR স্টেট এবং অন্য কোনও লিমিটার বা ওভারলে অন্তর্ভুক্ত করুন।

[বাগ ফর্ম](https://github.com/Zendo-GIT/NV-Laboratory/issues/new?template=bug-report.yml) ব্যবহার করুন। একটি সম্পূর্ণ প্রাইভেট ডেভেলপমেন্ট ফোল্ডার, ড্রাইভার আর্কাইভ, মডেল, গেম DLL, রেজিস্ট্রি ডাম্প বা অরিভিউ করা লগ সংগ্রহ কখনই সংযুক্ত করবেন না।

| সমস্যা | প্রথম চেক |
| --- | --- |
| ভুল অ্যাপ্লিকেশন সংস্করণ | EXE পরিচয় নিশ্চিত করুন এবং হ্যাশ রিলিজ করুন; প্রতিস্থাপনের আগে পুরানো কপি বন্ধ করুন। |
| রানটাইম/স্টার্টআপ ত্রুটি | প্রয়োজনীয় ফ্রেমওয়ার্ক 4.8 ইনস্টল করুন বা সমস্ত সরবরাহ করা পোর্টেবল সাবফোল্ডার ধরে রাখুন। |
| UAC বাতিল করা হয়েছে | শুধুমাত্র উদ্দেশ্যমূলক অপারেশন পুনরায় চেষ্টা করুন; বাতিল করা সফল ইনস্টলেশন নয়। |
| হ্যাশ/স্বাক্ষর অমিল | সেই প্রার্থীর ব্যবহার বন্ধ করুন এবং প্রত্যাশিত অফিসিয়াল বাইটগুলি পান। |
| NVPI রঙ/মোড প্রত্যাখ্যান করা হয়েছে | প্রত্যাবর্তন করুন এবং প্রকৃত ডিসপ্লে/ড্রাইভার দ্বারা সমর্থিত একটি সমন্বয় ব্যবহার করুন। |
| NVDF ব্যাকআপ বা পুনরুদ্ধার ব্যর্থতা | সুরক্ষিত কাজ এবং RECOVERY.txt সংরক্ষণ করুন; জার্নাল মুছে ফেলবেন না বা বিরোধপূর্ণ লেখা জোর করবেন না। |
| NVMFG মুলতুবি সেটিংস | গেম বন্ধ করে পুনরুদ্ধারের সমাধান করুন, অন্যান্য সরঞ্জাম থেকে পরিবর্তনগুলি সংরক্ষণ করুন। |
| RP ক্যাপ কোন প্রভাব নেই | RTSS চালান, আসল গেম EXE শনাক্ত করুন, হুকের অবস্থা এবং প্রতিযোগী সীমা পরিদর্শন করুন। |
| RP ক্যাপ অপসারণের পরেও টিকে থাকে | RTSS গ্লোবাল পরিদর্শন করুন; অপসারণ পরিবর্তন শুধুমাত্র স্থানীয় লিমিটার ওভাররাইড করে। |

<a id="logs-and-privacy"></a>
## লগ এবং গোপনীয়তা

| টুল | স্থানীয় ডেটা পর্যালোচনা করার জন্য, পাইকারি আপলোড নয় |
| --- | --- |
| NVDF | `%LOCALAPPDATA%\NVDriverForge`; সুরক্ষিত চাকরি `%PROGRAMDATA%\NVDriverForge\Jobs` |
| NVMFG | `%LOCALAPPDATA%\RtxMfg`; ব্যাকআপ `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`; EXE এর পাশে `Sessions` |
| RP | `%LOCALAPPDATA%\NVRasterPulse`; `Backups\RTSS` এর নিচে |
| NVPI | আপনার নির্বাচিত রপ্তানি এবং প্রদর্শিত ত্রুটি; কোনো সার্বজনীন লগ পাথ উদ্ভাবিত হয়নি |

আপনার শেয়ার করা টেক্সট/ছবি থেকে অ্যাকাউন্টের নাম, হোম ডিরেক্টরি, গেম-লাইব্রেরি পাথ, ডিভাইস শনাক্তকারী, টোকেন এবং সম্পর্কহীন উইন্ডোগুলি সরান। পুনরুদ্ধারের জন্য মূলগুলি ব্যক্তিগতভাবে রাখুন। পাবলিক ইস্যু সবার কাছে দৃশ্যমান।

একটি দুর্বলতা, বিপজ্জনক সুবিধাপ্রাপ্ত আচরণ বা অনিচ্ছাকৃত ধ্বংসাত্মক অপারেশনের জন্য, সর্বজনীনভাবে বিশদ পোস্ট করার পরিবর্তে [SECURITY.md](../SECURITY.md) অনুসরণ করুন।

<a id="what-has-been-verified"></a>
## যা যাচাই করা হয়েছে

হাব প্রস্তুতির জন্য, স্ট্যাটিক পেলোড/ZIP/হ্যাশ/মেটাডেটা স্ক্যান এবং ডকুমেন্টেশন চেক চালানো হয়েছিল। বিদ্যমান প্রাইভেট অ্যাপ্লিকেশন বিল্ড/ইউনিট/ইউআই পরীক্ষা ঐতিহাসিক, তারিখের প্রমাণ। এই প্রস্তুতির অংশ হিসেবে কোনো ড্রাইভার ইনস্টল, ডিসপ্লে পরিবর্তন, লাইভ RTSS অপারেশন বা গেম বেঞ্চমার্ক করা হয়নি।

"শনাক্ত করা", "লিখিত", "পুনরায় লোড করা", "ক্ষমতা উপলব্ধ" এবং "গেমে পরিমাপ করা" ভিন্ন ফলাফল। আপনি কোনটি পর্যবেক্ষণ করেছেন তা রিপোর্ট করুন।
