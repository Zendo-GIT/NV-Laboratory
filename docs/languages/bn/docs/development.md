# সংগ্রহস্থল আর্কিটেকচার এবং রক্ষণাবেক্ষণ

NV Laboratory হল একটি সর্বজনীন **ডকুমেন্টেশন এবং বাইনারি-ডিস্ট্রিবিউশন হাব**। এটি অ্যাপ্লিকেশন উত্স ধারণ করে না. চারটি প্রকল্প পৃথক বিল্ড ট্রি, সংস্করণ, পরিচয় এবং রিলিজ সম্পদ ধরে রাখে। তাদের ব্যক্তিগত উন্নয়ন ইতিহাস এই Git সংগ্রহস্থলে আমদানি করা হয় না।

<a id="layout"></a>
## লেআউট

| অবস্থান | উদ্দেশ্য |
| --- | --- |
| README.md / README.fr.md | ইংরেজি/ফ্রেঞ্চ এন্ট্রি পয়েন্ট |
| চারটি প্রকল্প ফোল্ডার | সম্পূর্ণ গাইড এবং প্রযোজ্য মূল নোটিশ |
| ডক্স | ডাউনলোড, সামঞ্জস্য, উদ্ভব, বিকাশ এবং প্রকাশ পদ্ধতি |
| ডক্স/releases.json | নিরীক্ষিত প্রার্থী/রিলিজ মেটাডেটা, আকার এবং হ্যাশ |
| ডক্স/উদ্দেশ্য | ফাইল/হ্যাশ তুলনা; কোনো অ্যাপ্লিকেশন কোড নেই |
| লাইসেন্স | সম্পূর্ণ তৃতীয় পক্ষের পাঠ্য এবং ইনস্টলার অনুবাদক ক্রেডিট শেয়ার করা হয়েছে৷ |
| সম্পদ | বিদ্যমান পর্যালোচিত UI পূর্বরূপ এবং তাদের উদ্ভব |
| .গিথুব | ইস্যু ফর্ম এবং শুধুমাত্র পঠন ডকুমেন্টেশন বৈধতা |
| টুলস/validate_repository.py | স্ট্যান্ডার্ড-লাইব্রেরি প্রকাশনা-সীমানা এবং লিঙ্ক চেক |

ইংরেজি ডিফল্ট GitHub README রয়ে গেছে। বিদ্যমান সংলগ্ন `.fr.md` লিঙ্কগুলি বৈধ থাকবে৷ অতিরিক্ত অনুবাদগুলি `docs/languages/<code>` এর অধীনে ডকুমেন্টেশনকে মিরর করে; ভাষা পরিবর্তন করার সময় ভাষা নির্বাচক একই পৃষ্ঠা রাখে। ক্যাটালগ `docs/languages/catalog.json` সমস্ত 34টি ভাষা এবং উৎস আঙ্গুলের ছাপ রেকর্ড করে। GitHub ব্রাউজারের ভাষা দ্বারা স্বয়ংক্রিয়ভাবে একটি README নির্বাচন করে না। [ভাষা সূচক এবং অনুবাদ নীতি](../../README.md) দেখুন।

| প্রোগ্রাম | ব্যক্তিগত প্রযুক্তি | বিতরণ |

<a id="local-checks"></a>
## স্থানীয় চেক

সংগ্রহস্থল রুট থেকে:

```text
python tools/validate_repository.py
```

Python 3.10 বা নতুন যথেষ্ট। চেকটি ফাইল, স্থানীয় মার্কডাউন লিঙ্ক, প্রয়োজনীয় নোটিশ/RTSS লিঙ্ক, রিলিজ মেটাডেটা এবং প্রকাশনার সীমানা পড়ে। এটি সফ্টওয়্যার চালায় না, নির্ভরতা ইনস্টল করে না বা নেটওয়ার্কের সাথে যোগাযোগ করে না।

GitHub ওয়ার্কফ্লো পুশ, পুল রিকোয়েস্ট বা ম্যানুয়াল প্রেষণে শুধুমাত্র-পঠনযোগ্য বিষয়বস্তুর অনুমতি সহ একই চেক চালায়। চেকআউট একটি নিরীক্ষিত প্রতিশ্রুতিতে পিন করা হয় এবং শংসাপত্রগুলি স্থায়ী হয় না। কোনো রিলিজ বা স্থাপনার কাজ কনফিগার করা নেই।

<a id="maintain-the-boundary"></a>
## সীমানা বজায় রাখুন

ইংরেজি রেফারেন্স, ফ্রেঞ্চ গাইড এবং প্রভাবিত অনুবাদ একসাথে আপডেট করুন। শুধুমাত্র ফর্ম্যাটিং তুলনা থেকে মূল পরিবর্তনগুলিকে আলাদা রাখুন৷ প্রকৃত প্রার্থীর হ্যাশ, আপস্ট্রিম কমিট রেফারেন্স এবং লাইসেন্স রেকর্ড করুন; একটি প্রকল্পের জনপ্রিয়তা থেকে একটি লাইসেন্স অনুমান না.

নতুন সংস্করণযুক্ত রিলিজ সম্পদ ব্যবহার করুন এবং পরিবর্তিত বাইনারি, আর্কাইভ এবং এমবেডেড নোটিশ পুনরায় অডিট করুন। এই সংগ্রহস্থলের বাইরে ব্যক্তিগত ব্যাকআপ সংরক্ষণ করুন। ব্যক্তিগত অ্যাপ্লিকেশন উত্স বা স্থানীয় বিল্ড ফোল্ডার আমদানি করতে একটি পাবলিক ওয়ার্কফ্লো ব্যবহার করবেন না৷

একটি কার্যকরী অ্যাপ্লিকেশন পরিবর্তনের জন্য উপযুক্ত পরীক্ষাগুলি ব্যক্তিগত প্রকল্পে চালানো হয়। ডকুমেন্টেশন আপডেটের জন্য ড্রাইভার ইনস্টলারদের পুনরায় চালাবেন না বা বাস্তব প্রোফাইল লিখবেন না। [ম্যানুয়াল রিলিজ পদ্ধতি](releasing.md)।
