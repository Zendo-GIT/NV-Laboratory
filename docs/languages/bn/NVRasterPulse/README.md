# NVRasterPulse

**অ্যাপ্লিকেশন প্রতি FPS RivaTuner Statistics Server এর মাধ্যমে সীমা।**

> **প্রথমে RTSS ইনস্টল করুন।** NVRasterPulse এর জন্য [RivaTuner Statistics Server (RTSS), Guru3D থেকে ডাউনলোড করা](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) প্রয়োজন। RTSS সীমা কার্যকর করার জন্য চলমান থাকতে হবে। কোন RTSS ইনস্টলার, হুক DLL বা SDK বান্ডিল করা নেই।

[0.1 এবং স্ট্যাটাস ডাউনলোড করুন](../docs/downloads.md#nvrasterpulse) · [ইনস্টলেশন](#installation) · [কিভাবে সীমাবদ্ধতা কাজ করে](#usage) · [লাইসেন্স](../../../../NVRasterPulse/LICENSE)

<a id="overview-and-purpose"></a>
## ওভারভিউ এবং উদ্দেশ্য

NVRasterPulse হল একটি কমপ্যাক্ট Windows ইন্টারফেস যা এক্সিকিউটেবল নামের RTSS ফ্রেম সীমা পরিচালনা করার জন্য। RTSS সীমাবদ্ধতা সম্পাদন করে। NVRasterPulse ট্রে অ্যাক্সেস এবং অবিরাম পছন্দ সহ সংশ্লিষ্ট প্রোফাইল মান, ব্যাকআপ এবং পুনরায় লোড করার অনুরোধগুলি পরিচালনা করে।

সম্পূর্ণ RTSS প্রোফাইল প্রতিস্থাপন না করে বা এর ওভারলে সেটিংসে বিরক্ত না করে সঠিক প্রতি-গেম সীমা সম্পাদনা করা সহজ করার জন্য এটি বিদ্যমান। বর্তমান **0.1** প্রার্থী হল একটি প্রয়োজনীয় RTSS ইনস্টলেশন চেক সহ 9 সেপ্টেম্বর, 2026-এর বিল্ড৷

<a id="features"></a>
## বৈশিষ্ট্য

- একটি চলমান অ্যাপ্লিকেশন নির্বাচন করুন বা ম্যানুয়ালি এটি সম্পাদনযোগ্য যোগ করুন।
- FPS সীমা 1 থেকে 1000 পর্যন্ত, তিন দশমিক স্থান পর্যন্ত সংরক্ষণ করুন।
- প্রবেশ করা মানগুলির সঠিক যুক্তিসঙ্গত এনকোডিং: 59.94 2997/50 হয়ে যায়।
- সক্রিয় অপেক্ষা (`PassiveWait=0`) সহ ফ্রন্ট এজ সিঙ্ক কনফিগারেশন (`SyncLimiter=1`)।
- প্রতি-নির্বাহযোগ্য প্রোফাইল আপডেট, স্বয়ংক্রিয় ব্যাকআপ এবং পারমাণবিক লেখা।
- অন্যান্য প্রোফাইল সামগ্রী বজায় রাখার সময় লিমিটার ওভাররাইড অপসারণ।
- RTSS ইনস্টলেশন সনাক্তকরণ, ম্যানুয়াল পাথ নির্বাচন এবং স্পষ্ট লঞ্চ/রিলোড।
- একক-ইন্সট্যান্স ট্রে অপারেশন, ঐচ্ছিক ইনস্টল করা স্টার্টআপ, 34টি ভাষা এবং চারটি থিম।
- স্বাভাবিক প্রস্থান এবং **প্রস্থান + RTSS** অ্যাকশন আলাদা করুন।

<a id="compatibility"></a>
## সামঞ্জস্য

| প্রয়োজনীয়তা | বিস্তারিত |
| --- | --- |
| সিস্টেম | Windows 10/11 x64 |
| রানটাইম | [.NET ফ্রেমওয়ার্ক 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48), প্রয়োজন হলে আলাদাভাবে ইনস্টল করুন |
| প্রয়োজনীয় সফটওয়্যার | RTSS এর সাথে `RTSS.exe`, একটি মিলে যাওয়া `Profiles` ডিরেক্টরি এবং সামঞ্জস্যপূর্ণ প্রোফাইল/রিলোড সমর্থন |
| GPU | RTSS সামঞ্জস্য সীমা নির্ধারণ করে; এই প্রোফাইল ম্যানেজারের একটি নির্দিষ্ট RTX প্রজন্মের প্রয়োজন নেই |
| অনুমতি | বর্তমান অ্যাপ্লিকেশন অ্যাডমিনিস্ট্রেটর অ্যাক্সেসের অনুরোধ করে; নির্বাচিত RTSS প্রোফাইল ফোল্ডারটি অবশ্যই অ্যাক্সেসযোগ্য হতে হবে |
| গেমস | RTSS হুকিং সমর্থন এবং প্রতিটি গেমের সীমাবদ্ধতার উপর নির্ভর করে; প্রতারণা বিরোধী গ্যারান্টি নেই |

এই হাব অডিট দ্বারা প্রতিটি ফাংশনের জন্য কোনও নির্দিষ্ট RTSS ন্যূনতম সংস্করণ প্রত্যয়িত হয়নি। একটি প্রোফাইল কী/রিলোড কাজ না করলে অফিসিয়াল বর্তমান বিতরণ ব্যবহার করুন এবং সঠিক সংস্করণটি রিপোর্ট করুন। ইনস্টল করা-কিন্তু থামানো RTSS ইনস্টলেশন চেক পাস করে; তারপর প্রকৃত সীমাবদ্ধ করার জন্য এটি শুরু করা আবশ্যক।

<a id="installation"></a>
## ইনস্টলেশন

1. **[Guru3D থেকে RTSS ডাউনলোড এবং ইনস্টল করুন](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/).**
2. [NVRasterPulse ডাউনলোড](../docs/downloads.md#nvrasterpulse) খুলুন এবং রিলিজের প্রাপ্যতা পরীক্ষা করুন।
3. `NVRasterPulse-0.1-win-x64-Setup.exe` বা `NVRasterPulse-0.1-win-x64-portable.zip` এবং নোটিশ/চেকসাম ডাউনলোড করুন।
4. SHA-256 তুলনা করুন। একটি লিখনযোগ্য স্থানীয় ফোল্ডারে সেটআপ চালান বা সমগ্র পোর্টেবল জিপটি বের করুন।
5. `NVRasterPulse.exe` খুলুন। যদি RTSS অনুপস্থিত থাকে, তাহলে **RTSS ডাউনলোড করুন** ব্যবহার করুন, এটি ইনস্টল করুন, তারপর **আবার চেক করুন**, অথবা ম্যানুয়ালি `RTSS.exe` নির্বাচন করুন।
6. RTSS এর স্বাভাবিক শর্টকাট বা NVRasterPulse এর RTSS বোতাম ব্যবহার করে শুরু করুন যদি এটি বন্ধ হয়ে যায়।

ঐচ্ছিক অনুস্মারক বন্ধ করা পূর্বশর্ত চেক এড়িয়ে যায় না। একটি নীরব Windows ট্রে স্টার্টআপ এই চেকটি প্রদর্শন করার আগে মূল উইন্ডোটি খোলা না হওয়া পর্যন্ত অপেক্ষা করে। সেটআপ শুধুমাত্র NVRasterPulse ইনস্টল করে। এর EXE স্বাক্ষরবিহীন।

<a id="usage"></a>
## ব্যবহার

1. উদ্দিষ্ট চলমান অ্যাপ্লিকেশন নির্বাচন করুন বা এর গেম EXE ব্রাউজ করুন।
2. প্রয়োজনে ভগ্নাংশের মান সহ 1 এবং 1000 FPS এর মধ্যে একটি সীমা লিখুন।
3. রিপোর্ট করা ফলাফল সংরক্ষণ করুন এবং চেক করুন। NVRasterPulse এক্সিকিউটেবলের RTSS প্রোফাইল আপডেট করে এবং পুনরায় লোড করার অনুরোধ করে।
4. RTSS চলছে তা নিশ্চিত করুন এবং অভিপ্রেত গেমের আচরণ যাচাই করুন।

প্রোফাইলগুলিকে **এক্সিকিউটেবল নাম** দ্বারা চাবি করা হয়, যেমন `Game.exe.cfg`। `Game.exe` ধারণকারী দুটি ভিন্ন ফোল্ডার একই RTSS প্রোফাইল শেয়ার করে; সম্পূর্ণ পথ সংরক্ষণ করা এই সংঘর্ষকে সরিয়ে দেয় না।

সংরক্ষণ ফ্রন্ট এজ সিঙ্ক এবং সক্রিয় অপেক্ষা ব্যবহার করে। সক্রিয় অপেক্ষা CPU ব্যবহার বাড়াতে পারে। বিকল্প `LimitTime` ক্ষেত্রগুলি নিরপেক্ষ করা হয়। বিদ্যমান মন্তব্য, ওভারলে সেটিংস এবং `EnableHooking=0` সংরক্ষিত আছে। RTSS গ্লোবাল প্রোফাইল পরিবর্তন করা হয়নি।

NVRasterPulse এর লিমিটার ওভাররাইডগুলি সরাতে ট্র্যাশ অ্যাকশন ব্যবহার করুন। এটি সম্পূর্ণ RTSS প্রোফাইল মুছে দেয় না। RTSS Global বা অন্য টুল থেকে উত্তরাধিকারসূত্রে প্রাপ্ত একটি সীমা পরেও প্রযোজ্য হতে পারে।

**বন্ধ করা এবং প্রস্থান করা:** প্রধান উইন্ডোটি ট্রেতে লুকিয়ে রাখতে পারে। সাধারণ **প্রস্থান করুন** RTSS চলমান এবং সংরক্ষিত সীমা অক্ষত রেখে দেয়। **প্রস্থান করুন + RTSS** বর্তমান অধিবেশনে ম্যাচিং RTSS প্রক্রিয়ার স্বাভাবিক বন্ধের অনুরোধ করে, আট সেকেন্ড পর্যন্ত অপেক্ষা করে এবং জোর করে হত্যা করে না। সংরক্ষিত সীমা উভয় ক্ষেত্রেই থাকে।

অ্যাপটিতে ভাষা এবং থিম বেছে নেওয়া হয়েছে। Windows-এ স্টার্টআপ সাইন-ইন ঐচ্ছিক এবং একটি ইনস্টল করা অনুলিপির উদ্দেশ্যে। তথ্য বোতাম সাধারণ কর্ম ব্যাখ্যা করে।

<a id="update-and-uninstall"></a>
## আপডেট এবং আনইনস্টল

NVRasterPulse থেকে প্রস্থান করুন, নতুন সংস্করণটি ডাউনলোড করুন এবং যাচাই করুন, তারপর এটির সেটআপ চালান বা পোর্টেবলটিকে একটি নতুন ফোল্ডারে বের করুন৷ সেটিংস এবং RTSS ব্যাকআপ সংরক্ষণ করুন। RTSS আপডেটগুলি আলাদা এবং Guru3D থেকে আসে৷

একটি ইনস্টল করা অনুলিপি সরাতে, Windows **Installed apps** ব্যবহার করুন। পোর্টেবলের জন্য, প্রস্থান করুন তারপর আপনার ব্যাকআপগুলি নিরাপদ হলে এর নিষ্কাশিত ফোল্ডারটি সরান৷ সংরক্ষিত RTSS সীমা NVRasterPulse আনইনস্টল করে মুছে ফেলা হয় না: প্রথমে অভিপ্রেত লিমিটার ওভাররাইডগুলি সরান৷ RTSS এর নিজস্ব আনইনস্টলার আছে।

স্থানীয় রাজ্য: `%LOCALAPPDATA%\NVRasterPulse`। স্বয়ংক্রিয় RTSS ব্যাকআপ: `%LOCALAPPDATA%\NVRasterPulse\Backups\RTSS`। একটি পুরানো `%LOCALAPPDATA%\RTSSProfileBridge` অবস্থান মাইগ্রেশনের জন্য পড়া হতে পারে। এই ফাইলগুলিতে ব্যক্তিগত এক্সিকিউটেবল পাথ থাকতে পারে এবং সর্বজনীনভাবে পোস্ট করা উচিত নয়।

<a id="known-limitations"></a>
## পরিচিত সীমাবদ্ধতা

- RTSS ক্যাপটি সম্পাদন করে। একটি সংরক্ষিত মান বা সফল পুনরায় লোড অনুরোধ একটি পরিমাপ করা ফ্রেম-টাইম ফলাফল নয়৷
- একই নামের এক্সিকিউটেবলরা একটি প্রোফাইল শেয়ার করে।
- আরেকটি বিশ্বব্যাপী/প্রতি-গেম লিমিটার ফলাফলকে প্রভাবিত করতে পারে; স্থানীয় ওভাররাইড নিষ্ক্রিয় করা একটি উত্তরাধিকারসূত্রে প্রাপ্ত ক্যাপ অপসারণ করে না।
- একটি ইচ্ছাকৃতভাবে নিষ্ক্রিয় RTSS হুক নিষ্ক্রিয় থাকে৷
- সক্রিয় অপেক্ষার একটি CPU/পাওয়ার ট্রেড-অফ রয়েছে৷
- কোনো সার্বজনীন খেলা, অ্যান্টি-চিট বা এন্ড-টু-এন্ড লেটেন্সি বৈধতা নেই।
- পূর্বের পরীক্ষামূলক স্বাধীন লিমিটার ইঞ্জিন সংকলিত বা পাঠানো হয় না।
- স্বয়ংক্রিয় ব্যাকআপগুলি একটি এক-ক্লিক পূর্ণ ব্যাকআপ-পুনরুদ্ধার ইন্টারফেস বোঝায় না।

## সমস্যা সমাধান

| উপসর্গ | অ্যাকশন |
| --- | --- |
| RTSS পূর্বশর্ত খোলা থাকে | প্রকৃত `RTSS.exe` এবং ম্যাচিং প্রোফাইল ফোল্ডার নির্বাচন করুন, তারপর আবার চেক করুন। |
| সীমা সংরক্ষিত কিন্তু কোন প্রভাব | RTSS শুরু করুন; সঠিক গেম EXE/প্রোফাইল, হুক অনুমতি এবং অন্যান্য সীমাবদ্ধতা যাচাই করুন। |
| সংরক্ষণ ব্যর্থ হয় | ফোল্ডার অনুমতি পরীক্ষা করুন এবং প্রদর্শিত ত্রুটি/ব্যাকআপ সংরক্ষণ করুন। |
| সীমা অপসারণের পরে অবশেষ | RTSS গ্লোবাল এবং অন্যান্য সরঞ্জামগুলি পরিদর্শন করুন; ট্র্যাশ অ্যাকশন শুধুমাত্র স্থানীয় লিমিটার ওভাররাইড সরিয়ে দেয়। |
| দুটি গেম একই সীমা পায় | তাদের এক্সিকিউটেবল ফাইলের নামগুলি অভিন্ন কিনা তা পরীক্ষা করুন। |
| প্রস্থান করুন + RTSS RTSS খোলা রেখে দেয় | RTSS বন্ধ করুন সাধারণত নিজে; এই আদেশটি ইচ্ছাকৃতভাবে জোরপূর্বক সমাপ্তি এড়ায়। |

যদি ম্যানুয়ালি একটি RTSS ব্যাকআপ পুনরুদ্ধার করা হয়, তাহলে প্রথমে RTSS বন্ধ করুন এবং উদ্দিষ্ট ব্যাকআপ দিয়ে প্রতিস্থাপন করার আগে বর্তমান প্রোফাইলটি সংরক্ষণ করুন। এটি সম্পর্কহীন প্রোফাইল সম্পাদনাগুলিকে ওভাররাইট করতে পারে; ফাইল এবং তারিখ পরিদর্শন করুন। [ভাগ করা সমর্থন](../docs/support.md)।

<a id="faq"></a>
## FAQ

**আমারও কি MSI আফটারবার্নার দরকার?** NVRasterPulse-এর RTSS প্রয়োজন; এটি আফটারবার্নার অ্যাপ্লিকেশনের উপর নির্ভর করে না। RTSS ডিস্ট্রিবিউটরের ইনস্টলেশন বিকল্পগুলি অনুসরণ করুন৷

**আমি কি RTSS চালানো ছাড়াই এটি ব্যবহার করতে পারি?** একবার ইনস্টলেশন শনাক্ত হলে আপনি প্রোফাইলগুলি পরিচালনা করতে পারেন, তবে RTSS সীমিত করার জন্য অবশ্যই চালাতে হবে৷

**কি প্রস্থান বা আনইনস্টল করা ক্যাপগুলি সরিয়ে দেয়?** না। NVRasterPulse সরানোর আগে স্পষ্টভাবে পছন্দসই লিমিটার ওভাররাইডগুলি সরান।

**এটি কি RTSS-এর fork?** না। এটি একটি স্বাধীন প্রোফাইল ম্যানেজার; কোনো RTSS উৎস বা এক্সিকিউটেবল অন্তর্ভুক্ত করা হয়নি।
