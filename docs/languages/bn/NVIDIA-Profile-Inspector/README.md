# NVIDIA Profile Inspector – NV Tools Fork

**[NVIDIA Profile Inspector Orbmu2k দ্বারা](https://github.com/Orbmu2k/nvidiaProfileInspector)-এর একটি স্বাধীন fork, যুক্ত ডিসপ্লে নিয়ন্ত্রণ সহ।** প্রাক্তন প্রকল্পের নাম: **NVPI Custom**।

[ডাউনলোড এবং রিলিজ অবস্থা](../docs/downloads.md#nvidia-profile-inspector) · [ইনস্টলেশন](#installation) · [আপস্ট্রিম এবং পরিবর্তন](#upstream-and-changes) · [লাইসেন্স](../../../../NVIDIA-Profile-Inspector/LICENSE)

<a id="overview"></a>
## ওভারভিউ

অ্যাপ্লিকেশনটি NVIDIA ড্রাইভার প্রোফাইল সম্পাদনা করে, প্রতি-অ্যাপ্লিকেশন সেটিংস সহ। এই fork সক্রিয় Windows প্রদর্শনের জন্য একটি **স্ক্রিন** সম্পাদক যোগ করে: রেজোলিউশন, রিফ্রেশ রেট, আউটপুট কালার সেটিংস, HDR এবং ইনস্টল করা ICC/WCS প্রোফাইল অ্যাসোসিয়েশন।

এটি প্রোফাইল এডিটরে সম্পর্কিত ডিসপ্লে নিয়ন্ত্রণ আনতে এবং পূর্বরূপ, নিশ্চিতকরণ এবং পুনরুদ্ধারের ফলাফলগুলিকে আরও পরিষ্কার করতে বিদ্যমান। এটি নতুন হার্ডওয়্যার ক্ষমতা স্থাপন করে না।

প্রথম প্রার্থী হল **3.0.2.3**, 9 সেপ্টেম্বর, 2026 থেকে পরিষ্কার করা স্বতন্ত্র সহচর বিল্ড ব্যবহার করে। এর বিদ্যমান এক্সিকিউটেবল `nvidiaProfileInspector.exe` রয়ে গেছে; ইনস্টলার এবং কিছু অভ্যন্তরীণ লেবেল এখনও `NVPI Custom NV` বলে। উপরের সর্বজনীন শিরোনামটি fork কে সনাক্ত করে ইনস্টলেশনের পরিচয় পরিবর্তন না করে বা এটি Orbmu2k এর অফিসিয়াল প্রকাশের ভান না করে।

<a id="features"></a>
## বৈশিষ্ট্য

- বিদ্যমান আপস্ট্রিম প্রোফাইল ব্রাউজিং, অ্যাপ্লিকেশন অ্যাসোসিয়েশন, সেটিং সম্পাদনা এবং প্রোফাইল আমদানি/রপ্তানি।
- **স্ক্রিন** ডিসপ্লে, মোড, Hz, RGB/YCbCr, রঙের গভীরতা, পরিসীমা এবং কালারমিট্রির জন্য ডায়ালগ।
- Windows HDR নিয়ন্ত্রণ এবং ইনস্টল করা ICC/WCS অ্যাসোসিয়েশন নির্বাচন।
- **কিপ** / **প্রত্যাবর্তন** এবং টাইমআউট পুনরুদ্ধারের সাথে একটি 15-সেকেন্ডের ডিসপ্লে প্রিভিউ।
- মোডের রিড-ব্যাক/HDR পরিবর্তন এবং পুনরুদ্ধার ব্যর্থতার রিপোর্ট করা হয়েছে।
- HDR এর আলাদা রিপোর্টিং, ACM/WCG সহ SDR এবং সিগন্যালের রঙের গভীরতা।
- আলাদাভাবে ইনস্টল করা অনুলিপির জন্য একটি NVRasterPulse লঞ্চার।

<a id="installation"></a>
## ইনস্টলেশন

1. [ডাউনলোড পৃষ্ঠা](../docs/downloads.md#nvidia-profile-inspector) খুলুন এবং প্রকাশনার স্থিতি পরীক্ষা করুন।
2. সেটআপ বা পোর্টেবল সম্পদ ডাউনলোড করুন এবং এর SHA-256 রিলিজ ম্যানিফেস্টের সাথে তুলনা করুন।
3. সেটআপের জন্য, `NVPI-CustomNV-3.0.2.3-Setup-r2.exe` চালান, একটি ভাষা নির্বাচন করুন এবং ইনস্টলার অনুসরণ করুন। এটি তার নিজস্ব শর্টকাট এবং আনইনস্টলার তৈরি করে।
4. পোর্টেবলের জন্য, একটি নতুন লিখনযোগ্য ফোল্ডারে সম্পূর্ণ জিপটি বের করুন। এক্সিকিউটেবলের পাশে `Reference.xml`, EXE কনফিগারেশন এবং সমস্ত নোটিশ রাখুন।
5. `nvidiaProfileInspector.exe` চালু করুন।

একা এডিটর ইনস্টল করা একটি প্রোফাইল প্রয়োগ করে না বা একটি GPU ড্রাইভার ইনস্টল করে না। সঙ্গী আলাদাভাবে ইনস্টল করে, `.nip` অ্যাসোসিয়েশন দখল করে না এবং সাইন-ইন করার সময় স্টার্টআপ সক্ষম করে না। বিদ্যমান বাইনারিগুলি স্বাক্ষরবিহীন।

<a id="usage"></a>
## ব্যবহার

**ইনস্টলার রিভিশন 2** মাউস/কীবোর্ড নেভিগেশন, হালকা/গাঢ় চেহারা এবং বাতিলকরণ সহ অন্যান্য সরঞ্জামগুলির মতো একই স্থানীয় 34-ভাষা নির্বাচক যোগ করে। পছন্দ সেটআপ প্রযোজ্য; এটি NVPI সম্পাদককে অনুবাদ করে না। একটি সুস্পষ্ট `/LANG=fr` যুক্তি বা নীরব মোড ইতিমধ্যেই একটি ভাষা প্রদানকারী কলকারীদের জন্য নির্বাচনকে বাইপাস করে।

**ড্রাইভার প্রোফাইল:** একটি প্রোফাইল নির্বাচন করুন, একটি ব্যাকআপ রপ্তানি করুন, তারপর শুধুমাত্র উদ্দিষ্ট সেটিংস সম্পাদনা করুন এবং সেগুলি প্রয়োগ করুন৷ অ্যাপ্লিকেশন অ্যাসোসিয়েশনগুলি নির্ধারণ করে কোন গেমটি একটি প্রোফাইল গ্রহণ করে। একটি সঞ্চিত মান প্রমাণ নয় যে প্রতিটি ড্রাইভার বা গেম এটি ব্যবহার করে।

**ডিসপ্লে কন্ট্রোল:** **স্ক্রিন** খুলুন, ডিসপ্লে এবং অনুরোধ করা মান বেছে নিন, তারপর প্রিভিউ শুরু করুন। 15 সেকেন্ডের মধ্যে **কিপ** বেছে নেওয়ার আগে ছবিটি পরীক্ষা করুন। **প্রত্যাবর্তন** ব্যবহার করুন, নিশ্চিতকরণ বন্ধ করুন বা পুনরুদ্ধারের অনুরোধ করতে এটির মেয়াদ শেষ হতে দিন। যেকোনো ব্যর্থতার বার্তা পড়ুন: একা একটি সফল API কল পুনরুদ্ধারের প্রমাণ নয়।

একটি ICC নির্বাচন একটি ইনস্টল করা প্রোফাইল অ্যাসোসিয়েশন পরিবর্তন করে; এটি একটি ICC ফাইল তৈরি, ক্যালিব্রেট বা পুনরায় বিতরণ করে না। HDR, ACM/WCG, RGB/YCbCr এবং bpc পাইপলাইনের বিভিন্ন দিক বর্ণনা করে। কোন নতুন স্বাধীন ACM সুইচ প্রদান করা হয় না.

**NVRasterPulse:** টুলবার বোতামটি সুরক্ষিত মালিকানা এবং অনুমতি সহ প্রোগ্রাম ফাইলের নীচে একটি পৃথকভাবে নিবন্ধিত সিস্টেম-ব্যাপী ইনস্টলেশন গ্রহণ করে। একটি পোর্টেবল কপি বা একটি ব্যবহারকারী-লেখাযোগ্য/লিঙ্ক করা পথ এই উন্নত লঞ্চার দ্বারা প্রত্যাখ্যান করা যেতে পারে। সেক্ষেত্রে নিজস্ব শর্টকাট ব্যবহার করে NVRasterPulse খুলুন। [RTSS আলাদাভাবে ইনস্টল করুন](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) NVRasterPulse ব্যবহার করতে।

<a id="update-and-uninstall"></a>
## আপডেট এবং আনইনস্টল

আপডেট করার আগে সম্পাদক বন্ধ করুন। এক্সপোর্ট করা প্রোফাইল রাখুন এবং নতুন fork রিলিজ ডাউনলোড করুন; একই সহচর আইডেন্টিটি ইনস্টল করুন বা একটি নতুন ফোল্ডারে পোর্টেবল ফাইলগুলি বের করুন৷ একটি নতুন এক্সিকিউটেবলের সাথে একটি পুরানো `Reference.xml` মিশ্রিত করবেন না। বান্ডিল আপস্ট্রিম আপডেট-চেক সাপ্রেশন এই fork এর অন্তর্গত।

একটি ইনস্টল করা অনুলিপির জন্য, Windows **Installed apps** এবং এর আনইনস্টলার ব্যবহার করুন৷ পোর্টেবলের জন্য, এটি বন্ধ করুন এবং আপনার রপ্তানি নিরাপদ হলে এটির নিষ্কাশিত ফোল্ডার সরান৷ এডিটর সরানো হলে ড্রাইভার প্রোফাইল এডিট, ডিসপ্লে প্রেফারেন্স, NVRasterPulse বা RTSS **না** পূর্বাবস্থায় ফেরানো যায়। অপসারণের আগে পছন্দসই সেটিংস পুনরুদ্ধার করুন।

<a id="known-limitations"></a>
## পরিচিত সীমাবদ্ধতা

- 15-সেকেন্ডের নিশ্চিতকরণ প্রতিটি ড্রাইভার ক্র্যাশ, পাওয়ার লস বা জোরপূর্বক শাটডাউনের জন্য একটি নজরদারি নয়।
- কিছু রঙ/গভীরতা/রিফ্রেশ সমন্বয় `NVAPI_NOT_SUPPORTED` প্রদান করে।
- সফ্টওয়্যার রিড-ব্যাক প্যানেলের বিট গভীরতা, রঙের নির্ভুলতা বা লেটেন্সি পরিমাপ করে না।
- স্ক্রীন সেটিংস বর্তমান Windows প্রদর্শনকে প্রভাবিত করে; এই ডায়ালগ প্রতি-গেম প্রদর্শন প্রিসেট তৈরি করে না।
- কোনো পারফরম্যান্স, অ্যান্টি-চিট বা সর্বজনীন HDR সামঞ্জস্যের গ্যারান্টি নেই।

## FAQ

**এটি কি অফিসিয়াল NVIDIA সফটওয়্যার নাকি Orbmu2k এর অফিসিয়াল বিল্ড?** না। এটি একটি স্বাধীন fork; আপস্ট্রিম লেখক এবং MIT লাইসেন্স ক্রেডিট রয়ে গেছে।

**NVDriverForge-এর কি এই সম্পাদকের প্রয়োজন?** না। NVDriverForge-এর ঐচ্ছিক Custom NV প্রিসেট নিজস্ব ইন্টিগ্রেশন ব্যবহার করে। সম্পাদক ইনস্টল করা একটি পৃথক পছন্দ।

**এই fork-এর জন্য কি RTSS বাধ্যতামূলক?** নং RTSS NVRasterPulse-এর FPS লিমিটারের জন্য বাধ্যতামূলক, প্রোফাইল বা স্ক্রিন সম্পাদনার জন্য নয়।

**উৎস কোথায়?** পরিবর্তিত আবেদনের উৎস ব্যক্তিগতভাবে রক্ষণাবেক্ষণ করা হয়। MIT নোটিশ এবং আপস্ট্রিম রিপোজিটরি প্রদান করা হয়; MIT-এর পরিবর্তিত উৎস প্রকাশের প্রয়োজন নেই।
