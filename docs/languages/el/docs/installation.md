# Οδηγός εγκατάστασης

Ξεκινήστε με το [Λήψεις](downloads.md), το οποίο καταγράφει την κατάσταση δημοσίευσης και τα ακριβή ονόματα στοιχείων. Αυτά είναι ξεχωριστά εργαλεία: εγκαταστήστε μόνο αυτά που χρειάζεστε.

> **Για το NVRasterPulse, εγκαταστήστε το [RTSS από την Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) πριν ανοίξετε τη διαχείριση προφίλ.**
> Το RTSS πρέπει να εκτελείται για την εφαρμογή ορίων. δεν περιλαμβάνεται στο NV Tools.

| Εργαλείο | Εγκατεστημένη έκδοση | Φορητή έκδοση | Κύριο προαπαιτούμενο |
| --- | --- | --- | --- |
| NVIDIA Profile Inspector – NV Tools Fork | NVPI-CustomNV-3.0.2.3-Setup-r2.exe | Εξαγωγή πλήρους NVPI ZIP | Πρόγραμμα οδήγησης NVIDIA και .NET Framework 4.8 |
| NVDriverForge | NVDriverForge-Setup.exe | NVDriverForge.exe, περιλαμβάνεται χρόνος εκτέλεσης | Συμβατό πρωτότυπο πακέτο προγραμμάτων οδήγησης NVIDIA για λειτουργίες εγκατάστασης |
| NVMFG Unlock40 | NVMFGUnlock40-0.2.3-Setup-x64.exe | Εξαγάγετε πλήρες NVMFG ZIP, διατηρήστε τους υποφακέλους | RTX 40, υπάρχον DLSS FG, ακριβής πάροχος και βοηθοί .NET Framework 4.8 |
| NVRasterPulse | NVRasterPulse-0.2-win-x64-Setup.exe | Εξαγωγή πλήρους RP ZIP | RTSS και .NET Framework 4.8 |

<a id="download-verify-install"></a>
## Λήψη, επαλήθευση, εγκατάσταση

1. Στην επιλεγμένη δημοσιευμένη Έκδοση, πραγματοποιήστε λήψη του ονομασμένου στοιχείου εφαρμογής, των ειδοποιήσεων ZIP και SHA256SUMS.txt.
2. Χρησιμοποιήστε το [Παράδειγμα SHA-256](downloads.md#sha-256), με το πραγματικό όνομα αρχείου που έχετε λάβει.
3. Για την εγκατάσταση, ακολουθήστε το κανονικό πρόγραμμα εγκατάστασης. Για φορητό ZIP, εξαγάγετε τα πάντα σε έναν νέο τοπικό εγγράψιμο φάκελο. μην εκτελείτε από το εσωτερικό του ZIP.
4. Ανοίξτε το EXE της εφαρμογής. Διατηρήστε τα συνοδευτικά αρχεία άδειας/διαμόρφωσης/δεδομένων.
5. Διαβάστε τις οδηγίες χρήσης αυτού του εργαλείου πριν ενεργοποιήσετε τις ρυθμίσεις ή τις λειτουργίες συστήματος.

Τα τρέχοντα δυαδικά αρχεία δεν είναι υπογεγραμμένα. Ένας κατακερματισμός που ταιριάζει επιβεβαιώνει τα αναμενόμενα byte. δεν είναι πιστοποιητικό ασφάλειας ή συμβατότητας. Μην απενεργοποιείτε τις προστασίες ασφαλείας Windows μόνο και μόνο για να καταστείλετε μια προειδοποίηση.

Η εγκατάσταση του NVDF ή του προαιρετικού του NVPI είναι ξεχωριστή από την εγκατάσταση ενός προγράμματος οδήγησης GPU. Το συνοδευτικό NVPI διατηρεί το υπάρχον όνομα εσωτερικής εγκατάστασης. Το ανυψωμένο κουμπί RasterPulse του απαιτεί μια προστατευμένη εγκατάσταση σε όλο το σύστημα. άλλα αντίγραφα RP μπορούν να ανοίξουν μέσω των δικών τους συντομεύσεων.

Το NVMFG είναι πειραματικό και έχει το [τεκμηριωμένο αποθεματικό άδειας NVIDIA SDK](provenance.md). Δεν περιλαμβάνεται πρόγραμμα οδήγησης NVIDIA, πάροχος/μοντέλο NGX ή χρόνος εκτέλεσης παιχνιδιού Streamline. Επιλεγμένες λήψεις SDK και ενημερώσεις παιχνιδιών αποτελούν ρητά ξεχωριστές λειτουργίες.

<a id="language-and-updates"></a>
## Γλώσσα και ενημερώσεις

Χρησιμοποιήστε τον επιλογέα 34 γλωσσών του README για τεκμηρίωση. Τα NVDF, NVMFG και RP έχουν τη δική τους ρύθμιση διεπαφής χρήστη 34 γλωσσών. Το NVPI διατηρεί την υπάρχουσα γλωσσική του υποστήριξη. Ορισμένες τεχνικές συμβολοσειρές του προγράμματος εγκατάστασης επιστρέφουν στα Αγγλικά.

Διατηρήστε την ταυτότητα εγκατάστασης ενός εργαλείου κατά την ενημέρωση. Κλείστε το πρώτα και διατηρήστε τα αντίγραφα ασφαλείας. Για το NVMFG, κλείστε τα επηρεαζόμενα παιχνίδια και επιλύστε την ανάκτηση προφίλ που εκκρεμεί. Για φορητές ενημερώσεις, χρησιμοποιήστε έναν νέο φάκελο αντί να συνδυάσετε εκδόσεις.

<a id="removing-a-tool"></a>
## Αφαίρεση εργαλείου

Η απεγκατάσταση μιας εφαρμογής δεν αναιρεί αυτόματα τις ρυθμίσεις της.

- **NVPI:** επαναφέρετε τα προβλεπόμενα προφίλ/ρυθμίσεις οθόνης πριν την αφαίρεση, εάν χρειάζεται.
- **NVDF:** χρησιμοποιήστε πρώτα την ανάκτηση εάν θέλετε να επαναφέρετε προχωρημένους/NVENC αλλαγές. Uninstall αφήνει το πρόγραμμα οδήγησης γραφικών, τις ρυθμίσεις και τα αντίγραφα ασφαλείας.
- **NVMFG:** κλείστε παιχνίδια, απενεργοποιήστε/κλείστε το χειριστήριο, επιλύστε την ανάκτηση NVIDIA και επαναφέρετε τα επιθυμητά αντίγραφα ασφαλείας του παιχνιδιού SDK πριν την αφαίρεση.
- **RP:** καταργήστε πρώτα τις προβλεπόμενες παρακάμψεις περιοριστή. Το Uninstall δεν διαγράφει τα αποθηκευμένα καλύμματα RTSS ούτε αφαιρεί το RTSS.

Δείτε κάθε [οδηγός έργου](../README.md#projects) για ακριβείς τοποθεσίες δεδομένων και περιορισμούς ή [υποστήριξη](support.md) εάν ένα βήμα ανάκτησης αποτύχει.
