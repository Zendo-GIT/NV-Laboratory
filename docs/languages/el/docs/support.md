# Συμβατότητα και αντιμετώπιση προβλημάτων

Αυτοί είναι οι προετοιμασμένοι υποψήφιοι, όχι μια μήτρα πιστοποίησης για όλους τους συνδυασμούς Windows, GPU, προγραμμάτων οδήγησης και παιχνιδιών.

| Εργαλείο | Windows / χρόνος εκτέλεσης | Υλικό / εξωτερική εξάρτηση | Επεμβάσεις που χρειάζονται φροντίδα |
| --- | --- | --- | --- |
| NVPI fork 3.0.2.3 | Windows 10/11 x64, .NET Framework 4.8 | Συμβατό πρόγραμμα οδήγησης/οθόνη NVIDIA | Το προφίλ γράφει και εμφανίζει προεπισκοπήσεις |
| NVDriverForge 0.1.4 | Windows 10 έκδοση 19041+ / 11 x64; Περιλαμβάνεται .NET/WPF | Συμβατό πακέτο προγραμμάτων οδήγησης NVIDIA | Αυξημένη εγκατάσταση, προηγμένες ρυθμίσεις, προαιρετικό NVENC |
| NVMFG Unlock40 0.2.3 | Windows 10/11 x64; Περιλαμβάνεται .NET/WPF, βοηθοί Framework 4.8 | RTX 40, κατάλληλο παιχνίδι DLSS FG και καρφιτσωμένος πάροχος | Εγγενής ενημέρωση κώδικα εντός παιχνιδιού, παγκόσμιο ημερολόγιο προφίλ, ενημερώσεις παιχνιδιών SDK |
| NVRasterPulse 0.2 | Windows 10/11 x64, .NET Framework 4.8 | Εγκατεστημένο το RTSS. τρέχει για καπάκια | Αλλαγές προφίλ RTSS ανά εκτελέσιμο |

Δεν έχει ετοιμαστεί πακέτο ARM64. Η διαθεσιμότητα Display/API και οι παλιές εκδόσεις Windows μπορούν να περιορίσουν μεμονωμένες λειτουργίες. Δεν έχει εφευρεθεί καμία καθολική ελάχιστη έκδοση NVIDIA ή RTSS. Ο ακριβής κατακερματισμός παρόχου NVMFG βρίσκεται στο [προέλευσης](provenance.md).

<a id="before-reporting-a-bug"></a>
## Πριν αναφέρετε ένα σφάλμα

Προσδιορίστε το ακριβές εκτελέσιμο αρχείο/έκδοση που ανοίξατε. Ένα προηγούμενο εγκατεστημένο αντίγραφο δεν είναι απαραίτητα η έκδοση ενός ZIP που λήφθηκε πρόσφατα. Καταγράψτε τα βήματα αναπαραγωγής, το αναμενόμενο αποτέλεσμα και το πραγματικό αποτέλεσμα. Για ζητήματα απόδοσης/περιορισμού, συμπεριλάβετε την έκδοση παιχνιδιού, την ανανέωση οθόνης, την κατάσταση FG/V-Sync/VRR και οποιονδήποτε άλλο περιοριστή ή επικάλυψη.

Χρησιμοποιήστε το [φόρμα σφάλματος](https://github.com/Zendo-GIT/NV-Laboratory/issues/new?template=bug-report.yml). Ποτέ μην επισυνάπτετε έναν ολόκληρο φάκελο ιδιωτικής ανάπτυξης, αρχείο προγράμματος οδήγησης, μοντέλο, DLL παιχνιδιού, ένδειξη μητρώου ή συλλογή αρχείων καταγραφής που δεν έχει ελεγχθεί.

| Πρόβλημα | Πρώτοι έλεγχοι |
| --- | --- |
| Λάθος έκδοση εφαρμογής | Επιβεβαίωση ταυτότητας EXE και απελευθέρωση κατακερματισμού. κλείστε το παλαιότερο αντίγραφο πριν το αντικαταστήσετε. |
| Σφάλμα χρόνου εκτέλεσης/εκκίνησης | Εγκαταστήστε το απαιτούμενο Framework 4.8 ή διατηρήστε όλους τους παρεχόμενους φορητούς υποφακέλους. |
| Το UAC ακυρώθηκε | Δοκιμάστε ξανά μόνο την προβλεπόμενη λειτουργία. Η ακύρωση δεν είναι επιτυχής εγκατάσταση. |
| Αναντιστοιχία κατακερματισμού/υπογραφής | Σταματήστε να χρησιμοποιείτε αυτόν τον υποψήφιο και αποκτήστε τα αναμενόμενα επίσημα byte. |
| Το χρώμα/λειτουργία NVPI απορρίφθηκε | Επαναφέρετε και χρησιμοποιήστε έναν συνδυασμό που υποστηρίζεται από την πραγματική οθόνη/πρόγραμμα οδήγησης. |
| Αποτυχία δημιουργίας αντιγράφων ασφαλείας ή ανάκτησης NVDF | Διατήρηση προστατευμένης εργασίας και RECOVERY.txt. Μην διαγράφετε το ημερολόγιο και μην επιβάλλετε αντικρουόμενες εγγραφές. |
| Ρυθμίσεις NVMFG σε εκκρεμότητα | Επιλύστε την ανάκτηση με παιχνίδια κλειστά, διατηρώντας τις αλλαγές από άλλα εργαλεία. |
| Το καπάκι RP δεν έχει κανένα αποτέλεσμα | Εκτελέστε το RTSS, αναγνωρίστε το πραγματικό παιχνίδι EXE, επιθεωρήστε την κατάσταση του άγκιστρου και τα ανταγωνιστικά όρια. |
| Το καπάκι RP παραμένει μετά την αφαίρεση | Επιθεωρήστε το RTSS Global. η αφαίρεση αλλάζει μόνο παρακάμψεις τοπικού περιοριστή. |

Το NVDriverForge προσφέρει μια τοπική αναφορά JSON με δυνατότητα προεπισκόπησης. Το NVMFG προσφέρει ένα διαγνωστικό στο About. Προτιμήστε αυτές τις φιλτραρισμένες αναφορές σε ένα πλήρες αρχείο καταγραφής και επιθεωρήστε τις πριν τις κοινοποιήσετε. Μια απόφραξη αποκατάστασης που αναφέρθηκε στο NVMFG 0.1.1 εξακολουθεί να μην έχει τεκμηριωμένη αιτία. διατηρεί το ημερολόγιό του και καταγράφει οποιονδήποτε διαθέσιμο κωδικό σφάλματος. Το NVRasterPulse Το 0.2 προσφέρει διαγνωστικά διαμόρφωσης στο μενού ενεργειών του, χωρίς μέτρηση του FPS.

<a id="logs-and-privacy"></a>
## Αρχεία καταγραφής και απόρρητο

| Εργαλείο | Τοπικά δεδομένα για έλεγχο, όχι για μεταφόρτωση χονδρικής |
| --- | --- |
| NVDF | `%LOCALAPPDATA%\NVDriverForge`; προστατευμένες εργασίες `%PROGRAMDATA%\NVDriverForge\Jobs` |
| NVMFG | `%LOCALAPPDATA%\RtxMfg`; αντίγραφα ασφαλείας `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`. `Sessions` δίπλα στο EXE |
| RP | `%LOCALAPPDATA%\NVRasterPulse`; `Backups\RTSS` κάτω από αυτό |
| NVPI | Οι εξαγωγές που επιλέξατε και το εμφανιζόμενο σφάλμα. καμία επινοημένη καθολική διαδρομή καταγραφής |

Καταργήστε ονόματα λογαριασμών, οικιακούς καταλόγους, διαδρομές παιχνιδιών-βιβλιοθήκης, αναγνωριστικά συσκευών, διακριτικά και άσχετα παράθυρα από το κείμενο/εικόνες που μοιράζεστε. Κρατήστε τα πρωτότυπα ιδιωτικά για ανάκτηση. Τα δημόσια θέματα είναι ορατά σε όλους.

Για ευπάθεια, επικίνδυνη προνομιακή συμπεριφορά ή ακούσια καταστροφική λειτουργία, ακολουθήστε το [SECURITY.md](../SECURITY.md) αντί να δημοσιεύετε λεπτομέρειες δημόσια.

<a id="what-has-been-verified"></a>
## Τι έχει επαληθευτεί

Για την προετοιμασία του διανομέα, πραγματοποιήθηκαν σαρώσεις στατικού ωφέλιμου φορτίου/ZIP/hash/μεταδεδομένων και έλεγχοι τεκμηρίωσης. Οι υπάρχουσες δοκιμές κατασκευής/μονάδας/UI της ιδιωτικής εφαρμογής αποτελούν ιστορικά, χρονολογημένα στοιχεία. Δεν πραγματοποιήθηκε εγκατάσταση προγράμματος οδήγησης, αλλαγή οθόνης, ζωντανή λειτουργία RTSS ή συγκριτική αξιολόγηση παιχνιδιού ως μέρος αυτής της προετοιμασίας.

"Εντοπίστηκε", "γραμμένο", "επαναφορτώθηκε", "διαθέσιμη δυνατότητα" και "μετρήθηκε στο παιχνίδι" είναι διαφορετικά αποτελέσματα. Αναφέρετε ποιο από αυτά παρατηρήσατε.
