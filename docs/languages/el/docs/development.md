<a id="repository-architecture-and-maintenance"></a>
# Αρχιτεκτονική και συντήρηση αποθετηρίου

Το NV Laboratory είναι ένας δημόσιος **κόμβος τεκμηρίωσης και δυαδικής διανομής**. Δεν περιέχει πηγή εφαρμογής. Τα τέσσερα έργα διατηρούν ξεχωριστά δέντρα κατασκευής, εκδόσεις, ταυτότητες και στοιχεία κυκλοφορίας. Το ιδιωτικό ιστορικό ανάπτυξής τους δεν εισάγεται σε αυτό το αποθετήριο Git.

<a id="layout"></a>
## Διάταξη

| Τοποθεσία | Σκοπός |
| --- | --- |
| README.md / README.fr.md | Σημεία εισόδου Αγγλικά/Γαλλικά |
| Τέσσερις φάκελοι έργου | Πλήρεις οδηγούς και ισχύουσες πρωτότυπες ανακοινώσεις |
| έγγραφα | Λήψεις, συμβατότητα, προέλευση, διαδικασία ανάπτυξης και έκδοσης |
| docs/releases.json | Ελεγμένα μεταδεδομένα υποψηφίου/έκδοσης, μεγέθη και κατακερματισμοί |
| έγγραφα/προέλευση | Συγκρίσεις αρχείων/κατακερματισμού. χωρίς κωδικό εφαρμογής |
| άδειες | Κοινόχρηστα πλήρη κείμενα τρίτων και πιστώσεις μεταφραστή προγράμματος εγκατάστασης |
| περιουσιακά στοιχεία | Υπάρχουσες αναθεωρημένες προεπισκοπήσεις διεπαφής χρήστη και η προέλευσή τους |
| .github | Έντυπα έκδοσης και επικύρωση τεκμηρίωσης μόνο για ανάγνωση |
| εργαλεία/validate_repository.py | Έλεγχοι τυποποιημένων εκδόσεων βιβλιοθήκης και ορίων και συνδέσμων |

Τα αγγλικά παραμένουν το προεπιλεγμένο GitHub README. Οι υπάρχοντες γειτονικοί σύνδεσμοι `.fr.md` παραμένουν έγκυροι. Οι πρόσθετες μεταφράσεις αντικατοπτρίζουν την τεκμηρίωση στο `docs/languages/<code>`. ο επιλογέας γλώσσας διατηρεί την ίδια σελίδα όταν αλλάζει γλώσσα. Ο κατάλογος `docs/languages/catalog.json` καταγράφει και τις 34 γλώσσες και τα δακτυλικά αποτυπώματα πηγής. Το GitHub δεν επιλέγει αυτόματα μια README ανά γλώσσα προγράμματος περιήγησης. Δείτε το [γλωσσικό ευρετήριο και μεταφραστική πολιτική](../../README.md).

## Τεχνολογίες εφαρμογών

| πρόγραμμα | Ιδιωτική τεχνολογία | Διανομή |
| --- | --- | --- |
| NVPI fork | C#, WPF, .NET Framework 4.8, NVAPI/Windows interop | Ολοκληρώστε τον φορητό φάκελο και ξεχωριστό Inno Setup |

| NVMFG Unlock40 | C#/WPF .NET 8, Βοηθοί Framework 4.8, κινητήρας C++20/MASM/MinHook | Φορητό δέντρο και εγκατάσταση |

Αυτό το δημόσιο ταμείο δεν μπορεί να δημιουργήσει εκ νέου τις εφαρμογές. Τα αυτόματα αρχεία "Source code" είναι στιγμιότυπα κόμβου. Οι σύνδεσμοι ανοδικής πηγής δεν αντιπροσωπεύουν την ακριβή ιδιωτική τροποποιημένη πηγή. Το δημόσιο CI επικυρώνει μόνο αυτό το αποθετήριο.

<a id="local-checks"></a>
## Τοπικοί έλεγχοι

Από τη ρίζα του αποθετηρίου:

```text
python tools/validate_repository.py
```

Python 3.10 ή νεότερο είναι αρκετό. Ο έλεγχος διαβάζει αρχεία, τοπικούς συνδέσμους Markdown, απαιτούμενες ειδοποιήσεις/ συνδέσμους RTSS, μεταδεδομένα έκδοσης και όρια δημοσίευσης. Δεν εκτελεί το λογισμικό, δεν εγκαθιστά εξαρτήσεις ή δεν έρχεται σε επαφή με δίκτυο.

Η ροή εργασίας GitHub εκτελεί τον ίδιο έλεγχο με άδεια περιεχομένου μόνο για ανάγνωση σε αίτημα ώθησης, έλξης ή μη αυτόματης αποστολής. Το Checkout είναι καρφιτσωμένο σε μια ελεγμένη δέσμευση και δεν διατηρεί τα διαπιστευτήρια. Δεν έχει ρυθμιστεί καμία εργασία απελευθέρωσης ή ανάπτυξης.

<a id="maintain-the-boundary"></a>
## Διατηρήστε το όριο

Ενημερώστε την αγγλική αναφορά, τους γαλλικούς οδηγούς και τις επηρεαζόμενες μεταφράσεις μαζί. Διατηρήστε τις ουσιαστικές αλλαγές χωριστά από τις συγκρίσεις μόνο για μορφοποίηση. Καταγράψτε πραγματικούς κατακερματισμούς υποψηφίου, αναφορές δέσμευσης ανάντη και άδειες χρήσης. Μην συνάγετε ποτέ μια άδεια από τη δημοτικότητα ενός έργου.

Χρησιμοποιήστε νέα εκδομένα στοιχεία Έκδοσης και ελέγξτε ξανά τα τροποποιημένα δυαδικά αρχεία, τα αρχεία και τις ενσωματωμένες ειδοποιήσεις. Διατηρήστε ιδιωτικά αντίγραφα ασφαλείας εκτός αυτού του αποθετηρίου. Μην χρησιμοποιείτε δημόσια ροή εργασιών για την εισαγωγή φακέλων πηγής ιδιωτικής εφαρμογής ή τοπικής έκδοσης.

Δοκιμές κατάλληλες για μια αλλαγή λειτουργικής εφαρμογής που εκτελούνται στο ιδιωτικό έργο. Μην εκτελείτε ξανά προγράμματα εγκατάστασης προγραμμάτων οδήγησης και μην γράφετε πραγματικά προφίλ για ενημέρωση τεκμηρίωσης. [Διαδικασία χειροκίνητης απελευθέρωσης](releasing.md).
