# Λήψεις

Επιλέξτε ένα πρόγραμμα και είτε **Ρύθμιση** ή **φορητό**. Η σελίδα Έκδοσης κάθε εργαλείου δείχνει την τρέχουσα διαθεσιμότητα, την ημερομηνία δημοσίευσης και τις σημειώσεις έκδοσης. Οι άμεσοι σύνδεσμοι λειτουργούν όταν ο συντηρητής δημοσιεύει τα αντίστοιχα περιουσιακά στοιχεία. Η πηγή της εφαρμογής παραμένει ιδιωτική. Διατηρήστε τα `Licenses-and-Credits.zip` και `SHA256SUMS.txt` με τη λήψη σας. Το κουμπί **Source code (zip)** του GitHub περιέχει την τεκμηρίωση του διανομέα.

> **Το NVRasterPulse απαιτεί RTSS.** Εγκαταστήστε το [RivaTuner Statistics Server από την Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) ξεχωριστά και εκτελέστε το για περιορισμό FPS.

<a id="sha-256"></a>
## SHA-256

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\NVDriverForge.exe'
```

Αντικαταστήστε το όνομα με το αρχείο που έχετε κατεβάσει και συγκρίνετε ολόκληρο τον κατακερματισμό. Μια αντιστοίχιση επαληθεύει την ταυτότητα με το μανιφέστο. Τα τρέχοντα EXE είναι ανυπόγραφα.
