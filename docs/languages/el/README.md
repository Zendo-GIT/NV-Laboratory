# NV Laboratory

**NV Tools από 禅堂 Zendo (RevoluSound Team).** Τέσσερα ανεξάρτητα βοηθητικά προγράμματα Windows για προφίλ προγραμμάτων οδήγησης NVIDIA, εγκατάσταση προγραμμάτων οδήγησης, πειραματικά όρια πλαισίου Multi Frame Generation και RTSS.

[Πάρτε τα εργαλεία](docs/downloads.md) · [Εγκατάσταση](docs/installation.md) · [Συμβατότητα και βοήθεια](docs/support.md) · [Πιστώσεις & άδειες](THIRD_PARTY_NOTICES.md)

> **Το NVRasterPulse απαιτεί RTSS.** Εγκαταστήστε πρώτα το [RivaTuner Statistics Server από την Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/). Το RTSS πρέπει να εκτελείται για να λειτουργήσουν τα όριά του FPS. Γίνεται λήψη χωριστά.

<a id="start-here"></a>
## Ξεκινήστε εδώ

1. Επιλέξτε ένα εργαλείο παραπάνω. Κάθε ένα λειτουργεί ανεξάρτητα. Η εγκατάσταση ολόκληρης της σουίτας είναι περιττή.
2. Διαβάστε τις απαιτήσεις του και επιλέξτε **Ρύθμιση** για μια εγκατεστημένη εφαρμογή ή **φορητή** για ξεχωριστό φάκελο.
3. Όταν δημοσιευτεί η Έκδοσή της, πραγματοποιήστε λήψη του ονομαζόμενου στοιχείου εφαρμογής, διαβάστε τις συνοδευτικές σημειώσεις και συγκρίνετε το SHA-256.
4. Διατηρήστε αντίγραφα ασφαλείας πριν αλλάξετε πρόγραμμα οδήγησης, ρύθμιση οθόνης, προφίλ NVIDIA ή χρόνο εκτέλεσης παιχνιδιού.

Η τεκμηρίωση είναι διαθέσιμη στις ίδιες 34 γλώσσες με τις εφαρμογές NV μέσω του επιλογέα στο επάνω μέρος κάθε οδηγού. Το GitHub δεν επιλέγει αυτόματα μια README ανά γλώσσα προγράμματος περιήγησης. Η γλώσσα τεκμηρίωσης και η ρύθμιση γλώσσας της εφαρμογής είναι ξεχωριστά.

<a id="provenance-and-ownership"></a>
## Προέλευση και ιδιοκτησία

Αυτός ο κόμβος διανέμει τεκμηρίωση και μεταγλωττισμένες εφαρμογές. Ο πηγαίος κώδικας της εφαρμογής διατηρείται ιδιωτικά. Τα έργα ανάντη διατηρούν την συγγραφή και τις άδειές τους. Η διανομή ιδιωτικής πηγής δεν αντικαθιστά αυτούς τους όρους.

- Το Profile Inspector fork διατηρεί την άδεια MIT του Orbmu2k και προσδιορίζεται ρητά ως fork.
- Το NVDriverForge έχει τους δικούς του όρους δυαδικής διανομής και περιλαμβάνει στοιχεία χρόνου εκτέλεσης/εργαλείου με χωριστή άδεια χρήσης.
- Το NVMFG Unlock40 είναι μια ανεξάρτητα αναπτυγμένη εφαρμογή. Ζητήθηκε η γνώμη του RTX40MFG-Unlock για σύγκριση και βελτίωση. Τα κοινά εγγενή στοιχεία διατηρούν τις πιστώσεις MIT τους. Οι όροι MinHook και NVIDIA SDK παραμένουν ξεχωριστοί.
- Το NVRasterPulse διατηρεί την παρεχόμενη άδεια MIT και πιστώνει τη διεπαφή χρήστη που προέρχεται από το Profile Inspector. Το RTSS είναι ένα απαιτούμενο εξωτερικό πρόγραμμα.

Δείτε τα [πλήρης πίνακας στοιχείων](THIRD_PARTY_NOTICES.md), [προέλευση και αλλαγές του αρχείου](docs/provenance.md) και [εύρος άδειας](../../../LICENSE).
