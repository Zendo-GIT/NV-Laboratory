# NVDriverForge

**Ετοιμάστε μια εγκατάσταση προγράμματος οδήγησης NVIDIA με σαφείς επιλογές στοιχείων και προαιρετικές ρυθμίσεις.**

[Λήψη 0.1.3 & κατάσταση](../docs/downloads.md#nvdriverforge) · [Εγκατάσταση](#installation) · [Πιστώσεις](#credits-and-upstream) · [Άδεια](../../../../NVDriverForge/LICENSE)

<a id="overview-and-purpose"></a>
## Επισκόπηση και σκοπός

Το NVDriverForge σάς καθοδηγεί μέσα από ένα αρχικό πακέτο προγραμμάτων οδήγησης NVIDIA: επιλέξτε το πρόγραμμα οδήγησης, επιθεωρήστε τα στοιχεία του, ελέγξτε τις προαιρετικές τροποποιήσεις και, στη συνέχεια, επιβεβαιώστε την εγκατάσταση. Υπάρχει για να κάνει αυτές τις επιλογές κατανοητές και να διατηρεί μαζί την εγκατάσταση, τις προνομιακές λειτουργίες και τις πληροφορίες ανάκτησης.

Είναι μια ανεξάρτητα αναπτυγμένη εφαρμογή εμπνευσμένη εν μέρει από τη ροή εργασιών του NVCleanstall. Δεν περιλαμβάνει NVCleanstall ούτε διεκδικεί πλήρη ισοτιμία χαρακτηριστικών.

<a id="features"></a>
## Χαρακτηριστικά

- NVIDIA Game Ready / Studio αναζήτηση και λήψεις. προαιρετική ανακάλυψη επείγουσας επιδιόρθωσης με μη αυτόματη εναλλακτική.
- Ανάλυση του αρχικού πακέτου, κατακερματισμών, υπογραφών NVIDIA, δηλώσεων και συμβατών εγγραφών INF.
- Επιλογή εξαρτημάτων με εξαρτήσεις και διατήρηση άγνωστων στοιχείων.
- Η έκδοση 0.1.3 διατηρεί επιλεγμένα προαιρετικά στοιχεία NVIDIA με δυνατότητα παράβλεψης και εξαιρεί μόνο επαληθευμένα μη ελεγμένα στοιχεία από τον εντοπισμό. Οι ήδη τρέχοντες ή μη εφαρμόσιμοι προαιρετικοί χρόνοι εκτέλεσης δεν επιβάλλονται πλέον ως κρίσιμα στοιχεία.
- Διαγράψτε τις περιλήψεις αποτυχίας εγκατάστασης και πρόσβαση σε λεπτομερή αρχεία καταγραφής και στις 34 γλώσσες.
- Ρητή επιβεβαίωση εγκατάστασης, προστατευμένη σταδιοποίηση και εξαγωγή υπαρχόντων πακέτων προγραμμάτων οδήγησης-καταστήματος.
- Προαιρετικές προηγμένες ρυθμίσεις, με ελέγχους πριν από την πτήση, ημερολόγια και ανάκτηση με επίγνωση συγκρούσεων.
- Προαιρετική προκαθορισμένη **Custom NV** με επώνυμες επιλογές και επεξηγήσεις, συμπεριλαμβανομένης μιας ξεχωριστής επιλογής αντοχής SILK και ελέγχων συμβατότητας.
- Προαιρετικές λήψεις ενημερωμένων εκδόσεων NVENC ακριβούς έκδοσης. Η δέσμευση πηγής και τα byte στόχου ελέγχονται.
- Μια ξεχωριστή, προαιρετική εγκατάσταση του Profile Inspector fork από την οθόνη Εργαλεία.
- Προαιρετικοί έλεγχοι ενημέρωσης εγκατεστημένου χρήστη, 34 γλώσσες διεπαφής και τέσσερα θέματα.

Οι διαθέσιμες σύνθετες επιλογές αφορούν το MPO, την ένδειξη DLSS, το Ansel, τον ύπνο ήχου NVIDIA, το MSI, την πολιτική/προτεραιότητα διακοπής, το HDCP, την εκκίνηση του κοντέινερ οθόνης και μια κατάλληλη υπηρεσία τηλεμετρίας παλαιού τύπου. Το καθένα έχει τις δικές του προϋποθέσεις και επιπτώσεις. αυτές δεν είναι καθολικές βελτιώσεις απόδοσης.

<a id="compatibility"></a>
## Συμβατότητα

| Απαίτηση | Λεπτομέρειες |
| --- | --- |
| Σύστημα | Windows 10 build 19041 ή νεότερο / Windows 11, x64 |
| GPU/πρόγραμμα οδήγησης | Συμβατό πακέτο NVIDIA και ανιχνευμένο υλικό. Η αυτόματη αναζήτηση καταλόγου καλύπτει κυρίως γνωστά μοντέλα GeForce |
| Χρόνος εκτέλεσης | .NET 8 / WPF 8.0.31 περιλαμβάνεται στην προετοιμασμένη αυτόνομη συσκευασία |
| Προνόμια | Κανονική ρύθμιση διεπαφής χρήστη/ανά χρήστη. Η εγκατάσταση του προγράμματος οδήγησης και οι αλλαγές συστήματος ζητούν πρόσβαση διαχειριστή |
| Δίκτυο | Απαιτείται για online αναζήτηση/λήψη NVIDIA και ρητά αιτήματα ανάντη NVENC. μπορεί να επιλεγεί ένα τοπικό πρωτότυπο πρόγραμμα οδήγησης |
| Συμπεριλαμβανόμενα εργαλεία | Μη τροποποιημένο 7-Zip 26.03, ειδοποιήσεις χρόνου εκτέλεσης, προαιρετικό συνοδευτικό MIT Profile Inspector |
| Προαιρετικός σύντροφος | .NET Framework 4.8 για το ξεχωριστό Profile Inspector fork |

Καμία αυθαίρετη ελάχιστη έκδοση προγράμματος οδήγησης δεν καλύπτει όλες τις δυνατότητες. Η αναζήτηση πολλαπλών GPU πρέπει να ταιριάζει με κάθε εντοπισμένο GPU. Τα μη υποστηριζόμενα/επαγγελματικά μοντέλα ενδέχεται να απαιτούν χειροκίνητη επιλογή προγράμματος οδήγησης. Το πρόγραμμα εγκατάστασης του NVIDIA παραμένει η τελική αρχή υλικού/OS.

<a id="installation"></a>
## Εγκατάσταση

1. Επισκεφτείτε το [λήψεις](../docs/downloads.md#nvdriverforge) και επιβεβαιώστε τη δημοσίευση της Έκδοσης.
2. Επιλέξτε `NVDriverForge-Setup.exe` για εγκατάσταση ή `NVDriverForge.exe` για φορητή χρήση.
3. Συγκρίνετε το SHA-256 με το `SHA256SUMS.txt` της έκδοσης.
4. Εκτελέστε το Setup για εγκατάσταση ανά χρήστη και τυπικό πρόγραμμα απεγκατάστασης ή τοποθετήστε το φορητό EXE σε έναν εγγράψιμο φάκελο και ανοίξτε τον.

Το φορητό περιλαμβάνει τον χρόνο εκτέλεσης και τον προαιρετικό εγκαταστάτη του. Η εγκατάσταση του NVDriverForge δεν εγκαθιστά πρόγραμμα οδήγησης GPU. Τα EXE του είναι προς το παρόν ανυπόγραφα.

<a id="usage"></a>
## Χρήση

1. **Πρόγραμμα οδήγησης:** λήψη από το NVIDIA ή επιλέξτε ένα αρχικό πρόγραμμα εγκατάστασης NVIDIA EXE. Αφήστε την ανάλυση να τελειώσει.
2. **Στοιχεία:** ελέγξτε τις περιγραφές και τις απαιτούμενες εξαρτήσεις. Διατηρούνται άγνωστα εξαρτήματα.
3. **Tweaks:** αφήστε τις ανεπιθύμητες επιλογές αμετάβλητες. Διαβάστε εφέ και συμβιβασμούς πριν επιλέξετε οτιδήποτε.
4. **Επισκόπηση:** ελέγξτε το ακριβές πρόγραμμα οδήγησης, τα στοιχεία και τις προαιρετικές λειτουργίες και, στη συνέχεια, επιβεβαιώστε την εγκατάσταση.
5. Αποδεχτείτε το UAC μόνο για τη λειτουργία που επιλέξατε. Τηρήστε τις οδηγίες ανάκτησης της προστατευμένης εργασίας.
6. Εάν το νέο πρόγραμμα οδήγησης χρειάζεται επανεκκίνηση, ακολουθήστε την κατάσταση που αναφέρεται. Οι αναβαλλόμενες λειτουργίες απαιτούν ρητή συνέχιση μετά από αυτήν την επανεκκίνηση.

Το Custom NV ξεκινά αμετάβλητο. Επιλέξτε μεμονωμένες ονομασμένες τιμές ή ελέγξτε την παρεχόμενη προεπιλογή και τις εξαιρέσεις της. Τα δύο πληροφοριακά εσωτερικά πεδία του δεν είναι γραμμένα ανεξάρτητα. Οι ρυθμίσεις εφαρμόζονται μόνο στην επαληθευμένη ροή εργασίας νέου προγράμματος οδήγησης, ποτέ με το άνοιγμα μιας προεπισκόπησης. Δεν απαιτείται εγκατάσταση του ξεχωριστού επεξεργαστή NVPI.

Η προαιρετική εργασία NVENC λαμβάνει συμβατά δεδομένα από μια καρφιτσωμένη δέσμευση keylase. Αλλάζει δύο DLL προγραμμάτων οδήγησης και ακυρώνει τις υπογραφές τους. μπορεί να απορριφθεί από Windows, κωδικοποιητές, DRM ή anti-cheat. Δεν υπάρχουν τέτοια δεδομένα ή NVIDIA DLL ενσωματωμένα στο NVDriverForge. [Όρια προέλευσης και αδειοδότησης](../docs/provenance.md).

Οι προτιμήσεις ελέγχουν τη γλώσσα, το θέμα και τους προαιρετικούς ελέγχους ενημέρωσης εγκατεστημένου χρήστη. Το φορητό δεν δημιουργεί την εγκατεστημένη εργασία ελέγχου φόντου. Τα εργαλεία και η ανάκτηση είναι ξεχωριστά από τα τέσσερα βήματα εγκατάστασης.

<a id="update-and-uninstall"></a>
## Ενημέρωση και απεγκατάσταση

Κλείστε το NVDriverForge, αποκτήστε το επόμενο επίσημο πακέτο και επαληθεύστε τον κατακερματισμό του. Χρησιμοποιήστε την ίδια ταυτότητα Setup για μια εγκατεστημένη ενημέρωση. αντικαταστήστε ένα κλειστό φορητό EXE με το νέο. Διατηρήστε τις ρυθμίσεις και τις προστατευμένες εργασίες.

Uninstall από Windows **Installed apps**. Καταργεί την εφαρμογή και την εργασία ενημέρωσης, όχι το πρόγραμμα οδήγησης NVIDIA. Οι ρυθμίσεις, τα αρχεία καταγραφής και τα αντίγραφα ασφαλείας παραμένουν. Εάν θέλετε, επαναφέρετε τις προηγμένες αλλαγές/NVENC μέσω της τεκμηριωμένης ροής ανάκτησης **πριν** την κατάργηση της εφαρμογής. Η επαναφορά απορρίπτει αντικρουόμενες αλλαγές από άλλο εργαλείο.

Τα τοπικά δεδομένα βρίσκονται κάτω από το `%LOCALAPPDATA%\NVDriverForge`. Οι προστατευμένες θέσεις εργασίας και οι εξαγωγές προγραμμάτων οδήγησης είναι υπό `%PROGRAMDATA%\NVDriverForge\Jobs`. Η φορητή χρήση δημιουργεί επίσης τοπικά δεδομένα. Η εξαγωγή από το κατάστημα προγραμμάτων οδήγησης δεν είναι εικόνα συστήματος ή αντίγραφο ασφαλείας πλήρους προφίλ.

<a id="known-limitations"></a>
## Γνωστοί περιορισμοί

- Χωρίς προσθήκες υλικού/επεξεργασία INF, αναγεννημένες υπογραφές NVIDIA, παραίτηση συμβατή με αντι-απάτη ή αυτόματη αποδοχή ανυπόγραφης προειδοποίησης.
- Χωρίς πλήρη αφαίρεση τηλεμετρίας/διαφήμισης, εξαγωγή λεπτού πακέτου ή αυτόματη πλήρη επαναφορά στο προηγούμενο πρόγραμμα οδήγησης.
- Η εγκατάσταση προγραμμάτων οδήγησης, η ανάκτηση εκκίνησης και η προαιρετική εγγραφή προφίλ δεν έχουν επικυρωθεί πλήρως σε πραγματικές μηχανές από τον έλεγχο του διανομέα.
- Η επανάληψη του μητρώου δεν αποτελεί απόδειξη πραγματικών εφέ HDCP, απόδοσης ή καθυστέρησης.
- Οι έλεγχοι υπογραφής χρησιμοποιούν τοπικά διαθέσιμο αξιόπιστο Windows. δεν πραγματοποιείται ηλεκτρονική ανάκληση.
- Υπάρχουν 34 γλώσσες, αλλά η πλήρης δοκιμή φυσικών ομιλητών/προσβασιμότητας παραμένει ημιτελής.

<a id="troubleshooting"></a>
## Αντιμετώπιση προβλημάτων

| Σύμπτωμα | Δράση |
| --- | --- |
| Ο διαδικτυακός κατάλογος δεν είναι διαθέσιμος | Επιλέξτε ένα αρχικό πακέτο από το [Λήψη προγραμμάτων οδήγησης NVIDIA](https://www.nvidia.com/en-us/drivers/). Μην αντικαταστήσετε ένα γειτονικό μοντέλο GPU. |
| Η αναζήτηση επείγουσας επιδιόρθωσης δεν είναι διαθέσιμη | Χρησιμοποιήστε το [Το φόρουμ προγραμμάτων οδήγησης NVIDIA Game Ready](https://www.nvidia.com/en-us/geforce/forums/game-ready-drivers/13/) και επαληθεύστε το πραγματικό πακέτο. |
| Η εγκατάσταση του NVIDIA αποτυγχάνει | Διαβάστε τη σύνοψη αποτυχίας και ανοίξτε τα λεπτομερή αρχεία καταγραφής. Τα προαιρετικά στοιχεία που είναι ήδη τρέχοντα ή δεν εφαρμόζονται παραμένουν με δυνατότητα παράβλεψης στο 0.1.3. Οι αποτυχημένες εγκαταστάσεις δεν ενεργοποιούν προαιρετικές τροποποιήσεις ή ροή επιτυχίας/επανεκκίνησης. |
| Αποτυχία υπογραφής/κατακερματισμού/δημιουργίας αντιγράφων ασφαλείας | Σταματήστε αυτήν την εγκατάσταση και διατηρήστε το σφάλμα. αποκτήστε ξανά το αρχικό πακέτο εάν είναι κατεστραμμένο. |
| Η επιλογή δεν είναι διαθέσιμη | Διαβάστε τον λόγο του υλικού, του στοιχείου ή του προγράμματος οδήγησης στόχου. κρατήστε το αναλλοίωτο. |
| Επανεκκίνηση ή εργασία σε εκκρεμότητα | Χρησιμοποιήστε τις οδηγίες ανάκτησης της εργασίας και το ρητό βιογραφικό. μην σβήσετε το ημερολόγιο του. |
| Επαναφορά της σύγκρουσης | Μια άλλη κατάσταση διαφέρει από την καταγεγραμμένη συναλλαγή. Διατηρήστε το και ζητήστε βοήθεια αντί να επιβάλλετε επαναφορά. |

Για αναφορές, συμπεριλάβετε την επιλεγμένη έκδοση εργαλείου, Windows, GPU, πρόγραμμα οδήγησης και αναπαραγώγιμα βήματα. διόρθωση μονοπατιών και προσωπικών στοιχείων από αρχεία καταγραφής. [Υποστήριξη](../docs/support.md).

<a id="faq"></a>
## FAQ

**Το Setup εγκαθιστά πρόγραμμα οδήγησης γραφικών;** Όχι. Αυτό απαιτεί ξεχωριστή ανάλυση, έλεγχο, επιβεβαίωση και αυξημένη διαδικασία εγκατάστασης της εφαρμογής.

**Χρειάζομαι NVCleanstall ή NVPI;** Όχι. Το NVCleanstall είναι μόνο έμπνευση. Το συνοδευτικό Profile Inspector είναι ένας ανεξάρτητος προαιρετικός επεξεργαστής.

**Κάνει κάθε πρόγραμμα οδήγησης NVIDIA μικρότερο ή ταχύτερο;** Όχι. Τα επιλεγμένα στοιχεία και οι προϋποθέσεις καθορίζουν τι μπορεί να αλλάξει. δεν υπόσχεται μετρημένο κέρδος.

**Πού είναι οι πηγές;** Οι δοκιμές πηγής και ιδιωτικών δοκιμών για συγκεκριμένη εφαρμογή διατηρούνται χωριστά. Αυτός ο κόμβος παρέχει τεκμηρίωση, δυαδικά αρχεία και συνδέσμους πηγών τρίτων που απαιτούνται για την απόδοση/αδειοδότηση.

Διατηρούνται τα δικαιώματα πηγής για συγκεκριμένη εφαρμογή. Δεν περιορίζει τα δικαιώματα που παρέχονται από τις ξεχωριστές άδειες τρίτων. [Πλήρεις ανακοινώσεις](LICENSES/README.md).
