# Ασφάλεια

Αυτή η πολιτική καλύπτει πακέτα εφαρμογών NV Tools και αυτόν τον κόμβο διανομής. Ο συντηρητής δίνει προτεραιότητα στις αναφορές που επηρεάζουν την πιο πρόσφατη δημοσιευμένη έκδοση κάθε εργαλείου. Οι προετοιμασμένοι υποψήφιοι δεν είναι μια ανακοινωμένη υποστηριζόμενη σταθερή έκδοση. Δεν υπόσχεται προθεσμία απάντησης ή πιστοποίηση ασφαλείας.

<a id="report-privately"></a>
## Αναφορά ιδιωτικά

Για ευπάθειες, μη ασφαλή αυξημένη συμπεριφορά, ακούσιες καταστροφικές αλλαγές ή έκθεση σε ευαίσθητα δεδομένα, χρησιμοποιήστε τη λειτουργία **Ασφάλεια → Report a vulnerability** του αποθετηρίου **όταν είναι ενεργοποιημένη**: [ιδιωτική αναφορά](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new).

**Αρχική ρύθμιση:** ο συντηρητής πρέπει να ενεργοποιήσει την ιδιωτική αναφορά ευπάθειας μετά τη δημιουργία του δημόσιου αποθετηρίου. Αυτό το αρχείο δεν το ενεργοποιεί και δεν έχει ισχυριστεί ότι υπάρχει γραμματοκιβώτιο ή ιδιωτικό κανάλι πριν από αυτό.

Εάν το κουμπί δεν είναι διαθέσιμο, ανοίξτε ένα δημόσιο ζήτημα που περιέχει μόνο: «Χρειάζομαι ένα ιδιωτικό κανάλι επαφής για μια αναφορά ασφαλείας σχετικά με το [εργαλείο/έκδοση]». Μην συμπεριλάβετε λεπτομέρειες εκμετάλλευσης, διαπιστευτήρια, επηρεαζόμενες διαδρομές, αρχεία καταγραφής ή συνημμένα. Περιμένετε να παράσχει ο συντηρητής ένα ιδιωτικό κανάλι πριν το μοιραστείτε.

Στην ιδιωτική αναφορά, συμπεριλάβετε εργαλείο/έκδοση και κατακερματισμό, εκδόσεις Windows/GPU/προγράμματος οδήγησης, αντίκτυπο, ελάχιστη ασφαλή αναπαραγωγή και εάν χρειάζεται ανάκτηση. Διαγραφή μυστικών και προσωπικών δεδομένων. διατήρηση τοπικών αρχείων ανάκτησης. Μην ανεβάζετε ιδιόκτητα DLL προγραμμάτων οδήγησης ή παιχνιδιών. Συντονίζει την αποκάλυψη με τον συντηρητή. μια ενημέρωση κώδικα/έκδοση απαιτεί έλεγχο και δεν είναι αυτόματη.


[GitHub ιδιωτική τεκμηρίωση αναφοράς](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
