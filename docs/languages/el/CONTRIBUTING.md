# Συμβάλλοντας

Το NV Laboratory διατηρείται από το 禅堂 Zendo (RevoluSound Team). Ο συντηρητής αποφασίζει τι γίνεται αποδεκτό και αποδεσμευμένο. Το άνοιγμα ενός αιτήματος έκδοσης ή έλξης δεν σημαίνει ότι μια συνεισφορά γίνεται αποδεκτή ή εξουσιοδοτείται για διανομή.

Χρησιμοποιήστε τη φόρμα σφάλματος ή δυνατότητας και προσδιορίστε το πρόγραμμα/έκδοση. Πρώτα αναζητήστε τα υπάρχοντα ζητήματα. Συζητήστε τις ουσιαστικές αλλαγές πριν προετοιμάσετε μια μεγάλη συνεισφορά. Για θέματα ασφαλείας, ακολουθήστε το [SECURITY.md](SECURITY.md).

Αυτός ο δημόσιος κόμβος περιέχει τεκμηρίωση, ειδοποιήσεις, μεταδεδομένα έκδοσης και επικύρωση αποθετηρίου. Η πηγή της εφαρμογής και οι δοκιμές διατηρούνται ιδιωτικά. Μην υποβάλλετε απομεταγλωττισμένο κώδικα, ιδιωτική πηγή, διαπιστευτήρια, προφίλ χρήστη ή εκτελέσιμα ωφέλιμα φορτία.

Τα PR τεκμηρίωσης θα πρέπει να διατηρούν τις 34 αντίστοιχες γλώσσες και την πλοήγηση ευθυγραμμισμένες, να διατηρούν τα ονόματα εντολών/αρχείων/προϊόντων και να περιγράφουν την πραγματική συμπεριφορά. Τα νέα στιγμιότυπα οθόνης πρέπει να είναι δικά σας, να προσδιορίζονται από την έκδοση και να μην έχουν προσωπικά στοιχεία. τα συνθετικά δεδομένα πρέπει να φέρουν ετικέτα. Παρέχετε προέλευση και άδεια για κάθε νέο περιουσιακό στοιχείο τρίτων.

Χρησιμοποιήστε UTF-8, LF, αναγνώσιμο Markdown και μικρές εστιασμένες αλλαγές. Το πρόγραμμα επικύρωσης Python χρησιμοποιεί μόνο την τυπική βιβλιοθήκη. Ταιριάξτε το υπάρχον στυλ του, αποφύγετε τις περιττές εξαρτήσεις και εκτελέστε:

```text
python tools/validate_repository.py
```

Για αλλαγές μεταδεδομένων έκδοσης, συμπεριλάβετε την ακριβή έκδοση/ετικέτα, τα μεγέθη αρχείων και το SHA-256 από τα ελεγμένα δυαδικά αρχεία και διατηρήστε τις σελίδες λήψης ευθυγραμμισμένες. Οι αλλαγές στην εφαρμογή απαιτούν ιδιωτική κατασκευή/δοκιμές κατάλληλες για την επηρεαζόμενη συμπεριφορά. ο έλεγχος τεκμηρίωσης δεν είναι δοκιμή εφαρμογής. Ποτέ μην εφευρίσκετε ιστορικά αποτελέσματα ή κέρδη.

Συνεισφέροντας πρωτότυπο υλικό του κέντρου, συμφωνείτε με την εμβέλεια της άδειας MIT στο [ΑΔΕΙΑ](../../../LICENSE). Κρατήστε ειδοποιήσεις τρίτων και προσδιορίστε τις αλλαγές σας. μην αντικαταστήσετε μια άδεια ανάντη. Η αποδοχή και η δημοσίευση παραμένουν αποφάσεις συντήρησης.
