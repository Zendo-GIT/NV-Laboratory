# Πιστώσεις ενεργητικού

Αυτές οι εικόνες καταγράφηκαν από τις εφαρμογές ή τη ρύθμιση στις 2026-09-09 και εξετάστηκαν οπτικά πριν συμπεριληφθούν. Είναι μη επεξεργασμένες προεπισκοπήσεις διεπαφής. Οι προεπισκοπήσεις εφαρμογών χρησιμοποιούν δεδομένα συνθετικών παραδειγμάτων. Η καταγραφή της εγκατάστασης προέρχεται από μια ιδιωτική δοκιμή που ακυρώθηκε πριν από την εγκατάσταση. Αυτές οι εικόνες δεν καθορίζουν συμβατότητα προγράμματος οδήγησης/SDK, αποτελέσματα συγκριτικής αξιολόγησης ή παιχνίδι που τρέχει.
