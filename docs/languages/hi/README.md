# NV Laboratory

**禅堂 Zendo (RevoluSound Team) द्वारा NV Tools।** NVIDIA ड्राइवर प्रोफाइल, ड्राइवर इंस्टॉलेशन, प्रयोगात्मक Multi Frame Generation और RTSS फ्रेम सीमाओं के लिए चार स्वतंत्र Windows उपयोगिताएँ।

[उपकरण प्राप्त करें](docs/downloads.md) · [स्थापना](docs/installation.md) · [अनुकूलता एवं सहायता](docs/support.md) · [क्रेडिट और लाइसेंस](THIRD_PARTY_NOTICES.md)

> **NVRasterPulse को RTSS की आवश्यकता है।** पहले [Guru3D से RivaTuner Statistics Server](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) इंस्टॉल करें। RTSS को अपनी FPS सीमाओं के काम करने के लिए चलना चाहिए। इसे अलग से डाउनलोड किया जाता है.

<a id="start-here"></a>
## यहां से प्रारंभ करें

1. ऊपर एक उपकरण चुनें. प्रत्येक स्वतंत्र रूप से कार्य करता है; संपूर्ण सुइट स्थापित करना अनावश्यक है.
2. इसकी आवश्यकताएं पढ़ें और इंस्टॉल किए गए ऐप के लिए **सेटअप** चुनें, या एक अलग फ़ोल्डर के लिए **पोर्टेबल** चुनें।
3. जब इसकी रिलीज़ प्रकाशित हो, तो नामित एप्लिकेशन एसेट डाउनलोड करें, संलग्न नोटिस पढ़ें और इसकी SHA-256 की तुलना करें।
4. ड्राइवर, डिस्प्ले सेटिंग, NVIDIA प्रोफ़ाइल या गेम रनटाइम बदलने से पहले बैकअप रखें।

दस्तावेज़ीकरण प्रत्येक गाइड के शीर्ष पर चयनकर्ता के माध्यम से एनवी अनुप्रयोगों के समान 34 भाषाओं में उपलब्ध है। GitHub स्वचालित रूप से ब्राउज़र भाषा द्वारा README का चयन नहीं करता है। दस्तावेज़ीकरण भाषा और एप्लिकेशन की अपनी भाषा सेटिंग अलग-अलग हैं।

<a id="provenance-and-ownership"></a>
## उत्पत्ति और स्वामित्व

यह हब दस्तावेज़ीकरण और संकलित एप्लिकेशन वितरित करता है। एप्लिकेशन स्रोत कोड निजी तौर पर बनाए रखा जाता है। अपस्ट्रीम परियोजनाएँ अपना लेखकत्व और लाइसेंस बरकरार रखती हैं; निजी स्रोत वितरण उन शर्तों को प्रतिस्थापित नहीं करता है।

- Profile Inspector fork Orbmu2k के MIT लाइसेंस को बरकरार रखता है और इसे स्पष्ट रूप से fork के रूप में पहचाना जाता है।
- NVDriverForge की अपनी बाइनरी वितरण शर्तें हैं और इसमें अलग से लाइसेंस प्राप्त रनटाइम/टूल घटक शामिल हैं।
- NVMFG Unlock40 एक स्वतंत्र रूप से विकसित एप्लिकेशन है। तुलना और परिशोधन के लिए RTX40MFG-Unlock से परामर्श लिया गया; साझा मूल घटक अपने MIT क्रेडिट बनाए रखते हैं। MinHook और NVIDIA SDK शब्द अलग-अलग रहते हैं।
- NVRasterPulse आपूर्ति किए गए MIT लाइसेंस को बरकरार रखता है और Profile Inspector-व्युत्पन्न यूआई को श्रेय देता है। RTSS एक आवश्यक बाह्य प्रोग्राम है।

[संपूर्ण घटक तालिका](THIRD_PARTY_NOTICES.md), [फ़ाइल उद्गम और परिवर्तन](docs/provenance.md) और [लाइसेंस का दायरा](../../../LICENSE) देखें।
