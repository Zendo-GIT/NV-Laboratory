<a id="compatibility-and-troubleshooting"></a>
# अनुकूलता और समस्या निवारण

ये तैयार उम्मीदवार हैं, सभी Windows, GPU, ड्राइवर और गेम संयोजनों के लिए प्रमाणन मैट्रिक्स नहीं।

| औज़ार | Windows / रनटाइम | हार्डवेयर/बाहरी निर्भरता | संचालन में देखभाल की आवश्यकता है |
| --- | --- | --- | --- |
| NVPI fork 3.0.2.3 | Windows 10/11 x64, .NET फ्रेमवर्क 4.8 | संगत NVIDIA ड्राइवर/डिस्प्ले | प्रोफ़ाइल लिखती है और पूर्वावलोकन प्रदर्शित करती है |
| NVDriverForge 0.1.4 | Windows 10 बिल्ड 19041+ / 11 x64; .NET/WPF शामिल है | संगत NVIDIA ड्राइवर पैकेज | उन्नत स्थापना, उन्नत सेटिंग्स, वैकल्पिक NVENC |
| NVMFG Unlock40 0.2.3 | Windows 10/11 x64; .NET/WPF शामिल, फ्रेमवर्क 4.8 सहायक | RTX 40, योग्य DLSS FG गेम और पिन किया हुआ प्रदाता | नेटिव इन-गेम पैचिंग, ग्लोबल प्रोफाइल जर्नल, SDK गेम अपडेट |
| NVRasterPulse 0.2 | Windows 10/11 x64, .NET फ्रेमवर्क 4.8 | RTSS स्थापित; टोपी के लिए दौड़ रहे हैं | RTSS प्रति-निष्पादन योग्य प्रोफ़ाइल परिवर्तन |

कोई ARM64 पैकेज तैयार नहीं है. डिस्प्ले/एपीआई उपलब्धता और पुराने Windows संस्करण व्यक्तिगत सुविधाओं को सीमित कर सकते हैं। कोई सार्वभौमिक न्यूनतम NVIDIA या RTSS संस्करण का आविष्कार नहीं किया गया है। सटीक NVMFG प्रदाता हैश [उद्गम](provenance.md) में है।

<a id="before-reporting-a-bug"></a>
## बग की रिपोर्ट करने से पहले

आपके द्वारा खोले गए सटीक निष्पादन योग्य/संस्करण की पहचान करें। जरूरी नहीं कि पिछली स्थापित प्रतिलिपि नए डाउनलोड किए गए ज़िप का संस्करण हो। पुनरुत्पादन चरण, अपेक्षित परिणाम और वास्तविक परिणाम रिकॉर्ड करें। रेंडरिंग/सीमित समस्याओं के लिए, गेम संस्करण, डिस्प्ले रिफ्रेश, FG/V-Sync/VRR स्थिति और कोई अन्य लिमिटर या ओवरले शामिल करें।

[बग फॉर्म](https://github.com/Zendo-GIT/NV-Laboratory/issues/new?template=bug-report.yml) का उपयोग करें। संपूर्ण निजी विकास फ़ोल्डर, ड्राइवर संग्रह, मॉडल, गेम डीएलएल, रजिस्ट्री डंप या बिना समीक्षा किए गए लॉग संग्रह को कभी भी संलग्न न करें।

| समस्या | पहले जाँच करता है |
| --- | --- |
| गलत एप्लिकेशन संस्करण | EXE पहचान और रिलीज़ हैश की पुष्टि करें; बदलने से पहले पुरानी प्रति बंद कर दें। |
| रनटाइम/स्टार्टअप त्रुटि | आवश्यक फ्रेमवर्क 4.8 स्थापित करें या सभी आपूर्ति किए गए पोर्टेबल सबफ़ोल्डर्स को बनाए रखें। |
| UAC रद्द कर दिया गया | केवल इच्छित ऑपरेशन का पुनः प्रयास करें; रद्दीकरण सफल स्थापना नहीं है. |
| हैश/हस्ताक्षर बेमेल | उस उम्मीदवार का उपयोग करना बंद करें और अपेक्षित आधिकारिक बाइट्स प्राप्त करें। |
| NVPI रंग/मोड अस्वीकृत | वास्तविक डिस्प्ले/ड्राइवर द्वारा समर्थित संयोजन को वापस लाएं और उसका उपयोग करें। |
| NVDF बैकअप या पुनर्प्राप्ति विफलता | संरक्षित नौकरी और RECOVERY.txt को सुरक्षित रखें; जर्नल को न मिटाएं और न ही बलपूर्वक विरोधाभासी लेख लिखें। |
| एनवीएमएफजी लंबित सेटिंग्स | गेम बंद होने पर पुनर्प्राप्ति का समाधान करें, अन्य टूल से परिवर्तनों को संरक्षित करें। |
| RP कैप का कोई प्रभाव नहीं है | RTSS चलाएँ, वास्तविक गेम EXE की पहचान करें, हुक स्थिति और प्रतिस्पर्धी सीमाओं का निरीक्षण करें। |
| RP कैप हटाने के बाद भी बनी रहती है | RTSS ग्लोबल का निरीक्षण करें; निष्कासन केवल स्थानीय सीमक को ओवरराइड करता है। |

NVDriverForge एक पूर्वावलोकन योग्य स्थानीय JSON रिपोर्ट प्रदान करता है; एनवीएमएफजी अबाउट में एक निदान प्रदान करता है। संपूर्ण लॉग संग्रह के बजाय इन फ़िल्टर की गई रिपोर्ट को प्राथमिकता दें और साझा करने से पहले उनका निरीक्षण करें। NVMFG 0.1.1 पर रिपोर्ट की गई पुनर्स्थापना रुकावट का अभी भी कोई स्थापित कारण नहीं है; इसके जर्नल को सुरक्षित रखें और किसी भी उपलब्ध त्रुटि कोड को रिकॉर्ड करें। NVRasterPulse 0.2, FPS को मापे बिना, अपने क्रिया मेनू में कॉन्फ़िगरेशन डायग्नोस्टिक्स प्रदान करता है।

<a id="logs-and-privacy"></a>
## लॉग और गोपनीयता

| औज़ार | स्थानीय डेटा की समीक्षा करें, थोक में अपलोड न करें |
| --- | --- |
| NVDF | `%LOCALAPPDATA%\NVDriverForge`; संरक्षित नौकरियाँ `%PROGRAMDATA%\NVDriverForge\Jobs` |
| एनवीएमएफजी | `%LOCALAPPDATA%\RtxMfg`; बैकअप `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`; EXE के बगल में `Sessions` |
| RP | `%LOCALAPPDATA%\NVRasterPulse`; इसके नीचे `Backups\RTSS` है |
| NVPI | आपके द्वारा चुने गए निर्यात और प्रदर्शित त्रुटि; कोई आविष्कृत सार्वभौमिक लॉग पथ नहीं |

आपके द्वारा साझा किए गए टेक्स्ट/छवियों से खाता नाम, होम निर्देशिका, गेम-लाइब्रेरी पथ, डिवाइस पहचानकर्ता, टोकन और असंबंधित विंडो हटा दें। पुनर्प्राप्ति के लिए मूल प्रतियों को निजी तौर पर रखें। जनता के मुद्दे सबको दिखते हैं.

किसी भेद्यता, खतरनाक विशेषाधिकार प्राप्त व्यवहार या अनपेक्षित विनाशकारी ऑपरेशन के लिए, विवरण सार्वजनिक रूप से पोस्ट करने के बजाय [SECURITY.md](../SECURITY.md) का पालन करें।

<a id="what-has-been-verified"></a>
## क्या सत्यापित किया गया है

हब की तैयारी के लिए, स्थिर पेलोड/ज़िप/हैश/मेटाडेटा स्कैन और दस्तावेज़ीकरण जाँचें चलाई गईं। मौजूदा निजी एप्लिकेशन बिल्ड/यूनिट/यूआई परीक्षण ऐतिहासिक, दिनांकित साक्ष्य हैं। इस तैयारी के हिस्से के रूप में कोई ड्राइवर इंस्टॉल, डिस्प्ले परिवर्तन, लाइव RTSS ऑपरेशन या गेम बेंचमार्क नहीं किया गया था।

"पता लगाया गया", "लिखा हुआ", "पुनः लोड किया गया", "क्षमता उपलब्ध" और "गेम में मापा गया" अलग-अलग परिणाम हैं। रिपोर्ट करें कि आपने किसका अवलोकन किया।
