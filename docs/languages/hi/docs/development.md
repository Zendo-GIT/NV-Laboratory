# रिपॉजिटरी वास्तुकला और रखरखाव

NV Laboratory एक सार्वजनिक **दस्तावेज़ीकरण और बाइनरी-वितरण केंद्र** है। इसमें एप्लिकेशन स्रोत शामिल नहीं है. चार परियोजनाएं अलग-अलग बिल्ड ट्री, संस्करण, पहचान और रिलीज़ संपत्तियां बरकरार रखती हैं। उनका निजी विकास इतिहास इस Git रिपॉजिटरी में आयात नहीं किया जाता है।

<a id="layout"></a>
## लेआउट

| स्थान | प्रयोजन |
| --- | --- |

| दस्तावेज़/releases.json | लेखापरीक्षित उम्मीदवार/रिलीज़ मेटाडेटा, आकार और हैश |

| लाइसेंस | संपूर्ण तृतीय-पक्ष टेक्स्ट और इंस्टॉलर अनुवादक क्रेडिट साझा किए गए |

अंग्रेजी डिफ़ॉल्ट GitHub README बनी हुई है। मौजूदा निकटवर्ती `.fr.md` लिंक वैध रहेंगे। अतिरिक्त अनुवाद `docs/languages/<code>` के अंतर्गत दस्तावेज़ीकरण को प्रतिबिंबित करते हैं; भाषा स्विच करते समय भाषा चयनकर्ता वही पृष्ठ रखता है। कैटलॉग `docs/languages/catalog.json` सभी 34 भाषाओं और स्रोत फ़िंगरप्रिंट को रिकॉर्ड करता है। GitHub स्वचालित रूप से ब्राउज़र भाषा द्वारा README का चयन नहीं करता है। [भाषा सूचकांक और अनुवाद नीति](../../README.md) देखें।

<a id="local-checks"></a>
## स्थानीय जाँच

रिपॉजिटरी रूट से:

```text
python tools/validate_repository.py
```

Python 3.10 या नया पर्याप्त है। चेक फ़ाइलें, स्थानीय मार्कडाउन लिंक, आवश्यक नोटिस/RTSS लिंक, रिलीज़ मेटाडेटा और प्रकाशन सीमाओं को पढ़ता है। यह सॉफ़्टवेयर निष्पादित नहीं करता, निर्भरताएँ स्थापित नहीं करता या किसी नेटवर्क से संपर्क नहीं करता।

GitHub वर्कफ़्लो पुश, पुल अनुरोध या मैन्युअल प्रेषण पर केवल पढ़ने योग्य सामग्री अनुमति के साथ इसी जांच को चलाता है। चेकआउट को एक ऑडिटेड कमिट पर पिन किया गया है और क्रेडेंशियल कायम नहीं है। कोई रिलीज़ या परिनियोजन कार्य कॉन्फ़िगर नहीं किया गया है.

<a id="maintain-the-boundary"></a>
## सीमा बनाए रखें

अंग्रेजी संदर्भ, फ्रेंच गाइड और प्रभावित अनुवादों को एक साथ अपडेट करें। महत्वपूर्ण परिवर्तनों को केवल फ़ॉर्मेटिंग तुलनाओं से अलग रखें। वास्तविक उम्मीदवार हैश, अपस्ट्रीम प्रतिबद्ध संदर्भ और लाइसेंस रिकॉर्ड करें; किसी प्रोजेक्ट की लोकप्रियता से कभी भी लाइसेंस का अनुमान न लगाएं।

ताज़ा संस्करण वाली रिलीज़ परिसंपत्तियों का उपयोग करें और परिवर्तित बायनेरिज़, अभिलेखागार और एम्बेडेड नोटिस का पुन: ऑडिट करें। इस भंडार के बाहर निजी बैकअप सुरक्षित रखें। निजी एप्लिकेशन स्रोत या स्थानीय बिल्ड फ़ोल्डर आयात करने के लिए सार्वजनिक वर्कफ़्लो का उपयोग न करें।

कार्यात्मक अनुप्रयोग परिवर्तन के लिए उपयुक्त परीक्षण निजी प्रोजेक्ट में चलाए जाते हैं। दस्तावेज़ीकरण अद्यतन के लिए ड्राइवर इंस्टॉलर को दोबारा न चलाएँ या वास्तविक प्रोफ़ाइल न लिखें। [मैन्युअल रिलीज़ प्रक्रिया](releasing.md).
