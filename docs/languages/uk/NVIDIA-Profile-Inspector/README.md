# NVIDIA Profile Inspector – NV Tools Fork

**Незалежний fork від [NVIDIA Profile Inspector від Orbmu2k](https://github.com/Orbmu2k/nvidiaProfileInspector) із доданими елементами керування дисплеєм.** Попередня назва проекту: **NVPI Custom**.

[Статус завантаження та випуску](../docs/downloads.md#nvidia-profile-inspector) · [монтаж](#installation) · [Вгору та зміни](#upstream-and-changes) · [Ліцензія](../../../../NVIDIA-Profile-Inspector/LICENSE)

<a id="overview"></a>
## Огляд

Програма редагує профілі драйверів NVIDIA, включаючи налаштування для кожної програми. Цей fork також додає **Редактор екрану** для активного дисплея Windows: роздільна здатність, частота оновлення, параметри вихідного кольору, HDR і встановлені асоціації профілів ICC/WCS.

Він існує, щоб перенести пов’язані елементи керування відображенням у редактор профілю та зробити попередній перегляд, підтвердження та результати відновлення зрозумілішими. Він не створює нових апаратних можливостей.

Перший кандидат – **3.0.2.3**, який використовує очищену автономну компаньйонну збірку від 9 вересня 2026 р. Його існуючий виконуваний файл залишається `nvidiaProfileInspector.exe`; у інсталяторі та на деяких внутрішніх мітках все ще написано `NVPI Custom NV`. Загальнодоступна назва вище ідентифікує fork без зміни ідентифікатора інсталяції та не вдає, що це офіційний випуск Orbmu2k.

<a id="features"></a>
## особливості

- Перегляд існуючого попереднього профілю, асоціації програм, редагування налаштувань та імпорт/експорт профілю.
- Діалогове вікно **Екран** для відображення, режиму, Гц, RGB/YCbCr, глибини кольору, діапазону та колориметрії.
- Контроль Windows HDR і встановлений вибір асоціації ICC/WCS.
- 15-секундний попередній перегляд із **Зберегти** / **Повернути** та відновленням часу очікування.
- Повторне зчитування змін режиму/HDR і повідомлень про помилки відновлення.
- Окремий звіт про HDR, SDR з ACM/WCG і глибину кольору сигналу.
- Засіб запуску NVRasterPulse для відповідної окремо встановленої копії.

<a id="compatibility"></a>
## Сумісність

| Вимога | Подробиці |
| --- | --- |
| система | Windows 10/11 x64 із сумісним драйвером NVIDIA |
| Час виконання | [.NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48), поставляється Windows або встановлюється окремо |
| Дозволи | При відкритті редактор запитує права адміністратора |
| Дисплеї | Фактичні режими та комбінації кольорів залежать від GPU, драйвера, дисплея, кабелю та Windows API |
| Додаткові інструменти | NVRasterPulse для керування обмеженнями RTSS; ані він, ані RTSS не потрібні для редактора екрану |
| Мови | Налаштування: 34-мовний селектор. Редактор зберігає наявну підтримку мови. |

Для кожного GPU немає підтвердженого мінімуму універсального драйвера або матриці підтримки. Доступні варіанти bpc у діалоговому вікні – це запити, а не сертифіковані комбінації. Сучасні елементи керування HDR і старіша резервна версія Windows мають різні можливості.

<a id="installation"></a>
## монтаж

1. Відкрийте [сторінка завантаження](../docs/downloads.md#nvidia-profile-inspector) і перевірте статус публікації.
2. Завантажте інсталяцію або портативний ресурс і порівняйте його SHA-256 із маніфестом випуску.
3. Для встановлення запустіть `NVPI-CustomNV-3.0.2.3-Setup-r2.exe`, виберіть мову та дотримуйтеся вказівок інсталятора. Він створює власний ярлик і програму видалення.
4. Для портативних розпакуйте повний ZIP-архів до нової папки, доступної для запису. Зберігайте `Reference.xml`, конфігурацію EXE та всі повідомлення поруч із виконуваним файлом.
5. Запустіть `nvidiaProfileInspector.exe`.

Встановлення лише редактора не застосовує профіль або інсталює драйвер GPU. Супутник встановлюється окремо, не приймає асоціації `.nip` і не вмикає запуск під час входу. Існуючі двійкові файли без знаку.

<a id="usage"></a>
## Використання

**Редакція інсталятора 2** додає той самий рідний 34-мовний селектор, що й інші інструменти, з навігацією за допомогою миші/клавіатури, світлим/темним виглядом і скасуванням. Вибір стосується налаштування; він не перекладає редактор NVPI. Явний аргумент `/LANG=fr` або беззвучний режим обходить вибір для абонентів, які вже надають мову.

**Профілі водія:** виберіть профіль, експортуйте резервну копію, а потім змініть лише потрібні налаштування та застосуйте їх. Асоціації програм визначають, яка гра отримає профіль. Збережене значення не є доказом того, що кожен драйвер чи гра його використовують.

**Елементи керування дисплеєм:** відкрийте **Екран**, виберіть дисплей і потрібні значення, а потім запустіть попередній перегляд. Перевірте зображення, перш ніж вибрати **Зберегти** протягом 15 секунд. Щоб подати запит на відновлення, скористайтеся **Повернути**, закрийте підтвердження або зачекайте, щоб воно закінчилося. Прочитайте будь-яке повідомлення про помилку: сам по собі успішний виклик API не є доказом відновлення.

Вибір ICC змінює асоціацію встановленого профілю; він не створює, не калібрує і не розповсюджує файл ICC. HDR, ACM/WCG, RGB/YCbCr і bpc описують різні аспекти конвеєра. Новий незалежний перемикач ACM не надається.

**NVRasterPulse:** кнопка панелі інструментів приймає окремо зареєстровану загальносистемну інсталяцію під програмними файлами із захищеним правом власності та дозволами. Цей засіб запуску з підвищеними правами може відхилити портативну копію або доступний для користувача запис/зв’язаний шлях. У такому випадку відкрийте NVRasterPulse за допомогою власного ярлика. [Встановіть RTSS окремо](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) для використання NVRasterPulse.

<a id="update-and-uninstall"></a>
## Оновіть і видаліть

Перед оновленням закрийте редактор. Збережіть експортовані профілі та завантажте новий випуск fork; інсталювати поверх того самого супутнього ідентифікатора або видобути портативні файли в нову папку. Не змішуйте старий `Reference.xml` з новим виконуваним файлом. Поєднане придушення перевірки оновлень належить до цього fork.

Для інстальованої копії використовуйте Windows **Installed apps** і її видалення. Для портативного комп’ютера закрийте його та видаліть розпаковану папку, коли ваш експорт буде безпечним. Видалення редактора **не** скасовує редагування профілю драйвера, налаштування відображення, NVRasterPulse або RTSS. Відновіть потрібні налаштування перед видаленням.

<a id="known-limitations"></a>
## Відомі обмеження

- 15-секундне підтвердження не є сторожовим псом для кожної аварії водія, втрати живлення або примусового вимкнення.
- Деякі комбінації кольору/глибини/оновлення повертають `NVAPI_NOT_SUPPORTED`.
- Програмне зчитування не вимірює бітову глибину панелі, точність кольору або затримку.
- Параметри екрана впливають на поточний дисплей Windows; це діалогове вікно не створює попередніх налаштувань відображення для кожної гри.
- Немає гарантії продуктивності, античітів або універсальної сумісності з HDR.

<a id="troubleshooting"></a>
## Усунення несправностей

| Симптом | Дія |
| --- | --- |
| Помилка виконання під час запуску | Перевірте оновлення Windows і .NET Framework 4.8; використовувати повний пакет. |
| Запитаний режим відображення відхилено | Поверніть і протестуйте режим, запропонований Windows/NVIDIA для цього дисплея. Прочитайте точну помилку та уникайте повторних сліпих змін. |
| HDR або колір повертається до старого стану | Перевірте, чи інша операція не вдалася та не викликало відновлення; відрізняти HDR від ACM. |
| Кнопка NVRasterPulse відмовляє шлях | Запустити власний ярлик; Ця кнопка потребує захищеної загальносистемної інсталяції. |
| Зміни залишаються після видалення | Відновіть експортований профіль NVIDIA або заплановані параметри відображення Windows; видалення не є відкатом налаштувань. |

Перегляньте [спільне керівництво з підтримки](../docs/support.md) перед надсиланням журналів.

<a id="faq"></a>
## FAQ

**Це офіційне програмне забезпечення NVIDIA чи офіційна збірка Orbmu2k?** Ні. Це незалежна fork; автор першої версії та ліцензія MIT залишаються зазначеними.

**Чи потрібен NVDriverForge цей редактор?** Ні. Додатковий стиль Custom NV NVDriverForge використовує власну інтеграцію. Встановлення редактора - окремий вибір.

**Чи є RTSS обов’язковим для цього fork?** Ні. RTSS є обов’язковим для обмежувача FPS NVRasterPulse, а не для редагування профілю чи екрана.

**Де джерело?** Змінене джерело програми зберігається приватно. Надається сповіщення про MIT і репозиторій попередньої версії; MIT не вимагає публікації зміненого джерела.
