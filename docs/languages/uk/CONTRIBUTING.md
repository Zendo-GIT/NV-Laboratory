# Сприяння

NV Laboratory підтримується 禅堂 Zendo (RevoluSound Team). Супроводжуючий вирішує, що прийнято, а що звільнено. Відкриття проблеми чи запиту на вилучення не означає, що внесок прийнято чи дозволено для розповсюдження.

Використовуйте форму повідомлення про помилку чи функцію та визначте програму/версію. Спочатку знайдіть наявні проблеми. Обговоріть суттєві зміни, перш ніж готувати великий внесок. З питань безпеки дотримуйтесь [SECURITY.md](SECURITY.md).

Цей загальнодоступний центр містить документацію, повідомлення, метадані випуску та перевірку сховища. Джерело програми та тести зберігаються конфіденційно. Не надсилайте декомпільований код, приватне джерело, облікові дані, профілі користувачів або виконувані корисні навантаження.

Документація PR повинна підтримувати 34 мовні відповідники та навігацію узгодженими, зберігати назви команд/файлів/продуктів і описувати фактичну поведінку. Нові скріншоти мають бути вашими, з ідентифікацією версії та без особистих даних; синтетичні дані повинні бути позначені. Укажіть походження та дозвіл для кожного нового стороннього активу.

Використовуйте UTF-8, LF, читабельну Markdown і невеликі цілеспрямовані зміни. Валідатор Python використовує лише стандартну бібліотеку. Відповідайте його існуючому стилю, уникайте непотрібних залежностей і виконайте:

```text
python tools/validate_repository.py
```

Для змін метаданих випуску включіть точну версію/тег, розміри файлів і SHA-256 із перевірених двійкових файлів, а також вирівнюйте сторінки завантаження. Зміни додатків вимагають приватної збірки/тестів, які відповідають ураженій поведінці; перевірка документації не є перевіркою заявки. Ніколи не вигадуйте історичні результати тестів або прибутки.

Надаючи оригінальний матеріал концентратора, ви погоджуєтеся з його ліцензією MIT у [ЛІЦЕНЗІЯ](../../../LICENSE). Зберігайте повідомлення третіх сторін і ідентифікуйте свої зміни; не замінюйте ліцензію на випередження. Прийняття та публікація залишаються рішеннями супроводжуючого.
