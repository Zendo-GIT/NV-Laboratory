<a id="nvmfg-unlock40"></a>
# NVMFG Unlock40

**Експериментальний NVIDIA Multi Frame Generation для GeForce RTX 40, із центральним контролером і вибором для кожної гри.**

[Завантажити 0.1.1 і статус](../docs/downloads.md#nvmfg-unlock40) · [монтаж](#installation) · [Вгору за течією](#upstream-and-modifications) · [Ліцензії](LICENSES/README.md)

<a id="overview-and-purpose"></a>
## Огляд і призначення

NVMFG Unlock40 – це програма, розроблена незалежною компанією 禅堂 Zendo (RevoluSound Team). Він поєднує в собі контролер Windows, рідний рівень, помічник профілю та керування грою/Streamline SDK. Він націлений на ігри, які вже інтегрують NVIDIA DLSS Frame Generation і сумісні середовища виконання NVIDIA.

Звернулися до [RTX40MFG-Unlock](https://github.com/dashdogy/RTX40MFG-Unlock), щоб порівняти та вдосконалити роботу. Поточний рідний рівень містить спільні та адаптовані компоненти, зазначені окремо нижче. Це посилання не робить всю програму NVMFG fork цього проекту.

Він існує для централізованої координації експериментальної поведінки MFG, запам’ятовування вибору, характерного для гри, і забезпечення видимості оновлень і резервних копій під час виконання. Він не додає DLSS Frame Generation до кожної гри або не перетворює довільну реалізацію FSR.

Підготовлений кандидат – **0.1.1**, включаючи візуальну корекцію списку SDK, внутрішню записану як UI2. Публічна версія залишається 0.1.1; його точні хеші відрізняють цього кандидата від старих локальних збірок.

<a id="features"></a>
## особливості

- Центральне керування ввімкненням/вимкненням і додатковий запуск лотка Windows.
- Вибір для кожної гри між Dynamic MFG, налаштуваннями гри та підтримуваними фіксованими множниками.
- Окремі запам'ятовані варіанти для спостережуваних станів увімкнення/вимкнення V-Sync.
- Dynamic використовує режим NVIDIA; він призупиняється, коли V-Sync вимкнено, з окремим вибором у грі/фіксованим.
- Підказки в ігровому меню та постійні виключення; ігри без DLSS FG залишаються під контролем.
- Виявлення гри, вибір батьківської папки, пошук, групування та видалення без видалення файлів гри.
- Streamline SDK завантаження/імпорт, перевірений локальний кеш, явний вибір, резервне копіювання та відновлення для кожної гри.
- Власна перевірка постачальника, сеансова діагностика, глобальний журнал профілів і відновлення з урахуванням конфліктів.
- 34 мови інтерфейсу та чотири теми.

Якщо вимкнути FG у грі, він утримується. Фіксовані варіанти від 2x до 6x залежать від гри/меню/часу виконання; вони не обіцяють, що кожна комбінація працює. Контролер дотримується V-Sync і не встановлює V-Sync або VRR для користувача.

<a id="installation"></a>
## монтаж

1. Прочитайте [статус кандидата та довідка про ліцензування](../docs/downloads.md#nvmfg-unlock40).
2. Завантажте `NVMFGUnlock40-0.1.1-Setup-x64.exe` або `NVMFGUnlock40-0.1.1-Portable-x64.zip`, коли буде доступний випуск.
3. Перевірте SHA-256 і збережіть супровідні повідомлення. Установіть .NET Framework 4.8, якщо Windows ще не надає його.
4. Запустіть інсталяцію або розпакуйте **весь** портативний ZIP-архів у доступну для запису локальну папку.
5. Запустіть `NVMFGUnlock40.exe`; зберігайте `agent`, `driver`, `engine` і `Licenses` у наданому макеті.

Папка під назвою `driver` містить помічники простору користувача, а не драйвер ядра. Не копіюйте лише основний EXE і не замінюйте хеш постачальника, щоб забезпечити сумісність. Поточні файли EXE не мають підпису.

<a id="usage"></a>
## Використання

1. Почніть з відключеного контролера. Додайте гру або батьківську папку та виберіть фактичні інсталяції.
2. Перегляньте налаштування MFG кожної гри. Дайте відповідь, що пропонує його меню; відповідь зберігається для кожної гри.
3. Виберіть Dynamic або налаштування в грі в усьому світі, а потім налаштуйте відповідні параметри для кожної гри за потреби.
4. Вмикайте контролер лише тоді, коли ви збираєтеся його використовувати. Він може тимчасово змінити шість глобальних налаштувань профілю NVIDIA із журналом відновлення.
5. Запустіть придатну гру та ввімкніть її власний DLSS Frame Generation. Виконайте будь-який запит для вибору V-Sync-off.
6. Використовуйте виключення для ігор, якими ви не хочете керувати. Видалення гри записує виключення та зберігає її файли/резервні копії.
7. Використовуйте повний вихід/вимкнення програми та процес відновлення після завершення.

Якщо закрити головне вікно, контролер залишиться в треї. DLL, уже завантажена в гру, залишається там до завершення гри; відключення контролера не є гарантією вивантаження. Перед обслуговуванням або оновленням закривайте ігри, на які впливає проблема.

**Streamline SDKs:** на сторінці NVIDIA SDK завантажте офіційну версію або імпортуйте сумісний локальний SDK. Імпорт зберігає перевірену копію; **Use this version** вибирає його, а **Uninstall** видаляє цю кешовану копію. Відсутні бібліотеки DLL Streamline можна доповнити з офіційної NVIDIA SDK із зазначенням джерела. Це не завантажує/замінює модель NGX. Закрийте гру, виберіть потрібне оновлення гри та збережіть оригінальну резервну копію. Щоб повернути файли гри, скористайтеся її резервною копією, а не кнопкою Uninstall кешу.

<a id="update-and-uninstall"></a>
## Оновіть і видаліть

Закрити ігри, які зазнали впливу. Вимкніть/закрийте NVMFG і вирішіть будь-яке незавершене відновлення налаштувань NVIDIA перед оновленням. Встановіть наступну установку з існуючим ідентифікатором або витягніть нову переносну програму в нову папку; зберегти стан/резервні копії.

Перед видаленням відновіть потрібні резервні копії гри SDK і налаштування NVIDIA за допомогою програми, потім закрийте ігри та вийдіть з контролера. Використовуйте Windows **Installed apps** для налаштування або видаліть закриту портативну папку після збереження необхідних файлів. Не видаляйте вручну активний журнал відновлення, щоб розблокувати налаштування.

Локальні резервні копії гри під час виконання використовують `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`. Параметри MFG/дані SDK використовують `%LOCALAPPDATA%\RtxMfg`; вихід сеансу знаходиться під `Sessions` поруч із програмою. Ці файли можуть містити ігрові шляхи. Не публікуйте їх без редагування.

<a id="known-limitations"></a>
## Відомі обмеження

- Експериментальні нативні патчі можуть викликати збої або візуальні артефакти; невирішений збій Bodycam зареєстровано в історії розробки.
- Контрольовані тести візуалізації не є сертифікацією для кожної гри, драйвера чи античіта.
- Згенеровані кадри не створюють нових вхідних зразків; цей хаб не обіцяє виміряної затримки чи збільшення продуктивності.
- Кілька інструментів генерації кадрів/накладень можуть конфліктувати. Додаток повідомляє про спостережувані модулі, не підтверджуючи кожен сценарій співіснування.
- Маніфест сумісності – це допомога у виявленні, а не список повністю перевірених ігор.
- Повні умови NVIDIA SDK і невирішені технічні обмеження залишаються задокументованими в [походження](../docs/provenance.md).

<a id="troubleshooting"></a>
## Усунення несправностей

| Симптом | Дія |
| --- | --- |
| Провайдер не підтримується | Зберігайте оригінальні перевірені файли. Повідомити про версії драйвера/провайдера та помилку; не обходьте хеш-перевірку. |
| У грі немає DLSS FG | Виберіть цю відповідь і залиште контроль над грою; цей інструмент не може створити таку інтеграцію. |
| Збої/артефакти гри | Вийдіть із гри, вимкніть NVMFG, скористайтеся оригінальною резервною копією гри під час виконання, якщо вона була змінена, і повідомте про відтворювані деталі. |
| SDK список або завантаження недоступні | Оновіть та перевірте офіційне джерело; кешована/імпортована версія все одно має пройти перевірку. |

| Видалена гра не відкривається повторно | Його виключення є стійким. Додайте його явно, коли захочете знову керувати ним. |

<a id="faq"></a>
## FAQ

**Чи включає файли DLL NVIDIA або моделі?** Немає драйвера, постачальника/моделі NGX або середовища виконання Streamline. Явні завантаження SDK надходять із NVIDIA.

**Чи працює Dynamic, якщо V-Sync вимкнено?** У цьому стані його призупинено. Виберіть налаштування в грі або придатний фіксований множник для окремого стану цієї гри.

**Це пакет ReShade/OptiScaler/FSR?** Ні. Вони не скомпільовані та не постачаються як частина цього робочого пакета.

**Чи є змінені джерела загальнодоступними?** Ні. Надаються скомпільовані пакети та необхідні кредити/ліцензії. Це не скасовує прав чи обмежень третіх сторін.
