<a id="compatibility-and-troubleshooting"></a>
# Сумісність і усунення несправностей

Це підготовлені кандидати, а не матриця сертифікації для всіх комбінацій Windows, GPU, драйвера та гри.

| Інструмент | Windows / час виконання | Обладнання / зовнішня залежність | Операції, що потребують догляду |
| --- | --- | --- | --- |
| NVPI fork 3.0.2.3 | Windows 10/11 x64, .NET Framework 4.8 | Сумісний драйвер/дисплей NVIDIA | Запис профілю та попередній перегляд |
| NVDriverForge 0.1.2 | Windows 10 збірка 19041+ / 11 x64; .NET/WPF включено | Сумісний пакет драйверів NVIDIA | Інсталяція з підвищеними правами, розширені налаштування, опціональний NVENC |
| NVMFG Unlock40 0.1.1 | Windows 10/11 x64; .NET/WPF включено, помічники Framework 4.8 | RTX 40, відповідна гра DLSS FG і закріплений постачальник | Внутрішньоігрові виправлення, глобальний журнал профілів, оновлення гри SDK |
| NVRasterPulse 0.1 | Windows 10/11 x64, .NET Framework 4.8 | встановлено RTSS; біг за шапками | Зміни профілю RTSS для кожного виконуваного файлу |

Пакет ARM64 не підготовлений. Доступність дисплея/API та старі версії Windows можуть обмежувати окремі функції. Універсальної мінімальної версії NVIDIA або RTSS не винайдено. Точний хеш постачальника NVMFG міститься в [походження](provenance.md).

<a id="before-reporting-a-bug"></a>
## Перш ніж повідомити про помилку

Визначте точний виконуваний файл/версію, яку ви відкрили. Попередня встановлена ​​копія не обов’язково є версією щойно завантаженого ZIP-архіву. Запишіть кроки відтворення, очікуваний і фактичний результат. Для проблем рендерингу/обмеження включіть версію гри, оновлення дисплея, стан FG/V-Sync/VRR і будь-який інший обмежувач або накладення.

Використовуйте [форма помилки](https://github.com/Zendo-GIT/NV-Laboratory/issues/new?template=bug-report.yml). Ніколи не вкладайте цілу приватну папку розробки, архів драйверів, модель, DLL гри, дамп реєстру чи непереглянуту колекцію журналів.

| проблема | Перші перевірки |
| --- | --- |
| Неправильна версія програми | Підтвердьте ідентичність EXE та вивільніть хеш; закрийте стару копію перед заміною. |
| Помилка виконання/запуску | Встановіть необхідний Framework 4.8 або збережіть усі надані портативні вкладені папки. |
| UAC скасовано | Повторіть лише заплановану операцію; скасування не є успішним встановленням. |
| Невідповідність хешу/підпису | Припиніть використання цього кандидата та отримайте очікувані офіційні байти. |
| Колір/режим NVPI відхилено | Поверніться та використовуйте комбінацію, яка підтримується фактичним дисплеєм/драйвером. |
| Помилка резервного копіювання або відновлення NVDF | Зберегти захищене завдання та RECOVERY.txt; не стирайте журнал і не насилуйте суперечливі записи. |
| Налаштування NVMFG очікують на розгляд | Вирішити відновлення із закритими іграми, зберігаючи зміни з інших інструментів. |
| Кришка RP не впливає | Запустіть RTSS, визначте справжню гру EXE, перевірте стан гака та конкуруючі обмеження. |
| Кришка RP залишається після видалення | Перевірте RTSS Global; видалення змінює лише локальний обмежувач. |

<a id="logs-and-privacy"></a>
## Журнали та конфіденційність

| Інструмент | Місцеві дані для перегляду, а не завантаження оптом |
| --- | --- |
| NVDF | `%LOCALAPPDATA%\NVDriverForge`; захищені роботи `%PROGRAMDATA%\NVDriverForge\Jobs` |
| NVMFG | `%LOCALAPPDATA%\RtxMfg`; резервні копії `%LOCALAPPDATA%\NvidiaStreamlineMaintenance\Backups`; `Sessions` поруч із EXE |
| RP | `%LOCALAPPDATA%\NVRasterPulse`; `Backups\RTSS` під ним |
| NVPI | Вибрані експорти та відображена помилка; немає винайденого універсального шляху журналу |

Видаліть імена облікових записів, домашні каталоги, шляхи до бібліотеки ігор, ідентифікатори пристроїв, маркери та непов’язані вікна з тексту/зображень, якими ви ділитеся. Зберігайте оригінали приватно для відновлення. Публічні проблеми доступні для всіх.

Для вразливості, небезпечної привілейованої поведінки або ненавмисної деструктивної операції дотримуйтесь [SECURITY.md](../SECURITY.md) замість того, щоб публікувати подробиці публічно.

<a id="what-has-been-verified"></a>
## Що було перевірено

Для підготовки концентратора було запущено статичне корисне навантаження/ZIP/хеш/метадані та перевірки документації. Існуючі приватні тести збірки/модуля/інтерфейсу користувача є історичними, датованими доказами. Під час цієї підготовки не було встановлено драйвера, змінено дисплей, не було виконано роботу з RTSS або ігровий тест.

«Виявлено», «записано», «перезавантажено», «доступна можливість» і «виміряно в грі» – це різні результати. Повідомте, який з них ви спостерігали.
