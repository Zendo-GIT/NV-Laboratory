<a id="repository-architecture-and-maintenance"></a>
# Архітектура репозиторію та обслуговування

NV Laboratory – загальнодоступний **центр документації та розповсюдження бінарних файлів**. Він не містить джерела програми. Чотири проекти зберігають окремі дерева збірки, версії, ідентифікатори та активи випуску. Їх приватна історія розробки не імпортується в це сховище Git.

<a id="layout"></a>
## Макет

| Розташування | призначення |

| README.md / README.fr.md | Англійська/французька точки входу |

Англійська мова залишається стандартною GitHub README. Існуючі суміжні посилання `.fr.md` залишаються дійсними. Додаткові переклади відображають документацію під `docs/languages/<code>`; селектор мови зберігає ту саму сторінку під час перемикання мов. У каталозі `docs/languages/catalog.json` записані всі 34 мови та вихідні відбитки. GitHub не вибирає файл README автоматично за мовою браузера. Див. [мовний індекс і політика перекладу](../../README.md).

<a id="application-technologies"></a>
## Технології застосування

| програма | Приватна техніка | Розподіл |
| --- | --- | --- |
| NVPI fork | Взаємодія C#, WPF, .NET Framework 4.8, NVAPI/Windows | Повна переносна папка та окрема Inno Setup |
| NVDriverForge | C#, WPF, .NET 8; власний початковий C++; Процес 7-Zip | Автономний портативний EXE та налаштування |
| NVMFG Unlock40 | C#/WPF .NET 8, помічники Framework 4.8, двигун C++20/MASM/MinHook | Портативне дерево та налаштування |
| NVRasterPulse | C#/WPF Framework 4.8; RTSS інтеграція профілю/перезавантаження; рідний bootstrap | Портативне дерево та налаштування |

Ця публічна перевірка не може перебудувати програми. Автоматичні архіви «Source code» є знімками концентратора. Вихідні вихідні посилання не представляють точного приватного зміненого джерела. Публічна КІ перевіряє лише це сховище.

<a id="local-checks"></a>
## Місцеві чеки

З кореня сховища:

```text
python tools/validate_repository.py
```

Python 3.10 або новішої версії достатньо. Перевірка читає файли, локальні посилання Markdown, обов’язкові повідомлення/посилання RTSS, метадані випуску та межі публікації. Він не запускає програмне забезпечення, не встановлює залежності та не зв’язується з мережею.

Робочий процес GitHub запускає ту саму перевірку з дозволом лише на читання вмісту під час push-запитів, запитів на отримання або надсилання вручну. Checkout закріплено на перевіреному коміті та не зберігає облікові дані. Не налаштовано завдання випуску чи розгортання.

<a id="maintain-the-boundary"></a>
## Дотримуйтеся кордону

Оновіть довідник англійською мовою, посібники французькою та відповідні переклади разом. Тримайте суттєві зміни окремо від порівнянь лише форматування. Запис фактичних хешів кандидатів, посилань на коміти та ліцензії; ніколи не виводьте ліцензію з популярності проекту.

Використовуйте активи Release із свіжими версіями та повторно перевіряйте змінені двійкові файли, архіви та вбудовані повідомлення. Зберігайте особисті резервні копії за межами цього сховища. Не використовуйте загальнодоступний робочий процес для імпорту приватного джерела програми або локальних папок збірки.

Тести, що відповідають функціональній зміні програми, виконуються в приватному проекті. Не запускайте повторно інсталятори драйверів і не створюйте справжні профілі для оновлення документації. [Процедура звільнення вручну](releasing.md).
