<a id="changelog"></a>
# Журнал змін

Цей хаб відповідає [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Записи описують це сховище; версії програми незалежні.

<a id="unreleased"></a>
## [Невиданий]

<a id="added"></a>
### Додано

- Хаб, повні посібники з проектів і документація зі сховища на 34 мовах програми NV.
- Селектори мови, що зберігають сторінку, метадані покриття перекладу та стабільні внутрішні прив’язки.
- Автори першої версії, повні відповідні повідомлення та походження файлу.
- Вимоги до RTSS і офіційне посилання для завантаження для NVRasterPulse.
- Окремі посилання RevoluSound Team.
- Підготовлений каталог пакетів першого випуску, перевірка SHA-256 і процедура випуску вручну.
- Форми помилок/функцій, внески та інструкції з безпеки.
- Документація лише для читання та перевірка меж публікації.

<a id="changed"></a>
### Змінено

- Атрибуція NVMFG тепер відрізняє незалежно розроблену програму,
посилання на порівняння/уточнення та фактичні спільні рідні компоненти.   Існуючі авторські права, ліцензії та порівняння файлів залишаються без змін.
- Кандидат NVDriverForge оновлено до 0.1.3: виправлено обробку додаткових компонентів,
читабельні локалізовані помилки та оновлене середовище виконання/супутнє пакування.

<a id="fixed"></a>
### Виправлено

- Версія 2 налаштування NVIDIA Profile Inspector – NV Tools Fork тепер показує спільний доступ
34-мовний селектор при безпосередньому запуску. Явна мова та тиха переадресація збережені; редактор і переносний пакет не змінені.

Історичні публічні дати випуску не реконструюються. Можливі версії програми: 3.0.2.3, 0.1.3, 0.1.1 і 0.1; їхні примітки до випуску додаються до їхніх майбутніх випусків. Підготовка 2026-09-09 не є датою випуску GitHub.
