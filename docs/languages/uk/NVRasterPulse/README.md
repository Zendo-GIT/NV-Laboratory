<a id="nvrasterpulse"></a>
# NVRasterPulse

**Обмеження FPS для кожної програми через RivaTuner Statistics Server.**

> **Спочатку встановіть RTSS.** Для NVRasterPulse потрібен [RivaTuner Statistics Server (RTSS), завантажено з Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/). RTSS має бути запущено, щоб застосувати обмеження. Немає інсталятора RTSS, прихоплюючої DLL або SDK у комплекті.

[Завантажити 0.2 і статус](../docs/downloads.md#nvrasterpulse) · [монтаж](#installation) · [Як працюють обмеження](#usage) · [Ліцензія](../../../../NVRasterPulse/LICENSE)

<a id="overview-and-purpose"></a>
## Огляд і призначення

NVRasterPulse – це компактний інтерфейс Windows для керування обмеженнями кадрів RTSS за назвою виконуваного файлу. RTSS виконує обмеження. NVRasterPulse керує відповідними значеннями профілю, резервними копіями та запитами на перезавантаження з доступом до трея та постійними виборами.

Він існує, щоб полегшити редагування точних обмежень для кожної гри, не замінюючи цілий профіль RTSS і не порушуючи його налаштування накладання. Версія **0.2** додає діагностику конфігурації, помічник FPS, паузу, скасування та спільний доступ до профілю.

<a id="features"></a>
## особливості

- Виберіть запущену програму або додайте її виконуваний файл вручну.
- Зберігайте обмеження FPS від 1 до 1000 із до трьох знаків після коми.
- Точне раціональне кодування введених значень: 59.94 стає 2997/50.
- Конфігурація Front Edge Sync (`SyncLimiter=1`) з активним очікуванням (`PassiveWait=0`).
- Оновлення профілю для кожного виконуваного файлу, автоматичне резервне копіювання та атомарний запис.
- Видалення перевизначення обмежувачів із збереженням іншого вмісту профілю.
- Виявлення встановлення RTSS, вибір шляху вручну та явний запуск/перезавантаження.
- Операція в системі панелі з одним екземпляром, додатковий інстальований завантажувач, 34 мови та чотири теми.
- Розділіть звичайний вихід і дії **Вийти + RTSS**.

<a id="compatibility"></a>
## Сумісність

| Вимога | Подробиці |
| --- | --- |
| система | Windows 10/11 x64 |
| Час виконання | [.NET Framework 4.8](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48), при необхідності встановлюється окремо |
| Необхідне програмне забезпечення | RTSS з `RTSS.exe`, відповідний каталог `Profiles` і підтримка сумісного профілю/перезавантаження |
| GPU | RTSS сумісність визначає обмежувач; цей менеджер профілів не потребує конкретного покоління RTX |
| Дозволи | Поточна програма вимагає доступу адміністратора; вибрана папка профілю RTSS має бути доступною |
| Ігри | Залежить від підтримки підключення RTSS і обмежень кожної гри; відсутність античіт гарантії |

Жодна конкретна мінімальна версія RTSS не була сертифікована для кожної функції під час цього аудиту концентратора. Використовуйте офіційний поточний дистрибутив і повідомляйте точну версію, якщо ключ профілю/перезавантаження не працює. Встановлено, але зупинено RTSS проходить перевірку встановлення; потім його потрібно запустити для фактичного обмеження.

<a id="installation"></a>
## монтаж

1. **[Завантажте та встановіть RTSS з Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/).**
2. Відкрийте [Завантаження NVRasterPulse](../docs/downloads.md#nvrasterpulse) і перевірте доступність випуску.
3. Завантажте `NVRasterPulse-0.2-win-x64-Setup.exe` або `NVRasterPulse-0.2-win-x64-portable.zip`, а також повідомлення/контрольні суми.
4. Порівняйте SHA-256. Запустіть програму встановлення або розпакуйте весь портативний ZIP-архів до локальної папки, доступної для запису.
5. Відкрийте `NVRasterPulse.exe`. Якщо RTSS відсутній, скористайтеся **Завантажити RTSS**, інсталюйте його, потім **Перевірте знову** або виберіть `RTSS.exe` вручну.
6. Запустіть RTSS за допомогою звичайного ярлика або кнопки RTSS NVRasterPulse, якщо його зупинено.

Вимкнення додаткового нагадування не пропускає перевірку передумов. Тихий запуск трея Windows очікує, поки відкриється головне вікно, перш ніж відобразити цю перевірку. Інсталяція встановлює лише NVRasterPulse. Його EXE не мають знаку.

<a id="usage"></a>
## Використання

1. Виберіть потрібну запущену програму або перейдіть до її гри EXE.
2. Введіть обмеження від 1 до 1000 FPS, включаючи дробове значення, якщо потрібно.
3. Збережіть і перевірте отриманий результат. NVRasterPulse оновлює профіль RTSS цього виконуваного файлу та запитує перезавантаження.
4. Переконайтеся, що RTSS запущено та перевірте поведінку в запланованій грі.

Профілі мають ключі за допомогою **виконуваного імені**, наприклад `Game.exe.cfg`. Дві різні папки, що містять `Game.exe`, мають спільний профіль RTSS; збереження повного шляху не усуває цю колізію.

Під час збереження використовується Front Edge Sync і активне очікування. Активне очікування може збільшити використання CPU. Альтернативні поля `LimitTime` нейтралізуються. Існуючі коментарі, налаштування накладання та `EnableHooking=0` збережено. Глобальний профіль RTSS не змінено.

Використовуйте дію «Кошик», щоб видалити перевизначення обмежувача NVRasterPulse. Він не видаляє весь профіль RTSS. Обмеження, успадковане від RTSS Global або іншого інструменту, може застосовуватися й пізніше.

**Закриття та вихід:** головне вікно може ховатися в треї. Звичайний **Вийти** залишає RTSS запущеним і збережені обмеження без змін. **Quit + RTSS** запитує звичайне закриття відповідного процесу RTSS у поточному сеансі, очікує до восьми секунд і не примусово припиняє його. Збережені ліміти залишаються в обох випадках.

Мова та тема вибираються в додатку. Запуск під час входу Windows необов’язковий і призначений для інстальованої копії. Інформаційна кнопка пояснює типові дії.

<a id="diagnostics-and-profile-tools"></a>
## Засоби діагностики та профілю

Відкрийте меню дій для додаткових інструментів. Вони зберігають глобальні параметри RTSS, накладення та виключення.

**Діагностика:** перевірте локальні/дієві обмеження, зупинено RTSS, відсутній виконуваний файл, не виявлено вікно, вимкнений перехоплення, успадкування, призупинені обмеження, конкуруючі налаштування та повторювані імена виконуваних файлів. Ця перевірка лише для читання описує конфігурацію; це не доводить, що гра підключена RTSS, і не вимірює її FPS.

**Помічник FPS:** виберіть дисплей і декларуйте VRR/G-Sync, V-Sync, Reflex і Frame Generation самостійно. Округлена частота оновлення походить від Windows. Якщо Reflex або Frame Generation активні або невідомі, автоматичне обмеження не пропонується. Для VRR із увімкненим V-Sync і вимкненим Reflex/FG евристика віднімає принаймні 3 FPS або приблизно 2% від частоти оновлення. Це не виміряний оптимум. Застосування пропозиції заповнює чернетку; **Зберегти** залишається окремою дією.

**Призупинити та відновити:** призупинити обмеження вибраної програми, а потім відновити попередні поля обмеження. Конфліктні зміни іншим інструментом запобігають неоднозначному резюме. Приховування запису не призупиняє його шапку.

**Скасувати:** відновити останню зміну шести полів керованого обмежувача для цієї програми. Є один рівень; це не відновлює весь RTSS. Від конфліктних зовнішніх змін відмовляються. Резервні копії файлів залишаються окремими.

**Поділитися профілями:** експортувати вибрані профілі у файл `.nvrp`. Імпорт показує попередній перегляд і залишає наявні обмеження непозначеними за умовчанням. Файл містить лише імена виконуваних файлів, обмеження та стани без абсолютних шляхів чи сценаріїв. Перегляньте свій вибір і подайте заявку. Помилка вводу/виводу може залишити деякі профілі вже застосованими; результат ідентифікує їх, і кожен зберігає своє скасування. Ідентичні імена виконуваних файлів все ще звертаються до того самого профілю RTSS.

**Вибране та приховані записи:** спочатку закріпіть корисні програми, приховайте непотрібні записи та відновіть їх у спеціальному діалоговому вікні. Ці варіанти зберігаються. Закрите вибране не відображається як запущена програма.

<a id="update-and-uninstall"></a>
## Оновіть і видаліть

Вийдіть з NVRasterPulse, завантажте та перевірте нову версію, а потім запустіть програму встановлення або розпакуйте портативний файл у нову папку. Зберігайте налаштування та резервні копії RTSS. Оновлення RTSS є окремими та надходять від Guru3D.

Щоб видалити встановлену копію, використовуйте Windows **Installed apps**. Для портативного комп’ютера закрийте його, а потім видаліть розпаковану папку, коли ваші резервні копії будуть у безпеці. Збережені обмеження RTSS не видаляються після видалення NVRasterPulse: спочатку видаліть заплановані перевизначення обмежувачів. RTSS має власний деінсталятор.

Локальний стан: `%LOCALAPPDATA%\NVRasterPulse`. Автоматичне резервне копіювання RTSS: `%LOCALAPPDATA%\NVRasterPulse\Backups\RTSS`. Для міграції може бути прочитано старіше місце розташування `%LOCALAPPDATA%\RTSSProfileBridge`. Ці файли можуть містити персональні шляхи до виконуваних файлів, і їх не можна публікувати публічно.

<a id="known-limitations"></a>
## Відомі обмеження

- RTSS виконує кап. Збережене значення або успішний запит на перезавантаження не є виміряним результатом кадрового часу.
- Однойменні виконувані файли мають спільний профіль.
- Інший глобальний/ігровий обмежувач може вплинути на результат; вимкнення локального перевизначення не видаляє успадковане обмеження.
- Навмисно вимкнений хук RTSS залишається вимкненим.
- Активне очікування має компроміс CPU/потужність.
- Немає універсальної гри, перевірки античітів або наскрізної затримки.
- Попередній експериментальний незалежний двигун обмеження не скомпільований і не відправлений.
- Автоматичне резервне копіювання не означає інтерфейс повного резервного копіювання та відновлення одним клацанням миші.

<a id="troubleshooting"></a>
## Усунення несправностей

| Симптом | Дія |
| --- | --- |
| Передумова RTSS залишається відкритою | Виберіть фактичний `RTSS.exe` і відповідну папку Profiles, а потім перевірте ще раз. |
| Ліміт збережено, але ефекту немає | Почати RTSS; перевірте правильний EXE/профіль гри, дозволи на підключення та інші обмежувачі. |
| Зберегти не вдалося | Перевірте дозволи папки та збережіть відображену помилку/резервну копію. |
| Ліміт залишається після видалення | Перевірте RTSS Global та інші інструменти; дія «смітник» видаляє лише перевизначення локального обмежувача. |
| Дві гри отримують однаковий ліміт | Перевірте, чи імена виконуваних файлів ідентичні. |
| Вийти + RTSS залишає RTSS відкритим | Закрийте RTSS самостійно; ця команда навмисно уникає примусового завершення. |

Якщо ви вручну відновлюєте резервну копію RTSS, спочатку закрийте RTSS і збережіть поточний профіль, перш ніж замінити його резервною копією. Це може перезаписати непов’язані зміни профілю; перевірте файл і дату. [Спільна підтримка](../docs/support.md).

<a id="faq"></a>
## FAQ

**Чи потрібен мені також MSI Afterburner?** Для NVRasterPulse потрібен RTSS; це не залежить від програми Afterburner. Дотримуйтеся параметрів встановлення дистриб’ютора RTSS.

**Чи можна використовувати це без запуску RTSS?** Ви можете керувати профілями після виявлення інсталяції, але RTSS має працювати для обмеження.

**Чи знімає обмеження після виходу з програми або видалення?** Ні. Видаляйте потрібні перевизначення обмежувачів перед видаленням NVRasterPulse.

**Це fork чи RTSS?** Ні. Це незалежний менеджер профілів; джерело чи виконуваний файл RTSS не включено.
