<a id="nvdriverforge"></a>
# NVDriverForge

**Підготуйте інсталяцію драйвера NVIDIA із чітким вибором компонентів і додатковими налаштуваннями.**

[Завантажити 0.1.3 і статус](../docs/downloads.md#nvdriverforge) · [монтаж](#installation) · [Кредити](#credits-and-upstream) · [Ліцензія](../../../../NVDriverForge/LICENSE)

<a id="overview-and-purpose"></a>
## Огляд і призначення

NVDriverForge guides you through an original NVIDIA driver package: choose the driver, inspect its components, review optional tweaks, then confirm installation. Він існує, щоб зробити ці варіанти зрозумілими та зберегти інсталяцію, привілейовані операції та інформацію про відновлення разом.

Це незалежно розроблена програма, частково натхненна робочим процесом NVCleanstall. Він не включає NVCleanstall і не вимагає повної парності функцій.

<a id="features"></a>
## особливості

- NVIDIA Game Ready / Studio пошук і завантаження; необов'язкове виявлення виправлень із ручним відновленням.
- Аналіз оригінального пакета, хешів, підписів NVIDIA, маніфестів і сумісних записів INF.
- Вибір компонентів із залежностями та збереженням невідомих компонентів.
- Версія 0.1.3 дозволяє пропускати вибрані додаткові компоненти NVIDIA і виключає з виявлення лише перевірені неперевірені компоненти. Уже поточні чи незастосовні додаткові середовища виконання більше не є критичними компонентами.
- Очистити підсумки помилок інсталяції та отримати доступ до детальних журналів усіма 34 мовами.
- Явне підтвердження інсталяції, захищене розміщення та експорт існуючих пакетів сховища драйверів.
- Необов’язкові розширені налаштування з перевірками перед друком, журналами та відновленням у разі конфлікту.
- Додаткова настройка **Custom NV** з іменованими параметрами та поясненнями, включаючи окремий вибір міцності SILK і перевірки сумісності.
- Додаткове завантаження виправлень точної версії NVENC; перевіряються вихідний фіксований і цільовий байти.
- Окрема додаткова інсталяція Profile Inspector fork з екрана інструментів.
- Додаткова перевірка встановлених оновлень користувачами, 34 мови інтерфейсу та чотири теми.

Доступні розширені параметри стосуються MPO, індикатора DLSS, Ansel, аудіорежиму сну NVIDIA, MSI, політики/пріоритету переривання, HDCP, запуску контейнера дисплея та прийнятної застарілої служби телеметрії. Кожен має власні передумови та наслідки; це не універсальні покращення продуктивності.

<a id="installation"></a>
## монтаж

1. Відвідайте [завантаження](../docs/downloads.md#nvdriverforge) і підтвердьте публікацію випуску.
2. Виберіть `NVDriverForge-Setup.exe` для встановлення або `NVDriverForge.exe` для портативного використання.
3. Порівняйте SHA-256 із `SHA256SUMS.txt` випуску.
4. Запустіть інсталяцію для встановлення для кожного користувача та стандартного видалення або помістіть портативний EXE у папку для запису та відкрийте його.

Портативний включає в себе середовище виконання та додатковий інсталятор. Інсталяція NVDriverForge не інсталює драйвер GPU. Його EXE наразі непідписані.

<a id="usage"></a>
## Використання

1. **Драйвер:** завантажте з NVIDIA або виберіть оригінальний EXE інсталятор NVIDIA. Нехай аналіз закінчиться.
2. **Компоненти:** перегляньте описи та необхідні залежності. Невідомі компоненти зберігаються.
3. **Налаштування:** залиште небажані параметри без змін. Прочитайте ефекти та компроміси, перш ніж щось вибрати.
4. **Огляд:** перевірте точний драйвер, компоненти та додаткові операції, а потім підтвердьте встановлення.
5. Приймайте UAC лише для вибраної вами операції. Зберігайте інструкції з відновлення захищеної роботи.
6. Якщо новий драйвер потребує перезавантаження, дотримуйтеся повідомленого стану. Відкладені операції вимагають явного відновлення після цього перезапуску.

Custom NV починається без змін. Виберіть індивідуальні іменовані значення або перегляньте наданий стиль і його виключення. Його два внутрішні інформаційні поля не записуються незалежно. Налаштування застосовуються лише в робочому процесі перевіреного нового драйвера, а не під час попереднього перегляду. Встановлювати окремий редактор NVPI не потрібно.

Додаткова робота NVENC завантажує сумісні дані із закріпленого коміту keylase. Він змінює дві бібліотеки DLL драйверів і робить їхні підписи недійсними; це може бути відхилено Windows, кодерами, DRM або античитом. Таких даних немає або DLL NVIDIA вбудовано в NVDriverForge. [Походження та межі ліцензування](../docs/provenance.md).

Параметри контролюють мову, тему та необов’язкові перевірки оновлень, встановлених користувачем. Портативний пристрій не створює встановлене завдання фонової перевірки. Інструменти та відновлення є окремими від чотирьох кроків інсталяції.

<a id="update-and-uninstall"></a>
## Оновіть і видаліть

Закрийте NVDriverForge, отримайте наступний офіційний пакет і перевірте його хеш. Використовуйте той самий ідентифікатор програми встановлення для встановленого оновлення; замініть закритий портативний EXE на новий. Зберігайте налаштування та захищені завдання.

Uninstall від Windows **Installed apps**. Він видаляє програму та її завдання оновлення, а не драйвер NVIDIA. Налаштування, журнали та резервні копії залишаються. За бажанням відновіть розширені/NVENC зміни за допомогою документованого процесу відновлення **перед** видаленням програми. Відновлення відхиляє конфліктні зміни з іншого інструменту.

Локальні дані під `%LOCALAPPDATA%\NVDriverForge`; захищені завдання та експорт драйверів підпадають під `%PROGRAMDATA%\NVDriverForge\Jobs`. Портативне використання також створює локальні дані. Експорт зі сховища драйверів не є системним образом або резервною копією повного профілю.

<a id="known-limitations"></a>
## Відомі обмеження

- Жодних апаратних доповнень/редагування INF, відновлених підписів NVIDIA, відмов від сумісності з античітом або автоматичного прийняття попереджень без підпису.
- Немає повного видалення телеметрії/реклами, експорту тонких пакетів або автоматичного повного відкату до попереднього драйвера.
- Інсталяція драйвера, відновлення завантаження та необов’язковий запис профілю не були повністю перевірені на реальних машинах під час аудиту концентратора.
- Перечитування реєстру не є доказом фактичного впливу HDCP, продуктивності чи затримки.
- Перевірка підпису використовує локально доступну довіру Windows; онлайн-відкликання не виконується.
- Присутні 34 мови, але повне тестування носіїв мови/доступності залишається незавершеним.

<a id="troubleshooting"></a>
## Усунення несправностей

| Симптом | Дія |
| --- | --- |
| Інтернет-каталог недоступний | Виберіть оригінальну упаковку з [Завантаження драйверів NVIDIA](https://www.nvidia.com/en-us/drivers/). Не замінюйте сусідню модель GPU. |
| Пошук виправлень недоступний | Використовуйте [Форум драйверів NVIDIA Game Ready](https://www.nvidia.com/en-us/geforce/forums/game-ready-drivers/13/) і перевірте фактичний пакет. |
| Помилка встановлення NVIDIA | Прочитайте зведення про помилки та відкрийте детальні журнали. У 0.1.3 додаткові компоненти, які вже діють або не застосовуються, можна пропустити. Невдала інсталяція не викликає додаткових налаштувань або успішного/перезапуску. |
| Помилка підпису/хешування/резервного копіювання | Зупиніть установку та збережіть помилку; отримати оригінальний пакет знову, якщо він пошкоджений. |
| Опція недоступна | Прочитайте причину апаратного забезпечення, компонента чи цільового драйвера; залишити його без змін. |
| Перезапуск або завдання все ще очікує | Використовуйте інструкції з відновлення роботи та чітке резюме; не стирайте його щоденник. |
| Відновити конфлікт | Інший стан відрізняється від зареєстрованої транзакції. Збережіть його та попросіть допомоги замість примусового відновлення. |

Для звітів додайте вибрану версію інструменту, Windows, GPU, драйвер і відтворювані кроки; редагувати шляхи та особисті дані з журналів. [Підтримка](../docs/support.md).

<a id="faq"></a>
## FAQ

**Чи встановлює програма встановлення графічний драйвер?** Ні. Для цього потрібен окремий процес аналізу, перегляду, підтвердження та інсталяції програми з підвищеними правами.

**Чи потрібен мені NVCleanstall чи NVPI?** Ні. NVCleanstall є лише джерелом натхнення. Супутник Profile Inspector є незалежним додатковим редактором.

**Чи робить кожен драйвер NVIDIA меншим або швидшим?** Ні. Вибрані компоненти та передумови визначають, що можна змінити; ніякого вимірюваного прибутку не обіцяють.

**Де джерела?** Спеціальне для програми джерело та приватні тести зберігаються окремо. Цей центр надає документацію, двійкові файли та посилання на сторонні джерела, необхідні для атрибуції/ліцензування.
