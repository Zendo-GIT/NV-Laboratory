# Descărcări

Alegeți un program și fie **Configurare**, fie **portabil**. Pagina de lansare a fiecărui instrument arată disponibilitatea curentă, data publicării și notele de lansare. Legăturile directe funcționează atunci când întreținătorul publică activele corespunzătoare. Sursa aplicației rămâne privată. Păstrați `Licenses-and-Credits.zip` și `SHA256SUMS.txt` cu descărcarea dvs. Butonul **Source code (zip)** al lui GitHub conține documentația hub-ului.

> **NVRasterPulse necesită RTSS.** Instalați [RivaTuner Statistics Server de la Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) separat și rulați-l pentru limitarea FPS.

## SHA-256

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\NVDriverForge.exe'
```

Înlocuiți numele cu fișierul descărcat și comparați întregul hash. O potrivire verifică identitatea cu manifestul. EXE-urile actuale sunt nesemnate.
