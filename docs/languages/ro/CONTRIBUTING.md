# Contribuind

NV Laboratory este întreținut de 禅堂 Zendo (RevoluSound Team). Menținătorul decide ce este acceptat și eliberat. Deschiderea unei probleme sau a unei cereri de tragere nu înseamnă că o contribuție este acceptată sau autorizată pentru distribuire.

Utilizați formularul de eroare sau caracteristică și identificați programul/versiunea. Căutați mai întâi problemele existente. Discutați schimbările substanțiale înainte de a pregăti o contribuție mare. Pentru probleme de securitate, urmați [SECURITY.md](SECURITY.md).

Acest hub public conține documentație, notificări, metadate de lansare și validare a depozitului. Sursa aplicației și testele sunt menținute în mod privat. Nu trimiteți cod decompilat, sursă privată, acreditări, profiluri de utilizator sau încărcături utile executabile.

PR-urile din documentație ar trebui să mențină aliniate cele 34 de limbi și navigarea, să păstreze numele comenzilor/fișierului/produsului și să descrie comportamentul real. Noile capturi de ecran trebuie să fie proprii, identificate în funcție de versiune și fără detalii personale; datele sintetice trebuie etichetate. Furnizați proveniența și permisiunea pentru fiecare nou activ terță parte.

Utilizați UTF-8, LF, Markdown lizibil și mici modificări concentrate. Validatorul Python utilizează numai biblioteca standard. Potriviți stilul său existent, evitați dependențele inutile și rulați:

```text
python tools/validate_repository.py
```

Pentru modificările metadatelor versiunii, includeți versiunea/eticheta exactă, dimensiunile fișierelor și SHA-256 din binarele auditate și mențineți paginile de descărcare aliniate. Modificările aplicației necesită o construcție/testări private adecvate comportamentului afectat; o verificare a documentației nu este un test de aplicație. Nu inventați niciodată rezultate sau câștiguri istorice ale testelor.

Contribuind cu material original hub, sunteți de acord cu licența MIT în domeniul său de aplicare în [LICENȚĂ](../../../LICENSE). Păstrați notificările terților și identificați modificările dvs.; nu înlocuiți o licență din amonte. Acceptarea și publicarea rămân decizii de întreținere.
