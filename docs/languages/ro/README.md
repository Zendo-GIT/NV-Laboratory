# NV Laboratory

**NV Tools de la 禅堂 Zendo (RevoluSound Team).** Patru utilitare independente Windows pentru profiluri de driver NVIDIA, instalare driver, limite experimentale Multi Frame Generation și RTSS.

[Ia instrumentele](docs/downloads.md) · [Instalare](docs/installation.md) · [Compatibilitate și ajutor](docs/support.md) · [Credite și licențe](THIRD_PARTY_NOTICES.md)

> **NVRasterPulse necesită RTSS.** Instalați mai întâi [RivaTuner Statistics Server de la Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/). RTSS trebuie să ruleze pentru ca limitele FPS să funcționeze. Se descarcă separat.

<a id="start-here"></a>
## Începeți de aici

1. Alegeți un instrument de mai sus. Fiecare lucrează independent; instalarea întregii suite nu este necesară.
2. Citiți cerințele și alegeți **Configurare** pentru o aplicație instalată sau **portabilă** pentru un dosar separat.
3. Când Lansarea sa este publicată, descărcați activul aplicației numite, citiți notificările însoțitoare și comparați SHA-256.
4. Păstrați copii de siguranță înainte de a schimba un driver, setarea de afișare, profilul NVIDIA sau timpul de rulare a jocului.

Documentația este disponibilă în aceleași 34 de limbi ca și aplicațiile NV prin selectorul din partea de sus a fiecărui ghid. GitHub nu selectează automat un README în funcție de limba browserului. Limba documentației și setarea propriei limbi a aplicației sunt separate.

<a id="provenance-and-ownership"></a>
## Proveniența și proprietatea

Acest hub distribuie documentație și aplicații compilate. Codul sursă al aplicației este păstrat în mod privat. Proiectele din amonte își păstrează autoritatea și licențele; distribuția sursă privată nu înlocuiește acești termeni.

- Profile Inspector fork păstrează licența MIT a lui Orbmu2k și este identificat în mod explicit ca fork.
- NVDriverForge are propriii termeni de distribuție binară și include componente de execuție/instrument cu licență separată.
- NVMFG Unlock40 este o aplicație dezvoltată independent. RTX40MFG-Unlock a fost consultat pentru comparare și rafinare; Componentele native partajate își păstrează creditele MIT. Termenii MinHook și NVIDIA SDK rămân separați.
- NVRasterPulse păstrează licența MIT furnizată și creditează interfața de utilizare derivată din Profile Inspector. RTSS este un program extern necesar.

Vedeți [tabel complet de componente](THIRD_PARTY_NOTICES.md), [proveniența dosarului și modificările](docs/provenance.md) și [domeniul de aplicare al licenței](../../../LICENSE).
