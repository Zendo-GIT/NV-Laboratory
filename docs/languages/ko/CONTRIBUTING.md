# 기여

NV Laboratory는 禅堂 Zendo (RevoluSound Team)에 의해 유지 관리됩니다. 관리자는 무엇이 승인되고 해제되는지 결정합니다. 이슈나 풀 요청을 열었다고 해서 기여가 승인되거나 배포 승인을 받은 것은 아닙니다.

버그 또는 기능 양식을 사용하고 프로그램/버전을 식별합니다. 기존 이슈를 먼저 검색하세요. 큰 기여를 준비하기 전에 실질적인 변화에 대해 논의하십시오. 보안 문제는 [SECURITY.md](SECURITY.md)를 따르세요.

이 공개 허브에는 문서, 공지, 릴리스 메타데이터 및 저장소 검증이 포함되어 있습니다. 애플리케이션 소스와 테스트는 비공개로 유지됩니다. 디컴파일된 코드, 비공개 소스, 자격 증명, 사용자 프로필 또는 실행 가능한 페이로드를 제출하지 마세요.

문서 PR은 34개 언어 대응 및 탐색 정렬을 유지하고 명령/파일/제품 이름을 유지하고 실제 동작을 설명해야 합니다. 새 스크린샷은 본인이 직접 제작하고 버전이 식별되어야 하며 개인 정보가 없어야 합니다. 합성 데이터에는 라벨이 지정되어야 합니다. 모든 새로운 제3자 자산에 대한 출처와 권한을 제공하세요.

UTF-8, LF, 읽을 수 있는 Markdown 및 작은 초점 변경을 사용하세요. Python 유효성 검사기는 표준 라이브러리만 사용합니다. 기존 스타일을 일치시키고 불필요한 종속성을 피하고 다음을 실행합니다.

```text
python tools/validate_repository.py
```

릴리스 메타데이터 변경 사항의 경우 감사된 바이너리의 정확한 버전/태그, 파일 크기 및 SHA-256를 포함하고 다운로드 페이지를 정렬하세요. 애플리케이션 변경에는 영향을 받는 동작에 적합한 비공개 빌드/테스트가 필요합니다. 문서 확인은 응용 프로그램 테스트가 아닙니다. 절대로 과거의 테스트 결과나 이득을 만들어내지 마십시오.

원본 허브 자료를 제공함으로써 귀하는 [라이센스](../../../LICENSE)의 범위가 지정된 MIT 라이선스에 동의하게 됩니다. 제3자 통지를 유지하고 변경 사항을 식별합니다. 업스트림 라이센스를 교체하지 마십시오. 수락 및 게시는 관리자의 결정으로 유지됩니다.
