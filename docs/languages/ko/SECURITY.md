# 보안

이 정책은 NV Tools 애플리케이션 패키지와 이 배포 허브에 적용됩니다. 관리자는 각 도구의 최신 게시 버전에 영향을 미치는 보고서의 우선순위를 정합니다. 준비된 후보는 발표된 지원 안정 릴리스가 아닙니다. 응답 기한이나 보안 인증은 약속되지 않습니다.

<a id="report-privately"></a>
## 비공개로 신고

취약점, 안전하지 않은 상승된 동작, 의도하지 않은 파괴적인 변경 또는 민감한 데이터 노출의 경우 리포지토리의 **보안 → Report a vulnerability** 기능 **활성화된 경우**: [비공개 보고서](https://github.com/Zendo-GIT/NV-Laboratory/security/advisories/new)를 사용하세요.

**초기 설정:** 관리자는 공개 저장소를 생성한 후 비공개 취약점 보고를 활성화해야 합니다. 이 파일은 이를 활성화하지 않으며 그 이전에는 사서함이나 개인 채널이 존재하지 않는다고 주장합니다.

버튼을 사용할 수 없는 경우 다음 내용만 포함된 공개 문제를 엽니다. "[도구/버전]에 관한 보안 보고서를 위한 비공개 연락 채널이 필요합니다." 익스플로잇 세부정보, 자격 증명, 영향을 받은 경로, 로그 또는 첨부 파일을 포함하지 마세요. 공유하기 전에 관리자가 비공개 채널을 제공할 때까지 기다리세요.

비공개 보고서에는 도구/버전 및 해시, Windows/GPU/드라이버 버전, 영향, 최소한의 안전 재생산 및 복구가 필요한지 여부가 포함됩니다. 비밀 및 개인 데이터를 수정합니다. 로컬 복구 파일을 보존합니다. 독점 드라이버나 게임 DLL을 업로드하지 마세요. 유지관리자와 공개를 조정합니다. 패치/릴리스에는 검토가 필요하며 자동으로 수행되지 않습니다.
