# 다운로드

프로그램을 선택하고 **설정** 또는 **휴대용**을 선택합니다. 각 도구의 릴리스 페이지에는 현재 가용성, 게시 날짜 및 릴리스 정보가 표시됩니다. 직접 링크는 관리자가 해당 자산을 게시할 때 작동합니다. 애플리케이션 소스는 비공개로 유지됩니다. 다운로드 시 `Licenses-and-Credits.zip` 및 `SHA256SUMS.txt`를 유지하세요. GitHub의 **Source code (zip)** 버튼에는 허브 문서가 포함되어 있습니다.

> **NVRasterPulse에는 RTSS가 필요합니다.** FPS 제한을 위해 [Guru3D의 RivaTuner Statistics Server](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/)를 별도로 설치하고 실행하세요.
