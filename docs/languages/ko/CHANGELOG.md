<a id="changelog"></a>
# 변경 내역

이 허브는 [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)를 따릅니다. 항목은 이 저장소를 설명합니다. 애플리케이션 버전은 독립적입니다.

<a id="unreleased"></a>
## [미공개]

<a id="added"></a>
### 추가됨

- 34개 NV 애플리케이션 언어로 된 허브, 전체 프로젝트 가이드 및 저장소 문서.
- 페이지 보존 언어 선택기, 번역 적용 범위 메타데이터 및 안정적인 내부 앵커.
- 업스트림 크레딧, 전체 적용 가능한 통지 및 파일 출처.
- RTSS 요구 사항 및 NVRasterPulse에 대한 공식 다운로드 링크입니다.
- RevoluSound Team 링크를 분리합니다.
- 첫 번째 릴리스 패키지 카탈로그, SHA-256 검증 및 수동 릴리스 절차를 준비했습니다.
- 버그/기능 양식, 기여 및 보안 지침.
- 읽기 전용 문서 및 출판 경계 확인.

<a id="changed"></a>
### 변경됨

- NVMFG 속성은 이제 독립적으로 개발된 애플리케이션을 구별합니다.
비교/세분화 참조 및 실제 공유 기본 구성 요소.   기존 저작권, 라이센스 및 파일 비교는 그대로 유지됩니다.
- NVDriverForge 후보가 0.1.3로 업데이트되었습니다. 선택적 구성 요소 처리가 수정되었습니다.
읽을 수 있는 현지화된 오류 및 업데이트된 런타임/동반자 패키징.

<a id="fixed"></a>
### 고정

- NVIDIA Profile Inspector – NV Tools Fork 설정 개정 2는 이제 공유 항목을 표시합니다.
직접 실행 시 34개 언어 선택기. 노골적인 언어와 자동 전달은 보존됩니다. 편집기와 이식 가능한 패키지는 변경되지 않았습니다.

과거 공개 출시 날짜는 재구성되지 않습니다. 후보 애플리케이션 버전은 3.0.2.3, 0.1.3, 0.1.1 및 0.1입니다. 해당 릴리스 노트는 향후 릴리스에 첨부되어 있습니다. 2026-09-09 준비는 GitHub 출시일이 아닙니다.
