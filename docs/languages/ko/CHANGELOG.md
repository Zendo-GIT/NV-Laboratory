<a id="changelog"></a>
# 변경 내역

이 허브는 [Keep a Changelog](https://keepachangelog.com/en/1.1.0/)를 따릅니다. 애플리케이션 버전과 출시 날짜는 독립적입니다. 아래 준비된 패키지는 해당 GitHub 릴리스에 대한 실제 게시 날짜를 받습니다.

<a id="unreleased"></a>
## [미공개]

<a id="changed"></a>
### 변경됨

- NVDriverForge 0.1.4에 대한 허브 및 34개 문서 언어를 모두 새로 고칩니다.
NVMFG Unlock40 0.2.3 및 NVRasterPulse 0.2, 2026-09-18에 준비되었습니다.
- NVDriverForge: 준비 상태 확인, 기본 프로필 백업 및 보호 복구,
구성 요소 지침, 재사용 가능한 기본 설정, 드라이버 키트, 세부 결과, 로컬 지원 보고서 및 별도의 애플리케이션 업데이트.
- NVMFG: 다중 폴더 검색, 영구 라이브러리 캐시, MFG 활동 관찰,
런타임 기능 정보, 다음 실행 제외, 로컬 진단, 기본 설정 전송 및 선택적 애플리케이션 업데이트.
- NVRasterPulse: 구성 진단, FPS 제안, 일시 중지/재개,
1단계 실행 취소, 선택적 프로필 가져오기/내보내기, 즐겨찾기 및 숨겨진 항목.
- 패키지 해시, 릴리스 노트 및 기본 구성 요소 출처 맵을 새로 고칩니다.
이미 게시된 Profile Inspector 3.0.2.3/setup-r2 자산을 변경하지 않고 유지합니다.

<a id="fixed"></a>
### 고정

- NVMFG 게임 선택/카운트, Ctrl+D 처리 및 완료된 진행 메시지;
Wallpaper Engine는 게임 감지에서 제외됩니다. 별도로 보고된 0.1.1 복원 막힘은 재현되지 않은 상태로 남아 있으며 수정되었다고 주장되지 않습니다.

<a id="initial-public-hub--2026-09-10"></a>
## [초기 공개 허브] – 2026-09-10

<a id="added"></a>
### 추가됨

- 34개 언어로 된 4개의 프로젝트 가이드 및 저장소 문서
페이지 보존 선택기, 안정적인 앵커 및 번역 적용 범위 메타데이터.
- 구성 요소 크레딧, 원본 라이선스, 출처, RTSS 요구 사항 및
별도의 RevoluSound Team 링크.
- 수동 릴리스 패키지, SHA-256 값, 문제 양식, 보안 정책 및
읽기 전용 문서 유효성 검사. 애플리케이션 소스는 비공개로 유지됩니다.
- 첫 번째 공개 태그: `nvpi-v3.0.2.3`, `nvdriverforge-v0.1.3`,
`nvmfg-unlock40-v0.1.1` 및 `nvrasterpulse-v0.1`.

<a id="included-fixes"></a>
### 포함된 수정 사항

- Profile Inspector 설치 프로그램 개정 2: 독립형 34개 언어 선택기;
편집기 및 휴대용 페이로드는 변경되지 않았습니다.
- NVDriverForge 0.1.3: 선택적 구성 요소 처리를 수정하고 현지화했습니다.
업데이트된 런타임 및 컴패니언 패키징이 포함된 실패 요약.

위의 날짜는 재구성된 개발 날짜가 아닌 확인된 공개 허브 기록입니다.
