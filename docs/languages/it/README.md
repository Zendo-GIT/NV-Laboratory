# NV Laboratory

**NV Tools di 禅堂 Zendo (RevoluSound Team).** Quattro utilità Windows indipendenti per profili driver NVIDIA, installazione driver, limiti frame sperimentali Multi Frame Generation e RTSS.

[Ottieni gli strumenti](docs/downloads.md) · [Installazione](docs/installation.md) · [Compatibilità e aiuto](docs/support.md) · [Crediti e licenze](THIRD_PARTY_NOTICES.md)

> **NVRasterPulse richiede RTSS.** Installare prima [RivaTuner Statistics Server di Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/). RTSS deve essere in esecuzione affinché i limiti FPS funzionino. Viene scaricato separatamente.

<a id="start-here"></a>
## Inizia qui

1. Scegli uno strumento sopra. Ciascuno funziona in modo indipendente; non è necessario installare l'intera suite.
2. Leggi i suoi requisiti e scegli **Configurazione** per un'app installata o **portatile** per una cartella separata.
3. Quando viene pubblicata la sua Release, scarica l'asset applicativo indicato, leggi gli avvisi di accompagnamento e confronta il suo SHA-256.
4. Conserva i backup prima di modificare un driver, un'impostazione dello schermo, un profilo NVIDIA o il runtime del gioco.

La documentazione è disponibile nelle stesse 34 lingue delle applicazioni NV tramite il selettore nella parte superiore di ciascuna guida. GitHub non seleziona automaticamente un README in base alla lingua del browser. La lingua della documentazione e l'impostazione della lingua dell'applicazione sono separate.

<a id="provenance-and-ownership"></a>
## Provenienza e proprietà

Questo hub distribuisce documentazione e applicazioni compilate. Il codice sorgente dell'applicazione viene mantenuto privatamente. I progetti upstream mantengono la paternità e le licenze; la distribuzione tramite fonte privata non sostituisce tali termini.

- Profile Inspector fork mantiene la licenza MIT di Orbmu2k ed è esplicitamente identificato come fork.
- NVDriverForge ha i propri termini di distribuzione binaria e include componenti runtime/strumento concessi in licenza separatamente.
- NVMFG Unlock40 è un'applicazione sviluppata in modo indipendente. RTX40MFG-Unlock è stato consultato per confronto e perfezionamento; i componenti nativi condivisi mantengono i propri crediti MIT. I termini MinHook e NVIDIA SDK rimangono separati.
- NVRasterPulse mantiene la licenza MIT fornita e accredita l'interfaccia utente derivata da Profile Inspector. RTSS è un programma esterno richiesto.

Vedere [tabella completa dei componenti](THIRD_PARTY_NOTICES.md), [provenienza e modifiche del file](docs/provenance.md) e [ambito della licenza](../../../LICENSE).
