## Obblighi e confini

**Componenti MIT:** conservano il copyright, il testo dell'autorizzazione e la dichiarazione di non responsabilità con le copie. La loro licenza non richiede la pubblicazione della fonte modificata. La paternità originale viene preservata anche quando l'origine dell'applicazione viene mantenuta privatamente.

**MinHook/HDE:** preserva gli avvisi, le condizioni e le esclusioni di responsabilità nella documentazione binaria. Viene fornito l'avviso combinato completo.

**7-Zip:** preserva gli avvisi LGPL/BSD/unRAR e fornisce l'accesso all'esatta fonte non modificata. L'archivio sorgente è collegato sopra, insieme al file LGPL completo. La restrizione unRAR si applica al relativo codice di decompressione; questa non è una dipendenza generale di MIT. Vedi [domande frequenti sulla distribuzione](https://www.7-zip.org/faq.html) dell'autore.

**Inno Setup:** preserva gli avvisi sul copyright/sito Web del motore richiesti e contrassegna le modifiche alla fonte ove applicabile. I crediti del motore non modificato rimangono negli installatori. I cataloghi adattati conservano gli avvisi sulle fonti originali; i nomi sono indicizzati qui.

**Materiale NVIDIA:** la licenza MIT per le intestazioni di integrazione Streamline non copre tutti i file SDK. Il suo avviso separa esplicitamente il materiale Nsight Perf SDK; quel materiale non è utilizzato in questo target di produzione. Le intestazioni NGX sono soggette ai termini proprietari RTX SDK di NVIDIA. È stato aggiunto il loro testo completo, con un [copia del byte originale](../../../NVMFG-Unlock40/LICENSES/NVIDIA-RTX-SDK.original.txt). La restrizione della Sezione 4(d) riguardante le limitazioni tecniche rimane irrisolta per l'utilizzo da parte di NVMFG. Non si deduce alcun permesso affermativo dall'esistenza di un altro mod.

**Componenti esterni sconosciuti/proprietari:** Driver, modelli e dati patch keylase RTSS, NVCleanstall, NVIDIA non sono raggruppati nelle risorse hub preparate. I collegamenti identificano i loro effettivi proprietari. Un download attivato dall'utente non concede una nuova licenza a un componente.

Gli strumenti utilizzano API e caratteri forniti da Windows. Nessun file Windows SDK/compiler/font viene copiato in questo repository Git. Gli strumenti di creazione e i test privati ​​sono esterni alla distribuzione. Gli avvisi sui componenti interni al runtime rimangono nel file di avvisi Microsoft completo anziché essere riassegnati all'editore.
