## SHA-256

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\NVDriverForge.exe'
```

Replace the name with your actual downloaded file and compare the entire hash. A match establishes identity with the manifest, not software safety. Current EXEs are unsigned.
