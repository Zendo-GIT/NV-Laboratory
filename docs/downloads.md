# Downloads

Choose a program and either **Setup** or **portable**. Each tool's Release page
shows current availability, publication date and release notes. Direct links work
when the maintainer publishes the corresponding assets. Application source remains private. Keep `Licenses-and-Credits.zip`
and `SHA256SUMS.txt` with your download. GitHub's **Source code (zip)** button
contains the hub documentation.

> **NVRasterPulse requires RTSS.** Install [RivaTuner Statistics Server from Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) separately and run it for FPS limiting.

## SHA-256

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\NVDriverForge.exe'
```

Replace the name with your downloaded file and compare the entire hash. A match verifies identity with the manifest. Current EXEs are unsigned.
