# Téléchargements

**Aucune Release GitHub n'est encore publiée.** Les liens de Release ci-dessous
sont des destinations prévues, pas des téléchargements déjà disponibles.
Les candidates ont été préparées le 2026-09-09 ; leurs sources applicatives restent privées.

Choisissez un seul programme et l'édition Setup ou portable. Une fois sa Release
publiée, prenez l'asset nommé ci-dessous, `Licenses-and-Credits.zip` et `SHA256SUMS.txt`.
Le bouton GitHub **Source code (zip)** ne contient pas les exécutables ni les sources privées.

> **NVRasterPulse nécessite RTSS :** [téléchargement officiel Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/).
> Installez RTSS séparément et lancez-le pour appliquer les limites.

## SHA-256

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\NVDriverForge.exe'
```

Remplacez le nom par le fichier effectivement téléchargé et comparez toute l'empreinte. Un hash concordant prouve l'identité avec le manifeste, pas la sûreté du programme. Les EXE actuels ne sont pas signés.
