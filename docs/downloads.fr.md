# Téléchargements

Choisissez un programme et son édition **Setup** ou **portable**. La page de
Release de chaque outil indique sa disponibilité actuelle, sa date et ses notes.
Les liens directs fonctionnent dès que le mainteneur publie les fichiers correspondants.
Les sources applicatives restent privées.
Gardez `Licenses-and-Credits.zip` et `SHA256SUMS.txt` avec le fichier choisi.
Le bouton GitHub **Source code (zip)** contient la documentation du hub.

> **NVRasterPulse nécessite RTSS.** Installez [RivaTuner Statistics Server depuis Guru3D](https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/) séparément et lancez-le pour appliquer les limites.

<a id="sha-256"></a>
## SHA-256

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\NVDriverForge.exe'
```

Remplacez le nom par le fichier téléchargé et comparez toute l’empreinte. Le hash vérifie la correspondance au manifeste. Les EXE actuels ne sont pas signés.
