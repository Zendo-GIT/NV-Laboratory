# Installer catalog notices

Original header notices from the 34 catalogs used for the installer family.
Sources: [Inno Setup](https://jrsoftware.org/isinfo.php) and its
[translation collection](https://jrsoftware.org/files/istrans/).
Contact addresses are omitted in this public credit index; original comments
are retained in the private build sources. This is a credit transcription,
not a redistribution of the application or translation source catalogs.
Catalogs were adapted for keys, IDs, fonts and English technical fallback.
Filipino, Punjabi and Swahili include project-authored preview wizard translations.
Application translations are separate. Version dates in the headers are historical.
